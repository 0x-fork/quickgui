`ui.SwiftUI` 组件族在 Go 应用中嵌入真正的 macOS 控件。普通 QuickGUI 组件无需依赖它。

## Host

在 `ui.SwiftUI.Host` 内创建控件。Host 定义原生视图边界，并可根据内容确定自身尺寸。

```go
func SwiftUiHostExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## 原生控件

可用控件包括 Button、Slider、Toggle、ProgressView、Stepper、TextField、SecureField、Picker、SegmentedControl、DatePicker、ColorPicker 和 Gauge。它们的原生外观由 macOS 提供。

## 受控值

绑定访问器，并保存原生回调返回的值。SwiftUI 控件与 QuickGUI 节点可以共享同一个信号。DatePicker 使用以毫秒表示的 Unix 时间戳。

```go
func SwiftUiToggleExample() {
	on, setOn := ui.CreateSignal(true)
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## 尺寸

`MatchContents: true` 让两个方向都使用固有尺寸。要保留固有高度并自定义宽度，可使用 `ui.SwiftUIMatchContents{Vertical: true}`，并在 `PartProps.Style` 设置宽度。

```go
ui.SwiftUIHostProps{
	MatchContents: ui.SwiftUIMatchContents{Vertical: true},
	PartProps:     ui.PartProps{Style: ui.Style().Width(320)},
}
```

## 平台支持

SwiftUI 托管需要 macOS。预编译原生宿主包含桥接层，Go 应用仍然无需 CGO。原生样式可能随操作系统版本变化。
