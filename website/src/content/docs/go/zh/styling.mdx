基础组件直接接收 `ui.Style{}` 样式记录、事件选项和子节点。复合部件通过 `ui.PartProps.Style` 接收相同的记录。

## `style` 属性

多个样式记录按顺序逐字段合并。后面的记录只覆盖自己声明的字段，嵌套的 `Hover`、`Active` 等交互样式也会合并，共享记录不会被修改。数字长度以逻辑像素为单位，字符串也接受百分比。零是显式值，`nil` 表示省略。运行 `bun run fmt` 可统一较长调用的格式。

```go
func Card() {
	ui.View(
		ui.Text(
			"Hello",
			ui.Style{Color: "#e2e8f0"},
		),
		ui.Style{Padding: 20, BorderRadius: 12, BackgroundColor: "#111827"},
	)
}
```

## 合并样式

内边距保持 20，圆角变为 12，选中时只改变背景色。嵌套状态也按相同规则合并。

```go
func MergedCard() {
	selected, _ := ui.CreateSignal(false)
	ui.View(
		"Merged styles",
		ui.Style{Padding: 20, BorderRadius: 8, BackgroundColor: "#111827"},
		ui.Style{BorderRadius: 12},
		ui.When(selected, ui.Style{BackgroundColor: "#2563eb"}),
	)
}
```

## Flexbox

设置 `Display: "flex"`，再选择方向、尺寸与对齐方式。可滚动的 flex 子节点通常需要 `MinHeight: 0` 或 `MinWidth: 0` 才能收缩。

```go
func Row() {
	ui.View(
		func() {
			ui.Text("Flexible content", ui.Style{Flex: 1, MinWidth: 0})
			ui.Button("Action", ui.Style{FlexShrink: 0})
		},
		ui.Style{Display: "flex", Gap: 12, AlignItems: "center"},
	)
}
```

## 网格布局

网格使用熟悉的轨道字符串；自动放置不足以满足需求时，可以明确指定子节点位置。

```go
func Grid() {
	ui.View(
		func() {
			ui.Text("Sidebar")
			ui.Text("Content")
		},
		ui.Style{Display: "grid", GridTemplateColumns: "220px 1fr", Gap: 16},
	)
}
```

## 文本与颜色

字体样式会沿节点树继承。颜色接受十六进制、`rgb()`/`rgba()` 或打包的 RGBA 值。传入颜色或数值访问器即可响应式更新绘制与尺寸。

## 交互状态

在基础样式中添加 `Transition`，即可为绘制状态之间的变化添加动画。悬停效果、信号驱动的变化、时长和减少动态效果的用法见[过渡与动画](/zh/docs/go/animations)。

使用 `Hover: &ui.Style{...}`、`Active`、`Focus`、`Disabled` 和 `Selected` 声明交互样式。`ui.When` 在条件为真时合并样式记录，变为假时恢复前面的字段。只更新受影响的绑定，子节点保持挂载。

```go
func SelectableButton() {
	selected, setSelected := ui.CreateSignal(false)
	ui.Button(
		"Toggle selection",
		ui.Style{BackgroundColor: "#e5e7eb"},
		ui.When(
			selected,
			ui.Style{
				BackgroundColor: "#2563eb",
				Color:           "white",
			},
		),
		ui.Style{Hover: &ui.Style{Opacity: 0.85}},
		ui.OnClick(func() { setSelected(!selected()) }),
	)
}
```

## 分组与具名分组悬停

`ui.Group(true)` 声明匿名悬停分组，`ui.Group("card")` 声明具名分组。后代的 `GroupHover: &ui.Style{...}` 跟随最近的祖先分组，包括具名分组。`ui.GroupHoverNamed("card", ...)` 则跳过其他分组，跟随最近的同名祖先。

```go
func GroupExample() {
	ui.View(
		func() {
			ui.Text(
				"Changes when the card is hovered",
				ui.Style{Color: "#64748b", GroupHover: &ui.Style{Color: "#2563eb"}},
			)
			ui.View(
				func() {
					ui.Text(
						"Follows the card and the nested toolbar",
						ui.GroupHoverNamed("card", ui.Style{Color: "#2563eb"}),
						ui.GroupHoverNamed("toolbar", ui.Style{Opacity: 0.8}),
					)
				},
				ui.Group("toolbar"),
			)
		},
		ui.Group("card"),
		ui.Style{Padding: 20},
	)
}
```

鼠标悬停在分组的任意区域（包括内边距和后代）都会启用对应规则。嵌套分组会成为匿名规则的目标，具名规则仍可跟随外层分组。没有匹配的祖先时，规则不生效。多条分组规则按声明顺序叠加；属性冲突时，节点自身的 `Hover` 优先。请使用颜色、透明度、轮廓和变换等绘制属性。悬停由原生层处理，不会重新运行组件或更改布局。


`GroupActive: &ui.Style{...}` 和 `ui.GroupActiveNamed("card", ui.Style{...})` 跟随分组的按下状态。`FocusWithin: &ui.Style{...}` 跟随节点或后代的焦点状态。这些状态接受绘制样式，不能设置光标。
