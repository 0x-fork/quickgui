扩展可以是可复用组件的 Go 包，也可以是 Go 包加上应用可调用的原生库。先从 Go 包开始。只有需要可选后端时才添加原生库，例如终端和[更新器](/docs/go/updater)包。

## 选择扩展类型

| 你要添加的内容 | 需要交付的内容 |
| --- | --- |
| 组件或应用逻辑 | 一个 Go 模块 |
| 原生服务或可选后端 | Go 包、清单，以及原生库 |
| 由原生数据驱动的界面 | 原生服务加上 Go 组件 |

使用者导入你的 Go 包。CLI 会找到清单并打包匹配的原生产物。

## 创建扩展项目

```sh
quickgui init-extension my-components --type go
quickgui init-extension my-service --type zig
quickgui init-extension my-service --type rust
```

`go` 是默认值，会生成可复用组件。`zig` 和 `rust` 会生成带类型化 Go 包装、清单和 npm 产物包的原生服务。每个模板都包含 `cmd/demo` 和 `quickgui.toml`：

```sh
cd my-service
bun run dev
```

用 `--module github.com/acme/my-service` 指定 Go 模块，用 `--npm-package @acme/extension-my-service` 指定产物包。Zig 模板需要 Zig 0.16.x。在本仓库中，在 CLI 发布前运行 `bun packages/cli/src/cli.ts init-extension`。

## 共享组件

从你自己的模块导出组件函数。这个包不需要原生清单。

```go
package notice

import "github.com/egoist/quickgui/go/ui"

func Notice(message func() string, styles ...ui.StyleBuilder) *ui.Element {
	return ui.Text(
		message(),
	).
		Padding(12).
		BackgroundColor("#eff6ff").
		TextColor("#1e40af").
		BorderRadius(8).
		Style(ui.Style().
			Merge(styles...))
}
```

用 Go 版本标签发布。使用者通过 `go get` 添加。导入 `terminal` 或 `updater` 仍会让应用选择这些原生包，因此把可选集成放在单独的包中。

## 组织原生扩展

[`native-extension` 示例](https://github.com/egoist/quickgui/tree/main/examples/native-extension) 把 Go 包和小型 C 库配对。它针对 [`quickgui_extension.h`](https://github.com/egoist/quickgui/blob/main/include/quickgui_extension.h) 构建。

```text
go.mod
echo/
  echo.go
  quickgui.extension.json
native/
  quickgui_extension.h
  echo.c
artifacts/
  package.json
  lib/darwin-arm64/libquickgui_acme_echo.dylib
build-extension.ts
```

C、C++、Rust 以及其他导出 C ABI 的语言都可以实现扩展。Rust 扩展可以内置 [`extension_api.rs`](https://github.com/egoist/quickgui/blob/main/src/extension_api.rs)，并构建 `cdylib`，无需链接 QuickGUI 本身。

## 声明依赖

把这份清单放在**被导入的 Go 包源码旁边**：

```json
{
  "schema": 1,
  "name": "acme-echo",
  "abi": 1,
  "package": "@acme/extension-echo",
  "version": "1.0.0",
  "library": "quickgui_acme_echo"
}
```

名称以小写字母开头，最多包含 64 个小写字母、数字或连字符。`host` 是保留名。library 字段是 `quickgui_` 加上把连字符替换为下划线后的名称。

Go 包记录该要求并暴露类型化调用：

```go
package echo

import (
	"encoding/json"

	"github.com/egoist/quickgui/go/host"
	"github.com/egoist/quickgui/go/native"
)

func init() {
	host.RequireExtension("acme-echo", "1.0.0")
}

func Send(message string, done func(string, error)) {
	native.InvokeExtension("acme-echo", "echo", message, func(raw string, err error) {
		var reply string
		if err == nil {
			err = json.Unmarshal([]byte(raw), &reply)
		}
		done(reply, err)
	})
}
```

在 `native.Run` 就绪之后再调用操作。持久服务用 `native.OpenExtension(name, options, changed, ready)` 返回会话。所有者销毁时，在 UI 协程上关闭它。

CLI 通过 `go list -deps` 发现清单。清单和 `RequireExtension` 都需要：一个控制打包，另一个控制加载。

## 实现原生接口

导出带 C 链接的 `quickgui_extension_v1`。它返回描述符，包含名称、版本、ABI 版本 `1`，以及含两个函数（`invoke` 和 `shutdown`）的表。在保留借用的请求字节之前先复制它们，尽快返回，稍后再回复。

| 请求 | 扩展要做的事 |
| --- | --- |
| 像 `echo` 这样的一次性方法 | 回复一次 |
| `start` | 打开会话并保留其事件接收器 |
| 像 `send` 这样的命令 | 找到该会话并回复此命令 |
| `stop` | 取消该会话 |
| `shutdown` | 取消所有会话且不阻塞 |

请求和回复载荷各自限制为 64 KiB。[C echo 实现](https://github.com/egoist/quickgui/blob/main/examples/native-extension/backend/echo.c) 是完整的一次性示例。

## 自动注册

应用在启动时加载每个选定的库，并检查名称、版本和 ABI。同一名称的冲突版本会失败。镜像在进程生命周期内保持加载；你的 shutdown 函数必须取消剩余会话。

## 构建与打包产物

为每个支持的宿主构建原生库，并放到 `artifacts/lib/<platform>-<arch>/` 下。把该文件夹作为 npm 包发布，其 `version` 与清单一致。

```json
{
  "name": "@acme/extension-echo",
  "version": "1.0.0",
  "files": ["lib", "README.md"],
  "exports": { "./package.json": "./package.json" }
}
```

辅助文件放在库旁边。在清单的 `resources` 对象中按 `darwin`、`linux` 或 `windows` 声明它们的基本名称。

## 测试与分发

使用者 `go get` 你的模块并运行 `quickgui dev`。CLI 会获取匹配的 npm 包；开发时也可以把 `QUICKGUI_EXTENSION_DIR` 设为本地产物目录。

确认未导入的应用不会打包该扩展，添加导入后会包含它，关闭会话会停止事件。最终用户拿到的是打包后的应用；运行不需要 Bun 或原生工具链。
