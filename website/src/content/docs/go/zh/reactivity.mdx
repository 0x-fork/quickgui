信号将状态连接到读取它的文本和属性。更新只改变保留的节点，不会重新执行整个组件。

## 响应式状态

动态文本或属性应传入访问器。在构造字符串时调用 `count()` 只会捕获当前值；放入 `func() string` 才会保持响应式。事件处理器会自动批处理写入；其他位置可用 `ui.Batch` 合并写入，用 `ui.CreateMemo` 创建派生值。

字符串和数字信号可以直接作为子节点：`ui.Text("Count: ", count)`。前缀会保留，只有数字文本会更新。数字绑定使用 `strconv`，无需解析格式字符串。需要单个字符串的属性可以在访问器中使用 `strconv.Itoa(count())` 和字符串拼接。

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			"Count: ",
			count,
			ui.FontSize(20),
		)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

## 派生状态

使用 `ui.CreateMemo` 计算依赖其他信号的值。它返回访问器，使用方可以像订阅普通信号一样订阅派生值。

```go
func DerivedExample() {
	count, setCount := ui.CreateSignal(0)
	doubled := ui.CreateMemo(func() int { return count() * 2 })
	ui.View(func() {
		ui.Text("Doubled: ", doubled)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

## 副作用与清理

使用 `ui.CreateEffect` 将副作用与它读取的信号同步。每次运行都会根据实际读取追踪依赖，包括条件分支。通过 `ui.OnCleanup` 注册清理逻辑；释放所属组件时会移除副作用和订阅。动态文本和属性应直接绑定，不要在副作用中重建视图。

副作用适合视图树之外的工作，例如同步订阅或更新原生窗口标题。它会在初次创建时运行，并在读取过的值变化后再次运行。在副作用中注册的清理会在下次执行之前以及所属作用域销毁时运行。下面用日志展示生命周期；实际应用中可替换为订阅的启动和停止操作。每次执行时保存当前主题，让清理操作引用旧主题。

```go
func EffectExample() {
	topic, setTopic := ui.CreateSignal("Inbox")
	ui.CreateEffect(func() {
		current := topic()
		log.Print("Subscribe: ", current)
		ui.OnCleanup(func() { log.Print("Unsubscribe: ", current) })
	})
	ui.View(func() {
		ui.Text("Watching: ", topic)
		ui.Button(
			"Switch topic",
			ui.OnClick(func() {
				if topic() == "Inbox" {
					setTopic("Archive")
				} else {
					setTopic("Inbox")
				}
			}),
		)
	})
}
```

## 批量更新

事件处理函数会自动批处理信号写入。在其他位置使用 `ui.Batch(func() { ... })` 合并相关写入，让依赖工作一起刷新。`ui.Untrack` 可在不订阅当前计算的情况下读取状态。信号应在 UI goroutine 上访问；使用 `ui.Async` 或 `native.Dispatch` 传回后台结果。

这里将两个字段作为一次更新修改。观察者会在批处理结束后读到 “Grace Hopper”，不会读到中间的 “Grace Lovelace”。按钮事件本身已经自动批处理；显式批处理让其他 UI 代码调用 `applyProfile` 时也具有相同语义。批处理是同步的：后台任务应先把结果派发回 UI 线程，再写入信号。日志示例使用 Go 标准库的 `log` 包。

```go
func BatchedExample() {
	first, setFirst := ui.CreateSignal("Ada")
	last, setLast := ui.CreateSignal("Lovelace")
	ui.CreateEffect(func() { log.Print(first() + " " + last()) })
	applyProfile := func() {
		ui.Batch(func() {
			setFirst("Grace")
			setLast("Hopper")
		})
	}
	ui.View(func() {
		ui.Text(first, " ", last)
		ui.Button("Apply profile", ui.OnClick(applyProfile))
	})
}
```
