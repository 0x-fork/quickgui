使用 `ui.Transition(...)` 为保留节点的变化添加动画。原生运行时推进动画帧，组件不会逐帧重新执行。从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

## 悬停过渡

将过渡放在基础样式上，让指针移入和移出时都生效。同一声明也适用于 `Active`、`Focus`、`Expanded`、`DragOver` 等绘制状态。

```go
func HoverAction() {
	ui.Button(
		"Continue",
		ui.Padding(12),
		ui.BorderRadius(8),
		ui.BackgroundColor("#334155"),
		ui.Color("white"),
		ui.Opacity(0.85),
		ui.Transition("background-color 160ms ease-out, opacity 160ms ease-out"),
		ui.Hover(ui.BackgroundColor("#2563eb"), ui.Opacity(1)),
	)
}
```

## 状态驱动的动画

通过信号或 `ui.When` 改变目标值。下面的卡片在颜色和透明度变化时保留同一个节点及其子节点。

```go
func AnimatedSelection() {
	selected, setSelected := ui.CreateSignal(false)
	ui.View(
		func() {
			ui.Button("Toggle emphasis", ui.OnClick(func() { setSelected(!selected()) }))
			ui.View(
				"Your selection",
				ui.Padding(20),
				ui.BorderRadius(12),
				ui.BackgroundColor("#334155"),
				ui.Color("white"),
				ui.Opacity(0.6),
				ui.Transition("background-color 180ms ease-out, opacity 180ms ease-out"),
				ui.When(selected, ui.BackgroundColor("#2563eb"), ui.Opacity(1)),
			)
		},
		ui.Display("flex"),
		ui.FlexDirection("column"),
		ui.Gap(12),
	)
}
```

过渡尚未结束时再次改变目标，会从当前显示的值继续，包括反向过渡。

## 时长与帧率

多个属性共用一组时间设置时，使用 `ui.TransitionDeclaration`。此示例的时长需要导入 `time`。

```go
func CappedTransition() {
	ui.Button(
		"Hover me",
		ui.Padding(12),
		ui.BackgroundColor("#334155"),
		ui.Color("white"),
		ui.Opacity(0.8),
		ui.Transition(ui.TransitionDeclaration{
			Properties: []string{"background-color", "opacity"},
			Duration:   180 * time.Millisecond,
			Easing:     "ease-out",
			MaxFps:     30,
		}),
		ui.Hover(ui.BackgroundColor("#2563eb"), ui.Opacity(1)),
	)
}
```

将独立的过渡选项直接传给基础组件：

| 字段 | 用法 |
| --- | --- |
| `ui.TransitionProperty(...)` | 以逗号分隔的字符串，或由支持的属性名组成的 `[]string`。 |
| `ui.TransitionDuration(...)` | 毫秒数、`time.Duration`，或 `"180ms"`、`"0.18s"` 等字符串。宿主将时长限制在 0–10 秒。 |
| `ui.TransitionEasing(...)` | `"linear"`、`"ease"`、`"ease-in"`、`"ease-out"` 或 `"ease-in-out"`。`"ease"` 是默认值 `"ease-in-out"` 的别名，使用 QuickGUI 的缓动曲线。 |
| `ui.TransitionTimingFunction(...)` | `ui.TransitionEasing(...)` 的别名。 |
| `ui.TransitionMaxFps(...)` | 可选的帧率上限。不指定时跟随显示呈现；即使限帧，也会在过渡截止时间完成。 |

同一个节点的所有过渡属性共用时长、缓动和帧率上限。逗号分隔的简写会收集属性名，最后出现的时长和缓动应用于整个列表。不支持延迟、`cubic-bezier()` 或逐属性独立计时。独立字段会覆盖简写中的对应设置。

只提供时长，例如 `ui.Transition(180 * time.Millisecond)`，会过渡背景色、边框色和文字颜色。显式选择 `"all"` 才会包含所有支持的绘制属性。使用 `ui.Transition("none")` 移除简写声明。

## 支持的属性

| 过渡名称 | Go 样式选项 |
| --- | --- |
| `background-color` 或 `background` | `ui.BackgroundColor(...)` 或纯色 `ui.Background(...)` |
| `border-color` | `ui.BorderColor(...)` |
| `border-width` | `ui.BorderWidth(...)` 和各边宽度 |
| `border-radius` | `ui.BorderRadius(...)` 和各角半径 |
| `color` | 继承的 `ui.Color(...)` |
| `opacity` | 子树的 `ui.Opacity(...)` |
| `box-shadow` | `ui.BoxShadow(...)` |
| `transform` | 子树的 `ui.Transform(...)`，包括平移、缩放和旋转 |

`"all"` 指的是上表中的属性。`Transition` 不会插值渐变色标、宽高、内边距或其他布局值。不支持的过渡属性名会被拒绝。

要让开关滑块平滑移动，可设置 `ui.Transform("translateX(20px)")` 和 `ui.Transition("transform 160ms ease-out")`，取消选中时将目标改为 `"translateX(0px)"`。绘制子树及其命中区域会一起移动，不影响相邻元素的布局。变换会插值仿射矩阵的平移、缩放、斜切和最短路径旋转；`TransformOrigin` 本身会立即改变。

Go UI API 提供绘制属性过渡和动态图像。CSS 关键帧、时间线回调和弹簧声明不是 Go 样式属性。

## 挂载与减少动态效果

过渡用于已有节点的变化，初始样式会直接应用。改变目标时应保持节点挂载。`ui.Show` 在条件为 false 时立即移除子节点，不会等待淡出。仅将透明度设为零仍会保留布局和输入行为。

对话框的 `ui.DialogRootProps.EnterDuration`、`ExitDuration` 控制过渡完成时机与关闭内容的保留时间，`OnOpenChangeComplete` 报告完成。这些时长本身不会产生视觉样式。参见 [Dialog](/zh/docs/go/components/dialog)。

过渡遵循系统的“减少动态效果”偏好。`native.WindowOptions.ReduceMotion` 接受 `*bool` 以显式指定窗口策略；保持 nil 则跟随系统。启用后直接采用目标值。隐藏或被遮挡的窗口会暂停局部过渡，已完成的过渡不再请求帧。

## 动态图像

把动态 GIF 或 WebP 的路径传给 `ui.Image`。原生解码器保留帧和文件的循环策略，不需要 Go 定时器或逐帧更新信号。

```go
func AnimatedImage(path string) {
	ui.Image(
		ui.Value(path),
		ui.Width(96),
		ui.Height(96),
		ui.ObjectFit("contain"),
	)
}
```

路径必须指向可用文件，也可以使用 data URL。通过 CLI 的 `resources` 选项打包文件资源。参见 [Image](/zh/docs/go/components/image) 和[项目配置](/zh/docs/go/project-structure#配置)。
