Go の要素と `ui.Style()` は、`.P4()`、`.MxAuto()`、`.GridCols(3)`、`.RoundedLg()` などの fluent スタイルメソッドを共有します。コンストラクターには子要素を渡し、共通スタイルは `.Style(shared)` で適用します。

```go
ui.View(ui.Text("hello"), ui.Input().Value("xxx")).
	FlexCol().PaddingLeft(20).RoundedLg().TextAlign("center")
```

## スタイルメソッド

宣言は順番に適用され、同じプロパティは後の値が優先されます。明示的なゼロも上書きします。数値の長さは論理ピクセルで、文字列ではパーセントも使えます。

```go
func Card() {
	ui.View(ui.Text("Hello").TextColor("#e2e8f0")).
		Padding(20).BorderRadius(12).Bg("#111827")
}
```

## スタイルのマージ

`.Style(base).Style(overrides)` は宣言を順番にマージします。ビルダーの合成には `.Merge(...)` を使います。同じインタラクション状態のプロパティもマージされます。

```go
func MergedCard() {
	base := ui.Style().Padding(20).BorderRadius(8).Bg("#111827")
	overrides := ui.Style().BorderRadius(12)
	ui.View("Merged styles").Style(base).Style(overrides)
}
```

## スタイルの再利用

`ui.Style()` は `ui.StyleBuilder` を返します。各メソッドは新しい値を返し、共有スタイルを変更しません。派生スタイルを作るときは戻り値を代入してください。`.Style(...)` または複合パーツの `PartProps.Style` に渡します。パーツはビルダーのスライスや、それらを返すアクセサーも受け取れます。プロパティのアクセサーは各ノードで独立してバインドされます。

```go
func SharedCard() {
	card := ui.Style().Padding(20).BorderRadius(12)
	emphasized := card.PaddingLeft(28).Bg("#1e293b")
	ui.View("Hello").Style(card).Bg("#111827")
	ui.View("Another card").Style(emphasized)
}
```

ビルダーの `.When(condition, func(s ui.StyleBuilder) ui.StyleBuilder { ... })` は真偽値に応じてスタイルを派生します。リアクティブな条件には、要素の `.When(getter, style)` またはパーツのスタイルアクセサーを使います。プロパティには `.Width(width)` のように getter を渡してください。セットアップ時の `width()` は現在の値を取得するだけです。

## Flexbox

`.Flex()`、`.FlexRow()`、`.FlexCol()` で flex レイアウトを設定します。スクロールする子要素には `.MinHeight(0)` や `.MinWidth(0)` を指定して縮小できるようにします。

```go
func Row() {
	ui.View(
		ui.Text("Flexible content").Flex1().MinWidth(0),
		ui.Button("Action").FlexShrink(0),
	).Flex().Gap(12).ItemsCenter()
}
```

## グリッド

グリッドはトラック文字列を受け取ります。要素とスタイルビルダーで Rust と共通のレイアウトヘルパーを使えます。

```go
func Grid() {
	ui.View(ui.Text("Sidebar"), ui.Text("Content")).
		Display("grid").GridTemplateColumns("220px 1fr").Gap(16)
}
```

## テキストと色

文字のスタイルはノードツリーを通じて継承されます。色には16進数、`rgb()`/`rgba()`、パックした RGBA 値を使えます。子要素では異なるプロパティだけを上書きします。余白とボーダーは継承されません。

```go
func TypographyExample() {
	ui.View(
		ui.Text("Inbox").FontSize(24).FontWeight(600),
		ui.Text("All caught up."),
	).TextColor("#334155").FontSize(14).Padding(20)
}
```

## インタラクション状態

要素とスタイルビルダーの `.Hover(...)`、`.Active(...)`、`.FocusStyle(...)`、`.DisabledStyle(...)`、`.SelectedStyle(...)` はコールバックを受け取ります。状態はネイティブコアで処理されます。描画の変化をアニメーションにするには基底スタイルに `.Transition(...)` を指定します。[トランジションとアニメーション](/docs/go/animations)も参照してください。

```go
func SelectableButton() {
	selected, setSelected := ui.CreateSignal(false)
	button := ui.Style().Padding(12).Bg("#e5e7eb").
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.Opacity(0.85) })
	ui.Button("Toggle selection").Style(button).
		When(selected(), ui.Style().Bg("#2563eb").TextColor("white")).
		OnClick(func() { setSelected(!selected()) })
}
```

## グループと名前付きグループのホバー

`.Group(true)` は名前なしグループ、`.Group("card")` は名前付きグループを作ります。`.GroupHover(...)` は最も近い祖先グループに従い、`.GroupHoverNamed("card", ...)` はその名前を持つ最も近い祖先に従います。ルールは宣言順に追加され、重複するプロパティではノード自身のホバーが優先されます。

```go
func GroupExample() {
	ui.View(
		ui.Text("Changes when the card is hovered").
			TextColor("#64748b").
			GroupHoverNamed("card", func(s ui.StyleBuilder) ui.StyleBuilder {
				return s.TextColor("#2563eb")
			}),
	).Group("card").Padding(20)
}
```

`.GroupActive(...)` と `.GroupActiveNamed(...)` は押されたグループに従います。`.FocusWithin(...)` はノード自身や子孫のフォーカスに従います。これらは描画プロパティを受け取り、カーソルは設定できません。グループの余白や子孫へのホバーも、コンポーネントを再実行せずにルールを有効にします。
