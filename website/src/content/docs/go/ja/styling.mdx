プリミティブには `ui.Style{}` レコード、イベントオプション、子要素を直接渡せます。複合パーツも `ui.PartProps.Style` で同じレコードを受け取ります。

## `style` プロパティ

複数のスタイルレコードは宣言順にフィールド単位でマージされます。後のレコードは自分が指定したフィールドだけを上書きし、`Hover` や `Active` などの入れ子の状態もマージします。共有レコードは変更されません。数値の長さは論理ピクセルで、文字列ではパーセントも指定できます。ゼロは明示的な値、`nil` は省略です。`bun run fmt` で長い呼び出しを整形できます。

```go
func Card() {
	ui.View(
		ui.Text(
			"Hello",
			ui.Style{Color: "#e2e8f0"},
		),
		ui.Style{Padding: 20, BorderRadius: 12, BackgroundColor: "#111827"},
	)
}
```

## スタイルのマージ

余白は 20 のまま、角丸は 12 になり、選択状態では背景色だけが変わります。入れ子の状態にも同じマージ規則が適用されます。

```go
func MergedCard() {
	selected, _ := ui.CreateSignal(false)
	ui.View(
		"Merged styles",
		ui.Style{Padding: 20, BorderRadius: 8, BackgroundColor: "#111827"},
		ui.Style{BorderRadius: 12},
		ui.When(selected, ui.Style{BackgroundColor: "#2563eb"}),
	)
}
```

## Flexbox

`Display: "flex"` を指定し、方向、サイズ、配置を設定します。スクロールする flex の子には通常 `MinHeight: 0` または `MinWidth: 0` が必要です。

```go
func Row() {
	ui.View(
		func() {
			ui.Text("Flexible content", ui.Style{Flex: 1, MinWidth: 0})
			ui.Button("Action", ui.Style{FlexShrink: 0})
		},
		ui.Style{Display: "flex", Gap: 12, AlignItems: "center"},
	)
}
```

## グリッド

Grid では使い慣れたトラック文字列を使います。自動配置だけでは足りない場合は子の位置を明示できます。

```go
func Grid() {
	ui.View(
		func() {
			ui.Text("Sidebar")
			ui.Text("Content")
		},
		ui.Style{Display: "grid", GridTemplateColumns: "220px 1fr", Gap: 16},
	)
}
```

## テキストと色

文字スタイルはノードツリー内で継承されます。色は16進数、`rgb()`/`rgba()`、またはパックした RGBA 値を使えます。色や数値のアクセサーを渡すと描画やサイズがリアクティブに変わります。

## インタラクション状態

基本スタイルに `Transition` を指定すると、描画状態の変化をアニメーション化できます。ホバー効果、シグナルによる変更、時間設定、視差効果の抑制については[トランジションとアニメーション](/ja/docs/go/animations)を参照してください。

インタラクションのスタイルには `Hover: &ui.Style{...}`、`Active`、`Focus`、`Disabled`、`Selected` を使います。`ui.When` は条件が真の間レコードをマージし、偽になると以前のフィールドを復元します。影響するバインディングだけが更新され、子要素はマウントされたままです。

```go
func SelectableButton() {
	selected, setSelected := ui.CreateSignal(false)
	ui.Button(
		"Toggle selection",
		ui.Style{BackgroundColor: "#e5e7eb"},
		ui.When(
			selected,
			ui.Style{
				BackgroundColor: "#2563eb",
				Color:           "white",
			},
		),
		ui.Style{Hover: &ui.Style{Opacity: 0.85}},
		ui.OnClick(func() { setSelected(!selected()) }),
	)
}
```

## グループと名前付きグループのホバー

`ui.Group(true)` は名前なしのホバーグループ、`ui.Group("card")` は名前付きグループを作ります。子孫の `GroupHover: &ui.Style{...}` は、名前の有無にかかわらず最も近い祖先グループを参照します。`ui.GroupHoverNamed("card", ...)` は、別名のグループを飛び越えて同名の最も近い祖先を参照します。

```go
func GroupExample() {
	ui.View(
		func() {
			ui.Text(
				"Changes when the card is hovered",
				ui.Style{Color: "#64748b", GroupHover: &ui.Style{Color: "#2563eb"}},
			)
			ui.View(
				func() {
					ui.Text(
						"Follows the card and the nested toolbar",
						ui.GroupHoverNamed("card", ui.Style{Color: "#2563eb"}),
						ui.GroupHoverNamed("toolbar", ui.Style{Opacity: 0.8}),
					)
				},
				ui.Group("toolbar"),
			)
		},
		ui.Group("card"),
		ui.Style{Padding: 20},
	)
}
```

グループの余白や子孫を含む領域にポインターが入ると、そのルールが有効になります。名前なしのルールは入れ子のグループを参照し、名前付きのルールは外側のグループも参照できます。一致する祖先がなければ効果はありません。複数のグループルールは宣言順に適用され、同じプロパティには要素自身の `Hover` が優先されます。色、不透明度、アウトライン、変形などの描画プロパティを使ってください。ネイティブ側が処理するため、コンポーネントの再実行やレイアウト変更は発生しません。


`GroupActive: &ui.Style{...}` と `ui.GroupActiveNamed("card", ui.Style{...})` はグループの押下状態を参照します。`FocusWithin: &ui.Style{...}` はノード自身または子孫のフォーカスを参照します。これらの状態では描画スタイルを指定でき、カーソルは指定できません。
