フィールド値をシグナルで保持し、コールバックで受け入れた変更を書き戻します。

## テキスト入力

`ui.Input` と `ui.TextArea` はネイティブテキストエディターをホストします。`ui.Value` にアクセサーを渡し、`OnInput` で `event.Value` から更新します。単一行入力での Return は `OnSubmit` が処理します。

```go
func InputExample() *ui.Element {
	value, setValue := ui.CreateSignal("")
	return ui.Input().
		Value(value()).
		Placeholder("Write here").
		OnInputEvent(func(event *native.Event) { setValue(event.Value) }).
		Width(320).Height(32)
}
```

## フィールド

`Field.Root` はラベル、コントロール、説明、エラーを関連付けます。アプリ状態から `Required`、`Invalid`、`ValidationMessage` を設定します。`ValidationMode` と `ValidationDebounceTime` は検証要求のタイミングを設定し、検証ルールはアプリが定義します。

```go
func FieldExample() *native.Node {
	email, setEmail := ui.CreateSignal("")
	return ui.Field.Root(
		ui.FieldRootProps{
			Required: true,
			Filled:   func() bool { return email() != "" },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Field.Label(ui.FieldLabelProps{}, "Email"),
				ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{
					Value:       email,
					Placeholder: "you@example.com",
					OnInput:     func(event *native.Event) { setEmail(event.Value) },
				}}),
				ui.Field.Description(ui.PartProps{}, "Used for receipts"),
				ui.Field.Error(ui.PartProps{}, "Enter a valid email address")})
		},
	)
}
```

## 選択コントロール

チェックボックスは `ui.CheckedState` を通して `bool` または `ui.CheckedIndeterminate` を受け取ります。ラジオグループは一つの値を、チェックボックスやトグルのグループは複数の値を保持できます。読み取り専用と無効状態は別の意味を持ちます。

```go
func CheckboxGroupExample() *native.Node {
	values, setValues := ui.CreateSignal([]string{"email"})
	return ui.CheckboxGroup.Root(
		ui.CheckboxGroupProps{
			AllValues:     []string{"email", "push"},
			Value:         values,
			OnValueChange: func(next []string, _ *native.Event) { setValues(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Checkbox.Root(ui.CheckboxProps{Parent: true}, "All notifications"),
				ui.Checkbox.Root(ui.CheckboxProps{Value: "email"}, "Email"),
				ui.Checkbox.Root(ui.CheckboxProps{Value: "push"}, "Push")})
		},
	)
}
```

## Select

`PickerSourceProps.Items` で選択肢を宣言します。Select は選択値、Combobox はテキスト検索と選択、Autocomplete は自由入力を扱います。複数選択には `Values` と `OnValuesChange` を使います。

```go
func SelectExample() *native.Node {
	value, setValue := ui.CreateSignal[*string](nil)
	return ui.Select.Root(
		ui.SelectRootProps{
			PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
				return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
			}},
			Value:         value,
			OnValueChange: func(next *string, _ *native.Event) { setValue(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Select.Value(ui.PartProps{}), ui.Select.Icon(ui.PartProps{}, "▾")})
		},
	)
}
```

## イベント

通常のボタンには `ui.OnClick(func() { ... })` を渡します。`*native.Event` が必要な場合は `ui.OnClickEvent` を使います。複合コントロールのコールバックは型付きの値と、必要に応じてネイティブイベントを受け取ります。UI 状態は UI goroutine で更新し、バックグラウンド処理には `ui.Async` を使います。
