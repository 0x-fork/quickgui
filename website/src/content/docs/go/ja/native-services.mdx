`main` から `native.Run` を一度呼びます。起動コールバックでウィンドウを作成し、アプリのサービスを登録します。ネイティブの完了コールバックと UI 状態の変更は Go の UI goroutine で実行します。

## ウィンドウのライフタイム

`native.NewWindow(native.WindowOptions{Component: App})` は独立した所有者と保持ツリーを持つウィンドウを作成します。閉じるとバインディング、リスナー、コンポーネントのクリーンアップを破棄します。後の処理で必要なウィンドウは構築中やイベント処理中に `native.CurrentWindow()` で取得します。

## コマンドとサービス

ダイアログ、クリップボード、シェル、外観、メニューなどには型付きの `native` API を使います。結果を返す操作は完了コールバックを使い、UI goroutine をブロックせずにエラーを処理します。独立したプロバイダーには `native.InvokeExtension` と `native.OpenExtension` を使います。

バックグラウンド処理にはコンポーネントと一緒にキャンセルされる `ui.Async`、または結果を UI goroutine に戻す `native.Dispatch` を使います。シグナルの読み書きは UI 側で行います。サービスの所有関係は[拡張の作成](/docs/go/extensions)を参照してください。

## イベントとファイル監視

`native.WatchFiles(paths, changed, ready)` は OS のファイル通知を使い、停止関数を返します。コンポーネントのリソースは `ui.OnCleanup` で解放し、アプリ全体のリスナーには停止関数を保持します。ネイティブイベントや watcher がある場合はポーリングを避けます。拡張セッションを閉じるとイベントも停止します。
