QuickGUI プロジェクトではアプリコードを Go モジュールに置き、小さな Bun パッケージで開発コマンドを提供します。

## 生成されるファイル

CLI は次のファイルを生成します。依存関係を解決したら `go.sum` もコミットします。

```text
my-app/
├── main.go
├── go.mod
├── go.sum
├── quickgui.config.ts
├── package.json
└── README.md
```

## アプリケーションのエントリ

`main.go` で `native.Run` を開始し、ウィンドウを作成します。コンポーネントと子要素ブロックは同じ `func()` を使い、ノードを返さずに子を順番に宣言します。大きなアプリは通常の Go パッケージに分割できます。

```go
func ViewExample() {
	ui.View(
		func() {
			ui.Text("Hello from Go")
			ui.Button("Continue", ui.OnClick(func() {}))
		},
		ui.Padding(20),
		ui.Gap(12),
	)
}
```

## 設定

`entry` はビルドする Go パッケージです。設定ファイルは Bun CLI が評価し、実行中のアプリには含まれません。

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
});
```

同じ設定を `quickgui.toml` に書くこともできます。

```toml
name = "My App"
identifier = "com.example.my-app"
entry = "."

[native]
tags = ["production"]
```

CLI は `quickgui.toml`、`quickgui.config.ts` の順に探します。`quickgui dev --config configs/dev.toml` や `quickgui build --config configs/release.toml` でファイルを明示できます。相対パスはプロジェクトディレクトリが基準となり、`dev` は設定の変更も再読み込みします。バージョンは `version = "0.1.0"` のように文字列で指定し、アプリ全体の設定は `[native]` テーブルより前に置きます。

## パッケージ

ウィンドウとプラットフォームサービスには `github.com/egoist/quickgui/go/native`、UI には `github.com/egoist/quickgui/go/ui`、所有者とコンテキストには `github.com/egoist/quickgui/go/reactive` を使います。`@quickgui/cli` は開発依存です。Go SDK と CLI は互換性のあるリリースに固定してください。

コンポーネントの共有やオプションのネイティブバックエンドの作成については、[拡張の作成](/docs/go/extensions)を参照してください。
