シグナルは状態を、それを読むテキストやプロパティに結び付けます。更新時は保持されたノードだけを変更し、コンポーネント全体を再実行しません。

## リアクティブな状態

変化するテキストやプロパティにはアクセサーを渡します。文字列の構築時に `count()` を呼ぶと現在値だけを取得しますが、`func() string` 内ならリアクティブになります。イベント内の更新は自動的にバッチ処理されます。それ以外では `ui.Batch`、派生値には `ui.CreateMemo` を使います。

文字列や数値のシグナルは `ui.Text("Count: ", count)` のように子要素へ直接渡せます。接頭辞は保持され、数値のテキストだけが更新されます。数値の変換には `strconv` を使います。単一の文字列が必要なプロパティでは、アクセサー内で `strconv.Itoa(count())` と文字列連結を使ってください。

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			"Count: ",
			count,
		).FontSize(20)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

## 派生状態

`ui.CreateMemo` で他のシグナルから値を計算します。アクセサーを返すため、通常のシグナルと同様に派生値を購読できます。

```go
func DerivedExample() {
	count, setCount := ui.CreateSignal(0)
	doubled := ui.CreateMemo(func() int { return count() * 2 })
	ui.View(func() {
		ui.Text("Doubled: ", doubled)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

## 副作用とクリーンアップ

`ui.CreateEffect` は副作用を読み取ったシグナルと同期します。条件分岐を含め、各実行で実際に読んだ依存を追跡します。後始末は `ui.OnCleanup` に登録します。所有するコンポーネントを破棄すると副作用と購読も解除されます。動的なテキストやプロパティは直接バインドし、副作用でビューを再構築しないでください。

エフェクトは、購読の同期やネイティブウィンドウのタイトル更新など、ビューの外部と連携する処理に使います。初回と、読み取った値が変わったときに実行されます。エフェクト内で登録したクリーンアップは、次の実行前と所有スコープの破棄時に呼ばれます。以下ではログでライフサイクルを示します。実際の購読では開始・停止処理に置き換えてください。実行ごとのトピックを保存すると、古いトピックを正しく解除できます。

```go
func EffectExample() {
	topic, setTopic := ui.CreateSignal("Inbox")
	ui.CreateEffect(func() {
		current := topic()
		log.Print("Subscribe: ", current)
		ui.OnCleanup(func() { log.Print("Unsubscribe: ", current) })
	})
	ui.View(func() {
		ui.Text("Watching: ", topic)
		ui.Button(
			"Switch topic",
			ui.OnClick(func() {
				if topic() == "Inbox" {
					setTopic("Archive")
				} else {
					setTopic("Inbox")
				}
			}),
		)
	})
}
```

## 更新のバッチ処理

イベントハンドラー内の書き込みは自動的にまとめられます。それ以外では `ui.Batch(func() { ... })` で関連する更新をまとめます。`ui.Untrack` は現在の計算を購読させずに状態を読みます。シグナルは UI goroutine で操作し、バックグラウンドの結果は `ui.Async` や `native.Dispatch` で戻してください。

ここでは2つのフィールドをまとめて更新します。購読側はバッチ終了後に “Grace Hopper” を受け取り、途中の “Grace Lovelace” は受け取りません。ボタンのイベントは自動でバッチ化されますが、明示的なバッチにより他の UI コードから `applyProfile` を呼んでも同じ動作になります。バッチは同期処理です。バックグラウンド処理の結果は UI スレッドに戻してからシグナルに書き込んでください。ログの例では Go 標準の `log` パッケージを使います。

```go
func BatchedExample() {
	first, setFirst := ui.CreateSignal("Ada")
	last, setLast := ui.CreateSignal("Lovelace")
	ui.CreateEffect(func() { log.Print(first() + " " + last()) })
	applyProfile := func() {
		ui.Batch(func() {
			setFirst("Grace")
			setLast("Hopper")
		})
	}
	ui.View(func() {
		ui.Text(first, " ", last)
		ui.Button("Apply profile", ui.OnClick(applyProfile))
	})
}
```
