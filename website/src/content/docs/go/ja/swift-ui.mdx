`ui.SwiftUI` は Go アプリに本物の macOS コントロールを埋め込みます。通常の QuickGUI コンポーネントはこれを使わずに動作します。

## Host

コントロールは `ui.SwiftUI.Host` の中で作成します。Host はネイティブビューの境界を定義し、内容に応じてサイズを決められます。

```go
func SwiftUiHostExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## ネイティブコントロール

Button、Slider、Toggle、ProgressView、Stepper、TextField、SecureField、Picker、SegmentedControl、DatePicker、ColorPicker、Gauge が使えます。プラットフォームの外観は macOS が提供します。

## 制御値

アクセサーをバインドし、ネイティブコールバックが返した値を保存します。SwiftUI コントロールと QuickGUI ノードは同じシグナルを共有できます。DatePicker はミリ秒単位の Unix タイムスタンプを使います。

```go
func SwiftUiToggleExample() {
	on, setOn := ui.CreateSignal(true)
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## サイズ

`MatchContents: true` は両軸を固有サイズにします。固有の高さとアプリ指定の幅を組み合わせる場合は `ui.SwiftUIMatchContents{Vertical: true}` を使い、`PartProps.Style` で幅を設定します。

```go
ui.SwiftUIHostProps{
	MatchContents: ui.SwiftUIMatchContents{Vertical: true},
	PartProps:     ui.PartProps{Style: ui.Style{Width: 320}},
}
```

## 対応プラットフォーム

SwiftUI ホスティングには macOS が必要です。ビルド済みのネイティブホストにブリッジが含まれ、Go アプリは引き続き CGO なしでビルドできます。ネイティブスタイルは OS バージョンにより異なる場合があります。
