このガイドは既定の Go フロントエンドを使います。MoonBit の fluent API はサイドバーから選べます。

QuickGUI アプリは通常の Go プログラムです。Go でコンポーネントと細粒度のリアクティブな状態を記述し、`CGO_ENABLED=0` でビルドします。purego が同じプロセス内でビルド済みネイティブライブラリを読み込み、Bun は開発・パッケージング用 CLI を実行します。

## 動作要件

- macOS 14 以降
- Go 1.23 以降
- Bun 1.3 以降
- Xcode Command Line Tools（`xcode-select --install`）

現在、パッケージ化した UI アプリは macOS が対象です。通常のアプリビルドではビルド済みのネイティブホストを使用します。

## プロジェクトを作成

CLI はまだ公開されていません。[QuickGUI のチェックアウト](https://github.com/egoist/quickgui)から Go のカウンターを実行してください。

```bash
bun install
bun packages/cli/src/cli.ts dev --project examples/counter
```

別のアプリを作るには、レジストリのパッケージをインストールせずに雛形を生成します。

```bash
bun packages/cli/src/cli.ts init ../my-app --no-install
cd ../my-app
go mod edit -replace github.com/egoist/quickgui/go=../quickgui/go
go mod tidy
```

生成された `quickgui.config.ts` で `defineConfig` のインポートを `../quickgui/packages/cli/src/index.ts` に変更し、ローカル CLI を使います。その後 QuickGUI チェックアウトから `bun packages/cli/src/cli.ts dev --project ../my-app` を実行します。Go が既定なので `--frontend go` は省略できます。

## 最初のウィンドウ

生成された `main.go` は、ウィンドウ API を `native`、コンポーネントを `ui` からインポートします。コンポーネント関数を `WindowOptions.Component` に直接渡し、`native.Run` を一度呼んでイベントループを開始します。

```go
package main

import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"log"
)

func Counter() {
	count, setCount := ui.CreateSignal(0)
	ui.View(
		func() {
			ui.Text("Count: ", count)
			ui.Button(
				"Increment",
				ui.Padding(12),
				ui.BorderRadius(8),
				ui.BackgroundColor("#2563eb"),
				ui.Color("white"),
				ui.OnClick(func() { setCount(count() + 1) }),
			)
		},
		ui.Display("flex"),
		ui.FlexDirection("column"),
		ui.Width("100%"),
		ui.Height("100%"),
		ui.AlignItems("center"),
		ui.JustifyContent("center"),
		ui.Gap(12),
	)
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

## 実行とビルド

ウォッチャーは Go ソースを再ビルドして開発アプリを再起動します。フォーマッターは通常の Go 構文を保ちながら、長いコンポーネント呼び出しの改行を整えます。配布用バンドルは `dist/darwin-*` に出力されます。

```bash
bun packages/cli/src/cli.ts dev --project ../my-app
bun packages/cli/src/cli.ts fmt --project ../my-app
bun packages/cli/src/cli.ts build --project ../my-app
```
