QuickGUI はスタイルなしのプリミティブとアクセシブルな複合コントロールを組み合わせます。どちらも通常の Go 関数で構成できます。

## コンポーネントの定義

Go コンポーネントは `*ui.Element` または `*native.Node` を返します。通常の型の props と子ノードを直接組み合わせます。戻り値の型でコンポーネントを識別するため、`CounterLabel(count())` は注釈や `ui.View(func() { ... })` のラッパーなしで更新されます。ウィンドウには関数を直接渡せます。

```go
func CounterLabel(count int) *ui.Element {
	return ui.Text("Count: ", count).FontSize(20)
}

func ComponentExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View(
		CounterLabel(count()),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

構造体の props にも通常の Go の型を使います。`quantity` を更新すると、`LineItem` とそのノードを再構築せずに、バインドされたテキストが変わります。

```go
type Product struct {
	ID    string
	Name  string
	Price int
}

func LineItem(product Product, quantity int) *ui.Element {
	return ui.Text(product.Name, " × ", quantity, " = $", product.Price*quantity)
}

func Cart() *ui.Element {
	quantity, setQuantity := ui.CreateSignal(1)
	return ui.View(
		LineItem(Product{ID: "mug", Name: "Mug", Price: 12}, quantity()),
		ui.Button("Add one").OnClick(func() { setQuantity(quantity() + 1) }),
	)
}
```

コンテナーは以下のように子ノードを直接受け取れます。子のコールバックは任意で、マウント時に一度実行されます。遅延構築や複合コントロールのコンテキストが必要な場合に使います。イベントハンドラーは引き続きコールバックです。

```go
func CardComponent(title string, children ...any) *ui.Element {
	return ui.View(
		ui.Text(title).FontWeight(600),
		children,
	).Padding(20).Gap(12).FlexCol()
}

func CardComposition() *ui.Element {
	return CardComponent("Account",
		ui.Text("Manage your account settings."),
		ui.Button("Save").OnClick(func() { log.Print("Saved") }),
	)
}
```

## プリミティブ

`ui.View`、`ui.Text`、`ui.Button`、`ui.Input` から始めます。オプションとテキストを直接渡せます。`func() { ... }` 引数は複数の子を現在の親の下にまとめます。

```go
func ButtonExample(save func()) *ui.Element {
	return ui.Button(
		"Save changes",
	).
		Height(40).
		PaddingLeft(16).
		PaddingRight(16).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
		OnClick(save)

}
```

## 複合コンポーネント

複合コンポーネントは `ui.Tabs.Root`、`ui.Tabs.List`、`ui.Tabs.Panel` などのパーツを公開します。コアがロール、キーボード操作、フォーカス、状態を処理します。コンテキストが存在するように、パーツはルートの子要素コールバック内で作成してください。

```go
func TabsExample() *native.Node {
	return ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Tabs.List(
				ui.PartProps{},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview"),
						ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings")})
				},
			),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content"),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content")})
		},
	)
}
```

## 制御された状態

制御値にはアクセサーを渡し、コールバックでコントロールが受け入れた値を保存します。デフォルト値を使うとコンポーネントが状態を管理します。省略可能なスカラー値はポインター、複数選択はスライスで表します。

```go
func CheckboxExample() *native.Node {
	checked, setChecked := ui.CreateSignal(false)
	return ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Checkbox.Indicator(ui.PartProps{}, "✓"), ui.Text("Remember me").
				Node})
		},
	)
}
```

## コンポーネントの種類

リファレンスにはフォーム、ピッカー、レイアウトとデータ、オーバーレイ、メニュー、ルーティングを収録しています。`examples/components` には5,000行のテーブルと遅延読み込みツリーを含む、元の42デモすべてがあります。`examples/swift-ui` はネイティブ SwiftUI ホスティングの別ギャラリーです。

```bash
bun packages/cli/src/cli.ts dev --project examples/components
```

## 各パーツのスタイル

各パーツのスタイルには `PartProps.Style` を使います。`ui.Style()` と fluent メソッドでスタイルを作り、`.Merge(...)` で共有ビルダーを合成します。ビルダーのスライスや、それらを返すアクセサーも使えます。選択状態やテーマのシグナルは子要素を作り直さずにパーツを更新します。

```go
ui.PartProps{
	Style: ui.Style().
		Display("flex").
		Height(32).
		PaddingLeft(12).
		PaddingRight(12).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8),
}
```

Components サイドバーでは各ネイティブコントロールに専用ページがあります。実際の組み合わせは[フォームと入力](/docs/go/forms-and-input)と[オーバーレイとダイアログ](/docs/go/overlays-and-dialogs)を参照してください。
