現在の画面を変えず、トリガーの横により詳しいホバー／フォーカスプレビューを表示します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func PreviewCardExample() *ui.Element {
	card := ui.NewPreviewCard().Placement("bottom-start")
	return card.Root().Children(
		card.Trigger(ui.PreviewCardTriggerProps{Delay: 350}).Child("@ada"),
		card.Positioner().Child(
			card.Popup().Child("Ada Lovelace"),
		),
	)
}
```

## 構成

- `previewCard.Root`
- `previewCard.Trigger`
- `previewCard.Portal`
- `previewCard.Backdrop`
- `previewCard.Positioner`
- `previewCard.Popup`
- `previewCard.Arrow`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `CloseDelay` | 閉じるまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `Placement` | 衝突処理前に優先する配置方向です。 |
