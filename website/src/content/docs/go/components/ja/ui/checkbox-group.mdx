有限個のチェックボックス値をまとめ、必要に応じて親チェックボックスの状態も導出します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func CheckboxGroupExample() *ui.Element {
	values, setValues := ui.CreateSignal([]string{"email"})
	group := ui.NewCheckboxGroup(ui.CheckboxGroupProps{AllValues: []string{"email", "push"}, Value: values, OnValueChange: func(next []string, _ *native.Event) {
		setValues(next)
	}})
	all := ui.NewCheckbox().Parent(true)
	email := ui.NewCheckbox().Value("email")
	push := ui.NewCheckbox().Value("push")
	return group.Root().Children(
		all.Root().Child("All notifications"),
		email.Root().Child("Email"),
		push.Root().Child("Push"),
	)
}
```

## 構成

- `checkboxGroup.Root`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `AllValues` | 親チェックボックスの状態導出に使う、完全で順序付きの値集合です。 |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
