既知の範囲内のスカラー測定値を、低・高・最適のセマンティックな帯域とともに表示します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func MeterExample(value func() *float64) {
	ui.Meter.Root(
		ui.MeterProps{
			Value:   value,
			Min:     0,
			Max:     100,
			Low:     25,
			High:    80,
			Optimum: 50,
		},
		func() {
			ui.Meter.Label(ui.PartProps{}, "Disk used")
			ui.Meter.Track(
				ui.PartProps{},
				func() { ui.Meter.Indicator(ui.PartProps{}) },
			)
			ui.Meter.Value(ui.PartProps{})
		},
	)
}
```

## 構成

- `ui.Meter.Root`
- `ui.Meter.Track`
- `ui.Meter.Indicator`
- `ui.Meter.Label`
- `ui.Meter.Value`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `Low` | Meter の低い範囲の上限です。 |
| `High` | Meter の高い範囲の下限です。 |
| `Optimum` | Meter 値の望ましい点または範囲です。 |
