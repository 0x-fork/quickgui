個別にスタイルできる入力セルで構成された、長さ制限付きのワンタイムコードエディターです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func OtpFieldExample() {
	code, setCode := ui.CreateSignal("")
	ui.OtpField.Root(
		ui.OtpFieldRootProps{
			Value:          code,
			Length:         6,
			ValidationType: "numeric",
			OnValueChange:  func(next string, _ *native.Event) { setCode(next) },
			OnComplete:     func(value string, _ *native.Event) { fmt.Println("Complete:", value) },
		},
		func() {
			for index := range 6 {
				ui.OtpField.Input(ui.OtpFieldInputProps{Index: index})
			}
		},
	)
}
```

## 構成

- `ui.OtpField.Root`
- `ui.OtpField.Input`
- `ui.OtpField.Separator`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Length` | ワンタイムコード入力スロットの数です。上限は 12 です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
