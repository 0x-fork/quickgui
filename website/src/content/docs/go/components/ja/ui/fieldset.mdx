関連するフィールドを 1 つの凡例と共有セマンティック状態の下にまとめます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func FieldsetExample(saving func() bool) *ui.Element {
	fieldset := ui.NewFieldset().Disabled(saving)
	field := ui.NewField()
	return fieldset.Root().Children(
		fieldset.Legend().Child("Profile"),
		field.Root().Children(
			field.Label().Child("Name"),
			field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Placeholder: "Ada"}}),
		),
	)
}
```

## 構成

- `fieldset.Root`
- `fieldset.Legend`
- `fieldset.Description`
- `fieldset.Control`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `Style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
