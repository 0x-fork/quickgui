関連するフィールドを 1 つの凡例と共有セマンティック状態の下にまとめます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func FieldsetExample(saving func() bool) *native.Node {
	fieldset1 := ui.NewFieldset(ui.PartProps{Disabled: saving})
	return fieldset1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{fieldset1.Legend(ui.PartProps{}).Children("Profile").NativeNode(), func() *native.Node {
			field2 := ui.NewField(ui.FieldRootProps{})
			return field2.Root().Children(func() *native.Node {
				return ui.Fragment([]*native.Node{field2.Label(ui.FieldLabelProps{}).Children("Name").NativeNode(), field2.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Placeholder: "Ada"}}).NativeNode()})
			}).NativeNode()
		}()})
	}).NativeNode()
}
```

## 構成

- `fieldset.Root`
- `fieldset.Legend`
- `fieldset.Description`
- `fieldset.Control`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `Style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
