独立してスタイルできるインジケーターを持つ、二値または不定状態の選択コントロールです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func CheckboxExample() {
	checked, setChecked := ui.CreateSignal(false)
	ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() {
			ui.Checkbox.Indicator(
				ui.PartProps{Style: ui.Styles(
					ui.Width(16),
					ui.Height(16),
					ui.BorderWidth(1),
					ui.BorderRadius(4),
					ui.BorderColor("#2563eb"),
					ui.Display("flex"),
					ui.AlignItems("center"),
					ui.JustifyContent("center"),
				)},
				func() {
					ui.Show(
						checked,
						func() {
							ui.SVG(
								ui.Value(`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 12 12"><path d="M3 6l2 2 4-4" fill="none" stroke="#2563eb" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"/></svg>`),
								ui.Width(12),
								ui.Height(12),
							)
						},
					)
				},
			)
			ui.Text("Remember me")
		},
	)
}
```

インジケーターには既定のスタイルがありません。この例では枠を保持し、選択時だけ SVG を表示します。`ReadOnly: true` を設定すると、フォーカスを保ちながら、ポインターやキーボード操作による値の変更を防ぎます。

## 構成

- `ui.Checkbox.Root`
- `ui.Checkbox.Indicator`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Checked` | 制御されたチェック状態です。 |
| `DefaultChecked` | コンポーネント自身が状態を管理するときの初期チェック状態です。 |
| `OnCheckedChange` | コアが受け入れたチェック状態を通知します。 |
| `ReadOnly` | 値の変更を防ぎつつ、コントロールはフォーカス可能なままにします。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
