アクセシブルな状態を保ちながら、トリガーで 1 つのパネルを表示／非表示にします。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func CollapsibleExample() *native.Node {
	collapsible1 := ui.NewCollapsible(ui.CollapsibleRootProps{})
	return collapsible1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{collapsible1.Trigger(ui.PartProps{}).Children("Show details").NativeNode(), collapsible1.Panel(ui.PartProps{}).Children("Mounted when opened").NativeNode()})
	}).NativeNode()
}
```

## 構成

- `collapsible.Root`
- `collapsible.Trigger`
- `collapsible.Panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `KeepMounted` | 非アクティブな内容をマウントしたまま、表示を無効にします。 |
