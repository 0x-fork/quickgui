アクセシブルな状態を保ちながら、トリガーで 1 つのパネルを表示／非表示にします。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func CollapsibleExample() *native.Node {
	return ui.Collapsible.Root(
		ui.CollapsibleRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Collapsible.Trigger(ui.PartProps{}, "Show details"),
				ui.Collapsible.Panel(ui.PartProps{}, "Mounted when opened")})
		},
	)
}
```

## 構成

- `ui.Collapsible.Root`
- `ui.Collapsible.Trigger`
- `ui.Collapsible.Panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `KeepMounted` | 非アクティブな内容をマウントしたまま、表示を無効にします。 |
