展開、選択、キーボードナビゲーションに対応した仮想化階層コレクションです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TreeExample() {
	nodes := []ui.TreeNodeDeclaration{{ID: "src", Label: "src", Children: []ui.TreeNodeDeclaration{{ID: "src/main.go", Label: "main.go"}}}}
	ui.Tree.Root(
		ui.TreeRootProps{
			Nodes:           func() []ui.TreeNodeDeclaration { return nodes },
			DefaultExpanded: []string{"src"},
			RowHeight:       26,
			PartProps:       ui.PartProps{Style: ui.Style().Height(200)},
		},
		func() {
			ui.Tree.Row(ui.TreeRowProps{NodeID: "src"}, "src")
			ui.Tree.Row(ui.TreeRowProps{NodeID: "src/main.go"}, "main.go")
		},
	)
}
```

## 構成

- `ui.Tree.Root`
- `ui.Tree.Row`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Nodes` | Tree の上限付き階層ノード宣言です。 |
| `Expanded` | 制御された展開済み Tree ノード ID です。 |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `OnExpandedChange` | コアが展開した順序付きノード ID を通知します。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
