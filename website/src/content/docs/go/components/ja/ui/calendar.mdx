1 つの日付を選ぶための、キーボードで操作できる月間カレンダーグリッドです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func CalendarExample(weeks [][]string) {
	ui.Calendar.Root(
		ui.CalendarRootProps{DefaultValue: "2026-09-03"},
		func() {
			for index, week := range weeks {
				ui.Calendar.Week(
					ui.CalendarWeekProps{Index: &index},
					func() {
						for _, day := range week {
							ui.Calendar.Day(ui.CalendarDayProps{Day: day}, day)
						}
					},
				)
			}
		},
	)
}
```

## 構成

- `ui.Calendar.Root`
- `ui.Calendar.Week`
- `ui.Calendar.Day`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `FirstWeekday` | 最初の曜日列です。月曜日が 0、日曜日が 6 です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
