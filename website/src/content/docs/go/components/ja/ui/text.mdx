継承されたタイポグラフィ、選択、アクセシビリティを使って Unicode テキストを組版・描画します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			"Count: ",
			count(),
		).FontSize(20)
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) })
	})
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `Ref` | 保持されたネイティブノードを受け取ります。 |
