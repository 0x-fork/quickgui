保持型の Markdown を描画し、ストリーミング内容向けの差分更新にも対応します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func MarkdownExample(source func() string, streaming func() bool) {
	ui.Markdown(ui.Value(source), ui.Streaming(streaming)).Width("100%")
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 組版・描画する Markdown ソースです。 |
| `Streaming` | 追記された内容に Markdown の差分更新を使います。 |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
