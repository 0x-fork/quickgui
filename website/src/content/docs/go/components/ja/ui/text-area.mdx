Input と同じ制御値の規約を持つ、複数行テキスト編集プリミティブです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TextAreaExample() {
	value, setValue := ui.CreateSignal("")
	ui.TextArea(
		ui.Value(value),
		ui.Placeholder("Write here"),
		ui.OnInput(func(event *native.Event) { setValue(event.Value) }),
	).Width(320).Height(96)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Placeholder` | 編集値が空のときに表示するテキストです。 |
| `OnInput` | ネイティブ編集の入力を通知します。 |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
