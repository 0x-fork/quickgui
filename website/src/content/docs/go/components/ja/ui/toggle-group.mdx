ロービングフォーカスを使い、単一または複数の押下値を管理します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ToggleGroupExample() *native.Node {
	values, setValues := ui.CreateSignal([]string{"bold"})
	return ui.ToggleGroup.Root(
		ui.ToggleGroupProps{
			Multiple:      true,
			Value:         values,
			Items:         []ui.ComponentItem{{Value: "bold"}, {Value: "italic"}},
			OnValueChange: func(next []string, _ *native.Event) { setValues(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.ToggleGroup.Item(ui.ToggleGroupItemProps{Value: "bold"}, "Bold"),
				ui.ToggleGroup.Item(ui.ToggleGroupItemProps{Value: "italic"}, "Italic")})
		},
	)
}
```

## 構成

- `ui.ToggleGroup.Root`
- `ui.ToggleGroup.Item`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Multiple` | 単一選択または複数選択の方針を選びます。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
