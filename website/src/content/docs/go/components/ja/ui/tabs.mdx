ラベル付きパネルを切り替え、キーボードによる自動または手動のアクティブ化に対応します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TabsExample() *native.Node {
	return ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Tabs.List(
				ui.PartProps{},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview"),
						ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings")})
				},
			),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content"),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content")})
		},
	)
}
```

## 構成

- `ui.Tabs.Root`
- `ui.Tabs.List`
- `ui.Tabs.Tab`
- `ui.Tabs.Indicator`
- `ui.Tabs.Panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `Activation` | フォーカスまたは明示的な押下で Tab をアクティブにするかどうかです。 |
