ラベル付きパネルを切り替え、キーボードによる自動または手動のアクティブ化に対応します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TabsExample() *ui.Element {
	tabs := ui.NewTabs().DefaultValue("overview").Activation("automatic")
	return tabs.Root().Children(
		tabs.List().Children(
			tabs.Tab("overview").Child("Overview"),
			tabs.Tab("settings").Child("Settings"),
		),
		tabs.Panel("overview").Child("Overview content"),
		tabs.Panel("settings").Child("Settings content"),
	)
}
```

## 構成

- `tabs.Root`
- `tabs.List`
- `tabs.Tab`
- `tabs.Indicator`
- `tabs.Panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `Activation` | フォーカスまたは明示的な押下で Tab をアクティブにするかどうかです。 |
