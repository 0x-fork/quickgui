組み込みの見た目を持たない、セマンティックな水平または垂直区切り線です。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SeparatorExample() *native.Node {
	return ui.Separator.Root(ui.SeparatorProps{
		Orientation: "horizontal",
		PartProps:   ui.PartProps{Style: ui.Style().Height(1).BackgroundColor("#d1d5db")},
	})
}
```

## 構成

- `ui.Separator.Root`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `Style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
