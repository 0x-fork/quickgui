呼び出し側がスタイルした内容を、現在のウィンドウ内でアンカーの横に配置します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func PopoverExample() {
	ui.Popover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.Popover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.Popover.Positioner(
				ui.PopoverPositionerProps{},
				func() {
					ui.Popover.Popup(
						ui.PopoverPopupProps{PartProps: ui.PartProps{Style: ui.Styles(
							ui.Width(240),
							ui.Padding(16),
						)}},
						func() {
							ui.Popover.Title(ui.PartProps{}, "Account")
							ui.Popover.Close(ui.PartProps{}, "Done")
						},
					)
				},
			)
		},
	)
}
```

## 構成

- `ui.Popover.Root`
- `ui.Popover.Trigger`
- `ui.Popover.Content`
- `ui.Popover.Portal`
- `ui.Popover.Backdrop`
- `ui.Popover.Positioner`
- `ui.Popover.Popup`
- `ui.Popover.Arrow`
- `ui.Popover.Viewport`
- `ui.Popover.Title`
- `ui.Popover.Description`
- `ui.Popover.Close`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `Side` | 衝突処理前に優先する配置方向です。 |
| `Align` | 配置の交差軸上で優先する揃え方です。 |
| `Modal` | フォーカスを内部に閉じ込め、背後のサーフェスへの操作を防ぎます。 |
