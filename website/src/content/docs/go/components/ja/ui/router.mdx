QuickGUI コアのルーティングを QuickGUI UI に投影し、ネストされたレイアウトと上限付きメモリ履歴を提供します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func RouterExample() {
	ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route(
				"/",
				func() {
					ui.Link(
						ui.LinkProps{Href: "/settings"},
						"Settings",
					)
				},
			),
			ui.Route(
				"/settings",
				func() { ui.Text("Settings") },
			),
		},
		Fallback: func() { ui.Text("Page not found") },
	})
}
```

## 構成

- `ui.Router`
- `ui.Route`
- `ui.Layout`
- `ui.Link`
- `ui.Outlet`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `InitialPath` | 上限付きメモリ履歴の初期移動先です。 |
| `Fallback` | どのルートにも一致しないときに描画する内容です。 |
| `Routes` | `ui.Route` と `ui.Layout` で作成する静的ルート宣言です。 |
| `Path` | 絶対または親からの相対ルートパターンです。 |
| `Component` | ルートが一致したときに描画するコンポーネントです。 |
| `Href` | QuickGUI Router が解決する移動先です。 |
