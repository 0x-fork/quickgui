時、分、秒、午前／午後の各パーツを持つ、キーボード編集可能な分割時刻フィールドです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TimeFieldExample() *ui.Element {
	field := ui.NewTimeField().DefaultValue("09:30").Hour12(true)
	segments := make([]*ui.Element, 0, 3)
	for _, segment := range []string{"hour", "minute", "period"} {
		segments = append(segments, field.Segment(segment))
	}
	return field.Root().Children(segments)
}
```

## 構成

- `timeField.Root`
- `timeField.Segment`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Hour12` | 午前／午後セグメントを追加し、12 時間表記を使います。 |
| `ShowSeconds` | 秒セグメントをマウントします。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
