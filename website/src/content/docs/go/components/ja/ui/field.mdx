1 つのコントロールをラベル、説明、検証状態、エラーメッセージに関連付けます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func FieldExample() *ui.Element {
	email, setEmail := ui.CreateSignal("")
	field := ui.NewField(ui.FieldRootProps{Required: true, Filled: func() bool {
		return email() != ""
	}})
	return field.Root().Children(
		field.Label().Child("Email"),
		field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Value: email, Placeholder: "you@example.com", OnInput: func(event *native.Event) {
			setEmail(event.Value)
		}}}),
		field.Description().Child("Used for receipts"),
		field.Error().Child("Enter a valid email address"),
	)
}
```

## 構成

- `field.Root`
- `field.Item`
- `field.Label`
- `field.Control`
- `field.Validity`
- `field.Description`
- `field.Error`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Invalid` | Field とそのパーツへ検証エラー状態を反映します。 |
| `Required` | 検証とフォーム送信で必須の値としてマークします。 |
| `ValidationMessage` | エラー内容とアクセシビリティに公開する、長さ制限付きメッセージです。 |
| `ValidationMode` | 検証を開始するインタラクション境界を選びます。 |
| `OnValidationChange` | コアが選んだ検証のトリガーとタイミングを通知します。 |
