1 つのロービングフォーカスモデルの下に操作と入力をまとめます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ToolbarExample() *native.Node {
	toolbar1 := ui.NewToolbar(ui.ToolbarRootProps{Items: []ui.ComponentItem{{Value: "select"}, {Value: "draw"}}, DefaultActive: "select"})
	return toolbar1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{toolbar1.Item(ui.ToolbarItemProps{Value: "select"}).Children("Select").NativeNode(), toolbar1.Item(ui.ToolbarItemProps{Value: "draw"}).Children("Draw").NativeNode()})
	}).NativeNode()
}
```

## 構成

- `toolbar.Root`
- `toolbar.Item`
- `toolbar.Button`
- `toolbar.Link`
- `toolbar.Input`
- `toolbar.Group`
- `toolbar.Separator`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `Active` | アクティブ状態またはロービングフォーカス状態を持つ、制御された項目です。 |
| `DefaultActive` | 非制御コンポーネントの初期アクティブ項目です。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `OnActiveChange` | ロービングフォーカス状態を現在持つ項目を通知します。 |
