1 つのロービングフォーカスモデルの下に操作と入力をまとめます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ToolbarExample() *native.Node {
	return ui.Toolbar.Root(
		ui.ToolbarRootProps{
			Items:         []ui.ComponentItem{{Value: "select"}, {Value: "draw"}},
			DefaultActive: "select",
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Toolbar.Item(ui.ToolbarItemProps{Value: "select"}, "Select"),
				ui.Toolbar.Item(ui.ToolbarItemProps{Value: "draw"}, "Draw")})
		},
	)
}
```

## 構成

- `ui.Toolbar.Root`
- `ui.Toolbar.Item`
- `ui.Toolbar.Button`
- `ui.Toolbar.Link`
- `ui.Toolbar.Input`
- `ui.Toolbar.Group`
- `ui.Toolbar.Separator`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `Active` | アクティブ状態またはロービングフォーカス状態を持つ、制御された項目です。 |
| `DefaultActive` | 非制御コンポーネントの初期アクティブ項目です。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `OnActiveChange` | ロービングフォーカス状態を現在持つ項目を通知します。 |
