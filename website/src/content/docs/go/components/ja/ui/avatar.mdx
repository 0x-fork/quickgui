画像を表示し、読み込めない場合はフォールバックを表示します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func AvatarExample(path string) {
	ui.Avatar.Root(
		ui.AvatarRootProps{PartProps: ui.PartProps{AriaLabel: "Ada Lovelace"}},
		func() {
			ui.Avatar.Image(ui.AvatarImageProps{Src: path})
			ui.Avatar.Fallback(ui.AvatarFallbackProps{}, "AL")
		},
	)
}
```

## 構成

- `ui.Avatar.Root`
- `ui.Avatar.Image`
- `ui.Avatar.Fallback`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `AriaLabel` | 表示パーツが変化するコンポーネントに付けるアクセシブル名です。 |
| `Src` | アバター画像のファイルパス、ファイル URL、または base64 データ URL です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `OnLoadingStatusChange` | アバター画像の読み込み状態が変わるたびに通知します。 |
