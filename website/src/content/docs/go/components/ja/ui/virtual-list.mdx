長いリストや高さが可変のコレクションの表示範囲をレイアウトして描画します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func VirtualListExample(rows []string) {
	ui.VirtualList(
		func() {
			for _, row := range rows {
				ui.Text(row).Height(36)
			}
		},
		ui.Style().Height(320),
		ui.EstimatedItemHeight(36),
		ui.Overscan(6),
		ui.FollowMode("normal"),
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `EstimatedItemHeight` | 仮想化で使う初期論理行高の推定値です。 |
| `Overscan` | 表示範囲の前後に追加でマウントする行数です。 |
| `ListAlignment` | 短いリスト内容を上端または下端に固定します。 |
| `FollowMode` | 通常のスクロールまたは末尾追従の動作を選びます。 |
| `children` | コンポーネント内にマウントする内容です。 |
