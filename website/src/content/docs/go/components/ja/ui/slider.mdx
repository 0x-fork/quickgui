ポインターとキーボード操作をコアが管理する、単一または複数つまみの範囲入力です。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SliderExample() *native.Node {
	volume, setVolume := ui.CreateSignal([]float64{40})
	slider1 := ui.NewSlider(ui.SliderRootProps{Value: volume, Min: 0, Max: 100, Step: 1, OnValueChange: func(next []float64, _ *native.Event) {
		setVolume(next)
	}})
	return slider1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{slider1.Label(ui.PartProps{}).Children("Volume").NativeNode(), slider1.Control(ui.PartProps{Style: ui.Style().Width(240).Height(24)}).Children(func() *native.Node {
			return ui.Fragment([]*native.Node{slider1.Track(ui.PartProps{}).Children(func() *native.Node {
				return slider1.Indicator(ui.PartProps{}).NativeNode()
			}).NativeNode(), slider1.Thumb(ui.SliderThumbProps{}).NativeNode()})
		}).NativeNode(), slider1.Value(ui.PartProps{}).NativeNode()})
	}).NativeNode()
}
```

## 構成

- `slider.Root`
- `slider.Label`
- `slider.Value`
- `slider.Control`
- `slider.Track`
- `slider.Range`
- `slider.Indicator`
- `slider.Thumb`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `Step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
