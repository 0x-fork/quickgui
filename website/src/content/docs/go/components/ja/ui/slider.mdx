ポインターとキーボード操作をコアが管理する、単一または複数つまみの範囲入力です。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SliderExample() {
	volume, setVolume := ui.CreateSignal([]float64{40})
	ui.Slider.Root(
		ui.SliderRootProps{
			Value:         volume,
			Min:           0,
			Max:           100,
			Step:          1,
			OnValueChange: func(next []float64, _ *native.Event) { setVolume(next) },
		},
		func() {
			ui.Slider.Label(ui.PartProps{}, "Volume")
			ui.Slider.Control(
				ui.PartProps{Style: ui.Style().Width(240).Height(24)},
				func() {
					ui.Slider.Track(
						ui.PartProps{},
						func() { ui.Slider.Indicator(ui.PartProps{}) },
					)
					ui.Slider.Thumb(ui.SliderThumbProps{})
				},
			)
			ui.Slider.Value(ui.PartProps{})
		},
	)
}
```

## 構成

- `ui.Slider.Root`
- `ui.Slider.Label`
- `ui.Slider.Value`
- `ui.Slider.Control`
- `ui.Slider.Track`
- `ui.Slider.Range`
- `ui.Slider.Indicator`
- `ui.Slider.Thumb`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `Step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
