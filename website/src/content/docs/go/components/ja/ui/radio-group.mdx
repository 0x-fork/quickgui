Radio 項目間の単一選択とキーボード移動を管理します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func RadioGroupExample() *ui.Element {
	value, setValue := ui.CreateSignal("system")
	group := ui.NewRadioGroup(ui.RadioGroupProps{Value: func() *string {
		current := value()
		return &current
	}, OnValueChange: func(next string, _ *native.Event) {
		setValue(next)
	}})
	options := make([]*ui.Element, 0, 3)
	for _, value := range []string{"light", "dark", "system"} {
		radio := ui.NewRadio().Value(value)
		options = append(options, radio.Root().Children(
			radio.Indicator(),
			ui.Text(value),
		))
	}
	return group.Root().Children(options)
}
```

## 構成

- `radioGroup.Root`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `ReadOnly` | 値の変更を防ぎつつ、コントロールはフォーカス可能なままにします。 |
| `Required` | 検証とフォーム送信で必須の値としてマークします。 |
