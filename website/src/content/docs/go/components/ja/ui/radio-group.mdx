Radio 項目間の単一選択とキーボード移動を管理します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func RadioGroupExample() *native.Node {
	value, setValue := ui.CreateSignal("system")
	return ui.RadioGroup.Root(
		ui.RadioGroupProps{
			Value:         func() *string { current := value(); return &current },
			OnValueChange: func(next string, _ *native.Event) { setValue(next) },
		},
		func() *native.Node {
			var children []*native.Node
			for _, option := range []string{"light", "dark", "system"} {
				children = append(children, ui.Radio.Root(
					ui.RadioProps{Value: option},
					func() *native.Node {
						return ui.Fragment([]*native.Node{ui.Radio.Indicator(ui.PartProps{}), ui.Text(option).Node})
					},
				))
			}
			return ui.Fragment(children)
		},
	)
}
```

## 構成

- `ui.RadioGroup.Root`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `ReadOnly` | 値の変更を防ぎつつ、コントロールはフォーカス可能なままにします。 |
| `Required` | 検証とフォーム送信で必須の値としてマークします。 |
