確定または不確定のタスク進捗を、組み合わせ可能なラベルとトラックで表します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ProgressExample(progress func() *float64) *native.Node {
	return ui.Progress.Root(
		ui.ProgressProps{Value: progress, Max: 100},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Progress.Label(ui.PartProps{}, "Uploading"),
				ui.Progress.Track(
					ui.PartProps{},
					func() *native.Node { return ui.Progress.Indicator(ui.PartProps{}) },
				),
				ui.Progress.Value(ui.PartProps{})})
		},
	)
}
```

## 構成

- `ui.Progress.Root`
- `ui.Progress.Track`
- `ui.Progress.Indicator`
- `ui.Progress.Label`
- `ui.Progress.Value`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Max` | 受け入れる最大値です。 |
| `Indeterminate` | 完了量が不明な進捗を表します。 |
| `ValueText` | 支援技術向けの読みやすい値です。 |
| `OnStatusChange` | 導出された状態、整形済みの値、完了率を通知します。 |
