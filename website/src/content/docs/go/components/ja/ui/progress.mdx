確定または不確定のタスク進捗を、組み合わせ可能なラベルとトラックで表します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ProgressExample(progress func() *float64) *ui.Element {
	bar := ui.NewProgress().SetValue(progress).Max(100)
	return bar.Root().Children(
		bar.Label().Child("Uploading"),
		bar.Track().Child(bar.Indicator()),
		bar.Value(),
	)
}
```

## 構成

- `progress.Root`
- `progress.Track`
- `progress.Indicator`
- `progress.Label`
- `progress.Value`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Max` | 受け入れる最大値です。 |
| `Indeterminate` | 完了量が不明な進捗を表します。 |
| `ValueText` | 支援技術向けの読みやすい値です。 |
| `OnStatusChange` | 導出された状態、整形済みの値、完了率を通知します。 |
