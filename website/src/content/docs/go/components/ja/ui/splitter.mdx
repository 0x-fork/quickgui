ポインターとキーボードで操作できるハンドルを備えた、サイズ変更可能なペインを作ります。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SplitterExample() *native.Node {
	return ui.Splitter.Root(
		ui.SplitterRootProps{
			DefaultValue: []float64{240, 400},
			Panes:        []ui.SplitterPaneDeclaration{{}, {}},
			PartProps:    ui.PartProps{Style: ui.Style().Display("flex").Height(240)},
		},
		func() *native.Node {
			var children []*native.Node
			first, second := 0, 1
			children = append(children, ui.Splitter.Pane(ui.SplitterPaneProps{Index: &first}, "Sidebar"))
			children = append(children, ui.Splitter.Handle(ui.SplitterPaneProps{
				Index: &first,
				PartProps: ui.PartProps{Style: ui.Style().
					Width(6).
					Cursor("col-resize")},
			}))
			children = append(children, ui.Splitter.Pane(ui.SplitterPaneProps{Index: &second}, "Content"))
			return ui.Fragment(children)
		},
	)
}
```

## 構成

- `ui.Splitter.Root`
- `ui.Splitter.Pane`
- `ui.Splitter.Handle`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Panes` | ペインごとの最小サイズと折りたたみ宣言です。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `OnSizesChange` | コアによるサイズ変更後、完全なペインサイズ集合を通知します。 |
