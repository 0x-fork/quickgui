テキストなどの内容を自由に組み合わせてスタイルできる、アクセシブルな押下ターゲットです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ButtonExample(save func()) {
	ui.Button(
		"Save changes",
		ui.Height(40),
		ui.PaddingLeft(16),
		ui.PaddingRight(16),
		ui.BackgroundColor("#2563eb"),
		ui.TextColor("white"),
		ui.BorderRadius(8),
		ui.Hover(ui.BackgroundColor("#3b82f6")),
		ui.OnClick(save),
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `OnClick` | コアがアクティブ化を解決した後に実行します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
