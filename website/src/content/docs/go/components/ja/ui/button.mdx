テキストなどの内容を自由に組み合わせてスタイルできる、アクセシブルな押下ターゲットです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ButtonExample(save func()) {
	ui.Button(
		"Save changes",
		ui.Style().Height(40),
		ui.Style().PaddingLeft(16),
		ui.Style().PaddingRight(16),
		ui.Style().BackgroundColor("#2563eb"),
		ui.Style().TextColor("white"),
		ui.Style().BorderRadius(8),
		ui.Style().Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }),
		ui.OnClick(save),
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `OnClick` | コアがアクティブ化を解決した後に実行します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
