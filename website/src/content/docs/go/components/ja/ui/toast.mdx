操作、閉じる、スワイプに対応した、時間制御される積み重ね通知を表示します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ToastExample() *native.Node {
	return ui.Toast.Provider(
		ui.ToastProviderProps{Timeout: 5000, Limit: 3},
		func() *native.Node {
			var children []*native.Node
			manager := ui.UseToastManager()
			children = append(children, ui.Button(
				"Save",
			).OnClick(func() { manager.Add(ui.ToastRequest{Title: "Saved", Type: "success"}) }).Node)
			children = append(children, ui.Toast.Viewport(
				ui.ToastViewportProps{},
				func() *native.Node {
					return ui.For(
						manager.Toasts,
						func(toast ui.ToastDeclaration, _ func() int) *native.Node {
							return ui.Toast.Root(
								ui.ToastPartProps{ToastID: toast.ID},
								func() *native.Node {
									return ui.Fragment([]*native.Node{ui.Toast.Title(
										ui.ToastPartProps{ToastID: toast.ID},
										toast.Title,
									),
										ui.Toast.Close(ui.ToastPartProps{ToastID: toast.ID}, "Dismiss")})
								},
							)
						},
						func(toast ui.ToastDeclaration) any { return toast.ID },
						nil,
					)
				},
			))
			return ui.Fragment(children)
		},
	)
}
```

## 構成

- `ui.Toast.Provider`
- `ui.Toast.Portal`
- `ui.Toast.Viewport`
- `ui.Toast.Positioner`
- `ui.Toast.Root`
- `ui.Toast.Content`
- `ui.Toast.Title`
- `ui.Toast.Description`
- `ui.Toast.Action`
- `ui.Toast.Close`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Toasts` | ビューポートが描画する、宣言済み Toast キュー全体です。 |
| `ToastID` | 描画された 1 つの Toast に対応する、安定したキュー ID です。 |
| `Timeout` | 継承する自動消去時間、またはウォームアップ済み Provider のタイムアウトです。 |
| `SwipeDirection` | スワイプでサーフェスを閉じる、または移動する方向の端です。 |
| `OnDismiss` | コアが閉じた Toast ID を通知します。 |
