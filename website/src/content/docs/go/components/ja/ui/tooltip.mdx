コアが正確に管理する遅延後に補助情報を表示し、Provider 単位のウォームアップにも対応します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TooltipExample() {
	ui.Tooltip.Provider(
		ui.TooltipProviderProps{Delay: 500},
		func() {
			ui.Tooltip.Root(
				ui.TooltipRootProps{Side: "top"},
				func() {
					ui.Tooltip.Trigger(ui.TooltipTriggerProps{}, "Hover me")
					ui.Tooltip.Positioner(
						ui.TooltipPositionerProps{},
						func() {
							ui.Tooltip.Popup(
								ui.PartProps{},
								"Helpful information",
							)
						},
					)
				},
			)
		},
	)
}
```

## 構成

- `ui.Tooltip.Provider`
- `ui.Tooltip.Root`
- `ui.Tooltip.Trigger`
- `ui.Tooltip.Portal`
- `ui.Tooltip.Positioner`
- `ui.Tooltip.Popup`
- `ui.Tooltip.Arrow`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `CloseDelay` | 閉じるまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `Side` | 衝突処理前に優先する配置方向です。 |
| `Hoverable` | 閉じずにポインターを Tooltip 内へ移動できるようにします。 |
