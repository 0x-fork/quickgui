コアが正確に管理する遅延後に補助情報を表示し、Provider 単位のウォームアップにも対応します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TooltipExample() *ui.Element {
	provider := ui.NewTooltipProvider(ui.TooltipProviderProps{Delay: 500})
	tooltip := ui.NewTooltip().Side("top")
	return provider.Root().Child(
		tooltip.Root().Children(
			tooltip.Trigger().Child("Hover me"),
			tooltip.Positioner().Child(
				tooltip.Popup().Child("Helpful information"),
			),
		),
	)
}
```

## 構成

- `tooltip.Provider`
- `tooltip.Root`
- `tooltip.Trigger`
- `tooltip.Portal`
- `tooltip.Positioner`
- `tooltip.Popup`
- `tooltip.Arrow`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `CloseDelay` | 閉じるまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `Side` | 衝突処理前に優先する配置方向です。 |
| `Hoverable` | 閉じずにポインターを Tooltip 内へ移動できるようにします。 |
