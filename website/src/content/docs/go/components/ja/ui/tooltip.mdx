コアが正確に管理する遅延後に補助情報を表示し、Provider 単位のウォームアップにも対応します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TooltipExample() *native.Node {
	return ui.NewTooltipProvider(ui.TooltipProviderProps{Delay: 500}).Root().Child(func() *native.Node {
		tooltip1 := ui.NewTooltip(ui.TooltipRootProps{Side: "top"})
		return tooltip1.Root().Children(func() *native.Node {
			return ui.Fragment([]*native.Node{tooltip1.Trigger(ui.TooltipTriggerProps{}).Children("Hover me").NativeNode(), tooltip1.Positioner(ui.TooltipPositionerProps{}).Children(func() *native.Node {
				return tooltip1.Popup(ui.PartProps{}).Children("Helpful information").NativeNode()
			}).NativeNode()})
		}).NativeNode()
	}).NativeNode()
}
```

## 構成

- `tooltip.Provider`
- `tooltip.Root`
- `tooltip.Trigger`
- `tooltip.Portal`
- `tooltip.Positioner`
- `tooltip.Popup`
- `tooltip.Arrow`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `CloseDelay` | 閉じるまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `Side` | 衝突処理前に優先する配置方向です。 |
| `Hoverable` | 閉じずにポインターを Tooltip 内へ移動できるようにします。 |
