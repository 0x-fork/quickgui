サブメニュー、グループ、リンク、チェック項目、ラジオ項目を組み合わせられるメニューです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func MenuExample() *ui.Element {
	menu := ui.NewMenu()
	return menu.Root().Children(
		menu.Trigger().Child("Actions"),
		menu.Positioner().Child(
			menu.Popup().Child(
				menu.Item(ui.MenuItemProps{Value: "copy", Label: "Copy", PartProps: ui.PartProps{OnClick: func(*native.Event) {
					fmt.Println("Copy")
				}}}).Child("Copy"),
			),
		),
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `LoopFocus` | 現在のメニューレベルの端でキーボードハイライトを循環させます。 |
