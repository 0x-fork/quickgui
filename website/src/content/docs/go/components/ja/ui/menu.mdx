サブメニュー、グループ、リンク、チェック項目、ラジオ項目を組み合わせられるメニューです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func MenuExample() *native.Node {
	return ui.Menu.Root(
		ui.MenuRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Menu.Trigger(ui.MenuTriggerProps{}, "Actions"),
				ui.Menu.Positioner(
					ui.MenuPositionerProps{},
					func() *native.Node {
						return ui.Menu.Popup(
							ui.PartProps{},
							func() *native.Node {
								return ui.Menu.Item(
									ui.MenuItemProps{
										Value:     "copy",
										Label:     "Copy",
										PartProps: ui.PartProps{OnClick: func(*native.Event) { fmt.Println("Copy") }},
									},
									"Copy",
								)
							},
						)
					},
				)})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `LoopFocus` | 現在のメニューレベルの端でキーボードハイライトを循環させます。 |
