サブメニュー、グループ、リンク、チェック項目、ラジオ項目を組み合わせられるメニューです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func MenuExample() *native.Node {
	menu1 := ui.NewMenu(ui.MenuRootProps{})
	return menu1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{menu1.Trigger(ui.MenuTriggerProps{}).Children("Actions").NativeNode(), menu1.Positioner(ui.MenuPositionerProps{}).Children(func() *native.Node {
			return menu1.Popup(ui.PartProps{}).Children(func() *native.Node {
				return menu1.Item(ui.MenuItemProps{Value: "copy", Label: "Copy", PartProps: ui.PartProps{OnClick: func(*native.Event) {
					fmt.Println("Copy")
				}}}).Children("Copy").NativeNode()
			}).NativeNode()
		}).NativeNode()})
	}).NativeNode()
}
```

- `menu.Portal`

- `menu.Popup`

- `menu.Group`
- `menu.GroupLabel`
- `menu.RadioGroup`
- `menu.RadioItem`
- `menu.RadioItemIndicator`
- `menu.CheckboxItem`
- `menu.CheckboxItemIndicator`
- `menu.Separator`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `LoopFocus` | 現在のメニューレベルの端でキーボードハイライトを循環させます。 |
