増加、減少、ドラッグ調整用のパーツを備えた数値エディターです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func NumberFieldExample() *ui.Element {
	value, setValue := ui.CreateSignal(8.0)
	numberField := ui.NewNumberField(ui.NumberFieldRootProps{Value: func() *float64 {
		current := value()
		return &current
	}, Min: 0, Max: 100, Step: 1, OnValueChange: func(next *float64, valid bool, _ *native.Event) {
		if valid && next != nil {
			setValue(*next)
		}
	}})
	return numberField.Root().Children(
		numberField.Decrement().Child("−"),
		numberField.Input(),
		numberField.Increment().Child("+"),
	)
}
```

## 構成

- `numberField.Root`
- `numberField.Group`
- `numberField.Input`
- `numberField.Increment`
- `numberField.Decrement`
- `numberField.ScrubArea`
- `numberField.ScrubAreaCursor`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `Step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
