ネイティブのキーボードとテキストサービスに対応した、コアが管理する制御テキストエディターです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func InputExample() {
	value, setValue := ui.CreateSignal("")
	ui.Input().
		Value(value()).
		Placeholder("Write here").
		OnInputEvent(func(event *native.Event) { setValue(event.Value) }).
		Width(320).Height(32)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Placeholder` | 編集値が空のときに表示するテキストです。 |
| `Multiline` | 複数行テキスト編集を有効にします。 |
| `OnInput` | ネイティブ編集の入力を通知します。 |
