QuickGUI の内容を独立したネイティブ子ウィンドウに表示し、親ウィンドウの外側にも広げられます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SystemPopoverExample() *native.Node {
	return ui.SystemPopover.Root(
		ui.PopoverRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.SystemPopover.Trigger(ui.PopoverTriggerProps{}, "Account"),
				ui.SystemPopover.Content(
					ui.PopoverContentProps{
						Width:     240,
						Height:    120,
						Placement: "bottom-start",
					},
					"Account settings",
				)})
		},
	)
}
```

## 構成

- `ui.SystemPopover.Root`
- `ui.SystemPopover.Trigger`
- `ui.SystemPopover.Content`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `Width` | 宣言された論理幅です。 |
| `Height` | 宣言された論理高さです。 |
| `Placement` | ネイティブ子ウィンドウの配置要求です。 |
