1 つ以上の展開セクションと、そのキーボードフォーカスを管理します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func AccordionExample() *native.Node {
	return ui.Accordion.Root(
		ui.AccordionRootProps{Multiple: true},
		func() *native.Node {
			return ui.Accordion.Item(
				ui.AccordionItemProps{Value: "details"},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Accordion.Header(
						ui.PartProps{},
						func() *native.Node {
							return ui.Accordion.Trigger(
								ui.PartProps{},
								"Details",
							)
						},
					),
						ui.Accordion.Panel(ui.PartProps{}, "Mounted when opened")})
				},
			)
		},
	)
}
```

## 構成

- `ui.Accordion.Root`
- `ui.Accordion.Item`
- `ui.Accordion.Header`
- `ui.Accordion.Trigger`
- `ui.Accordion.Panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Multiple` | 複数の値を選択または開けるようにします。 |
| `KeepMounted` | 非アクティブな内容をマウントしたまま、表示を無効にします。 |
