1 つ以上の展開セクションと、そのキーボードフォーカスを管理します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func AccordionExample() *native.Node {
	accordion1 := ui.NewAccordion(ui.AccordionRootProps{Multiple: true})
	return accordion1.Root().Children(func() *native.Node {
		return accordion1.ItemWith(ui.AccordionItemProps{Value: "details"}).Children(func() *native.Node {
			return ui.Fragment([]*native.Node{accordion1.Header(ui.PartProps{}).Children(func() *native.Node {
				return accordion1.Trigger(ui.PartProps{}).Children("Details").NativeNode()
			}).NativeNode(), accordion1.Panel(ui.PartProps{}).Children("Mounted when opened").NativeNode()})
		}).NativeNode()
	}).NativeNode()
}
```

## 構成

- `accordion.Root`
- `accordion.Item`
- `accordion.Header`
- `accordion.Trigger`
- `accordion.Panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Multiple` | 複数の値を選択または開けるようにします。 |
| `KeepMounted` | 非アクティブな内容をマウントしたまま、表示を無効にします。 |
