検証済みの WGSL を、数を制限した数値シェーダーパラメーターで描画します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ShaderExample(source string, parameters func() []float64) {
	ui.Shader(
		ui.Value(source),
		ui.ShaderParameters(parameters),
	).Width(320).Height(180)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | コンポーネントが受け取るファイルパス、データ URL、SVG ドキュメント、またはシェーダーソースです。 |
| `ShaderParameters` | 固定のシェーダーパラメーターベクトルへ格納する最大 16 個の数値です。 |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
