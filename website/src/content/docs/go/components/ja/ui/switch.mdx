ルートのトラックと個別にスタイルできるつまみを持つ、オン／オフコントロールです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwitchExample() *native.Node {
	on, setOn := ui.CreateSignal(false)
	return ui.Switch.Root(
		ui.SwitchProps{
			Checked:         on,
			OnCheckedChange: func(next bool, _ *native.Event) { setOn(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Switch.Thumb(ui.PartProps{}), ui.Text("Notifications").
				Node})
		},
	)
}
```

## 構成

- `ui.Switch.Root`
- `ui.Switch.Thumb`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Checked` | 制御されたチェック状態です。 |
| `DefaultChecked` | コンポーネント自身が状態を管理するときの初期チェック状態です。 |
| `OnCheckedChange` | コアが受け入れたチェック状態を通知します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
