レイアウト、描画、ポインター入力、アクセシビリティに使える汎用の保持型コンテナです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ViewExample() {
	ui.View(
		func() {
			ui.Text("Hello from Go")
			ui.Button("Continue", ui.OnClick(func() {}))
		},
		ui.Padding(20),
		ui.Gap(12),
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `OnClick` | コアがアクティブ化を解決した後に実行します。 |
| `Ref` | 保持されたネイティブノードを受け取ります。 |
