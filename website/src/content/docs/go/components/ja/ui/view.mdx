レイアウト、描画、ポインター入力、アクセシビリティに使える汎用の保持型コンテナです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ViewExample() *ui.Element {
	return ui.View().
		Padding(20).Gap(12).
		Child(ui.Text("Hello from Go")).
		Child(ui.Button().OnClick(func() {}).Child("Continue"))
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
| `Child`, `Children` | コンポーネント内にマウントする内容です。 |
| `OnClick` | コアがアクティブ化を解決した後に実行します。 |
| `Ref` | 保持されたネイティブノードを受け取ります。 |
