確認操作に特化し、背景クリックで閉じる既定動作をより厳格にしたダイアログです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func AlertDialogExample() *native.Node {
	return ui.AlertDialog.Root(
		ui.DialogRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.AlertDialog.Trigger(ui.PartProps{}, "Open dialog"),
				ui.AlertDialog.Portal(
					ui.PartProps{},
					func() *native.Node {
						return ui.Fragment([]*native.Node{ui.AlertDialog.Backdrop(ui.PartProps{}),
							ui.AlertDialog.Viewport(
								ui.PartProps{},
								func() *native.Node {
									return ui.AlertDialog.Popup(
										ui.DialogPopupProps{},
										func() *native.Node {
											return ui.Fragment([]*native.Node{ui.AlertDialog.Title(ui.PartProps{}, "Confirm action"),
												ui.AlertDialog.Description(
													ui.PartProps{},
													"Review the details before continuing.",
												),
												ui.AlertDialog.Close(ui.PartProps{}, "Cancel")})
										},
									)
								},
							)})
					},
				)})
		},
	)
}
```

## 構成

- `ui.AlertDialog.Root`
- `ui.AlertDialog.Trigger`
- `ui.AlertDialog.Portal`
- `ui.AlertDialog.Backdrop`
- `ui.AlertDialog.Viewport`
- `ui.AlertDialog.Popup`
- `ui.AlertDialog.Title`
- `ui.AlertDialog.Description`
- `ui.AlertDialog.Close`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `DismissOnEscape` | Escape キーでサーフェスを閉じられるようにします。 |
| `ExitDuration` | 閉じる内容を、正確な終了トランジション時間だけマウントしたままにします。 |
