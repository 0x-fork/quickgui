確認操作に特化し、背景クリックで閉じる既定動作をより厳格にしたダイアログです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func AlertDialogExample() *ui.Element {
	dialog := ui.NewAlertDialog()
	return dialog.Root().Children(
		dialog.Trigger().Child("Open dialog"),
		dialog.Portal().Children(
			dialog.Backdrop(),
			dialog.Viewport().Child(
				dialog.Popup().Children(
					dialog.Title().Child("Confirm action"),
					dialog.Description().Child("Review the details before continuing."),
					dialog.Close().Child("Cancel"),
				),
			),
		),
	)
}
```

## 構成

- `alertDialog.Root`
- `alertDialog.Trigger`
- `alertDialog.Portal`
- `alertDialog.Backdrop`
- `alertDialog.Viewport`
- `alertDialog.Popup`
- `alertDialog.Title`
- `alertDialog.Description`
- `alertDialog.Close`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `DismissOnEscape` | Escape キーでサーフェスを閉じられるようにします。 |
| `ExitDuration` | 閉じる内容を、正確な終了トランジション時間だけマウントしたままにします。 |
