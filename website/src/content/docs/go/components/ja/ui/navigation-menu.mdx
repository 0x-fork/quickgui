方向付きアニメーション、ビューポート、ポップアップの各パーツを備えた開閉式ナビゲーションです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func NavigationMenuExample() *native.Node {
	navigationMenu1 := ui.NewNavigationMenu(ui.NavigationMenuRootProps{Items: []ui.ComponentItem{{Value: "products"}}, Delay: 100})
	return navigationMenu1.Root().Children(func() *native.Node {
		return navigationMenu1.List(ui.PartProps{}).Children(func() *native.Node {
			return navigationMenu1.Item(ui.NavigationMenuItemProps{Value: "products"}).Children(func() *native.Node {
				return ui.Fragment([]*native.Node{navigationMenu1.Trigger(ui.NavigationMenuPartProps{}).Children("Products").NativeNode(), navigationMenu1.Positioner(ui.NavigationMenuPartProps{}).Children(func() *native.Node {
					return navigationMenu1.Popup(ui.NavigationMenuPartProps{}).Children(func() *native.Node {
						return navigationMenu1.Link(ui.NavigationMenuLinkProps{Value: "overview"}).Children("Overview").NativeNode()
					}).NativeNode()
				}).NativeNode()})
			}).NativeNode()
		}).NativeNode()
	}).NativeNode()
}
```

## 構成

- `navigationMenu.Root`
- `navigationMenu.List`
- `navigationMenu.Item`
- `navigationMenu.Trigger`
- `navigationMenu.Icon`
- `navigationMenu.Content`
- `navigationMenu.Link`
- `navigationMenu.Portal`
- `navigationMenu.Positioner`
- `navigationMenu.Popup`
- `navigationMenu.Viewport`
- `navigationMenu.Arrow`
- `navigationMenu.Backdrop`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
