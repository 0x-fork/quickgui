方向付きアニメーション、ビューポート、ポップアップの各パーツを備えた開閉式ナビゲーションです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func NavigationMenuExample() *ui.Element {
	menu := ui.NewNavigationMenu().Items([]ui.ComponentItem{{Value: "products"}}).Delay(100)
	return menu.Root().Child(
		menu.List().Child(
			menu.Item(ui.NavigationMenuItemProps{Value: "products"}).Children(
				menu.Trigger().Child("Products"),
				menu.Positioner().Child(
					menu.Popup().Child(
						menu.Link(ui.NavigationMenuLinkProps{Value: "overview"}).Child("Overview"),
					),
				),
			),
		),
	)
}
```

## 構成

- `navigationMenu.Root`
- `navigationMenu.List`
- `navigationMenu.Item`
- `navigationMenu.Trigger`
- `navigationMenu.Icon`
- `navigationMenu.Content`
- `navigationMenu.Link`
- `navigationMenu.Portal`
- `navigationMenu.Positioner`
- `navigationMenu.Popup`
- `navigationMenu.Viewport`
- `navigationMenu.Arrow`
- `navigationMenu.Backdrop`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
