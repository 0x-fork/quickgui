方向付きアニメーション、ビューポート、ポップアップの各パーツを備えた開閉式ナビゲーションです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func NavigationMenuExample() *native.Node {
	return ui.NavigationMenu.Root(
		ui.NavigationMenuRootProps{
			Items: []ui.ComponentItem{{Value: "products"}},
			Delay: 100,
		},
		func() *native.Node {
			return ui.NavigationMenu.List(
				ui.PartProps{},
				func() *native.Node {
					return ui.NavigationMenu.Item(
						ui.NavigationMenuItemProps{Value: "products"},
						func() *native.Node {
							return ui.Fragment([]*native.Node{ui.NavigationMenu.Trigger(ui.NavigationMenuPartProps{}, "Products"),
								ui.NavigationMenu.Positioner(
									ui.NavigationMenuPartProps{},
									func() *native.Node {
										return ui.NavigationMenu.Popup(
											ui.NavigationMenuPartProps{},
											func() *native.Node {
												return ui.NavigationMenu.Link(
													ui.NavigationMenuLinkProps{Value: "overview"},
													"Overview",
												)
											},
										)
									},
								)})
						},
					)
				},
			)
		},
	)
}
```

## 構成

- `ui.NavigationMenu.Root`
- `ui.NavigationMenu.List`
- `ui.NavigationMenu.Item`
- `ui.NavigationMenu.Trigger`
- `ui.NavigationMenu.Icon`
- `ui.NavigationMenu.Content`
- `ui.NavigationMenu.Link`
- `ui.NavigationMenu.Portal`
- `ui.NavigationMenu.Positioner`
- `ui.NavigationMenu.Popup`
- `ui.NavigationMenu.Viewport`
- `ui.NavigationMenu.Arrow`
- `ui.NavigationMenu.Backdrop`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `DefaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `Delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
