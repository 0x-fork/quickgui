スクロール可能なビューポートと、呼び出し側でスタイルできるスクロールバー、つまみ、コーナーを組み合わせます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ScrollAreaExample() *native.Node {
	return ui.ScrollArea.Root(
		ui.ScrollAreaRootProps{
			ViewportSize: func() ui.Extent { return ui.Extent{Width: 320, Height: 160} },
			ContentSize:  func() ui.Extent { return ui.Extent{Width: 320, Height: 880} },
		},
		func() *native.Node {
			var children []*native.Node
			state := ui.UseScrollAreaState()
			children = append(children, ui.ScrollArea.Viewport(
				ui.PartProps{Style: ui.Style().
					Width(320).
					Height(160).
					Overflow("hidden")},
				func() *native.Node {
					return ui.ScrollArea.Content(
						ui.PartProps{Style: func() ui.StyleBuilder {
							return ui.Style().Transform(fmt.Sprintf("translateY(%gpx)", -state().Offset.Y))
						}},
						func() *native.Node {
							var children []*native.Node
							for index := range 40 {
								children = append(children, ui.Text("Row ", index).Height(22).Node)
							}
							return ui.Fragment(children)
						},
					)
				},
			))
			children = append(children, ui.ScrollArea.Scrollbar(
				ui.ScrollAreaScrollbarProps{Orientation: "vertical"},
				func() *native.Node { return ui.ScrollArea.Thumb(ui.ScrollAreaThumbProps{Orientation: "vertical"}) },
			))
			return ui.Fragment(children)
		},
	)
}
```

## 構成

- `ui.ScrollArea.Root`
- `ui.ScrollArea.Viewport`
- `ui.ScrollArea.Content`
- `ui.ScrollArea.Scrollbar`
- `ui.ScrollArea.Thumb`
- `ui.ScrollArea.Corner`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ViewportSize` | 宣言されたスクロールビューポートの範囲です。 |
| `ContentSize` | 宣言されたスクロール内容の範囲です。 |
| `OverflowEdgeThreshold` | その端にいるとみなす最大距離です。 |
| `OnScrollStateChange` | 制限適用後のオフセットと、そこから得たオーバーフロー状態を通知します。 |
