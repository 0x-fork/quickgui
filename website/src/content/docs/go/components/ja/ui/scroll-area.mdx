スクロール可能なビューポートと、呼び出し側でスタイルできるスクロールバー、つまみ、コーナーを組み合わせます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ScrollAreaExample() *native.Node {
	scrollArea1 := ui.NewScrollArea(ui.ScrollAreaRootProps{ViewportSize: func() ui.Extent {
		return ui.Extent{Width: 320, Height: 160}
	}, ContentSize: func() ui.Extent {
		return ui.Extent{Width: 320, Height: 880}
	}})
	return scrollArea1.Root().Children(func() *native.Node {
		var children []*native.Node
		state := ui.UseScrollAreaState()
		children = append(children, scrollArea1.Viewport(ui.PartProps{Style: ui.Style().Width(320).Height(160).Overflow("hidden")}).Children(func() *native.Node {
			return scrollArea1.Content(ui.PartProps{Style: func() ui.StyleBuilder {
				return ui.Style().Transform(fmt.Sprintf("translateY(%gpx)", -state().Offset.Y))
			}}).Children(func() *native.Node {
				var children []*native.Node
				for index := range 40 {
					children = append(children, ui.Text("Row ", index).Height(22).Node)
				}
				return ui.Fragment(children)
			}).NativeNode()
		}).NativeNode())
		children = append(children, scrollArea1.Scrollbar(ui.ScrollAreaScrollbarProps{Orientation: "vertical"}).Children(func() *native.Node {
			return scrollArea1.Thumb(ui.ScrollAreaThumbProps{Orientation: "vertical"}).NativeNode()
		}).NativeNode())
		return ui.Fragment(children)
	}).NativeNode()
}
```

## 構成

- `scrollArea.Root`
- `scrollArea.Viewport`
- `scrollArea.Content`
- `scrollArea.Scrollbar`
- `scrollArea.Thumb`
- `scrollArea.Corner`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ViewportSize` | 宣言されたスクロールビューポートの範囲です。 |
| `ContentSize` | 宣言されたスクロール内容の範囲です。 |
| `OverflowEdgeThreshold` | その端にいるとみなす最大距離です。 |
| `OnScrollStateChange` | 制限適用後のオフセットと、そこから得たオーバーフロー状態を通知します。 |
