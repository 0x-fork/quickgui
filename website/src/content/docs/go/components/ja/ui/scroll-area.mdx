スクロール可能なビューポートと、呼び出し側でスタイルできるスクロールバー、つまみ、コーナーを組み合わせます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ScrollAreaExample() *ui.Element {
	scrollArea := ui.NewScrollArea(ui.ScrollAreaRootProps{ViewportSize: func() ui.Extent {
		return ui.Extent{Width: 320, Height: 160}
	}, ContentSize: func() ui.Extent {
		return ui.Extent{Width: 320, Height: 880}
	}})
	return scrollArea.Root().Child(func() *native.Node {
		state := ui.UseScrollAreaState()
		viewport := scrollArea.Viewport().Width(320).Height(160).Overflow("hidden").Child(
			scrollArea.Content(ui.PartProps{Style: func() ui.StyleBuilder {
				return ui.Style().Transform(fmt.Sprintf("translateY(%gpx)", -state().Offset.Y))
			}}).Child(func() *native.Node {
				rows := make([]*ui.Element, 0, 40)
				for index := range 40 {
					rows = append(rows, ui.Text("Row ", index).Height(22))
				}
				return ui.Fragment(rows)
			}),
		)
		scrollbar := scrollArea.Scrollbar(ui.ScrollAreaScrollbarProps{Orientation: "vertical"}).Child(
			scrollArea.Thumb(ui.ScrollAreaThumbProps{Orientation: "vertical"}),
		)
		return ui.Fragment(viewport, scrollbar)
	})
}
```

## 構成

- `scrollArea.Root`
- `scrollArea.Viewport`
- `scrollArea.Content`
- `scrollArea.Scrollbar`
- `scrollArea.Thumb`
- `scrollArea.Corner`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ViewportSize` | 宣言されたスクロールビューポートの範囲です。 |
| `ContentSize` | 宣言されたスクロール内容の範囲です。 |
| `OverflowEdgeThreshold` | その端にいるとみなす最大距離です。 |
| `OnScrollStateChange` | 制限適用後のオフセットと、そこから得たオーバーフロー状態を通知します。 |
