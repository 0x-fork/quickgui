トリガーを副ボタンで押すと、モデル駆動のネイティブメニューを開きます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ContextMenuExample() *native.Node {
	contextMenu1 := ui.NewContextMenu(ui.ContextMenuRootProps{Items: func() []ui.MenuItemDeclaration {
		return []ui.MenuItemDeclaration{{ID: "copy", Label: "Copy"}}
	}, OnSelect: func(item ui.MenuSelectDetails, _ *native.Event) {
		fmt.Println(item.ID)
	}})
	return contextMenu1.Root().Children(func() *native.Node {
		return contextMenu1.Trigger(ui.ContextMenuTriggerProps{}).Children("Right-click here").NativeNode()
	}).NativeNode()
}
```

## 構成

- `contextMenu.Root`
- `contextMenu.Trigger`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `Appearance` | コア描画のネイティブメニューまたはピッカーに使う構造色とジオメトリです。 |
| `OnSelect` | コアが選択したメニュー項目を通知します。 |
| `Loop` | メニューレベルの端でハイライト移動を循環させます。 |
