オン／オフの押下状態を保持する、押下可能なコントロールです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ToggleExample() *native.Node {
	on, setOn := ui.CreateSignal(false)
	return ui.Toggle.Root(
		ui.ToggleProps{
			Pressed:         on,
			OnPressedChange: func(next bool, _ *native.Event) { setOn(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Toggle.Indicator(ui.PartProps{}), ui.Text("Notifications").
				Node})
		},
	)
}
```

## 構成

- `ui.Toggle.Root`
- `ui.Toggle.Indicator`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Pressed` | 制御された押下状態です。 |
| `DefaultPressed` | コンポーネント自身が状態を管理するときの初期押下状態です。 |
| `OnPressedChange` | コアが受け入れた押下状態を通知します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
