制御されたネイティブの日付または日時ピッカーです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"time"
)
```

## 使い方

```go
func SwiftUiDatePickerExample() *native.Node {
	value, setValue := ui.CreateSignal(float64(time.Now().UnixMilli()))
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.DatePicker(ui.SwiftUIDatePickerProps{
				Value:               value,
				DisplayedComponents: "dateAndTime",
				OnValueChange:       func(next float64, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | ミリ秒単位の Unix タイムスタンプです。`Min` と `Max` も同じ単位です。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `DisplayedComponents` | 日付、時刻、または日付と時刻の両方のフィールドを選びます。 |
| `Style` | `automatic`、`field`、`stepperField`、`graphical` のいずれかです。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
