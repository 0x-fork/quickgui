テキスト、SF Symbol、セマンティックロール、押下処理に対応したネイティブ SwiftUI Button です。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiButtonExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{
				Label:       "Save",
				SystemImage: "checkmark",
				OnPress:     func(*native.Event) { fmt.Println("Saved") },
				Modifiers:   []ui.SwiftUIModifier{ui.SwiftUI.ButtonStyle("borderedProminent")},
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `SystemImage` | SwiftUI Button のラベルとともに表示する SF Symbols 名です。 |
| `Role` | SwiftUI のセマンティックロールです：`default`、`cancel`、`destructive`。 |
| `OnPress` | ネイティブ SwiftUI Button がアクティブになったときに実行します。 |
| `Modifiers` | ホストしたコントロールへ順番に適用する SwiftUI View モディファイアです。 |
