値の範囲を制限できる、制御されたネイティブ数値 Stepper です。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiStepperExample() *native.Node {
	value, setValue := ui.CreateSignal(40.0)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Stepper(ui.SwiftUIStepperProps{
				Value:         value,
				Min:           0,
				Max:           100,
				Step:          1,
				Label:         "Value",
				OnValueChange: func(next float64, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `Step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `Label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
