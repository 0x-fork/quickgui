制御されたネイティブ SwiftUI オン／オフスイッチです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiToggleExample() {
	on, setOn := ui.CreateSignal(true)
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `IsOn` | 制御された SwiftUI Toggle の値です。 |
| `Label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `OnIsOnChange` | ネイティブ SwiftUI Toggle が受け入れた値を通知します。 |
| `Modifiers` | ホストしたコントロールへ順番に適用する SwiftUI View モディファイアです。 |
