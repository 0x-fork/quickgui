値選択とニュートラルな Xcode 風タブロールを持つ、ネイティブのセグメントピッカーです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiSegmentedControlExample() {
	value, setValue := ui.CreateSignal("list")
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.SegmentedControl(ui.SwiftUISegmentedControlProps{
				Selection:         value,
				Options:           []ui.SwiftUIPickerOption{{Value: "list", Label: "List"}, {Value: "grid", Label: "Grid"}},
				OnSelectionChange: func(next string, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Selection` | テーブル、ネイティブピッカー、カラーコントロールの制御選択値です。 |
| `Options` | 順序付きのネイティブピッカー選択肢です。 |
| `Label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `Role` | 保持ノードが公開するアクセシビリティロールです。 |
| `OnSelectionChange` | 選択したネイティブピッカー項目または色を通知します。 |
