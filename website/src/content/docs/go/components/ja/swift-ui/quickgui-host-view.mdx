SwiftUI 階層の中へ通常の QuickGUI サブツリーをリバースホストします。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiQuickguiHostViewExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.QuickGUIHostView(
				ui.SwiftUIQuickGUIHostViewProps{Width: 320, Height: 180},
				func() {
					ui.View(
						"QuickGUI inside SwiftUI",
						ui.Style{Width: "100%", Height: "100%", Padding: 16},
					)
				},
			)
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Width` | 宣言された論理幅です。 |
| `Height` | 宣言された論理高さです。 |
| `MatchContents` | ホストしたサブツリー固有の幅、高さ、またはその両方を使います。 |
| `Background` | リバースホストした QuickGUI WGPU サーフェスのクリアカラーです。 |
| `children` | コンポーネント内にマウントする内容です。 |
