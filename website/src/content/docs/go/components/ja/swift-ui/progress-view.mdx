確定または不確定のネイティブ SwiftUI 進捗インジケーターです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiProgressViewExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.ProgressView(ui.SwiftUIProgressViewProps{
				Value: 0.4,
				Total: 1,
				Label: "Uploading",
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Total` | 確定型の SwiftUI 進捗で使う分母です。 |
| `Label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `CurrentValueLabel` | 現在のネイティブ進捗または Gauge 値を表す読みやすいラベルです。 |
