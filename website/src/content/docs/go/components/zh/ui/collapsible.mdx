通过触发器显示或隐藏单个面板，同时保留无障碍状态。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func CollapsibleExample() *ui.Element {
	collapsible := ui.NewCollapsible()
	return collapsible.Root().Children(
		collapsible.Trigger().Child("Show details"),
		collapsible.Panel().Child("Mounted when opened"),
	)
}
```

## 结构

- `collapsible.Root`
- `collapsible.Trigger`
- `collapsible.Panel`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `KeepMounted` | 保持非活动内容已挂载，但禁用其显示。 |
