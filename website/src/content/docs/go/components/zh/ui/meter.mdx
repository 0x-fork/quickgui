显示已知范围内的标量测量值，并带有语义化的低值、高值和最佳区间。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func MeterExample(value func() *float64) *ui.Element {
	meter := ui.NewMeter().SetValue(value).Min(0).Max(100).Low(25).High(80).Optimum(50)
	return meter.Root().Children(
		meter.Label().Child("Disk used"),
		meter.Track().Child(meter.Indicator()),
		meter.Value(),
	)
}
```

## 结构

- `meter.Root`
- `meter.Track`
- `meter.Indicator`
- `meter.Label`
- `meter.Value`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `Low` | 仪表低值区间的上界。 |
| `High` | 仪表高值区间的下界。 |
| `Optimum` | 仪表值的理想点或区间。 |
