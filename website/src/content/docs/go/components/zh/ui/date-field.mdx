可通过键盘编辑的分段日期字段，日期部分会适配区域设置。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func DateFieldExample() *native.Node {
	value, setValue := ui.CreateSignal[*string](nil)
	dateField1 := ui.NewDateField(ui.DateFieldRootProps{Value: value, Format: "ymd", Min: "2026-01-01", Max: "2026-12-31", OnValueChange: func(next *string, _ *native.Event) {
		setValue(next)
	}})
	return dateField1.Root().Children(func() *native.Node {
		var children []*native.Node
		for _, segment := range []string{"year", "month", "day"} {
			children = append(children, dateField1.SegmentWith(ui.DateFieldSegmentProps{Segment: segment}).NativeNode())
		}
		return ui.Fragment(children)
	}).NativeNode()
}
```

## 结构

- `dateField.Root`
- `dateField.Segment`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
