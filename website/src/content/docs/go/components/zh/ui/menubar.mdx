管理窗口内的水平菜单栏及其菜单项。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func MenubarExample() *ui.Element {
	menubar := ui.NewMenubar().Count(2)
	items := make([]*ui.Element, 0, 2)
	for index, label := range []string{"File", "Edit"} {
		items = append(items, menubar.Item(ui.MenubarItemProps{Index: &index}).Child(label))
	}
	return menubar.Root().Children(items)
}
```

## 结构

- `menubar.Root`
- `menubar.Item`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Count` | 已声明的菜单栏项目数。 |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `OnActiveChange` | 报告当前持有移动焦点状态的项目。 |
