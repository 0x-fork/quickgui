在触发器上按下次要按钮时打开模型驱动的原生菜单。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ContextMenuExample() *native.Node {
	contextMenu1 := ui.NewContextMenu(ui.ContextMenuRootProps{Items: func() []ui.MenuItemDeclaration {
		return []ui.MenuItemDeclaration{{ID: "copy", Label: "Copy"}}
	}, OnSelect: func(item ui.MenuSelectDetails, _ *native.Event) {
		fmt.Println(item.ID)
	}})
	return contextMenu1.Root().Children(func() *native.Node {
		return contextMenu1.Trigger(ui.ContextMenuTriggerProps{}).Children("Right-click here").NativeNode()
	}).NativeNode()
}
```

## 结构

- `contextMenu.Root`
- `contextMenu.Trigger`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `Appearance` | 核心绘制的原生菜单或选择器所用的结构颜色和几何属性。 |
| `OnSelect` | 报告核心选中的菜单项。 |
| `Loop` | 到达菜单层级末端时循环高亮导航。 |
