窗口内模态框，支持焦点约束、关闭操作和精确的过渡结束时机。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func DialogExample() *ui.Element {
	dialog := ui.NewDialog()
	return dialog.Root().Children(
		dialog.Trigger().Child("Open dialog"),
		dialog.Portal().Children(
			dialog.Backdrop(),
			dialog.Viewport().Child(
				dialog.Popup().Children(
					dialog.Title().Child("Confirm action"),
					dialog.Description().Child("Review the details before continuing."),
					dialog.Close().Child("Cancel"),
				),
			),
		),
	)
}
```

## 结构

- `dialog.Root`
- `dialog.Trigger`
- `dialog.Portal`
- `dialog.Backdrop`
- `dialog.Viewport`
- `dialog.Popup`
- `dialog.Title`
- `dialog.Description`
- `dialog.Close`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `DismissOnEscape` | 允许按 Escape 键关闭界面。 |
| `ExitDuration` | 在精确的退出过渡时长内保持关闭中的内容已挂载。 |
