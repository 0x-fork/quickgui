数字编辑器，提供递增、递减和拖动调节部件。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func NumberFieldExample() *native.Node {
	value, setValue := ui.CreateSignal(8.0)
	numberField1 := ui.NewNumberField(ui.NumberFieldRootProps{Value: func() *float64 {
		current := value()
		return &current
	}, Min: 0, Max: 100, Step: 1, OnValueChange: func(next *float64, valid bool, _ *native.Event) {
		if valid && next != nil {
			setValue(*next)
		}
	}})
	return numberField1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{numberField1.Decrement(ui.PartProps{}).Children("−").NativeNode(), numberField1.Input(ui.NumberFieldInputProps{}).NativeNode(), numberField1.Increment(ui.PartProps{}).Children("+").NativeNode()})
	}).NativeNode()
}
```

## 结构

- `numberField.Root`
- `numberField.Group`
- `numberField.Input`
- `numberField.Increment`
- `numberField.Decrement`
- `numberField.ScrubArea`
- `numberField.ScrubAreaCursor`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `Step` | 键盘、指针或原生控件输入使用的步长。 |
| `OnValueChange` | 报告核心接受的值。 |
