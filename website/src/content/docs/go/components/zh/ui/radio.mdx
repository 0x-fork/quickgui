单个可选项，通常在 RadioGroup 中声明。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func RadioExample() *ui.Element {
	value, setValue := ui.CreateSignal("system")
	group := ui.NewRadioGroup(ui.RadioGroupProps{Value: func() *string {
		current := value()
		return &current
	}, OnValueChange: func(next string, _ *native.Event) {
		setValue(next)
	}})
	options := make([]*ui.Element, 0, 3)
	for _, value := range []string{"light", "dark", "system"} {
		radio := ui.NewRadio().Value(value)
		options = append(options, radio.Root().Children(
			radio.Indicator(),
			ui.Text(value),
		))
	}
	return group.Root().Children(options)
}
```

## 结构

- `radio.Root`
- `radio.Indicator`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Checked` | 受控的选中状态。 |
| `OnCheckedChange` | 报告核心接受的选中状态。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
