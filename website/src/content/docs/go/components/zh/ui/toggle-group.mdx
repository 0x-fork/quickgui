配合移动式键盘焦点管理单选或多选的按下值。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ToggleGroupExample() *ui.Element {
	values, setValues := ui.CreateSignal([]string{"bold"})
	group := ui.NewToggleGroup(ui.ToggleGroupProps{Multiple: true, Value: values, Items: []ui.ComponentItem{{Value: "bold"}, {Value: "italic"}}, OnValueChange: func(next []string, _ *native.Event) {
		setValues(next)
	}})
	return group.Root().Children(
		group.Item("bold").Child("Bold"),
		group.Item("italic").Child("Italic"),
	)
}
```

## 结构

- `toggleGroup.Root`
- `toggleGroup.Item`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Multiple` | 选择单选或多选策略。 |
| `OnValueChange` | 报告核心接受的值。 |
