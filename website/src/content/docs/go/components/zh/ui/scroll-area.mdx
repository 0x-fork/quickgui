组合可滚动视口，以及可由调用方设置样式的滚动条、滑块和角落。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ScrollAreaExample() {
	ui.ScrollArea.Root(
		ui.ScrollAreaRootProps{
			ViewportSize: func() ui.Extent { return ui.Extent{Width: 320, Height: 160} },
			ContentSize:  func() ui.Extent { return ui.Extent{Width: 320, Height: 880} },
		},
		func() {
			state := ui.UseScrollAreaState()
			ui.ScrollArea.Viewport(
				ui.PartProps{Style: ui.Style().
					Width(320).
					Height(160).
					Overflow("hidden")},
				func() {
					ui.ScrollArea.Content(
						ui.PartProps{Style: func() ui.StyleBuilder {
							return ui.Style().
								Transform(fmt.Sprintf("translateY(%gpx)", -state().
									Offset.Y))
						}},
						func() {
							for index := range 40 {
								ui.Text("Row ", index).Height(22)
							}
						},
					)
				},
			)
			ui.ScrollArea.Scrollbar(
				ui.ScrollAreaScrollbarProps{Orientation: "vertical"},
				func() { ui.ScrollArea.Thumb(ui.ScrollAreaThumbProps{Orientation: "vertical"}) },
			)
		},
	)
}
```

## 结构

- `ui.ScrollArea.Root`
- `ui.ScrollArea.Viewport`
- `ui.ScrollArea.Content`
- `ui.ScrollArea.Scrollbar`
- `ui.ScrollArea.Thumb`
- `ui.ScrollArea.Corner`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `ViewportSize` | 声明的滚动视口范围。 |
| `ContentSize` | 声明的滚动内容范围。 |
| `OverflowEdgeThreshold` | 仍视为位于边缘的最大距离。 |
| `OnScrollStateChange` | 报告限制后的偏移量和派生的溢出状态。 |
