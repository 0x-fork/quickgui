支持键盘导航的月历网格，用于选择单个日期。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func CalendarExample(weeks [][]string) *native.Node {
	calendar1 := ui.NewCalendar(ui.CalendarRootProps{DefaultValue: "2026-09-03"})
	return calendar1.Root().Children(func() *native.Node {
		var children []*native.Node
		for index, week := range weeks {
			children = append(children, calendar1.WeekWith(ui.CalendarWeekProps{Index: &index}).Children(func() *native.Node {
				var children []*native.Node
				for _, day := range week {
					children = append(children, calendar1.DayWith(ui.CalendarDayProps{Day: day}).Children(day).NativeNode())
				}
				return ui.Fragment(children)
			}).NativeNode())
		}
		return ui.Fragment(children)
	}).NativeNode()
}
```

## 结构

- `calendar.Root`
- `calendar.Week`
- `calendar.Day`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `FirstWeekday` | 第一列对应的星期；周一为 0，周日为 6。 |
| `OnValueChange` | 报告核心接受的值。 |
