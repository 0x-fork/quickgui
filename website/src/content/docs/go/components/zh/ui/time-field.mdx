可通过键盘编辑的分段时间字段，包含时、分、秒和上下午部分。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TimeFieldExample() *native.Node {
	timeField1 := ui.NewTimeField(ui.TimeFieldRootProps{DefaultValue: "09:30", Hour12: true})
	return timeField1.Root().Children(func() *native.Node {
		var children []*native.Node
		for _, segment := range []string{"hour", "minute", "period"} {
			children = append(children, timeField1.SegmentWith(ui.TimeFieldSegmentProps{Segment: segment}).NativeNode())
		}
		return ui.Fragment(children)
	}).NativeNode()
}
```

## 结构

- `timeField.Root`
- `timeField.Segment`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Hour12` | 添加上午/下午分段，并使用 12 小时制。 |
| `ShowSeconds` | 挂载秒数分段。 |
| `OnValueChange` | 报告核心接受的值。 |
