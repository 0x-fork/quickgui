用于布局、绘制、指针输入和无障碍支持的通用保留式容器。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ViewExample() {
	ui.View(
		func() {
			ui.Text("Hello from Go")
			ui.Button("Continue", ui.OnClick(func() {}))
		},
		ui.Padding(20),
		ui.Gap(12),
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
| `OnClick` | 在核心完成激活判定后运行。 |
| `Ref` | 接收保留式原生节点。 |
