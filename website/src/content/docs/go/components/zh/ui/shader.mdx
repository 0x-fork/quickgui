使用有限数量的数值着色器参数绘制经过验证的 WGSL。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ShaderExample(source string, parameters func() []float64) {
	ui.Shader(
		ui.Value(source),
		ui.ShaderParameters(parameters),
	).Width(320).Height(180)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 组件所需的文件系统路径、数据 URL、SVG 文档或着色器源码。 |
| `ShaderParameters` | 最多 16 个数值，打包到固定的着色器参数向量中。 |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
