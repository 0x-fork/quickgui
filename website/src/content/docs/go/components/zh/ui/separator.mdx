具备语义的水平或垂直分隔线，不附带视觉样式。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SeparatorExample() {
	ui.Separator.Root(ui.SeparatorProps{
		Orientation: "horizontal",
		PartProps:   ui.PartProps{Style: ui.Styles(ui.Height(1), ui.BackgroundColor("#d1d5db"))},
	})
}
```

## 结构

- `ui.Separator.Root`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `Style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
