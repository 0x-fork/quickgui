多行文本编辑基础组件，受控值约定与 Input 相同。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TextAreaExample() {
	value, setValue := ui.CreateSignal("")
	ui.TextArea(
		ui.Value(value),
		ui.Placeholder("Write here"),
		ui.OnInput(func(event *native.Event) { setValue(event.Value) }),
	).Width(320).Height(96)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Placeholder` | 可编辑值为空时显示的文本。 |
| `OnInput` | 报告原生编辑输入。 |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
