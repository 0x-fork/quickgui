将 QuickGUI 核心路由投影到 QuickGUI UI，支持嵌套布局和容量受限的内存历史。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func RouterExample() *native.Node {
	return ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route(
				"/",
				func() *native.Node {
					return ui.Link(
						ui.LinkProps{Href: "/settings"},
						"Settings",
					)
				},
			),
			ui.Route(
				"/settings",
				func() *ui.Element { return ui.Text("Settings") },
			),
		},
		Fallback: func() *ui.Element { return ui.Text("Page not found") },
	})
}
```

## 结构

- `ui.Router`
- `ui.Route`
- `ui.Layout`
- `ui.Link`
- `ui.Outlet`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `InitialPath` | 有界内存历史的初始目标地址。 |
| `Fallback` | 没有路由匹配时渲染的内容。 |
| `Routes` | 使用 `ui.Route` 和 `ui.Layout` 创建的静态路由声明。 |
| `Path` | 绝对路由模式或相对于父路由的模式。 |
| `Component` | 路由匹配时渲染的组件。 |
| `Href` | QuickGUI 路由器解析的目标地址。 |
