可完全组合的菜单，支持子菜单、分组、链接、复选项和单选项。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func MenuExample() *ui.Element {
	menu := ui.NewMenu()
	return menu.Root().Children(
		menu.Trigger().Child("Actions"),
		menu.Positioner().Child(
			menu.Popup().Child(
				menu.Item(ui.MenuItemProps{Value: "copy", Label: "Copy", PartProps: ui.PartProps{OnClick: func(*native.Event) {
					fmt.Println("Copy")
				}}}).Child("Copy"),
			),
		),
	)
}
```

## 结构

- `menu.Root`
- `menu.Trigger`
- `menu.Portal`
- `menu.Backdrop`
- `menu.Positioner`
- `menu.Popup`
- `menu.Arrow`
- `menu.Item`
- `menu.LinkItem`
- `menu.SubmenuRoot`
- `menu.SubmenuTrigger`
- `menu.Group`
- `menu.GroupLabel`
- `menu.RadioGroup`
- `menu.RadioItem`
- `menu.RadioItemIndicator`
- `menu.CheckboxItem`
- `menu.CheckboxItemIndicator`
- `menu.Separator`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `LoopFocus` | 到达当前菜单层级末端时循环键盘高亮。 |
