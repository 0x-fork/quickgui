筛选自由输入文本的建议项，无需选中某个值。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func AutocompleteExample() *ui.Element {
	autocomplete := ui.NewAutocomplete(ui.AutocompleteRootProps{PickerInputProps: ui.PickerInputProps{PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
		return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
	}}, Placeholder: "Find a language", OnInputValueChange: func(query string, _ *native.Event) {
		fmt.Println(query)
	}}})
	return autocomplete.Root()
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `InputValue` | Combobox 或 Autocomplete 使用的可编辑查询文本。 |
| `FilterMode` | 由核心管理的包含、前缀、模糊或禁用筛选模式。 |
| `OnInputValueChange` | 报告核心保留的可编辑查询文本。 |
| `OnCommit` | 报告一次明确的提交边界及最终值详情。 |
