表示确定或不确定的任务进度，可组合标签和轨道。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ProgressExample(progress func() *float64) *ui.Element {
	bar := ui.NewProgress().SetValue(progress).Max(100)
	return bar.Root().Children(
		bar.Label().Child("Uploading"),
		bar.Track().Child(bar.Indicator()),
		bar.Value(),
	)
}
```

## 结构

- `progress.Root`
- `progress.Track`
- `progress.Indicator`
- `progress.Label`
- `progress.Value`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Max` | 可接受的最大值。 |
| `Indeterminate` | 表示完成量未知的进度。 |
| `ValueText` | 辅助技术优先使用的易读值。 |
| `OnStatusChange` | 报告派生状态、格式化值和完成比例。 |
