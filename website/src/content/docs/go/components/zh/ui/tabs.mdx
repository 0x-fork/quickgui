在带标签的面板之间切换，支持自动或手动键盘激活。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TabsExample() *ui.Element {
	tabs := ui.NewTabs().DefaultValue("overview").Activation("automatic")
	return tabs.Root().Children(
		tabs.List().Children(
			tabs.Tab("overview").Child("Overview"),
			tabs.Tab("settings").Child("Settings"),
		),
		tabs.Panel("overview").Child("Overview content"),
		tabs.Panel("settings").Child("Settings content"),
	)
}
```

## 结构

- `tabs.Root`
- `tabs.List`
- `tabs.Tab`
- `tabs.Indicator`
- `tabs.Panel`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `Activation` | 焦点或明确按下操作是否会激活标签页。 |
