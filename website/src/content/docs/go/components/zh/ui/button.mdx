可访问的按压目标，可自行设置样式并组合文本或其他内容。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ButtonExample(save func()) *ui.Element {
	return ui.Button(
		"Save changes",
	).
		Height(40).
		PaddingLeft(16).
		PaddingRight(16).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
		OnClick(save)

}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
| `OnClick` | 在核心完成激活判定后运行。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
