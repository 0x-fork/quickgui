虚拟化表格集合，包含表头、行和单元格部件。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TableExample(rows []string) {
	ui.Table.Root(
		ui.TableRootProps{
			Columns: func() []ui.TableColumnDeclaration {
				return []ui.TableColumnDeclaration{{ID: "name", Label: "Name", Track: "1fr", Sortable: true}}
			},
			RowCount:     func() float64 { return float64(len(rows)) },
			RowHeight:    26,
			HeaderHeight: 28,
			PartProps:    ui.PartProps{Style: ui.Styles(ui.Height(260), ui.OverflowY("scroll"))},
		},
		func() {
			ui.Table.Header(ui.TableHeaderProps{Column: "name"}, "Name")
			for index, name := range rows {
				ui.Table.Row(
					ui.TableRowProps{Index: index},
					func() {
						ui.Table.Cell(
							ui.TableCellProps{Column: "name"},
							name,
						)
					},
				)
			}
		},
	)
}
```

## 结构

- `ui.Table.Root`
- `ui.Table.Header`
- `ui.Table.Row`
- `ui.Table.Cell`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Columns` | 虚拟表格的列声明。 |
| `RowCount` | 逻辑总行数。 |
| `RowHeight` | 每个虚拟化行的逻辑高度。 |
| `SelectionMode` | 允许表格单选或多选。 |
| `Selection` | 表格、原生选择器或颜色控件的受控选中值。 |
