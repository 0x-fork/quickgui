在同一个图例和共享语义状态下组织相关字段。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func FieldsetExample(saving func() bool) *native.Node {
	return ui.Fieldset.Root(
		ui.PartProps{Disabled: saving},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Fieldset.Legend(ui.PartProps{}, "Profile"),
				ui.Field.Root(
					ui.FieldRootProps{},
					func() *native.Node {
						return ui.Fragment([]*native.Node{ui.Field.Label(ui.FieldLabelProps{}, "Name"),
							ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Placeholder: "Ada"}})})
					},
				)})
		},
	)
}
```

## 结构

- `ui.Fieldset.Root`
- `ui.Fieldset.Legend`
- `ui.Fieldset.Description`
- `ui.Fieldset.Control`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
| `children` | 挂载在组件内部的内容。 |
| `Style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
