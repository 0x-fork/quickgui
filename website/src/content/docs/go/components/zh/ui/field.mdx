将控件与标签、说明、验证状态和错误信息关联起来。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func FieldExample() *native.Node {
	email, setEmail := ui.CreateSignal("")
	return ui.Field.Root(
		ui.FieldRootProps{
			Required: true,
			Filled:   func() bool { return email() != "" },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Field.Label(ui.FieldLabelProps{}, "Email"),
				ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{
					Value:       email,
					Placeholder: "you@example.com",
					OnInput:     func(event *native.Event) { setEmail(event.Value) },
				}}),
				ui.Field.Description(ui.PartProps{}, "Used for receipts"),
				ui.Field.Error(ui.PartProps{}, "Enter a valid email address")})
		},
	)
}
```

## 结构

- `ui.Field.Root`
- `ui.Field.Item`
- `ui.Field.Label`
- `ui.Field.Control`
- `ui.Field.Validity`
- `ui.Field.Description`
- `ui.Field.Error`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Invalid` | 将无效状态传递给字段及其各部件。 |
| `Required` | 将值标记为验证和表单提交所必需。 |
| `ValidationMessage` | 向错误内容和无障碍 API 暴露的有限长度消息。 |
| `ValidationMode` | 选择触发验证的交互边界。 |
| `OnValidationChange` | 报告核心选择的验证触发条件和时机。 |
