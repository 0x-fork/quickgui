二态或不确定状态的选择控件，指示器可独立设置样式。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func CheckboxExample() {
	checked, setChecked := ui.CreateSignal(false)
	ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() {
			ui.Checkbox.Indicator(
				ui.PartProps{Style: ui.Styles(
					ui.Width(16),
					ui.Height(16),
					ui.BorderWidth(1),
					ui.BorderRadius(4),
					ui.BorderColor("#2563eb"),
					ui.Display("flex"),
					ui.AlignItems("center"),
					ui.JustifyContent("center"),
				)},
				func() {
					ui.Show(
						checked,
						func() {
							ui.SVG(
								ui.Value(`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 12 12"><path d="M3 6l2 2 4-4" fill="none" stroke="#2563eb" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"/></svg>`),
								ui.Width(12),
								ui.Height(12),
							)
						},
					)
				},
			)
			ui.Text("Remember me")
		},
	)
}
```

指示器不附带样式。此示例保留外框，仅在选中时显示 SVG。设置 `ReadOnly: true` 后，控件仍可获得焦点，但指针或键盘操作不会改变其值。

## 结构

- `ui.Checkbox.Root`
- `ui.Checkbox.Indicator`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Checked` | 受控的选中状态。 |
| `DefaultChecked` | 组件自行管理状态时的初始选中状态。 |
| `OnCheckedChange` | 报告核心接受的选中状态。 |
| `ReadOnly` | 阻止值变化，但仍允许控件获得焦点。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
