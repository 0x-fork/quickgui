在原生浮窗中渲染的紧凑型模型驱动菜单。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func PopoverMenuExample() *native.Node {
	popoverMenu1 := ui.NewPopoverMenu(ui.PopoverMenuRootProps{Items: func() []ui.MenuItemDeclaration {
		return []ui.MenuItemDeclaration{{ID: "copy", Label: "Copy"}, {ID: "paste", Label: "Paste"}}
	}, OnSelect: func(item ui.MenuSelectDetails, _ *native.Event) {
		fmt.Println(item.ID)
	}})
	return popoverMenu1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{popoverMenu1.Trigger(ui.PartProps{}).Children("Edit").NativeNode(), popoverMenu1.Popup(ui.PopoverMenuPopupProps{}).NativeNode()})
	}).NativeNode()
}
```

## 结构

- `popoverMenu.Root`
- `popoverMenu.Trigger`
- `popoverMenu.Popup`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `Appearance` | 核心绘制的原生菜单或选择器所用的结构颜色和几何属性。 |
| `Open` | 受控的打开状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `OnSelect` | 报告核心选中的菜单项。 |
