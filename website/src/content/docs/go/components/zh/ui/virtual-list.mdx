为长列表或不等高集合布局并绘制可见部分。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func VirtualListExample(rows []string) {
	ui.VirtualList(
		func() {
			for _, row := range rows {
				ui.Text(row, ui.Height(36))
			}
		},
		ui.Height(320),
		ui.EstimatedItemHeight(36),
		ui.Overscan(6),
		ui.FollowMode("normal"),
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `EstimatedItemHeight` | 虚拟化使用的初始逻辑行高估计值。 |
| `Overscan` | 在可见范围前后额外挂载的行数。 |
| `ListAlignment` | 将较短的列表内容固定在顶部或底部。 |
| `FollowMode` | 选择普通滚动或跟随末尾模式。 |
| `children` | 挂载在组件内部的内容。 |
