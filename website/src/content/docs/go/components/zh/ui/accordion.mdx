管理一个或多个可展开区域及其键盘焦点。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func AccordionExample() *ui.Element {
	accordion := ui.NewAccordion().Multiple(true)
	return accordion.Root().Child(
		accordion.Item("details").Children(
			accordion.Header().Child(
				accordion.Trigger().Child("Details"),
			),
			accordion.Panel().Child("Mounted when opened"),
		),
	)
}
```

## 结构

- `accordion.Root`
- `accordion.Item`
- `accordion.Header`
- `accordion.Trigger`
- `accordion.Panel`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `Multiple` | 允许选择或打开多个值。 |
| `KeepMounted` | 保持非活动内容已挂载，但禁用其显示。 |
