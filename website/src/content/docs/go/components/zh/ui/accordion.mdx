管理一个或多个可展开区域及其键盘焦点。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func AccordionExample() *native.Node {
	return ui.Accordion.Root(
		ui.AccordionRootProps{Multiple: true},
		func() *native.Node {
			return ui.Accordion.Item(
				ui.AccordionItemProps{Value: "details"},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Accordion.Header(
						ui.PartProps{},
						func() *native.Node {
							return ui.Accordion.Trigger(
								ui.PartProps{},
								"Details",
							)
						},
					),
						ui.Accordion.Panel(ui.PartProps{}, "Mounted when opened")})
				},
			)
		},
	)
}
```

## 结构

- `ui.Accordion.Root`
- `ui.Accordion.Item`
- `ui.Accordion.Header`
- `ui.Accordion.Trigger`
- `ui.Accordion.Panel`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `Multiple` | 允许选择或打开多个值。 |
| `KeepMounted` | 保持非活动内容已挂载，但禁用其显示。 |
