无需加载外部 SVG 资源即可渲染完整的内联 SVG 文档。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SvgExample() {
	ui.SVG().
		Width(20).
		Height(20).
		TextColor("#2563eb").
		Value(`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path fill="currentColor" d="M11 4h2v7h7v2h-7v7h-2v-7H4v-2h7z"/></svg>`)

}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 组件所需的文件系统路径、数据 URL、SVG 文档或着色器源码。 |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
