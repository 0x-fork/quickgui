单滑块或多滑块范围输入，指针与键盘交互由核心管理。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SliderExample() {
	volume, setVolume := ui.CreateSignal([]float64{40})
	ui.Slider.Root(
		ui.SliderRootProps{
			Value:         volume,
			Min:           0,
			Max:           100,
			Step:          1,
			OnValueChange: func(next []float64, _ *native.Event) { setVolume(next) },
		},
		func() {
			ui.Slider.Label(ui.PartProps{}, "Volume")
			ui.Slider.Control(
				ui.PartProps{Style: ui.Styles(ui.Width(240), ui.Height(24))},
				func() {
					ui.Slider.Track(
						ui.PartProps{},
						func() { ui.Slider.Indicator(ui.PartProps{}) },
					)
					ui.Slider.Thumb(ui.SliderThumbProps{})
				},
			)
			ui.Slider.Value(ui.PartProps{})
		},
	)
}
```

## 结构

- `ui.Slider.Root`
- `ui.Slider.Label`
- `ui.Slider.Value`
- `ui.Slider.Control`
- `ui.Slider.Track`
- `ui.Slider.Range`
- `ui.Slider.Indicator`
- `ui.Slider.Thumb`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `Step` | 键盘、指针或原生控件输入使用的步长。 |
| `OnValueChange` | 报告核心接受的值。 |
