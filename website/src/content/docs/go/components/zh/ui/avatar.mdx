显示图像；图像不可用时显示后备内容。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func AvatarExample(path string) *ui.Element {
	avatar := ui.NewAvatar()
	return avatar.Root().AriaLabel("Ada Lovelace").Children(
		avatar.Image(ui.AvatarImageProps{Src: path}),
		avatar.Fallback().Child("AL"),
	)
}
```

## 结构

- `avatar.Root`
- `avatar.Image`
- `avatar.Fallback`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `AriaLabel` | 当组件的可见部件可能变化时使用的无障碍名称。 |
| `Src` | 头像图像的文件系统路径、文件 URL 或 base64 数据 URL。 |
| `Delay` | 打开前由核心管理的延迟（毫秒）。 |
| `OnLoadingStatusChange` | 报告头像图像每次加载状态变化。 |
