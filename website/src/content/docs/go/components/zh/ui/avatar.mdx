显示图像；图像不可用时显示后备内容。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func AvatarExample(path string) *native.Node {
	return ui.Avatar.Root(
		ui.AvatarRootProps{PartProps: ui.PartProps{AriaLabel: "Ada Lovelace"}},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Avatar.Image(ui.AvatarImageProps{Src: path}),
				ui.Avatar.Fallback(ui.AvatarFallbackProps{}, "AL")})
		},
	)
}
```

## 结构

- `ui.Avatar.Root`
- `ui.Avatar.Image`
- `ui.Avatar.Fallback`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `AriaLabel` | 当组件的可见部件可能变化时使用的无障碍名称。 |
| `Src` | 头像图像的文件系统路径、文件 URL 或 base64 数据 URL。 |
| `Delay` | 打开前由核心管理的延迟（毫秒）。 |
| `OnLoadingStatusChange` | 报告头像图像每次加载状态变化。 |
