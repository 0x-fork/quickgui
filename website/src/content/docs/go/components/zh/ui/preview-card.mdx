在触发器旁显示更丰富的悬停或聚焦预览，不改变当前页面。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func PreviewCardExample() {
	ui.PreviewCard.Root(
		ui.PreviewCardRootProps{Placement: "bottom-start"},
		func() {
			ui.PreviewCard.Trigger(ui.PreviewCardTriggerProps{Delay: 350}, "@ada")
			ui.PreviewCard.Positioner(
				ui.PartProps{},
				func() {
					ui.PreviewCard.Popup(
						ui.PartProps{},
						"Ada Lovelace",
					)
				},
			)
		},
	)
}
```

## 结构

- `ui.PreviewCard.Root`
- `ui.PreviewCard.Trigger`
- `ui.PreviewCard.Portal`
- `ui.PreviewCard.Backdrop`
- `ui.PreviewCard.Positioner`
- `ui.PreviewCard.Popup`
- `ui.PreviewCard.Arrow`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `Delay` | 打开前由核心管理的延迟（毫秒）。 |
| `CloseDelay` | 关闭前由核心管理的延迟（毫秒）。 |
| `Placement` | 碰撞处理前的首选放置方向。 |
