在触发器旁显示更丰富的悬停或聚焦预览，不改变当前页面。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func PreviewCardExample() *native.Node {
	previewCard1 := ui.NewPreviewCard(ui.PreviewCardRootProps{Placement: "bottom-start"})
	return previewCard1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{previewCard1.Trigger(ui.PreviewCardTriggerProps{Delay: 350}).Children("@ada").NativeNode(), previewCard1.Positioner(ui.PartProps{}).Children(func() *native.Node {
			return previewCard1.Popup(ui.PartProps{}).Children("Ada Lovelace").NativeNode()
		}).NativeNode()})
	}).NativeNode()
}
```

## 结构

- `previewCard.Root`
- `previewCard.Trigger`
- `previewCard.Portal`
- `previewCard.Backdrop`
- `previewCard.Positioner`
- `previewCard.Popup`
- `previewCard.Arrow`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `Delay` | 打开前由核心管理的延迟（毫秒）。 |
| `CloseDelay` | 关闭前由核心管理的延迟（毫秒）。 |
| `Placement` | 碰撞处理前的首选放置方向。 |
