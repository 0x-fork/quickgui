管理单选状态以及 Radio 项之间的键盘移动。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func RadioGroupExample() {
	value, setValue := ui.CreateSignal("system")
	ui.RadioGroup.Root(
		ui.RadioGroupProps{
			Value:         func() *string { current := value(); return &current },
			OnValueChange: func(next string, _ *native.Event) { setValue(next) },
		},
		func() {
			for _, option := range []string{"light", "dark", "system"} {
				ui.Radio.Root(
					ui.RadioProps{Value: option},
					func() { ui.Radio.Indicator(ui.PartProps{}); ui.Text(option) },
				)
			}
		},
	)
}
```

## 结构

- `ui.RadioGroup.Root`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `ReadOnly` | 阻止值变化，但仍允许控件获得焦点。 |
| `Required` | 将值标记为验证和表单提交所必需。 |
