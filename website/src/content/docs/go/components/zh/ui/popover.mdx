在当前窗口中，将调用方设置样式的内容放在锚点旁。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func PopoverExample() {
	ui.Popover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.Popover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.Popover.Positioner(
				ui.PopoverPositionerProps{},
				func() {
					ui.Popover.Popup(
						ui.PopoverPopupProps{PartProps: ui.PartProps{Style: ui.Style().
							Width(240).
							Padding(16)}},
						func() {
							ui.Popover.Title(ui.PartProps{}, "Account")
							ui.Popover.Close(ui.PartProps{}, "Done")
						},
					)
				},
			)
		},
	)
}
```

## 结构

- `ui.Popover.Root`
- `ui.Popover.Trigger`
- `ui.Popover.Content`
- `ui.Popover.Portal`
- `ui.Popover.Backdrop`
- `ui.Popover.Positioner`
- `ui.Popover.Popup`
- `ui.Popover.Arrow`
- `ui.Popover.Viewport`
- `ui.Popover.Title`
- `ui.Popover.Description`
- `ui.Popover.Close`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `Side` | 碰撞处理前的首选放置方向。 |
| `Align` | 在放置交叉轴上的首选对齐方式。 |
| `Modal` | 将焦点限制在界面内，并阻止与后方内容交互。 |
