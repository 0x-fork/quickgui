在一套移动焦点的键盘模型下组织操作和输入。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ToolbarExample() *native.Node {
	toolbar1 := ui.NewToolbar(ui.ToolbarRootProps{Items: []ui.ComponentItem{{Value: "select"}, {Value: "draw"}}, DefaultActive: "select"})
	return toolbar1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{toolbar1.Item(ui.ToolbarItemProps{Value: "select"}).Children("Select").NativeNode(), toolbar1.Item(ui.ToolbarItemProps{Value: "draw"}).Children("Draw").NativeNode()})
	}).NativeNode()
}
```

## 结构

- `toolbar.Root`
- `toolbar.Item`
- `toolbar.Button`
- `toolbar.Link`
- `toolbar.Input`
- `toolbar.Group`
- `toolbar.Separator`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `Active` | 持有当前活动状态或移动焦点状态的受控项目。 |
| `DefaultActive` | 非受控组件的初始活动项目。 |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `OnActiveChange` | 报告当前持有移动焦点状态的项目。 |
