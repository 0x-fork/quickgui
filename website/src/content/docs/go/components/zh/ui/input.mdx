由核心管理的受控文本编辑器，支持原生键盘和文本服务。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func InputExample() {
	value, setValue := ui.CreateSignal("")
	ui.Input().
		Value(value()).
		Placeholder("Write here").
		OnInputEvent(func(event *native.Event) { setValue(event.Value) }).
		Width(320).Height(32)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Placeholder` | 可编辑值为空时显示的文本。 |
| `Multiline` | 启用多行文本编辑。 |
| `OnInput` | 报告原生编辑输入。 |
