创建可调整大小的面板，分隔手柄支持指针和键盘操作。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SplitterExample() {
	ui.Splitter.Root(
		ui.SplitterRootProps{
			DefaultValue: []float64{240, 400},
			Panes:        []ui.SplitterPaneDeclaration{{}, {}},
			PartProps:    ui.PartProps{Style: ui.Styles(ui.Display("flex"), ui.Height(240))},
		},
		func() {
			first, second := 0, 1
			ui.Splitter.Pane(ui.SplitterPaneProps{Index: &first}, "Sidebar")
			ui.Splitter.Handle(ui.SplitterPaneProps{
				Index: &first,
				PartProps: ui.PartProps{Style: ui.Styles(
					ui.Width(6),
					ui.Cursor("col-resize"),
				)},
			})
			ui.Splitter.Pane(ui.SplitterPaneProps{Index: &second}, "Content")
		},
	)
}
```

## 结构

- `ui.Splitter.Root`
- `ui.Splitter.Pane`
- `ui.Splitter.Handle`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Panes` | 每个面板的最小尺寸和折叠声明。 |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `OnSizesChange` | 在核心调整大小后报告完整的面板尺寸集合。 |
