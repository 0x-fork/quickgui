创建可调整大小的面板，分隔手柄支持指针和键盘操作。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SplitterExample() *native.Node {
	splitter1 := ui.NewSplitter(ui.SplitterRootProps{DefaultValue: []float64{240, 400}, Panes: []ui.SplitterPaneDeclaration{{}, {}}, PartProps: ui.PartProps{Style: ui.Style().Display("flex").Height(240)}})
	return splitter1.Root().Children(func() *native.Node {
		var children []*native.Node
		first, second := 0, 1
		children = append(children, splitter1.PaneWith(ui.SplitterPaneProps{Index: &first}).Children("Sidebar").NativeNode())
		children = append(children, splitter1.HandleWith(ui.SplitterPaneProps{Index: &first, PartProps: ui.PartProps{Style: ui.Style().Width(6).Cursor("col-resize")}}).NativeNode())
		children = append(children, splitter1.PaneWith(ui.SplitterPaneProps{Index: &second}).Children("Content").NativeNode())
		return ui.Fragment(children)
	}).NativeNode()
}
```

## 结构

- `splitter.Root`
- `splitter.Pane`
- `splitter.Handle`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Panes` | 每个面板的最小尺寸和折叠声明。 |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `OnSizesChange` | 在核心调整大小后报告完整的面板尺寸集合。 |
