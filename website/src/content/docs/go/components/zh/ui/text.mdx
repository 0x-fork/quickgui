使用继承的排版、文本选择和无障碍属性来排版并绘制 Unicode 文本。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			"Count: ",
			count,
			ui.Style{FontSize: 20},
		)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `ui.Style{}` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
| `Ref` | 接收保留式原生节点。 |
