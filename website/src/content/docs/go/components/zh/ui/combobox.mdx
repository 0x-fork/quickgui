将可编辑文本、筛选、可选标签项和原生建议界面结合在一起。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ComboboxExample() *ui.Element {
	value, setValue := ui.CreateSignal[*string](nil)
	combobox := ui.NewCombobox(ui.ComboboxRootProps{PickerInputProps: ui.PickerInputProps{PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
		return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
	}}, Placeholder: "Choose a language"}, Value: value, OnValueChange: func(next *string, _ *native.Event) {
		setValue(next)
	}})
	return combobox.Root()
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `InputValue` | Combobox 或 Autocomplete 使用的可编辑查询文本。 |
| `Multiple` | 允许选择或打开多个值。 |
| `FilterMode` | 由核心管理的包含、前缀、模糊或禁用筛选模式。 |
| `OnValueChange` | 报告核心接受的值。 |
