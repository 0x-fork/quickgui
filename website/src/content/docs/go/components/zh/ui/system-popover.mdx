在独立的原生子窗口中显示 QuickGUI 内容，可超出所属窗口边界。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SystemPopoverExample() {
	ui.SystemPopover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.SystemPopover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.SystemPopover.Content(
				ui.PopoverContentProps{
					Width:     240,
					Height:    120,
					Placement: "bottom-start",
				},
				"Account settings",
			)
		},
	)
}
```

## 结构

- `ui.SystemPopover.Root`
- `ui.SystemPopover.Trigger`
- `ui.SystemPopover.Content`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `Width` | 声明的逻辑宽度。 |
| `Height` | 声明的逻辑高度。 |
| `Placement` | 请求的原生子窗口放置位置。 |
