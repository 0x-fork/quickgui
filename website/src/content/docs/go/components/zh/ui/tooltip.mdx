在核心精确控制的延迟后显示辅助信息，并支持 Provider 级预热。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TooltipExample() *ui.Element {
	provider := ui.NewTooltipProvider(ui.TooltipProviderProps{Delay: 500})
	tooltip := ui.NewTooltip().Side("top")
	return provider.Root().Child(
		tooltip.Root().Children(
			tooltip.Trigger().Child("Hover me"),
			tooltip.Positioner().Child(
				tooltip.Popup().Child("Helpful information"),
			),
		),
	)
}
```

## 结构

- `tooltip.Provider`
- `tooltip.Root`
- `tooltip.Trigger`
- `tooltip.Portal`
- `tooltip.Positioner`
- `tooltip.Popup`
- `tooltip.Arrow`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `Delay` | 打开前由核心管理的延迟（毫秒）。 |
| `CloseDelay` | 关闭前由核心管理的延迟（毫秒）。 |
| `Side` | 碰撞处理前的首选放置方向。 |
| `Hoverable` | 允许指针移入 Tooltip 而不会将其关闭。 |
