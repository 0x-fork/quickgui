在核心精确控制的延迟后显示辅助信息，并支持 Provider 级预热。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TooltipExample() *native.Node {
	return ui.Tooltip.Provider(
		ui.TooltipProviderProps{Delay: 500},
		func() *native.Node {
			return ui.Tooltip.Root(
				ui.TooltipRootProps{Side: "top"},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Tooltip.Trigger(ui.TooltipTriggerProps{}, "Hover me"),
						ui.Tooltip.Positioner(
							ui.TooltipPositionerProps{},
							func() *native.Node {
								return ui.Tooltip.Popup(
									ui.PartProps{},
									"Helpful information",
								)
							},
						)})
				},
			)
		},
	)
}
```

## 结构

- `ui.Tooltip.Provider`
- `ui.Tooltip.Root`
- `ui.Tooltip.Trigger`
- `ui.Tooltip.Portal`
- `ui.Tooltip.Positioner`
- `ui.Tooltip.Popup`
- `ui.Tooltip.Arrow`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `Delay` | 打开前由核心管理的延迟（毫秒）。 |
| `CloseDelay` | 关闭前由核心管理的延迟（毫秒）。 |
| `Side` | 碰撞处理前的首选放置方向。 |
| `Hoverable` | 允许指针移入 Tooltip 而不会将其关闭。 |
