原生分段选择器，支持值选择和中性的 Xcode 风格标签页角色。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiSegmentedControlExample() *native.Node {
	value, setValue := ui.CreateSignal("list")
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.SegmentedControl(ui.SwiftUISegmentedControlProps{
				Selection:         value,
				Options:           []ui.SwiftUIPickerOption{{Value: "list", Label: "List"}, {Value: "grid", Label: "Grid"}},
				OnSelectionChange: func(next string, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Selection` | 表格、原生选择器或颜色控件的受控选中值。 |
| `Options` | 有序的原生选择器选项。 |
| `Label` | 原生 SwiftUI 控件的可见标签。 |
| `Role` | 保留节点暴露的无障碍角色。 |
| `OnSelectionChange` | 报告选中的原生选择器选项或颜色。 |
