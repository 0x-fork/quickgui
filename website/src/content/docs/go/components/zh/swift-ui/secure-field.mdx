隐藏输入内容的原生编辑器，受控约定与 TextField 相同。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiSecureFieldExample() {
	text, setText := ui.CreateSignal("")
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.SecureField(ui.SwiftUITextFieldProps{
				Value:         text,
				Placeholder:   "Enter text",
				OnValueChange: func(next string, _ *native.Event) { setText(next) },
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Placeholder` | 可编辑值为空时显示的文本。 |
| `OnValueChange` | 报告核心接受的值。 |
| `OnSubmit` | 原生字段提交当前值时运行。 |
