基于 NSHostingView 的叶节点，用于在 QuickGUI 中挂载一棵 SwiftUI 组件树。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiHostExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `MatchContents` | 使用托管子树的固有宽度、高度或两者。 |
| `Style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
