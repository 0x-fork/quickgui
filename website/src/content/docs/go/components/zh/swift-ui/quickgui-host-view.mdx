在 SwiftUI 层级中反向托管一棵普通的 QuickGUI 子树。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiQuickguiHostViewExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.QuickGUIHostView(
				ui.SwiftUIQuickGUIHostViewProps{Width: 320, Height: 180},
				func() {
					ui.View(
						"QuickGUI inside SwiftUI",
					).Width("100%").Height("100%").Padding(16)
				},
			)
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Width` | 声明的逻辑宽度。 |
| `Height` | 声明的逻辑高度。 |
| `MatchContents` | 使用托管子树的固有宽度、高度或两者。 |
| `Background` | 反向托管 QuickGUI WGPU 表面的清除颜色。 |
| `children` | 挂载在组件内部的内容。 |
