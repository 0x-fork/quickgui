原生 SwiftUI 按钮，支持文本、SF Symbol、语义角色和按下处理。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiButtonExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Button(ui.SwiftUIButtonProps{
				Label:       "Save",
				SystemImage: "checkmark",
				OnPress:     func(*native.Event) { fmt.Println("Saved") },
				Modifiers:   []ui.SwiftUIModifier{ui.SwiftUI.ButtonStyle("borderedProminent")},
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Label` | 原生 SwiftUI 控件的可见标签。 |
| `SystemImage` | 与 SwiftUI 按钮标签一起显示的 SF Symbols 名称。 |
| `Role` | SwiftUI 语义角色：`default`、`cancel` 或 `destructive`。 |
| `OnPress` | 原生 SwiftUI 按钮激活时运行。 |
| `Modifiers` | 应用于托管控件的有序 SwiftUI View 修饰器。 |
