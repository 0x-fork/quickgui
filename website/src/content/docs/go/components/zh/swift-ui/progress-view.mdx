确定或不确定的原生 SwiftUI 进度指示器。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiProgressViewExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.ProgressView(ui.SwiftUIProgressViewProps{
				Value: 0.4,
				Total: 1,
				Label: "Uploading",
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Total` | SwiftUI 确定进度的分母。 |
| `Label` | 原生 SwiftUI 控件的可见标签。 |
| `CurrentValueLabel` | 当前原生进度或仪表值的易读标签。 |
