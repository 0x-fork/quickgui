受控的原生日期或日期时间选择器。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"time"
)
```

## 用法

```go
func SwiftUiDatePickerExample() {
	value, setValue := ui.CreateSignal(float64(time.Now().UnixMilli()))
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.DatePicker(ui.SwiftUIDatePickerProps{
				Value:               value,
				DisplayedComponents: "dateAndTime",
				OnValueChange:       func(next float64, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 以毫秒表示的 Unix 时间戳；`Min` 和 `Max` 使用相同单位。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `DisplayedComponents` | 选择日期、时间或日期和时间组合字段。 |
| `Style` | `automatic`、`field`、`stepperField` 或 `graphical`。 |
| `OnValueChange` | 报告核心接受的值。 |
