原生 SwiftUI 仪表，支持线性和圆形附属样式。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiGaugeExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Gauge(ui.SwiftUIGaugeProps{
				Value: 60,
				Min:   0,
				Max:   100,
				Label: "Capacity",
				Style: "accessoryLinearCapacity",
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `Label` | 原生 SwiftUI 控件的可见标签。 |
| `CurrentValueLabel` | 当前原生进度或仪表值的易读标签。 |
| `Style` | 此控件的原生 SwiftUI 展示样式。 |
