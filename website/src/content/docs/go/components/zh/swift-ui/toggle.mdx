受控的原生 SwiftUI 开关。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiToggleExample() *native.Node {
	on, setOn := ui.CreateSignal(true)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `IsOn` | 受控的 SwiftUI 开关值。 |
| `Label` | 原生 SwiftUI 控件的可见标签。 |
| `OnIsOnChange` | 报告原生 SwiftUI 开关接受的值。 |
| `Modifiers` | 应用于托管控件的有序 SwiftUI View 修饰器。 |
