A fully composable menu with submenus, groups, links, checkbox items, and radio items.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func MenuExample() *native.Node {
	return ui.Menu.Root(
		ui.MenuRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Menu.Trigger(ui.MenuTriggerProps{}, "Actions"),
				ui.Menu.Positioner(
					ui.MenuPositionerProps{},
					func() *native.Node {
						return ui.Menu.Popup(
							ui.PartProps{},
							func() *native.Node {
								return ui.Menu.Item(
									ui.MenuItemProps{
										Value:     "copy",
										Label:     "Copy",
										PartProps: ui.PartProps{OnClick: func(*native.Event) { fmt.Println("Copy") }},
									},
									"Copy",
								)
							},
						)
					},
				)})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `LoopFocus` | Wraps keyboard highlight at the ends of the current menu level. |
