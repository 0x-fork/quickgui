A fully composable menu with submenus, groups, links, checkbox items, and radio items.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func MenuExample() *native.Node {
	menu1 := ui.NewMenu(ui.MenuRootProps{})
	return menu1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{menu1.Trigger(ui.MenuTriggerProps{}).Children("Actions").NativeNode(), menu1.Positioner(ui.MenuPositionerProps{}).Children(func() *native.Node {
			return menu1.Popup(ui.PartProps{}).Children(func() *native.Node {
				return menu1.Item(ui.MenuItemProps{Value: "copy", Label: "Copy", PartProps: ui.PartProps{OnClick: func(*native.Event) {
					fmt.Println("Copy")
				}}}).Children("Copy").NativeNode()
			}).NativeNode()
		}).NativeNode()})
	}).NativeNode()
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `LoopFocus` | Wraps keyboard highlight at the ends of the current menu level. |
