Renders retained Markdown, including an incremental mode for streaming content.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func MarkdownExample(source func() string, streaming func() bool) {
	ui.Markdown(ui.Value(source), ui.Streaming(streaming), ui.Width("100%"))
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Markdown source to shape and paint. |
| `Streaming` | Uses incremental Markdown reconciliation for appended content. |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
