Renders a complete inline SVG document without loading external SVG resources.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SvgExample() {
	ui.SVG(
		ui.Width(20),
		ui.Height(20),
		ui.TextColor("#2563eb"),
		ui.Value(`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path fill="currentColor" d="M11 4h2v7h7v2h-7v7h-2v-7H4v-2h7z"/></svg>`),
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Filesystem path, data URL, SVG document, or shader source expected by the component. |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
