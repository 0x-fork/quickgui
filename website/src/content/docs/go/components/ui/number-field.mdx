A numeric editor with increment, decrement, and drag-to-scrub parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func NumberFieldExample() *native.Node {
	value, setValue := ui.CreateSignal(8.0)
	numberField1 := ui.NewNumberField(ui.NumberFieldRootProps{Value: func() *float64 {
		current := value()
		return &current
	}, Min: 0, Max: 100, Step: 1, OnValueChange: func(next *float64, valid bool, _ *native.Event) {
		if valid && next != nil {
			setValue(*next)
		}
	}})
	return numberField1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{numberField1.Decrement(ui.PartProps{}).Children("−").NativeNode(), numberField1.Input(ui.NumberFieldInputProps{}).NativeNode(), numberField1.Increment(ui.PartProps{}).Children("+").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `numberField.Root`
- `numberField.Group`
- `numberField.Input`
- `numberField.Increment`
- `numberField.Decrement`
- `numberField.ScrubArea`
- `numberField.ScrubAreaCursor`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `Step` | Increment used by keyboard, pointer, or native control input. |
| `OnValueChange` | Reports the value accepted by the core. |
