A numeric editor with increment, decrement, and drag-to-scrub parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func NumberFieldExample() {
	value, setValue := ui.CreateSignal(8.0)
	ui.NumberField.Root(
		ui.NumberFieldRootProps{
			Value: func() *float64 { current := value(); return &current },
			Min:   0,
			Max:   100,
			Step:  1,
			OnValueChange: func(next *float64, valid bool, _ *native.Event) {
				if valid && next != nil {
					setValue(*next)
				}
			},
		},
		func() {
			ui.NumberField.Decrement(ui.PartProps{}, "−")
			ui.NumberField.Input(ui.NumberFieldInputProps{})
			ui.NumberField.Increment(ui.PartProps{}, "+")
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `Step` | Increment used by keyboard, pointer, or native control input. |
| `OnValueChange` | Reports the value accepted by the core. |
