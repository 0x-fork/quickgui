Displays a scalar measurement within a known range and semantic low, high, and optimum bands.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func MeterExample(value func() *float64) *native.Node {
	meter1 := ui.NewMeter(ui.MeterProps{Value: value, Min: 0, Max: 100, Low: 25, High: 80, Optimum: 50})
	return meter1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{meter1.Label(ui.PartProps{}).Children("Disk used").NativeNode(), meter1.Track(ui.PartProps{}).Children(func() *native.Node {
			return meter1.Indicator(ui.PartProps{}).NativeNode()
		}).NativeNode(), meter1.Value(ui.PartProps{}).NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `meter.Root`
- `meter.Track`
- `meter.Indicator`
- `meter.Label`
- `meter.Value`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `Low` | Upper boundary of the low meter range. |
| `High` | Lower boundary of the high meter range. |
| `Optimum` | Preferred point or range for the meter value. |
