Displays a scalar measurement within a known range and semantic low, high, and optimum bands.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func MeterExample(value func() *float64) *native.Node {
	return ui.Meter.Root(
		ui.MeterProps{
			Value:   value,
			Min:     0,
			Max:     100,
			Low:     25,
			High:    80,
			Optimum: 50,
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Meter.Label(ui.PartProps{}, "Disk used"),
				ui.Meter.Track(
					ui.PartProps{},
					func() *native.Node { return ui.Meter.Indicator(ui.PartProps{}) },
				),
				ui.Meter.Value(ui.PartProps{})})
		},
	)
}
```

## Anatomy

- `ui.Meter.Root`
- `ui.Meter.Track`
- `ui.Meter.Indicator`
- `ui.Meter.Label`
- `ui.Meter.Value`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `Low` | Upper boundary of the low meter range. |
| `High` | Lower boundary of the high meter range. |
| `Optimum` | Preferred point or range for the meter value. |
