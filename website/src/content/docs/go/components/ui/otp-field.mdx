A bounded one-time-code editor made from individually styled input cells.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func OtpFieldExample() *native.Node {
	code, setCode := ui.CreateSignal("")
	otpField1 := ui.NewOtpField(ui.OtpFieldRootProps{Value: code, Length: 6, ValidationType: "numeric", OnValueChange: func(next string, _ *native.Event) {
		setCode(next)
	}, OnComplete: func(value string, _ *native.Event) {
		fmt.Println("Complete:", value)
	}})
	return otpField1.Root().Children(func() *native.Node {
		var children []*native.Node
		for index := range 6 {
			children = append(children, otpField1.InputWith(ui.OtpFieldInputProps{Index: index}).NativeNode())
		}
		return ui.Fragment(children)
	}).NativeNode()
}
```

## Anatomy

- `otpField.Root`
- `otpField.Input`
- `otpField.Separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Length` | Number of one-time-code input slots, bounded to twelve. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
