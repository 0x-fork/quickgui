A bounded one-time-code editor made from individually styled input cells.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func OtpFieldExample() *ui.Element {
	code, setCode := ui.CreateSignal("")
	field := ui.NewOtpField(ui.OtpFieldRootProps{Value: code, Length: 6, ValidationType: "numeric", OnValueChange: func(next string, _ *native.Event) {
		setCode(next)
	}, OnComplete: func(value string, _ *native.Event) {
		fmt.Println("Complete:", value)
	}})
	inputs := make([]*ui.Element, 0, 6)
	for index := range 6 {
		inputs = append(inputs, field.Input(index))
	}
	return field.Root().Children(inputs)
}
```

## Anatomy

- `otpField.Root`
- `otpField.Input`
- `otpField.Separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Length` | Number of one-time-code input slots, bounded to twelve. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
