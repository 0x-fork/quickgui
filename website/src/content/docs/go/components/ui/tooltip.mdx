Shows passive help after an exact core-owned delay and supports provider-level warm-up behavior.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TooltipExample() *ui.Element {
	provider := ui.NewTooltipProvider(ui.TooltipProviderProps{Delay: 500})
	tooltip := ui.NewTooltip().Side("top")
	return provider.Root().Child(
		tooltip.Root().Children(
			tooltip.Trigger().Child("Hover me"),
			tooltip.Positioner().Child(
				tooltip.Popup().Child("Helpful information"),
			),
		),
	)
}
```

## Anatomy

- `tooltip.Provider`
- `tooltip.Root`
- `tooltip.Trigger`
- `tooltip.Portal`
- `tooltip.Positioner`
- `tooltip.Popup`
- `tooltip.Arrow`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `Delay` | Core-owned delay in milliseconds before opening. |
| `CloseDelay` | Core-owned delay in milliseconds before closing. |
| `Side` | Preferred placement side before collision handling. |
| `Hoverable` | Allows the pointer to cross into the tooltip without closing it. |
