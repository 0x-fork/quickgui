Shows passive help after an exact core-owned delay and supports provider-level warm-up behavior.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TooltipExample() *native.Node {
	return ui.Tooltip.Provider(
		ui.TooltipProviderProps{Delay: 500},
		func() *native.Node {
			return ui.Tooltip.Root(
				ui.TooltipRootProps{Side: "top"},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Tooltip.Trigger(ui.TooltipTriggerProps{}, "Hover me"),
						ui.Tooltip.Positioner(
							ui.TooltipPositionerProps{},
							func() *native.Node {
								return ui.Tooltip.Popup(
									ui.PartProps{},
									"Helpful information",
								)
							},
						)})
				},
			)
		},
	)
}
```

## Anatomy

- `ui.Tooltip.Provider`
- `ui.Tooltip.Root`
- `ui.Tooltip.Trigger`
- `ui.Tooltip.Portal`
- `ui.Tooltip.Positioner`
- `ui.Tooltip.Popup`
- `ui.Tooltip.Arrow`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `Delay` | Core-owned delay in milliseconds before opening. |
| `CloseDelay` | Core-owned delay in milliseconds before closing. |
| `Side` | Preferred placement side before collision handling. |
| `Hoverable` | Allows the pointer to cross into the tooltip without closing it. |
