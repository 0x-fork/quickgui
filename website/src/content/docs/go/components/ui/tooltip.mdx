Shows passive help after an exact core-owned delay and supports provider-level warm-up behavior.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TooltipExample() *native.Node {
	return ui.NewTooltipProvider(ui.TooltipProviderProps{Delay: 500}).Root().Child(func() *native.Node {
		tooltip1 := ui.NewTooltip(ui.TooltipRootProps{Side: "top"})
		return tooltip1.Root().Children(func() *native.Node {
			return ui.Fragment([]*native.Node{tooltip1.Trigger(ui.TooltipTriggerProps{}).Children("Hover me").NativeNode(), tooltip1.Positioner(ui.TooltipPositionerProps{}).Children(func() *native.Node {
				return tooltip1.Popup(ui.PartProps{}).Children("Helpful information").NativeNode()
			}).NativeNode()})
		}).NativeNode()
	}).NativeNode()
}
```

## Anatomy

- `tooltip.Provider`
- `tooltip.Root`
- `tooltip.Trigger`
- `tooltip.Portal`
- `tooltip.Positioner`
- `tooltip.Popup`
- `tooltip.Arrow`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `Delay` | Core-owned delay in milliseconds before opening. |
| `CloseDelay` | Core-owned delay in milliseconds before closing. |
| `Side` | Preferred placement side before collision handling. |
| `Hoverable` | Allows the pointer to cross into the tooltip without closing it. |
