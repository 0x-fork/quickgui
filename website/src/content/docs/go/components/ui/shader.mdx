Paints validated WGSL with a bounded set of numeric shader parameters.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ShaderExample(source string, parameters func() []float64) *ui.Element {
	return ui.Shader().Value(source).ShaderParameters(parameters).
		Width(320).Height(180)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Filesystem path, data URL, SVG document, or shader source expected by the component. |
| `ShaderParameters` | Up to sixteen numeric values packed into fixed shader parameter vectors. |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
