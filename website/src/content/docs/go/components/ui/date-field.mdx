A segmented, keyboard-editable date field with locale-aware date parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func DateFieldExample() *ui.Element {
	value, setValue := ui.CreateSignal[*string](nil)
	field := ui.NewDateField(ui.DateFieldRootProps{Value: value, Format: "ymd", Min: "2026-01-01", Max: "2026-12-31", OnValueChange: func(next *string, _ *native.Event) {
		setValue(next)
	}})
	segments := make([]*ui.Element, 0, 3)
	for _, segment := range []string{"year", "month", "day"} {
		segments = append(segments, field.Segment(segment))
	}
	return field.Root().Children(segments)
}
```

## Anatomy

- `dateField.Root`
- `dateField.Segment`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
