Shapes and paints Unicode text with inherited typography, selection, and accessibility.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TextExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View(
		ui.Text(
			"Count: ",
			count(),
		).FontSize(20),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
| `Ref` | Receives the retained native node. |
