Shapes and paints Unicode text with inherited typography, selection, and accessibility.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			"Count: ",
			count,
			ui.Style{FontSize: 20},
		)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `ui.Style{}` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
| `Ref` | Receives the retained native node. |
