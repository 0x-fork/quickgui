Coordinates a horizontal in-window menubar and its menu items.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func MenubarExample() *ui.Element {
	menubar := ui.NewMenubar().Count(2)
	items := make([]*ui.Element, 0, 2)
	for index, label := range []string{"File", "Edit"} {
		items = append(items, menubar.Item(ui.MenubarItemProps{Index: &index}).Child(label))
	}
	return menubar.Root().Children(items)
}
```

## Anatomy

- `menubar.Root`
- `menubar.Item`

## Key props

| Prop | Purpose |
| --- | --- |
| `Count` | Number of declared menubar items. |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `OnActiveChange` | Reports the item that now owns the roving focus state. |
