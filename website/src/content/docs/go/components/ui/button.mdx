An accessible press target that you style and compose with text or other content.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ButtonExample(save func()) {
	ui.Button(
		"Save changes",
		ui.Style().Height(40),
		ui.Style().PaddingLeft(16),
		ui.Style().PaddingRight(16),
		ui.Style().BackgroundColor("#2563eb"),
		ui.Style().TextColor("white"),
		ui.Style().BorderRadius(8),
		ui.Style().Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }),
		ui.OnClick(save),
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
| `OnClick` | Runs after the core resolves an activation. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
