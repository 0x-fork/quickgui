Groups related fields under one legend and shared semantic state.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func FieldsetExample(saving func() bool) *ui.Element {
	fieldset := ui.NewFieldset().Disabled(saving)
	field := ui.NewField()
	return fieldset.Root().Children(
		fieldset.Legend().Child("Profile"),
		field.Root().Children(
			field.Label().Child("Name"),
			field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Placeholder: "Ada"}}),
		),
	)
}
```

## Anatomy

- `fieldset.Root`
- `fieldset.Legend`
- `fieldset.Description`
- `fieldset.Control`

## Key props

| Prop | Purpose |
| --- | --- |
| `Disabled` | Prevents interaction and exposes the disabled state. |
| `children` | Content mounted inside the component. |
| `Style` | QuickGUI layout, paint, typography, and interaction-state styles. |
