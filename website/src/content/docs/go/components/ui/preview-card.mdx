Shows a richer hover or focus preview beside a trigger without changing the current screen.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func PreviewCardExample() *native.Node {
	previewCard1 := ui.NewPreviewCard(ui.PreviewCardRootProps{Placement: "bottom-start"})
	return previewCard1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{previewCard1.Trigger(ui.PreviewCardTriggerProps{Delay: 350}).Children("@ada").NativeNode(), previewCard1.Positioner(ui.PartProps{}).Children(func() *native.Node {
			return previewCard1.Popup(ui.PartProps{}).Children("Ada Lovelace").NativeNode()
		}).NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `previewCard.Root`
- `previewCard.Trigger`
- `previewCard.Portal`
- `previewCard.Backdrop`
- `previewCard.Positioner`
- `previewCard.Popup`
- `previewCard.Arrow`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `Delay` | Core-owned delay in milliseconds before opening. |
| `CloseDelay` | Core-owned delay in milliseconds before closing. |
| `Placement` | Preferred placement side before collision handling. |
