Shows a richer hover or focus preview beside a trigger without changing the current screen.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func PreviewCardExample() *native.Node {
	return ui.PreviewCard.Root(
		ui.PreviewCardRootProps{Placement: "bottom-start"},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.PreviewCard.Trigger(ui.PreviewCardTriggerProps{Delay: 350}, "@ada"),
				ui.PreviewCard.Positioner(
					ui.PartProps{},
					func() *native.Node {
						return ui.PreviewCard.Popup(
							ui.PartProps{},
							"Ada Lovelace",
						)
					},
				)})
		},
	)
}
```

## Anatomy

- `ui.PreviewCard.Root`
- `ui.PreviewCard.Trigger`
- `ui.PreviewCard.Portal`
- `ui.PreviewCard.Backdrop`
- `ui.PreviewCard.Positioner`
- `ui.PreviewCard.Popup`
- `ui.PreviewCard.Arrow`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `Delay` | Core-owned delay in milliseconds before opening. |
| `CloseDelay` | Core-owned delay in milliseconds before closing. |
| `Placement` | Preferred placement side before collision handling. |
