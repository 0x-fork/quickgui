Presents QuickGUI content in a separate native child window that can extend beyond its owner.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SystemPopoverExample() *native.Node {
	systemPopover1 := ui.NewSystemPopover(ui.PopoverRootProps{})
	return systemPopover1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{systemPopover1.Trigger(ui.PopoverTriggerProps{}).Children("Account").NativeNode(), systemPopover1.Content(ui.PopoverContentProps{Width: 240, Height: 120, Placement: "bottom-start"}).Children("Account settings").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `systemPopover.Root`
- `systemPopover.Trigger`
- `systemPopover.Content`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `Width` | Declared logical width. |
| `Height` | Declared logical height. |
| `Placement` | Requested native child-window placement. |
