The multiline text-editing primitive, with the same controlled value contract as Input.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TextAreaExample() {
	value, setValue := ui.CreateSignal("")
	ui.TextArea(
		ui.Value(value),
		ui.Placeholder("Write here"),
		ui.OnInput(func(event *native.Event) { setValue(event.Value) }),
		ui.Width(320),
		ui.Height(96),
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Placeholder` | Text shown while the editable value is empty. |
| `OnInput` | Reports native editing input. |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
