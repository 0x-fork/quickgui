A semantic horizontal or vertical divider with no built-in visual style.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SeparatorExample() {
	ui.Separator.Root(ui.SeparatorProps{
		Orientation: "horizontal",
		PartProps:   ui.PartProps{Style: ui.Style().Height(1).BackgroundColor("#d1d5db")},
	})
}
```

## Anatomy

- `ui.Separator.Root`

## Key props

| Prop | Purpose |
| --- | --- |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `Style` | QuickGUI layout, paint, typography, and interaction-state styles. |
