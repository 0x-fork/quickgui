Groups actions and inputs under one roving-focus keyboard model.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToolbarExample() *native.Node {
	toolbar1 := ui.NewToolbar(ui.ToolbarRootProps{Items: []ui.ComponentItem{{Value: "select"}, {Value: "draw"}}, DefaultActive: "select"})
	return toolbar1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{toolbar1.Item(ui.ToolbarItemProps{Value: "select"}).Children("Select").NativeNode(), toolbar1.Item(ui.ToolbarItemProps{Value: "draw"}).Children("Draw").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `toolbar.Root`
- `toolbar.Item`
- `toolbar.Button`
- `toolbar.Link`
- `toolbar.Input`
- `toolbar.Group`
- `toolbar.Separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Active` | Controlled item holding the active or roving focus state. |
| `DefaultActive` | Initial active item for an uncontrolled component. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `OnActiveChange` | Reports the item that now owns the roving focus state. |
