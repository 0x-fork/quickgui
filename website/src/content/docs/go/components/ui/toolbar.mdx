Groups actions and inputs under one roving-focus keyboard model.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToolbarExample() *ui.Element {
	toolbar := ui.NewToolbar(ui.ToolbarRootProps{Items: []ui.ComponentItem{{Value: "select"}, {Value: "draw"}}, DefaultActive: "select"})
	return toolbar.Root().Children(
		toolbar.Item(ui.ToolbarItemProps{Value: "select"}).Child("Select"),
		toolbar.Item(ui.ToolbarItemProps{Value: "draw"}).Child("Draw"),
	)
}
```

## Anatomy

- `toolbar.Root`
- `toolbar.Item`
- `toolbar.Button`
- `toolbar.Link`
- `toolbar.Input`
- `toolbar.Group`
- `toolbar.Separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Active` | Controlled item holding the active or roving focus state. |
| `DefaultActive` | Initial active item for an uncontrolled component. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `OnActiveChange` | Reports the item that now owns the roving focus state. |
