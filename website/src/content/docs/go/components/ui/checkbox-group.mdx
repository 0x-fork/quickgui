Coordinates a bounded set of checkbox values and an optional derived parent checkbox.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func CheckboxGroupExample() *ui.Element {
	values, setValues := ui.CreateSignal([]string{"email"})
	group := ui.NewCheckboxGroup(ui.CheckboxGroupProps{AllValues: []string{"email", "push"}, Value: values, OnValueChange: func(next []string, _ *native.Event) {
		setValues(next)
	}})
	all := ui.NewCheckbox().Parent(true)
	email := ui.NewCheckbox().Value("email")
	push := ui.NewCheckbox().Value("push")
	return group.Root().Children(
		all.Root().Child("All notifications"),
		email.Root().Child("Email"),
		push.Root().Child("Push"),
	)
}
```

## Anatomy

- `checkboxGroup.Root`

## Key props

| Prop | Purpose |
| --- | --- |
| `AllValues` | Complete ordered value universe used to derive a parent checkbox state. |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
