Creates resizable panes with pointer and keyboard-operated handles.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SplitterExample() *native.Node {
	return ui.Splitter.Root(
		ui.SplitterRootProps{
			DefaultValue: []float64{240, 400},
			Panes:        []ui.SplitterPaneDeclaration{{}, {}},
			PartProps:    ui.PartProps{Style: ui.Style().Display("flex").Height(240)},
		},
		func() *native.Node {
			var children []*native.Node
			first, second := 0, 1
			children = append(children, ui.Splitter.Pane(ui.SplitterPaneProps{Index: &first}, "Sidebar"))
			children = append(children, ui.Splitter.Handle(ui.SplitterPaneProps{
				Index: &first,
				PartProps: ui.PartProps{Style: ui.Style().
					Width(6).
					Cursor("col-resize")},
			}))
			children = append(children, ui.Splitter.Pane(ui.SplitterPaneProps{Index: &second}, "Content"))
			return ui.Fragment(children)
		},
	)
}
```

## Anatomy

- `ui.Splitter.Root`
- `ui.Splitter.Pane`
- `ui.Splitter.Handle`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Panes` | Per-pane minimum size and collapse declarations. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `OnSizesChange` | Reports the complete pane-size set after the core resizes it. |
