Creates resizable panes with pointer and keyboard-operated handles.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SplitterExample() *ui.Element {
	splitter := ui.NewSplitter().
		DefaultValue([]float64{240, 400}).
		Panes([]ui.SplitterPaneDeclaration{{}, {}})
	return splitter.Root().Display("flex").Height(240).Children(
		splitter.Pane(0).Child("Sidebar"),
		splitter.Handle(0).Width(6).Cursor("col-resize"),
		splitter.Pane(1).Child("Content"),
	)
}
```

## Anatomy

- `splitter.Root`
- `splitter.Pane`
- `splitter.Handle`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Panes` | Per-pane minimum size and collapse declarations. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `OnSizesChange` | Reports the complete pane-size set after the core resizes it. |
