Shows an image with a fallback that appears when the image is unavailable.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func AvatarExample(path string) *native.Node {
	avatar1 := ui.NewAvatar(ui.AvatarRootProps{PartProps: ui.PartProps{AriaLabel: "Ada Lovelace"}})
	return avatar1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{avatar1.Image(ui.AvatarImageProps{Src: path}).NativeNode(), avatar1.Fallback(ui.AvatarFallbackProps{}).Children("AL").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `avatar.Root`
- `avatar.Image`
- `avatar.Fallback`

## Key props

| Prop | Purpose |
| --- | --- |
| `AriaLabel` | Accessible name for a component whose visible parts may change. |
| `Src` | Filesystem path, file URL, or base64 data URL for an avatar image. |
| `Delay` | Core-owned delay in milliseconds before opening. |
| `OnLoadingStatusChange` | Reports every avatar image load-state transition. |
