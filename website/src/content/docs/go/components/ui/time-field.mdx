A segmented, keyboard-editable time field with hour, minute, second, and period parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TimeFieldExample() *ui.Element {
	field := ui.NewTimeField().DefaultValue("09:30").Hour12(true)
	segments := make([]*ui.Element, 0, 3)
	for _, segment := range []string{"hour", "minute", "period"} {
		segments = append(segments, field.Segment(segment))
	}
	return field.Root().Children(segments)
}
```

## Anatomy

- `timeField.Root`
- `timeField.Segment`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Hour12` | Adds an AM/PM segment and uses a twelve-hour clock. |
| `ShowSeconds` | Mounts a seconds segment. |
| `OnValueChange` | Reports the value accepted by the core. |
