Places caller-styled content beside an anchor inside the current window.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func PopoverExample() {
	ui.Popover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.Popover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.Popover.Positioner(
				ui.PopoverPositionerProps{},
				func() {
					ui.Popover.Popup(
						ui.PopoverPopupProps{PartProps: ui.PartProps{Style: ui.Style{
							Width:   240,
							Padding: 16,
						}}},
						func() {
							ui.Popover.Title(ui.PartProps{}, "Account")
							ui.Popover.Close(ui.PartProps{}, "Done")
						},
					)
				},
			)
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `Side` | Preferred placement side before collision handling. |
| `Align` | Preferred alignment on the placement cross-axis. |
| `Modal` | Contains focus and blocks interaction behind the surface. |
