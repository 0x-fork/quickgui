Opens a model-driven native menu from a secondary-button press on its trigger.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ContextMenuExample() *ui.Element {
	menu := ui.NewContextMenu(ui.ContextMenuRootProps{Items: func() []ui.MenuItemDeclaration {
		return []ui.MenuItemDeclaration{{ID: "copy", Label: "Copy"}}
	}, OnSelect: func(item ui.MenuSelectDetails, _ *native.Event) {
		fmt.Println(item.ID)
	}})
	return menu.Root().Child(
		menu.Trigger().Child("Right-click here"),
	)
}
```

## Anatomy

- `contextMenu.Root`
- `contextMenu.Trigger`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Appearance` | Structural colors and geometry for a core-painted native menu or picker. |
| `OnSelect` | Reports the menu entry selected by the core. |
| `Loop` | Wraps highlight navigation at the ends of a menu level. |
