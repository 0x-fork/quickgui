A binary or indeterminate choice with a separately styled indicator.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func CheckboxExample() *native.Node {
	checked, setChecked := ui.CreateSignal(false)
	return ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Checkbox.Indicator(
				ui.PartProps{Style: ui.Style().
					Width(16).
					Height(16).
					BorderWidth(1).
					BorderRadius(4).
					BorderColor("#2563eb").
					Display("flex").
					AlignItems("center").
					JustifyContent("center")},
				func() *native.Node {
					return ui.Show(
						checked,
						func() *ui.Element {
							return ui.SVG().
								Value(`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 12 12"><path d="M3 6l2 2 4-4" fill="none" stroke="#2563eb" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"/></svg>`).
								Width(12).Height(12)
						},
					)
				},
			),
				ui.Text("Remember me").Node})
		},
	)
}
```

The indicator is unstyled. This example keeps its outline mounted and shows the SVG only when checked. Set `ReadOnly: true` to preserve focus while preventing value changes from pointer or keyboard activation.

## Anatomy

- `ui.Checkbox.Root`
- `ui.Checkbox.Indicator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Checked` | Controlled checked state. |
| `DefaultChecked` | Initial checked state when the component owns it. |
| `OnCheckedChange` | Reports the checked state accepted by the core. |
| `ReadOnly` | Prevents value changes while leaving the control focusable. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
