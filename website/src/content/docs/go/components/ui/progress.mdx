Represents determinate or indeterminate task progress with composable labels and track.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ProgressExample(progress func() *float64) *native.Node {
	progress1 := ui.NewProgress(ui.ProgressProps{Value: progress, Max: 100})
	return progress1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{progress1.Label(ui.PartProps{}).Children("Uploading").NativeNode(), progress1.Track(ui.PartProps{}).Children(func() *native.Node {
			return progress1.Indicator(ui.PartProps{}).NativeNode()
		}).NativeNode(), progress1.Value(ui.PartProps{}).NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `progress.Root`
- `progress.Track`
- `progress.Indicator`
- `progress.Label`
- `progress.Value`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Max` | Maximum accepted value. |
| `Indeterminate` | Represents progress whose completed amount is unknown. |
| `ValueText` | Human-readable value preferred by assistive technology. |
| `OnStatusChange` | Reports the derived status, formatted value, and completion ratio. |
