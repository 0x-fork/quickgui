Owns single-choice selection and keyboard movement across Radio items.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func RadioGroupExample() *native.Node {
	value, setValue := ui.CreateSignal("system")
	return ui.RadioGroup.Root(
		ui.RadioGroupProps{
			Value:         func() *string { current := value(); return &current },
			OnValueChange: func(next string, _ *native.Event) { setValue(next) },
		},
		func() *native.Node {
			var children []*native.Node
			for _, option := range []string{"light", "dark", "system"} {
				children = append(children, ui.Radio.Root(
					ui.RadioProps{Value: option},
					func() *native.Node {
						return ui.Fragment([]*native.Node{ui.Radio.Indicator(ui.PartProps{}), ui.Text(option).Node})
					},
				))
			}
			return ui.Fragment(children)
		},
	)
}
```

## Anatomy

- `ui.RadioGroup.Root`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `ReadOnly` | Prevents value changes while leaving the control focusable. |
| `Required` | Marks the value as required for validation and form submission. |
