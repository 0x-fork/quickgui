Owns single-choice selection and keyboard movement across Radio items.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func RadioGroupExample() *ui.Element {
	value, setValue := ui.CreateSignal("system")
	group := ui.NewRadioGroup(ui.RadioGroupProps{Value: func() *string {
		current := value()
		return &current
	}, OnValueChange: func(next string, _ *native.Event) {
		setValue(next)
	}})
	options := make([]*ui.Element, 0, 3)
	for _, value := range []string{"light", "dark", "system"} {
		radio := ui.NewRadio().Value(value)
		options = append(options, radio.Root().Children(
			radio.Indicator(),
			ui.Text(value),
		))
	}
	return group.Root().Children(options)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `ReadOnly` | Prevents value changes while leaving the control focusable. |
| `Required` | Marks the value as required for validation and form submission. |
