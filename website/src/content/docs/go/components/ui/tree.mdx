A virtualized hierarchical collection with expansion, selection, and keyboard navigation.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TreeExample() *native.Node {
	nodes := []ui.TreeNodeDeclaration{{ID: "src", Label: "src", Children: []ui.TreeNodeDeclaration{{ID: "src/main.go", Label: "main.go"}}}}
	tree1 := ui.NewTree(ui.TreeRootProps{Nodes: func() []ui.TreeNodeDeclaration {
		return nodes
	}, DefaultExpanded: []string{"src"}, RowHeight: 26, PartProps: ui.PartProps{Style: ui.Style().Height(200)}})
	return tree1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{tree1.Row(ui.TreeRowProps{NodeID: "src"}).Children("src").NativeNode(), tree1.Row(ui.TreeRowProps{NodeID: "src/main.go"}).Children("main.go").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `tree.Root`
- `tree.Row`

## Key props

| Prop | Purpose |
| --- | --- |
| `Nodes` | Bounded hierarchical node declarations for the tree. |
| `Expanded` | Controlled expanded tree node identifiers. |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `OnExpandedChange` | Reports the ordered node identifiers expanded by the core. |
| `OnValueChange` | Reports the value accepted by the core. |
