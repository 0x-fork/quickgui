Displays a filesystem path, file URL, or base64 data URL with retained image resources.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ImageExample(path string) {
	ui.Image(ui.Value(path), ui.ObjectFit("cover"), ui.Width(160), ui.Height(120))
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Filesystem path, data URL, SVG document, or shader source expected by the component. |
| `ObjectFit` | How image content fits its declared box. |
| `ui.BackgroundColor(...)`, `ui.Padding(...)`, `ui.Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
