An in-window modal with focus containment, dismissal, and exact transition completion.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func DialogExample() *ui.Element {
	dialog := ui.NewDialog()
	return dialog.Root().Children(
		dialog.Trigger().Child("Open dialog"),
		dialog.Portal().Children(
			dialog.Backdrop(),
			dialog.Viewport().Child(
				dialog.Popup().Children(
					dialog.Title().Child("Confirm action"),
					dialog.Description().Child("Review the details before continuing."),
					dialog.Close().Child("Cancel"),
				),
			),
		),
	)
}
```

## Anatomy

- `dialog.Root`
- `dialog.Trigger`
- `dialog.Portal`
- `dialog.Backdrop`
- `dialog.Viewport`
- `dialog.Popup`
- `dialog.Title`
- `dialog.Description`
- `dialog.Close`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `DismissOnEscape` | Allows Escape to dismiss the surface. |
| `ExitDuration` | Keeps closing content mounted for the exact exit transition duration. |
