An in-window modal with focus containment, dismissal, and exact transition completion.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func DialogExample() *native.Node {
	return ui.Dialog.Root(
		ui.DialogRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Dialog.Trigger(ui.PartProps{}, "Open dialog"),
				ui.Dialog.Portal(
					ui.PartProps{},
					func() *native.Node {
						return ui.Fragment([]*native.Node{ui.Dialog.Backdrop(ui.PartProps{}),
							ui.Dialog.Viewport(
								ui.PartProps{},
								func() *native.Node {
									return ui.Dialog.Popup(
										ui.DialogPopupProps{},
										func() *native.Node {
											return ui.Fragment([]*native.Node{ui.Dialog.Title(ui.PartProps{}, "Confirm action"),
												ui.Dialog.Description(
													ui.PartProps{},
													"Review the details before continuing.",
												),
												ui.Dialog.Close(ui.PartProps{}, "Cancel")})
										},
									)
								},
							)})
					},
				)})
		},
	)
}
```

## Anatomy

- `ui.Dialog.Root`
- `ui.Dialog.Trigger`
- `ui.Dialog.Portal`
- `ui.Dialog.Backdrop`
- `ui.Dialog.Viewport`
- `ui.Dialog.Popup`
- `ui.Dialog.Title`
- `ui.Dialog.Description`
- `ui.Dialog.Close`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `DismissOnEscape` | Allows Escape to dismiss the surface. |
| `ExitDuration` | Keeps closing content mounted for the exact exit transition duration. |
