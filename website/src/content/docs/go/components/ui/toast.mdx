Presents timed, stacked notifications with action, close, and swipe behavior.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToastExample() *native.Node {
	return ui.Toast.Provider(
		ui.ToastProviderProps{Timeout: 5000, Limit: 3},
		func() *native.Node {
			var children []*native.Node
			manager := ui.UseToastManager()
			children = append(children, ui.Button(
				"Save",
			).OnClick(func() { manager.Add(ui.ToastRequest{Title: "Saved", Type: "success"}) }).Node)
			children = append(children, ui.Toast.Viewport(
				ui.ToastViewportProps{},
				func() *native.Node {
					return ui.For(
						manager.Toasts,
						func(toast ui.ToastDeclaration, _ func() int) *native.Node {
							return ui.Toast.Root(
								ui.ToastPartProps{ToastID: toast.ID},
								func() *native.Node {
									return ui.Fragment([]*native.Node{ui.Toast.Title(
										ui.ToastPartProps{ToastID: toast.ID},
										toast.Title,
									),
										ui.Toast.Close(ui.ToastPartProps{ToastID: toast.ID}, "Dismiss")})
								},
							)
						},
						func(toast ui.ToastDeclaration) any { return toast.ID },
						nil,
					)
				},
			))
			return ui.Fragment(children)
		},
	)
}
```

## Anatomy

- `ui.Toast.Provider`
- `ui.Toast.Portal`
- `ui.Toast.Viewport`
- `ui.Toast.Positioner`
- `ui.Toast.Root`
- `ui.Toast.Content`
- `ui.Toast.Title`
- `ui.Toast.Description`
- `ui.Toast.Action`
- `ui.Toast.Close`

## Key props

| Prop | Purpose |
| --- | --- |
| `Toasts` | Complete declared toast queue rendered by the viewport. |
| `ToastID` | Stable queue identifier associated with one rendered toast. |
| `Timeout` | Inherited auto-dismiss duration or warm-provider timeout. |
| `SwipeDirection` | Edge toward which a swipe dismisses or moves the surface. |
| `OnDismiss` | Reports toast identifiers dismissed by the core. |
