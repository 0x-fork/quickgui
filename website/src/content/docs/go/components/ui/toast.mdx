Presents timed, stacked notifications with action, close, and swipe behavior.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToastExample() *ui.Element {
	toast := ui.NewToast(ui.ToastProviderProps{Timeout: 5000, Limit: 3})
	return toast.Provider().Child(func() *native.Node {
		manager := ui.UseToastManager()
		save := ui.Button().Child("Save").OnClick(func() {
			manager.Add(ui.ToastRequest{Title: "Saved", Type: "success"})
		})
		viewport := toast.Viewport().Child(
			ui.For(manager.Toasts, func(item ui.ToastDeclaration, _ func() int) *ui.Element {
				return toast.Root(ui.ToastPartProps{ToastID: item.ID}).Children(
					toast.Title(ui.ToastPartProps{ToastID: item.ID}).Child(item.Title),
					toast.Close(ui.ToastPartProps{ToastID: item.ID}).Child("Dismiss"),
				)
			}, func(item ui.ToastDeclaration) any {
				return item.ID
			}, nil),
		)
		return ui.Fragment(save, viewport)
	})
}
```

## Anatomy

- `toast.Provider`
- `toast.Portal`
- `toast.Viewport`
- `toast.Positioner`
- `toast.Root`
- `toast.Content`
- `toast.Title`
- `toast.Description`
- `toast.Action`
- `toast.Close`

## Key props

| Prop | Purpose |
| --- | --- |
| `Toasts` | Complete declared toast queue rendered by the viewport. |
| `ToastID` | Stable queue identifier associated with one rendered toast. |
| `Timeout` | Inherited auto-dismiss duration or warm-provider timeout. |
| `SwipeDirection` | Edge toward which a swipe dismisses or moves the surface. |
| `OnDismiss` | Reports toast identifiers dismissed by the core. |
