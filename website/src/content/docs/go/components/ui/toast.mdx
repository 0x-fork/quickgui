Presents timed, stacked notifications with action, close, and swipe behavior.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToastExample() *native.Node {
	toast1 := ui.NewToast(ui.ToastProviderProps{Timeout: 5000, Limit: 3})
	return toast1.Provider().Children(func() *native.Node {
		var children []*native.Node
		manager := ui.UseToastManager()
		children = append(children, ui.Button().Child("Save").OnClick(func() {
			manager.Add(ui.ToastRequest{Title: "Saved", Type: "success"})
		}).Node)
		children = append(children, toast1.Viewport(ui.ToastViewportProps{}).Children(func() *native.Node {
			return ui.For(manager.Toasts, func(toast ui.ToastDeclaration, _ func() int) *native.Node {
				return toast1.Root(ui.ToastPartProps{ToastID: toast.ID}).Children(func() *native.Node {
					return ui.Fragment([]*native.Node{toast1.Title(ui.ToastPartProps{ToastID: toast.ID}).Children(toast.Title).NativeNode(), toast1.Close(ui.ToastPartProps{ToastID: toast.ID}).Children("Dismiss").NativeNode()})
				}).NativeNode()
			}, func(toast ui.ToastDeclaration) any {
				return toast.ID
			}, nil)
		}).NativeNode())
		return ui.Fragment(children)
	}).NativeNode()
}
```

## Anatomy

- `toast.Provider`
- `toast.Portal`
- `toast.Viewport`
- `toast.Positioner`
- `toast.Root`
- `toast.Content`
- `toast.Title`
- `toast.Description`
- `toast.Action`
- `toast.Close`

## Key props

| Prop | Purpose |
| --- | --- |
| `Toasts` | Complete declared toast queue rendered by the viewport. |
| `ToastID` | Stable queue identifier associated with one rendered toast. |
| `Timeout` | Inherited auto-dismiss duration or warm-provider timeout. |
| `SwipeDirection` | Edge toward which a swipe dismisses or moves the surface. |
| `OnDismiss` | Reports toast identifiers dismissed by the core. |
