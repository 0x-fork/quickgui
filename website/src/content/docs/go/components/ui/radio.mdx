One selectable item, normally declared inside a RadioGroup.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func RadioExample() *native.Node {
	value, setValue := ui.CreateSignal("system")
	radioGroup1 := ui.NewRadioGroup(ui.RadioGroupProps{Value: func() *string {
		current := value()
		return &current
	}, OnValueChange: func(next string, _ *native.Event) {
		setValue(next)
	}})
	return radioGroup1.Root().Children(func() *native.Node {
		var children []*native.Node
		for _, option := range []string{"light", "dark", "system"} {
			children = append(children, func() *native.Node {
				radio2 := ui.NewRadio(ui.RadioProps{Value: option})
				return radio2.Root().Children(func() *native.Node {
					return ui.Fragment([]*native.Node{radio2.Indicator(ui.PartProps{}).NativeNode(), ui.Text(option).Node})
				}).NativeNode()
			}())
		}
		return ui.Fragment(children)
	}).NativeNode()
}
```

## Anatomy

- `radio.Root`
- `radio.Indicator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Checked` | Controlled checked state. |
| `OnCheckedChange` | Reports the checked state accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
