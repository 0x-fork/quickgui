A disclosure-style navigation surface with animated direction, viewport, and popup parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func NavigationMenuExample() *native.Node {
	return ui.NavigationMenu.Root(
		ui.NavigationMenuRootProps{
			Items: []ui.ComponentItem{{Value: "products"}},
			Delay: 100,
		},
		func() *native.Node {
			return ui.NavigationMenu.List(
				ui.PartProps{},
				func() *native.Node {
					return ui.NavigationMenu.Item(
						ui.NavigationMenuItemProps{Value: "products"},
						func() *native.Node {
							return ui.Fragment([]*native.Node{ui.NavigationMenu.Trigger(ui.NavigationMenuPartProps{}, "Products"),
								ui.NavigationMenu.Positioner(
									ui.NavigationMenuPartProps{},
									func() *native.Node {
										return ui.NavigationMenu.Popup(
											ui.NavigationMenuPartProps{},
											func() *native.Node {
												return ui.NavigationMenu.Link(
													ui.NavigationMenuLinkProps{Value: "overview"},
													"Overview",
												)
											},
										)
									},
								)})
						},
					)
				},
			)
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `Delay` | Core-owned delay in milliseconds before opening. |
