A disclosure-style navigation surface with animated direction, viewport, and popup parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func NavigationMenuExample() *ui.Element {
	menu := ui.NewNavigationMenu().Items([]ui.ComponentItem{{Value: "products"}}).Delay(100)
	return menu.Root().Child(
		menu.List().Child(
			menu.Item(ui.NavigationMenuItemProps{Value: "products"}).Children(
				menu.Trigger().Child("Products"),
				menu.Positioner().Child(
					menu.Popup().Child(
						menu.Link(ui.NavigationMenuLinkProps{Value: "overview"}).Child("Overview"),
					),
				),
			),
		),
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `Delay` | Core-owned delay in milliseconds before opening. |
