A keyboard-navigable month grid for single-date selection.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func CalendarExample(weeks [][]string) *native.Node {
	return ui.Calendar.Root(
		ui.CalendarRootProps{DefaultValue: "2026-09-03"},
		func() *native.Node {
			var children []*native.Node
			for index, week := range weeks {
				children = append(children, ui.Calendar.Week(
					ui.CalendarWeekProps{Index: &index},
					func() *native.Node {
						var children []*native.Node
						for _, day := range week {
							children = append(children, ui.Calendar.Day(ui.CalendarDayProps{Day: day}, day))
						}
						return ui.Fragment(children)
					},
				))
			}
			return ui.Fragment(children)
		},
	)
}
```

## Anatomy

- `ui.Calendar.Root`
- `ui.Calendar.Week`
- `ui.Calendar.Day`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `FirstWeekday` | First weekday column, where Monday is 0 and Sunday is 6. |
| `OnValueChange` | Reports the value accepted by the core. |
