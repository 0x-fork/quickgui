A single- or multi-thumb range input with core-owned pointer and keyboard interaction.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SliderExample() {
	volume, setVolume := ui.CreateSignal([]float64{40})
	ui.Slider.Root(
		ui.SliderRootProps{
			Value:         volume,
			Min:           0,
			Max:           100,
			Step:          1,
			OnValueChange: func(next []float64, _ *native.Event) { setVolume(next) },
		},
		func() {
			ui.Slider.Label(ui.PartProps{}, "Volume")
			ui.Slider.Control(
				ui.PartProps{Style: ui.Styles(ui.Width(240), ui.Height(24))},
				func() {
					ui.Slider.Track(
						ui.PartProps{},
						func() { ui.Slider.Indicator(ui.PartProps{}) },
					)
					ui.Slider.Thumb(ui.SliderThumbProps{})
				},
			)
			ui.Slider.Value(ui.PartProps{})
		},
	)
}
```

## Anatomy

- `ui.Slider.Range`
- `ui.Slider.Indicator`
- `ui.Slider.Thumb`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `Step` | Increment used by keyboard, pointer, or native control input. |
| `OnValueChange` | Reports the value accepted by the core. |
