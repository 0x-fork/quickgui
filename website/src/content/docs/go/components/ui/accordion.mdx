Coordinates one or more expandable sections and their keyboard focus.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func AccordionExample() *native.Node {
	accordion1 := ui.NewAccordion(ui.AccordionRootProps{Multiple: true})
	return accordion1.Root().Children(func() *native.Node {
		return accordion1.ItemWith(ui.AccordionItemProps{Value: "details"}).Children(func() *native.Node {
			return ui.Fragment([]*native.Node{accordion1.Header(ui.PartProps{}).Children(func() *native.Node {
				return accordion1.Trigger(ui.PartProps{}).Children("Details").NativeNode()
			}).NativeNode(), accordion1.Panel(ui.PartProps{}).Children("Mounted when opened").NativeNode()})
		}).NativeNode()
	}).NativeNode()
}
```

## Anatomy

- `accordion.Root`
- `accordion.Item`
- `accordion.Header`
- `accordion.Trigger`
- `accordion.Panel`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Multiple` | Allows more than one value to be selected or opened. |
| `KeepMounted` | Keeps inactive content mounted with display disabled. |
