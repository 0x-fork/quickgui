Connects one control to its label, description, validation state, and error message.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func FieldExample() *native.Node {
	email, setEmail := ui.CreateSignal("")
	return ui.Field.Root(
		ui.FieldRootProps{
			Required: true,
			Filled:   func() bool { return email() != "" },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Field.Label(ui.FieldLabelProps{}, "Email"),
				ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{
					Value:       email,
					Placeholder: "you@example.com",
					OnInput:     func(event *native.Event) { setEmail(event.Value) },
				}}),
				ui.Field.Description(ui.PartProps{}, "Used for receipts"),
				ui.Field.Error(ui.PartProps{}, "Enter a valid email address")})
		},
	)
}
```

## Anatomy

- `ui.Field.Root`
- `ui.Field.Item`
- `ui.Field.Label`
- `ui.Field.Control`
- `ui.Field.Validity`
- `ui.Field.Description`
- `ui.Field.Error`

## Key props

| Prop | Purpose |
| --- | --- |
| `Invalid` | Projects invalid state to the field and its parts. |
| `Required` | Marks the value as required for validation and form submission. |
| `ValidationMessage` | Bounded message exposed to error content and accessibility. |
| `ValidationMode` | Selects which interaction boundary triggers validation. |
| `OnValidationChange` | Reports the validation trigger and timing selected by the core. |
