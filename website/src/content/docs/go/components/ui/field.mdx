Connects one control to its label, description, validation state, and error message.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func FieldExample() *native.Node {
	email, setEmail := ui.CreateSignal("")
	field1 := ui.NewField(ui.FieldRootProps{Required: true, Filled: func() bool {
		return email() != ""
	}})
	return field1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{field1.Label(ui.FieldLabelProps{}).Children("Email").NativeNode(), field1.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Value: email, Placeholder: "you@example.com", OnInput: func(event *native.Event) {
			setEmail(event.Value)
		}}}).NativeNode(), field1.Description(ui.PartProps{}).Children("Used for receipts").NativeNode(), field1.Error(ui.PartProps{}).Children("Enter a valid email address").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `field.Root`
- `field.Item`
- `field.Label`
- `field.Control`
- `field.Validity`
- `field.Description`
- `field.Error`

## Key props

| Prop | Purpose |
| --- | --- |
| `Invalid` | Projects invalid state to the field and its parts. |
| `Required` | Marks the value as required for validation and form submission. |
| `ValidationMessage` | Bounded message exposed to error content and accessibility. |
| `ValidationMode` | Selects which interaction boundary triggers validation. |
| `OnValidationChange` | Reports the validation trigger and timing selected by the core. |
