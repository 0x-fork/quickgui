A general-purpose retained container for layout, paint, pointer input, and accessibility.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ViewExample() *ui.Element {
	return ui.View().
		Padding(20).Gap(12).
		Child(ui.Text("Hello from Go")).
		Child(ui.Button().OnClick(func() {}).Child("Continue"))
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `ui.Style().BackgroundColor(...)`, `ui.Style().Padding(...)`, `ui.Style().Hover(...)` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `Child`, `Children` | Content mounted inside the component. |
| `OnClick` | Runs after the core resolves an activation. |
| `Ref` | Receives the retained native node. |
