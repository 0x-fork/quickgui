Switches between labeled panels with automatic or manual keyboard activation.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TabsExample() *ui.Element {
	tabs := ui.NewTabs().DefaultValue("overview").Activation("automatic")
	return tabs.Root().Children(
		tabs.List().Children(
			tabs.Tab("overview").Child("Overview"),
			tabs.Tab("settings").Child("Settings"),
		),
		tabs.Panel("overview").Child("Overview content"),
		tabs.Panel("settings").Child("Settings content"),
	)
}
```

## Anatomy

- `tabs.Root`
- `tabs.List`
- `tabs.Tab`
- `tabs.Indicator`
- `tabs.Panel`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `Activation` | Whether focus or an explicit press activates a tab. |
