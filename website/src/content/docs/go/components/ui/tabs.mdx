Switches between labeled panels with automatic or manual keyboard activation.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TabsExample() *native.Node {
	tabs1 := ui.NewTabs(ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"})
	return tabs1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{tabs1.List(ui.PartProps{}).Children(func() *native.Node {
			return ui.Fragment([]*native.Node{tabs1.TabWith(ui.TabsTabProps{Value: "overview"}).Children("Overview").NativeNode(), tabs1.TabWith(ui.TabsTabProps{Value: "settings"}).Children("Settings").NativeNode()})
		}).NativeNode(), tabs1.PanelWith(ui.TabsPanelProps{Value: "overview"}).Children("Overview content").NativeNode(), tabs1.PanelWith(ui.TabsPanelProps{Value: "settings"}).Children("Settings content").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `tabs.Root`
- `tabs.List`
- `tabs.Tab`
- `tabs.Indicator`
- `tabs.Panel`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `Activation` | Whether focus or an explicit press activates a tab. |
