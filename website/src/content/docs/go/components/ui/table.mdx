A virtualized tabular collection with header, row, and cell parts.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TableExample(rows []string) *native.Node {
	table1 := ui.NewTable(ui.TableRootProps{Columns: func() []ui.TableColumnDeclaration {
		return []ui.TableColumnDeclaration{{ID: "name", Label: "Name", Track: "1fr", Sortable: true}}
	}, RowCount: func() float64 {
		return float64(len(rows))
	}, RowHeight: 26, HeaderHeight: 28, PartProps: ui.PartProps{Style: ui.Style().Height(260).OverflowY("scroll")}})
	return table1.Root().Children(func() *native.Node {
		var children []*native.Node
		children = append(children, table1.Header(ui.TableHeaderProps{Column: "name"}).Children("Name").NativeNode())
		for index, name := range rows {
			children = append(children, table1.Row(ui.TableRowProps{Index: index}).Children(func() *native.Node {
				return table1.Cell(ui.TableCellProps{Column: "name"}).Children(name).NativeNode()
			}).NativeNode())
		}
		return ui.Fragment(children)
	}).NativeNode()
}
```

## Anatomy

- `table.Root`
- `table.Header`
- `table.Row`
- `table.Cell`

## Key props

| Prop | Purpose |
| --- | --- |
| `Columns` | Column declarations for the virtual table. |
| `RowCount` | Total logical row count. |
| `RowHeight` | Logical height of each virtualized row. |
| `SelectionMode` | Allows single or multiple table selection. |
| `Selection` | Controlled selection for a table, native picker, or color control. |
