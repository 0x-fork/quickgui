A single- or multiple-choice picker whose option surface is rendered in a native popover window.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SelectExample() *ui.Element {
	value, setValue := ui.CreateSignal[*string](nil)
	selectBox := ui.NewSelect(ui.SelectRootProps{PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
		return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
	}}, Value: value, OnValueChange: func(next *string, _ *native.Event) {
		setValue(next)
	}})
	return selectBox.Root().Children(
		selectBox.Value(),
		selectBox.Icon().Child("▾"),
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Multiple` | Allows more than one value to be selected or opened. |
| `OnValueChange` | Reports the value accepted by the core. |
