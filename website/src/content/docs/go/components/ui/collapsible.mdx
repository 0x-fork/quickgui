Shows and hides one panel from a trigger while preserving accessible state.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func CollapsibleExample() *native.Node {
	collapsible1 := ui.NewCollapsible(ui.CollapsibleRootProps{})
	return collapsible1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{collapsible1.Trigger(ui.PartProps{}).Children("Show details").NativeNode(), collapsible1.Panel(ui.PartProps{}).Children("Mounted when opened").NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `collapsible.Root`
- `collapsible.Trigger`
- `collapsible.Panel`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `KeepMounted` | Keeps inactive content mounted with display disabled. |
