The confirmation-focused dialog variant with stricter backdrop-dismissal defaults.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func AlertDialogExample() *native.Node {
	alertDialog1 := ui.NewAlertDialog(ui.DialogRootProps{})
	return alertDialog1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{alertDialog1.Trigger(ui.PartProps{}).Children("Open dialog").NativeNode(), alertDialog1.Portal(ui.PartProps{}).Children(func() *native.Node {
			return ui.Fragment([]*native.Node{alertDialog1.Backdrop(ui.PartProps{}).NativeNode(), alertDialog1.Viewport(ui.PartProps{}).Children(func() *native.Node {
				return alertDialog1.Popup(ui.DialogPopupProps{}).Children(func() *native.Node {
					return ui.Fragment([]*native.Node{alertDialog1.Title(ui.PartProps{}).Children("Confirm action").NativeNode(), alertDialog1.Description(ui.PartProps{}).Children("Review the details before continuing.").NativeNode(), alertDialog1.Close(ui.PartProps{}).Children("Cancel").NativeNode()})
				}).NativeNode()
			}).NativeNode()})
		}).NativeNode()})
	}).NativeNode()
}
```

## Anatomy

- `alertDialog.Root`
- `alertDialog.Trigger`
- `alertDialog.Portal`
- `alertDialog.Backdrop`
- `alertDialog.Viewport`
- `alertDialog.Popup`
- `alertDialog.Title`
- `alertDialog.Description`
- `alertDialog.Close`

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `DismissOnEscape` | Allows Escape to dismiss the surface. |
| `ExitDuration` | Keeps closing content mounted for the exact exit transition duration. |
