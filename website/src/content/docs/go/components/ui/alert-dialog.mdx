The confirmation-focused dialog variant with stricter backdrop-dismissal defaults.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func AlertDialogExample() {
	ui.AlertDialog.Root(
		ui.DialogRootProps{},
		func() {
			ui.AlertDialog.Trigger(ui.PartProps{}, "Open dialog")
			ui.AlertDialog.Portal(
				ui.PartProps{},
				func() {
					ui.AlertDialog.Backdrop(ui.PartProps{})
					ui.AlertDialog.Viewport(
						ui.PartProps{},
						func() {
							ui.AlertDialog.Popup(
								ui.DialogPopupProps{},
								func() {
									ui.AlertDialog.Title(ui.PartProps{}, "Confirm action")
									ui.AlertDialog.Description(
										ui.PartProps{},
										"Review the details before continuing.",
									)
									ui.AlertDialog.Close(ui.PartProps{}, "Cancel")
								},
							)
						},
					)
				},
			)
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Open` | Controlled open state. |
| `DefaultOpen` | Initial state when the component owns whether it is open. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `DismissOnEscape` | Allows Escape to dismiss the surface. |
| `ExitDuration` | Keeps closing content mounted for the exact exit transition duration. |
