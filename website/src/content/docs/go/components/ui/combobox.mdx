Combines editable text, filtering, optional chips, and a native suggestion surface.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ComboboxExample() *native.Node {
	value, setValue := ui.CreateSignal[*string](nil)
	combobox1 := ui.NewCombobox(ui.ComboboxRootProps{PickerInputProps: ui.PickerInputProps{PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
		return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
	}}, Placeholder: "Choose a language"}, Value: value, OnValueChange: func(next *string, _ *native.Event) {
		setValue(next)
	}})
	return combobox1.Root().NativeNode()
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `InputValue` | Editable query text used by a combobox or autocomplete. |
| `Multiple` | Allows more than one value to be selected or opened. |
| `FilterMode` | Core-owned contains, prefix, fuzzy, or disabled filtering. |
| `OnValueChange` | Reports the value accepted by the core. |
