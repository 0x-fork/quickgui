A pressable control that retains an on or off pressed state.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToggleExample() *native.Node {
	on, setOn := ui.CreateSignal(false)
	toggle1 := ui.NewToggle(ui.ToggleProps{Pressed: on, OnPressedChange: func(next bool, _ *native.Event) {
		setOn(next)
	}})
	return toggle1.Root().Children(func() *native.Node {
		return ui.Fragment([]*native.Node{toggle1.Indicator(ui.PartProps{}).NativeNode(), ui.Text("Notifications").Node})
	}).NativeNode()
}
```

## Anatomy

- `toggle.Root`
- `toggle.Indicator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Pressed` | Controlled pressed state. |
| `DefaultPressed` | Initial pressed state when the component owns it. |
| `OnPressedChange` | Reports the pressed state accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
