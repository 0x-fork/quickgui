A pressable control that retains an on or off pressed state.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToggleExample() {
	on, setOn := ui.CreateSignal(false)
	ui.Toggle.Root(
		ui.ToggleProps{
			Pressed:         on,
			OnPressedChange: func(next bool, _ *native.Event) { setOn(next) },
		},
		func() { ui.Toggle.Indicator(ui.PartProps{}); ui.Text("Notifications") },
	)
}
```

## Anatomy

- `ui.Toggle.Root`
- `ui.Toggle.Indicator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Pressed` | Controlled pressed state. |
| `DefaultPressed` | Initial pressed state when the component owns it. |
| `OnPressedChange` | Reports the pressed state accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
