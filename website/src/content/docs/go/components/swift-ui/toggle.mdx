A controlled native SwiftUI on/off switch.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiToggleExample() {
	on, setOn := ui.CreateSignal(true)
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `IsOn` | Controlled SwiftUI toggle value. |
| `Label` | Visible native SwiftUI control label. |
| `OnIsOnChange` | Reports the value accepted by the native SwiftUI toggle. |
| `Modifiers` | Ordered SwiftUI view modifiers applied to the hosted control. |
