A controlled SwiftUI picker with menu, segmented, radio-group, and inline styles.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiPickerExample() {
	value, setValue := ui.CreateSignal("list")
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Picker(ui.SwiftUIPickerProps{
				Selection:         value,
				Options:           []ui.SwiftUIPickerOption{{Value: "list", Label: "List"}, {Value: "grid", Label: "Grid"}},
				OnSelectionChange: func(next string, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Selection` | Controlled selection for a table, native picker, or color control. |
| `Options` | Ordered native picker options. |
| `Label` | Visible native SwiftUI control label. |
| `Style` | Native SwiftUI presentation style for this control. |
| `OnSelectionChange` | Reports the selected native picker option or color. |
