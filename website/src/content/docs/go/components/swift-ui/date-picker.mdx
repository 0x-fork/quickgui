A controlled native date or date-and-time picker.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"time"
)
```

## Usage

```go
func SwiftUiDatePickerExample() {
	value, setValue := ui.CreateSignal(float64(time.Now().UnixMilli()))
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.DatePicker(ui.SwiftUIDatePickerProps{
				Value:               value,
				DisplayedComponents: "dateAndTime",
				OnValueChange:       func(next float64, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Unix timestamp in milliseconds; `Min` and `Max` use the same unit. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `DisplayedComponents` | Chooses date, time, or combined date-and-time fields. |
| `Style` | `automatic`, `field`, `stepperField`, or `graphical`. |
| `OnValueChange` | Reports the value accepted by the core. |
