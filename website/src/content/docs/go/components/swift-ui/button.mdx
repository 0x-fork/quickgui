A native SwiftUI button with text, SF Symbol, semantic role, and press handling.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiButtonExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{
				Label:       "Save",
				SystemImage: "checkmark",
				OnPress:     func(*native.Event) { fmt.Println("Saved") },
				Modifiers:   []ui.SwiftUIModifier{ui.SwiftUI.ButtonStyle("borderedProminent")},
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Label` | Visible native SwiftUI control label. |
| `SystemImage` | SF Symbols name displayed with a SwiftUI button label. |
| `Role` | SwiftUI semantic role: `default`, `cancel`, or `destructive`. |
| `OnPress` | Runs when the native SwiftUI button is activated. |
| `Modifiers` | Ordered SwiftUI view modifiers applied to the hosted control. |
