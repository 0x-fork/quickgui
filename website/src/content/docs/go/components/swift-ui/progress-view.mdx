A determinate or indeterminate native SwiftUI progress indicator.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiProgressViewExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.ProgressView(ui.SwiftUIProgressViewProps{
				Value: 0.4,
				Total: 1,
				Label: "Uploading",
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Total` | Denominator for determinate SwiftUI progress. |
| `Label` | Visible native SwiftUI control label. |
| `CurrentValueLabel` | Readable label for the current native progress or gauge value. |
