A controlled native SwiftUI text field with edit and submit callbacks.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiTextFieldExample() *native.Node {
	text, setText := ui.CreateSignal("")
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.TextField(ui.SwiftUITextFieldProps{
				Value:         text,
				Placeholder:   "Enter text",
				OnValueChange: func(next string, _ *native.Event) { setText(next) },
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Placeholder` | Text shown while the editable value is empty. |
| `OnValueChange` | Reports the value accepted by the core. |
| `OnSubmit` | Runs when the native field submits its current value. |
