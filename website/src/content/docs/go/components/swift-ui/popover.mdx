Presents a native SwiftUI popover from a composed SwiftUI trigger.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiPopoverExample() *native.Node {
	open, setOpen := ui.CreateSignal(false)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Popover.Root(
				ui.SwiftUIPopoverProps{
					IsPresented:         open,
					OnIsPresentedChange: setOpen,
				},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.SwiftUI.Popover.Trigger(ui.SwiftUIPopoverTriggerProps{Render: func() *native.Node { return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Account"}) }}),
						ui.SwiftUI.Popover.Content(
							ui.SwiftUIPopoverContentProps{},
							func() *native.Node {
								return ui.SwiftUI.QuickGUIHostView(
									ui.SwiftUIQuickGUIHostViewProps{Width: 240, Height: 120},
									"Account settings",
								)
							},
						)})
				},
			)
		},
	)
}
```

## Anatomy

- `ui.SwiftUI.Popover.Trigger`
- `ui.SwiftUI.Popover.Content`

## Key props

| Prop | Purpose |
| --- | --- |
| `IsPresented` | Controlled native SwiftUI popover presentation state. |
| `OnIsPresentedChange` | Reports native SwiftUI popover presentation changes. |
| `AttachmentAnchor` | Anchor point on the composed SwiftUI trigger. |
| `ArrowEdge` | Preferred edge for the native SwiftUI popover arrow. |
