A native SwiftUI gauge with linear and circular accessory styles.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiGaugeExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Gauge(ui.SwiftUIGaugeProps{
				Value: 60,
				Min:   0,
				Max:   100,
				Label: "Capacity",
				Style: "accessoryLinearCapacity",
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Min` | Minimum accepted value. |
| `Max` | Maximum accepted value. |
| `Label` | Visible native SwiftUI control label. |
| `CurrentValueLabel` | Readable label for the current native progress or gauge value. |
| `Style` | Native SwiftUI presentation style for this control. |
