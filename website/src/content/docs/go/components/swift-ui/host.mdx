The NSHostingView-backed leaf that mounts one SwiftUI component tree inside QuickGUI.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiHostExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `MatchContents` | Uses the hosted subtree’s intrinsic width, height, or both. |
| `Style` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
