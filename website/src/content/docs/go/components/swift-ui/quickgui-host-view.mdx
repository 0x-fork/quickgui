Reverse-hosts one ordinary QuickGUI subtree inside a SwiftUI hierarchy.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiQuickguiHostViewExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.QuickGUIHostView(
				ui.SwiftUIQuickGUIHostViewProps{Width: 320, Height: 180},
				func() *ui.Element {
					return ui.View(
						"QuickGUI inside SwiftUI",
					).Width("100%").Height("100%").Padding(16)
				},
			)
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Width` | Declared logical width. |
| `Height` | Declared logical height. |
| `MatchContents` | Uses the hosted subtree’s intrinsic width, height, or both. |
| `Background` | Clear color for the reverse-hosted QuickGUI WGPU surface. |
| `children` | Content mounted inside the component. |
