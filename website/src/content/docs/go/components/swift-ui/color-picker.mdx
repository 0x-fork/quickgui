A native SwiftUI color well that returns CSS-style RGBA color strings.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiColorPickerExample() {
	value, setValue := ui.CreateSignal("#2563ebff")
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.ColorPicker(ui.SwiftUIColorPickerProps{
				Selection:         value,
				Label:             "Accent",
				SupportsOpacity:   true,
				OnSelectionChange: func(next string, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Selection` | Controlled selection for a table, native picker, or color control. |
| `Label` | Visible native SwiftUI control label. |
| `SupportsOpacity` | Allows alpha selection in the native color panel. |
| `OnSelectionChange` | Reports the selected native picker option or color. |
