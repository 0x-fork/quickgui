A native segmented picker with value-selection and neutral Xcode-style tab roles.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwiftUiSegmentedControlExample() *native.Node {
	value, setValue := ui.CreateSignal("list")
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.SegmentedControl(ui.SwiftUISegmentedControlProps{
				Selection:         value,
				Options:           []ui.SwiftUIPickerOption{{Value: "list", Label: "List"}, {Value: "grid", Label: "Grid"}},
				OnSelectionChange: func(next string, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Selection` | Controlled selection for a table, native picker, or color control. |
| `Options` | Ordered native picker options. |
| `Label` | Visible native SwiftUI control label. |
| `Role` | Accessibility role exposed by the retained node. |
| `OnSelectionChange` | Reports the selected native picker option or color. |
