Animate changes to retained nodes with `ui.Transition(...)`. The native runtime advances the frames; your component does not rerun for every frame. Import `ui` from `github.com/egoist/quickgui/go/ui`.

## Hover transitions

Put the transition on the base style so it applies when the pointer enters and leaves. The same declaration works with other paint states, including `Active`, `Focus`, `Expanded`, and `DragOver`.

```go
func HoverAction() {
	ui.Button(
		"Continue",
		ui.Padding(12),
		ui.BorderRadius(8),
		ui.BackgroundColor("#334155"),
		ui.Color("white"),
		ui.Opacity(0.85),
		ui.Transition("background-color 160ms ease-out, opacity 160ms ease-out"),
		ui.Hover(ui.BackgroundColor("#2563eb"), ui.Opacity(1)),
	)
}
```

## State-driven animation

Use a signal or `ui.When` to change the target. The card below keeps the same node and children while its color and opacity animate.

```go
func AnimatedSelection() {
	selected, setSelected := ui.CreateSignal(false)
	ui.View(
		func() {
			ui.Button("Toggle emphasis", ui.OnClick(func() { setSelected(!selected()) }))
			ui.View(
				"Your selection",
				ui.Padding(20),
				ui.BorderRadius(12),
				ui.BackgroundColor("#334155"),
				ui.Color("white"),
				ui.Opacity(0.6),
				ui.Transition("background-color 180ms ease-out, opacity 180ms ease-out"),
				ui.When(selected, ui.BackgroundColor("#2563eb"), ui.Opacity(1)),
			)
		},
		ui.Display("flex"),
		ui.FlexDirection("column"),
		ui.Gap(12),
	)
}
```

Updating the target during a transition starts from its current visible value, including when reversing direction.

## Timing and frame rate

Use `ui.TransitionDeclaration` when several properties share one timing configuration. Import `time` for the duration in this example.

```go
func CappedTransition() {
	ui.Button(
		"Hover me",
		ui.Padding(12),
		ui.BackgroundColor("#334155"),
		ui.Color("white"),
		ui.Opacity(0.8),
		ui.Transition(ui.TransitionDeclaration{
			Properties: []string{"background-color", "opacity"},
			Duration:   180 * time.Millisecond,
			Easing:     "ease-out",
			MaxFps:     30,
		}),
		ui.Hover(ui.BackgroundColor("#2563eb"), ui.Opacity(1)),
	)
}
```

Pass longhand transition props directly to the primitive:

| Field | Usage |
| --- | --- |
| `ui.TransitionProperty(...)` | A comma-separated string or `[]string` of supported property names. |
| `ui.TransitionDuration(...)` | Milliseconds as a number, a `time.Duration`, or a string such as `"180ms"` or `"0.18s"`. The host bounds durations to 0–10 seconds. |
| `ui.TransitionEasing(...)` | `"linear"`, `"ease"`, `"ease-in"`, `"ease-out"`, or `"ease-in-out"`. `"ease"` aliases the default `"ease-in-out"`; these select QuickGUI curves. |
| `ui.TransitionTimingFunction(...)` | Alias for `ui.TransitionEasing(...)`. |
| `ui.TransitionMaxFps(...)` | Optional frame-rate cap. Omit it to follow display presentation; completion still occurs at the transition deadline. |

A node has one duration, easing, and frame-rate cap for all selected properties. Comma-separated shorthand entries collect property names; the last duration and easing apply to the entire list. Delays, `cubic-bezier()`, and independent timings per property are not supported. Explicit longhand fields override the shorthand.

A duration alone, such as `ui.Transition(180 * time.Millisecond)`, transitions background, border, and text colors. Select `"all"` explicitly to include all supported paint properties. Use `ui.Transition("none")` to remove the shorthand declaration.

## Supported properties

| Transition name | Go style prop |
| --- | --- |
| `background-color` or `background` | `ui.BackgroundColor(...)` or a solid `ui.Background(...)` |
| `border-color` | `ui.BorderColor(...)` |
| `border-width` | `ui.BorderWidth(...)` and edge widths |
| `border-radius` | `ui.BorderRadius(...)` and corner radii |
| `color` | Inherited `ui.Color(...)` |
| `opacity` | Subtree `ui.Opacity(...)` |
| `box-shadow` | `ui.BoxShadow(...)` |
| `transform` | Subtree `ui.Transform(...)`, including translation, scale, and rotation |

`"all"` means these properties. Gradient stops, width, height, padding, and other layout values do not interpolate through `Transition`. Unsupported transition property names are rejected.

For a sliding switch thumb, use `ui.Transform("translateX(20px)")` and `ui.Transition("transform 160ms ease-out")`, then change the target to `"translateX(0px)"` when unchecked. This moves the painted subtree and its hit area without moving neighboring layout. Transforms interpolate their affine translation, scale, shear, and shortest rotation; `TransformOrigin` itself changes immediately.

The Go UI API exposes paint transitions and animated images. CSS keyframes, timeline callbacks, and spring declarations are not Go style props.

## Mounting and reduced motion

A transition animates a change on an existing node; initial styles are applied directly. Keep the node mounted while changing its target. `ui.Show` removes its children when false and does not wait for an exit fade. Opacity zero alone keeps layout and input behavior.

For dialogs, `ui.DialogRootProps.EnterDuration` and `ExitDuration` control transition completion and closing-content lifetime; `OnOpenChangeComplete` reports completion. Those durations do not create visual styles by themselves. See [Dialog](/docs/go/components/dialog).

Transitions respect the system's Reduce Motion preference. `native.WindowOptions.ReduceMotion` accepts a `*bool` for an explicit window policy; leave it nil to follow the system. Motion resolves to its target under Reduce Motion. Hidden or occluded windows pause local transitions, and completed transitions stop requesting frames.

## Animated images

Pass an animated GIF or WebP path to `ui.Image`. The native decoder retains the frames and the file's repeat policy; no Go timer or per-frame signal is needed.

```go
func AnimatedImage(path string) {
	ui.Image(
		ui.Value(path),
		ui.Width(96),
		ui.Height(96),
		ui.ObjectFit("contain"),
	)
}
```

The path must resolve to an available file, or you can pass a data URL. Package file assets with the CLI's `resources` option. See [Image](/docs/go/components/image) and [project configuration](/docs/go/project-structure#configuration).
