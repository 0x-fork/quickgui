QuickGUI combines unstyled primitives with accessible compound controls. Compose both through ordinary Go functions.

## Defining components

A Go component returns `*ui.Element` or `*native.Node`. Use plain typed props and compose children directly. The return type identifies the component, so `CounterLabel(count())` stays reactive without annotations or a `ui.View().Child(func() *ui.Element { ... })` wrapper. Window roots accept the component function directly.

```go
func CounterLabel(count int) *ui.Element {
	return ui.Text("Count: ", count).FontSize(20)
}

func ComponentExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().Children(
		CounterLabel(count()),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

Struct props use ordinary Go types too. Updating `quantity` changes the bound text while `LineItem` and its nodes remain mounted.

```go
type Product struct {
	ID    string
	Name  string
	Price int
}

func LineItem(product Product, quantity int) *ui.Element {
	return ui.Text(product.Name, " × ", quantity, " = $", product.Price*quantity)
}

func Cart() *ui.Element {
	quantity, setQuantity := ui.CreateSignal(1)
	return ui.View().Children(
		LineItem(Product{ID: "mug", Name: "Mug", Price: 12}, quantity()),
		ui.Button("Add one").OnClick(func() { setQuantity(quantity() + 1) }),
	)
}
```

Start containers with `ui.View()` and append content with `.Child(...)` or `.Children(...)`, as shown below. A children callback is optional and runs once when mounted; use it when construction must happen lazily or inside a compound control’s context. Event handlers remain callbacks.

```go
func CardComponent(title string, children ...any) *ui.Element {
	return ui.View().Children(
		ui.Text(title).FontWeight(600),
		children,
	).Padding(20).Gap(12).FlexCol()
}

func CardComposition() *ui.Element {
	return CardComponent("Account",
		ui.Text("Manage your account settings."),
		ui.Button("Save").OnClick(func() { log.Print("Saved") }),
	)
}
```

## Primitives

Start with `ui.View`, `ui.Text`, `ui.Button`, and `ui.Input`. Use `ui.View().Child(...).Child(...)` or `.Children(...)` for containers, and chain styles, properties, and handlers. Return a node from component functions and deferred child callbacks.

```go
func ButtonExample(save func()) *ui.Element {
	return ui.Button(
		"Save changes",
	).
		Height(40).
		PaddingLeft(16).
		PaddingRight(16).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
		OnClick(save)

}
```

## Compound components

Compound families expose parts such as `ui.Tabs.Root`, `ui.Tabs.List`, and `ui.Tabs.Panel`. The core handles roles, keyboard navigation, focus, and control state. Create a part inside its root’s children callback so its context exists.

```go
func TabsExample() *native.Node {
	return ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Tabs.List(
				ui.PartProps{},
				func() *native.Node {
					return ui.Fragment([]*native.Node{ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview"),
						ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings")})
				},
			),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content"),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content")})
		},
	)
}
```

## Controlled state

A controlled value is an accessor; its callback stores the value accepted by the control. Use a default value to let the component own its state. Optional scalar values use pointers, while multiple selections use slices.

```go
func CheckboxExample() *native.Node {
	checked, setChecked := ui.CreateSignal(false)
	return ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{ui.Checkbox.Indicator(ui.PartProps{}, "✓"), ui.Text("Remember me").
				Node})
		},
	)
}
```

## Styling parts

Use `PartProps.Style` for each part. Build styles with `ui.Style()` and fluent modifiers; combine shared builders with `.Merge(...)`. Parts also accept slices of builders and accessors returning them. Selection and theme signals update retained parts without rebuilding children.

```go
ui.PartProps{
	Style: ui.Style().
		Display("flex").
		Height(32).
		PaddingLeft(12).
		PaddingRight(12).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8),
}
```
