QuickGUI combines unstyled primitives with accessible compound controls. Compose both through ordinary Go functions.

## Defining components

A Go component returns `*ui.Element` or `*native.Node`. Use plain typed props and compose children directly. The return type identifies the component, so `CounterLabel(count())` stays reactive without annotations or a `ui.View().Child(func() *ui.Element { ... })` wrapper. Window roots accept the component function directly.

```go
func CounterLabel(count int) *ui.Element {
	return ui.Text("Count: ", count).FontSize(20)
}

func ComponentExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().Children(
		CounterLabel(count()),
		ui.Button().Child("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

Struct props use ordinary Go types too. Updating `quantity` changes the bound text while `LineItem` and its nodes remain mounted.

```go
type Product struct {
	ID    string
	Name  string
	Price int
}

func LineItem(product Product, quantity int) *ui.Element {
	return ui.Text(product.Name, " × ", quantity, " = $", product.Price*quantity)
}

func Cart() *ui.Element {
	quantity, setQuantity := ui.CreateSignal(1)
	return ui.View().Children(
		LineItem(Product{ID: "mug", Name: "Mug", Price: 12}, quantity()),
		ui.Button().Child("Add one").OnClick(func() { setQuantity(quantity() + 1) }),
	)
}
```

Start containers with `ui.View()` and append content with `.Child(...)` or `.Children(...)`, as shown below. A children callback is optional and runs once when mounted; use it when construction must happen lazily or inside a compound control’s context. Event handlers remain callbacks.

```go
func CardComponent(title string, children ...any) *ui.Element {
	return ui.View().Children(
		ui.Text(title).FontWeight(600),
		children,
	).Padding(20).Gap(12).FlexCol()
}

func CardComposition() *ui.Element {
	return CardComponent("Account",
		ui.Text("Manage your account settings."),
		ui.Button().Child("Save").OnClick(func() { log.Print("Saved") }),
	)
}
```

## Primitives

Start with `ui.View`, `ui.Text`, `ui.Button`, and `ui.Input`. Use `ui.View().Child(...).Child(...)` or `.Children(...)` for containers, and chain styles, properties, and handlers. Return a node from component functions and deferred child callbacks.

```go
func ButtonExample(save func()) *ui.Element {
	return ui.Button().Child("Save changes").
		Height(40).
		PaddingLeft(16).
		PaddingRight(16).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
		OnClick(save)

}
```

## Compound components

Create a component instance and compose its named parts. Every part returns a fluent `*ui.Element`; strings work directly as children, just as `.child("text")` does in Rust.

```go
func TabsExample() *ui.Element {
    tabs := ui.NewTabs().DefaultValue("account")
    return tabs.Root().Children(
        tabs.List().Children(
            tabs.Tab("account").Child("Account"),
            tabs.Tab("security").Child("Security"),
        ),
        tabs.Panel("account").Child("Account settings"),
        tabs.Panel("security").Child("Security settings"),
    )
}
```

Configure behavior on the instance and styles on its parts. Parts establish their context when inserted, so ordinary nesting works without provider callbacks. At native boundaries, `.NativeNode()` resolves a compound element; `.Node` becomes available after insertion.

## Controlled state

Instance settings accept values and accessors. The Go view compiler retains direct reactive expressions, while the component body runs once.

```go
func CheckboxExample() *ui.Element {
    checked, setChecked := ui.CreateSignal(false)
    checkbox := ui.NewCheckbox().Checked(checked()).OnCheckedChange(
        func(next bool, _ *native.Event) { setChecked(next) },
    )
    return checkbox.Root().FlexRow().Gap(8).Children(
        checkbox.Indicator().Child("✓"),
        "Remember me",
    )
}
```

Create each instance inside the component that owns it. Its state and bindings are released with its mounted root. Child factories remain useful for content that closes and later constructs new nodes when it reopens.

## Styling parts

Apply fluent styles directly to parts or share styles with `ui.Style()` and `.Merge(...)`:

```go
triggerStyle := ui.Style().Padding(12).RoundedLg().Bg("#2563eb")
return popover.Trigger().Style(triggerStyle).TextColor("#ffffff").Child("Account")
```

Scalar accessors retain independent bindings. Adding a user click handler preserves a part's default action; `OnClickEvent` can call `PreventDefault()` to cancel it.

Use `ui.NewPopover()`, `ui.NewTabs()`, and the corresponding component constructors. Constructors accept optional initial settings; instance methods configure individual settings before mounting.
