QuickGUI combines unstyled primitives with accessible compound controls. Compose both through ordinary Go functions.

## Defining components

A Go component is a `func()` that declares native children. Use ordinary parameters to configure it, and pass signal accessors for values that should stay reactive. Each call can own its own state and cleanup.

```go
func CounterLabel(count func() int) {
	ui.Text("Count: ", count).FontSize(20)
}

func ComponentExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		CounterLabel(count)
		ui.Button("Increment", ui.OnClick(func() { setCount(count() + 1) }))
	})
}
```

Pass callbacks for actions and a children callback for reusable containers. Call the children callback inside the container so its nodes attach to the right parent. Ordinary Go function calls share the current mount owner; cleanup is released when that owner, such as a conditional branch, keyed row, or window root, is disposed.

```go
func CardComponent(title string, children ui.Component) {
	ui.View(
		func() {
			ui.Text(title).FontWeight(600)
			children()
		},
	).Padding(20).Gap(12).Display("flex").FlexDirection("column")
}

func CardComposition() {
	CardComponent("Account", func() {
		ui.Text("Manage your account settings.")
		ui.Button("Save", ui.OnClick(func() { log.Print("Saved") }))
	})
}
```

## Primitives

Start with `ui.View`, `ui.Text`, `ui.Button`, and `ui.Input`. Options and text can be passed directly. A `func() { ... }` argument groups multiple children under the current parent.

```go
func ButtonExample(save func()) {
	ui.Button(
		"Save changes",
		ui.Style().Height(40),
		ui.Style().PaddingLeft(16),
		ui.Style().PaddingRight(16),
		ui.Style().BackgroundColor("#2563eb"),
		ui.Style().TextColor("white"),
		ui.Style().BorderRadius(8),
		ui.Style().Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }),
		ui.OnClick(save),
	)
}
```

## Compound components

Compound families expose parts such as `ui.Tabs.Root`, `ui.Tabs.List`, and `ui.Tabs.Panel`. The core handles roles, keyboard navigation, focus, and control state. Create a part inside its root’s children callback so its context exists.

```go
func TabsExample() {
	ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() {
			ui.Tabs.List(
				ui.PartProps{},
				func() {
					ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview")
					ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings")
				},
			)
			ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content")
			ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content")
		},
	)
}
```

## Controlled state

A controlled value is an accessor; its callback stores the value accepted by the control. Use a default value to let the component own its state. Optional scalar values use pointers, while multiple selections use slices.

```go
func CheckboxExample() {
	checked, setChecked := ui.CreateSignal(false)
	ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() { ui.Checkbox.Indicator(ui.PartProps{}, "✓"); ui.Text("Remember me") },
	)
}
```

## Styling parts

Use `PartProps.Style` for each part. Build styles with `ui.Style()` and fluent modifiers; combine shared builders with `.Merge(...)`. Parts also accept slices of builders and accessors returning them. Selection and theme signals update retained parts without rebuilding children.

```go
ui.PartProps{
	Style: ui.Style().
		Display("flex").
		Height(32).
		PaddingLeft(12).
		PaddingRight(12).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8),
}
```

Every native control has a dedicated page in the Components sidebar. For complete workflows, see [Forms & Input](/docs/go/forms-and-input) and [Overlays & Dialogs](/docs/go/overlays-and-dialogs).
