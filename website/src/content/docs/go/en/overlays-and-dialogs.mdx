Use a QuickGUI overlay for application-styled content, or a native dialog for platform file picking and alerts.

## Popover

A popover composes a trigger, positioner, and popup. The side is a preference; the core resolves collisions. Read the result through `ui.UsePopoverPlacement` inside the root.

```go
func PopoverExample() {
	ui.Popover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.Popover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.Popover.Positioner(
				ui.PopoverPositionerProps{},
				func() {
					ui.Popover.Popup(
						ui.PopoverPopupProps{PartProps: ui.PartProps{Style: ui.Styles(
							ui.Width(240),
							ui.Padding(16),
						)}},
						func() {
							ui.Popover.Title(ui.PartProps{}, "Account")
							ui.Popover.Close(ui.PartProps{}, "Done")
						},
					)
				},
			)
		},
	)
}
```

## Dialog

Create modal content under `Dialog.Portal`. `Dialog.Title` and `Dialog.Description` provide its accessible name and description. `AlertDialog` adds confirmation semantics. Controlled roots receive both the next open state and its reason.

```go
func DialogExample() {
	ui.Dialog.Root(
		ui.DialogRootProps{},
		func() {
			ui.Dialog.Trigger(ui.PartProps{}, "Open dialog")
			ui.Dialog.Portal(
				ui.PartProps{},
				func() {
					ui.Dialog.Backdrop(ui.PartProps{})
					ui.Dialog.Viewport(
						ui.PartProps{},
						func() {
							ui.Dialog.Popup(
								ui.DialogPopupProps{},
								func() {
									ui.Dialog.Title(ui.PartProps{}, "Confirm action")
									ui.Dialog.Description(
										ui.PartProps{},
										"Review the details before continuing.",
									)
									ui.Dialog.Close(ui.PartProps{}, "Cancel")
								},
							)
						},
					)
				},
			)
		},
	)
}
```

## System popover

`ui.SystemPopover` hosts its body in an operating-system popover. Specify its logical width and height, then declare ordinary QuickGUI children.

```go
func SystemPopoverExample() {
	ui.SystemPopover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.SystemPopover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.SystemPopover.Content(
				ui.PopoverContentProps{
					Width:     240,
					Height:    120,
					Placement: "bottom-start",
				},
				"Account settings",
			)
		},
	)
}
```

## Native dialogs

Native dialogs use asynchronous callbacks. Capture the parent window while rendering and pass it explicitly to the request. A canceled open panel returns `Canceled: true`.

```go
func OpenFolderButton() {
	window := native.CurrentWindow()
	ui.Button(
		"Open folder",
		ui.OnClick(func() {
			native.ShowOpenDialog(
				native.OpenDialogOptions{
					Window:     window,
					Title:      "Open folder",
					Properties: []string{"openDirectory"},
				},
				func(result native.OpenDialogResult, err error) {
					if err == nil && !result.Canceled {
						fmt.Println(result.FilePaths)
					}
				},
			)
		}),
	)
}
```
