## Requirements

- macOS 14 or later
- Go 1.23 or later
- Bun 1.4 or later
- Xcode Command Line Tools (`xcode-select --install`)

macOS is the supported target today.

## Create a project

The fastest way to try QuickGUI is the counter in this repository:

```bash
git clone https://github.com/egoist/quickgui.git
cd quickgui
bun install
bun run build:native
cd examples/counter
bun run dev
```

To start a new app from the same checkout:

```bash
bun packages/cli/src/cli.ts init ../my-app --language go --no-install
cd ../my-app
go mod edit -replace github.com/egoist/quickgui/go=../quickgui/go
go mod tidy
```

Then run the app with `bun packages/cli/src/cli.ts dev --project ../my-app` from the QuickGUI checkout. After packages are published, `quickgui init my-app --language go` will be the usual command.

## Your first window

`main.go` starts the app with `native.Run` and opens a window. Pass a component function to `WindowOptions.Component`. The component returns the UI for that window.

```go
package main

import (
	"log"

	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)

func Counter() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().
		FlexCol().
		SizeFull().
		ItemsCenter().
		JustifyCenter().
		Gap(20).
		Bg("#090d16").
		TextColor("#e2e8f0").
		Child(ui.Text("Count: ", count()).FontSize(28).FontWeight(700)).
		Child(ui.Button().
			OnClick(func() { setCount(count() + 1) }).
			Padding(12).
			RoundedLg().
			Bg("#2563eb").
			Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
			Child("Increment"))
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

`OnReopen` opens a window again when the user clicks the Dock icon and none are visible.

## Run and build

```bash
quickgui dev
quickgui fmt
quickgui build
```

`dev` rebuilds your Go code and relaunches the app as you edit. `fmt` wraps long UI calls. `build` writes a packaged app under `dist/`.

From this repository, prefix those commands with `bun packages/cli/src/cli.ts` and pass `--project` if you are not inside the app directory.
