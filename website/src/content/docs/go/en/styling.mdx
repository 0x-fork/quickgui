Pass style props such as `ui.BackgroundColor(...)` and `ui.PaddingLeft(...)` directly to `ui.View`, `ui.Text`, or another primitive, alongside its children and event handlers.

## Style props

Options apply in declaration order. Later values override the same property, including explicit zero; repeated `ui.Hover(...)`, `ui.Active(...)`, and other interaction options merge their properties. Numeric lengths are logical pixels; strings also accept percentages. Run `bun run fmt` to format long calls consistently.

```go
func Card() {
	ui.View(
		ui.Text(
			"Hello",
			ui.TextColor("#e2e8f0"),
		),
		ui.Padding(20),
		ui.BorderRadius(12),
		ui.BackgroundColor("#111827"),
	)
}
```

## Merging styles

The padding remains 20, the radius becomes 12, and the active state changes only the background color. Nested states follow the same merge rules.

```go
func MergedCard() {
	selected, _ := ui.CreateSignal(false)
	ui.View(
		"Merged styles",
		ui.Padding(20),
		ui.BorderRadius(8),
		ui.BackgroundColor("#111827"),
		ui.BorderRadius(12),
		ui.When(selected, ui.BackgroundColor("#2563eb")),
	)
}
```

## Reusable styles

Compose shared styles with `ui.Styles(...)`. It returns a reusable `ui.Style` value and leaves its inputs unchanged. Pass the result directly to a primitive, or to a compound part’s `Style` field. Individual style options also work in `PartProps.Style`. Accessors stay reactive and bind independently when mounted.

```go
func SharedCard() {
	card := ui.Styles(ui.Padding(20), ui.BorderRadius(12))
	ui.View("Hello", card, ui.BackgroundColor("#111827"))
	ui.View("Another card", card, ui.PaddingLeft(28))
}
```

## Flexbox

Set `ui.Display("flex")`, choose a direction, then declare sizing and alignment. A scrolling flex child usually needs `ui.MinHeight(0)` or `ui.MinWidth(0)` so it can shrink.

```go
func Row() {
	ui.View(
		func() {
			ui.Text("Flexible content", ui.Flex(1), ui.MinWidth(0))
			ui.Button("Action", ui.FlexShrink(0))
		},
		ui.Display("flex"),
		ui.Gap(12),
		ui.AlignItems("center"),
	)
}
```

## Grid

Grid uses familiar track strings. Place children explicitly when auto-placement is not enough.

```go
func Grid() {
	ui.View(
		func() {
			ui.Text("Sidebar")
			ui.Text("Content")
		},
		ui.Display("grid"),
		ui.GridTemplateColumns("220px 1fr"),
		ui.Gap(16),
	)
}
```

## Text and color

Typography inherits through the node tree. Colors accept hex, `rgb()`/`rgba()`, or packed RGBA values. Pass color and numeric accessors for reactive paint or size changes.

Set shared typography on a container, then override only the child properties that differ. Here both labels inherit the text color, while the heading overrides size and weight. Padding and borders do not inherit.

```go
func TypographyExample() {
	ui.View(
		func() {
			ui.Text("Inbox", ui.FontSize(24), ui.FontWeight(600))
			ui.Text("All caught up.")
		},
		ui.TextColor("#334155"),
		ui.FontSize(14),
		ui.Padding(20),
	)
}
```

## Interaction states

Add `Transition` to the base style to animate changes between paint states. See [Transitions & Animation](/docs/go/animations) for hover effects, signal-driven changes, timing, and reduced motion.

Use `ui.Hover(...)`, `ui.Active(...)`, `ui.Focus(...)`, `ui.DisabledStyle(...)`, and `ui.SelectedStyle(...)` for interaction styles. `ui.When` merges its options while the condition is true and restores the earlier values when it turns false. Only affected bindings update; children remain mounted.

```go
func SelectableButton() {
	selected, setSelected := ui.CreateSignal(false)
	ui.Button(
		"Toggle selection",
		ui.BackgroundColor("#e5e7eb"),
		ui.When(
			selected,
			ui.BackgroundColor("#2563eb"),
			ui.TextColor("white"),
		),
		ui.Hover(ui.Opacity(0.85)),
		ui.OnClick(func() { setSelected(!selected()) }),
	)
}
```

## Groups and named group hover

`ui.Group(true)` marks an unnamed hover group; `ui.Group("card")` names it. A descendant’s `ui.GroupHover(...)` follows its nearest ancestor group, including named groups. `ui.GroupHoverNamed("card", ...)` follows the nearest ancestor with that name, skipping intervening groups with other names.

```go
func GroupExample() {
	ui.View(
		func() {
			ui.Text(
				"Changes when the card is hovered",
				ui.TextColor("#64748b"),
				ui.GroupHover(ui.TextColor("#2563eb")),
			)
			ui.View(
				func() {
					ui.Text(
						"Follows the card and the nested toolbar",
						ui.GroupHoverNamed("card", ui.TextColor("#2563eb")),
						ui.GroupHoverNamed("toolbar", ui.Opacity(0.8)),
					)
				},
				ui.Group("toolbar"),
			)
		},
		ui.Group("card"),
		ui.Padding(20),
	)
}
```

Hovering any part of the group, including its padding and descendants, activates its rules. A nested group becomes the target for unnamed rules; named rules can still follow an outer group. With no matching ancestor, the rule has no effect. Repeated group rules accumulate in declaration order; a node’s own `Hover` wins for overlapping properties. Use paint properties such as colors, opacity, outlines, and transforms. Hover updates are handled natively without rerunning components or changing layout.


`ui.GroupActive(...)` and `ui.GroupActiveNamed("card", ui.Opacity(0.8))` follow pressed groups. `ui.FocusWithin(...)` follows focus in the node or a descendant. These states accept paint styles and cannot set the cursor.
