The `ui.SwiftUI` family embeds real macOS controls in a Go application. Ordinary QuickGUI components work without it.

## Host

Create controls inside `ui.SwiftUI.Host`. The host defines the native view boundary and can size itself from its content.

```go
func SwiftUiHostExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## Native controls

Available controls include Button, Slider, Toggle, ProgressView, Stepper, TextField, SecureField, Picker, SegmentedControl, DatePicker, ColorPicker, and Gauge. Their platform appearance comes from macOS.

## Controlled values

Bind an accessor and store the value returned by the native callback. A SwiftUI control and a QuickGUI node can share the same signal. DatePicker uses Unix timestamps in milliseconds.

```go
func SwiftUiToggleExample() *native.Node {
	on, setOn := ui.CreateSignal(true)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## Sizing

`MatchContents: true` sizes both axes intrinsically. Use `ui.SwiftUIMatchContents{Vertical: true}` for an intrinsic height with an application-defined width in `PartProps.Style`.

```go
ui.SwiftUIHostProps{
	MatchContents: ui.SwiftUIMatchContents{Vertical: true},
	PartProps:     ui.PartProps{Style: ui.Style().Width(320)},
}
```

## Platform support

SwiftUI hosting requires macOS. The prebuilt native host includes the bridge; your Go application still builds without CGO. Native styles can vary with the operating-system version.
