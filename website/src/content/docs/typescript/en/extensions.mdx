An extension is either a TypeScript package of reusable components, or a native library your app can call. Start with a TypeScript package. Add a native library when you need an optional backend.

## Choose an extension type

Use an ordinary TypeScript package for reusable Solid components. Use a native extension when a feature needs a Rust, Go, or Zig service. Native extensions load into the same process as the app.

## Create an extension project

```sh
quickgui init-extension my-components --type go
quickgui init-extension my-service --type rust
```

TypeScript apps consume the same native packages as Go. `--npm-package` sets the artifact package name.

## Share a component

```tsx
import { Button, type JSX } from "@quickgui/solid";

export function PrimaryButton(props: JSX.NativeProps) {
  return (
    <Button
      {...props}
      style={[props.style, { bg: "#2563eb", color: "#ffffff", roundedLg: true, p3: true }]}
    />
  );
}
```

Publish the package and add it as an application dependency.

## Lay out a native extension

A native extension ships `quickgui.extension.json`, a versioned shared library, and any declared resources. The manifest names the service, ABI, npm package, version, and library. See the Go [Authoring Extensions](/docs/go/extensions) guide for the native contract and the [`native-extension` example](https://github.com/egoist/quickgui/tree/main/examples/native-extension).

## Declare dependencies

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "Terminal App",
  identifier: "com.example.terminal",
  extensions: ["@quickgui/extension-terminal"],
});
```

Add the matching npm package to application dependencies. Custom extensions may use a scoped name such as `@acme/extension-echo`.

## Implement the native contract

Implement `invoke` and `shutdown` in the native library. Copy borrowed input before returning, keep events scoped to their sessions, and release workers when a session stops.

## Automatic registration

The CLI bundles declared extensions. The app loads them at startup, so components can call them after `app.whenReady()`.

## Build and package artifacts

Rebuild the native library when its implementation changes, then rebuild the app. Resources listed in the manifest are copied next to the library.

## Test and distribute

```tsx
import { ExtensionSession, invokeExtension } from "@quickgui/native";

const result = await invokeExtension("acme-service", "lookup", { key: "example" });
const session = new ExtensionSession("acme-service", {}, event => console.log(event));
await session.ready;
await session.request("refresh", null);
await session.close();
```

Test against a packed extension in a fresh project. Confirm that an app without the package does not bundle the library.
