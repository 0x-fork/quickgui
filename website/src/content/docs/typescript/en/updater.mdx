Install `@quickgui/extension-updater` to include automatic updates. Apps that omit it do not ship the updater.

## Configuration

```sh
bun add @quickgui/extension-updater
```

Generate a signing key pair and copy the public key into the project:

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

Keep the private `quickgui-update.key` out of version control.

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: "app.tsx",
  extensions: ["@quickgui/extension-updater"],
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

A `darwin-arm64` build checks `https://downloads.example.com/my-app/appcast-darwin-arm64.xml` unless you set `updates.feedUrl`. `{target}` in that URL is replaced with the current target.

## Application usage

Start after `app.whenReady()`, outside components, so every window shares one session:

```ts
import { app } from "@quickgui/native";
import Updater from "@quickgui/extension-updater";

await app.whenReady();

export const updater = new Updater({}, event => {
  if (event.error) console.error(event.error);
  if (event.quitRequired) {
    void app.quit().catch(console.error);
  }
});

await updater.ready;
```

```tsx
import { Button } from "@quickgui/solid";
import { updater } from "./updates";

export function CheckForUpdatesButton() {
  return (
    <Button style={{ p3: true, roundedLg: true }} onClick={() => void updater.check()}>
      Check for Updates
    </Button>
  );
}
```

## Lifecycle

| API | Use |
| --- | --- |
| `updater.check()` | Manually check for an update. |
| `updater.install()` | Install an available update. |
| `updater.setAutomaticChecks(enabled)` | Change the automatic-check preference. |
| `updater.state` | Read the last event. |
| `updater.close()` | Stop a session the app no longer needs. |

Status is `idle`, `checking`, `available`, `downloading`, `installing`, or `disabled`. Closing a window must not close the shared updater.

Development builds report `disabled` by default. Use `{ allowDevelopment: true }` only with a test feed and a disposable app bundle.

## Platforms

macOS uses Sparkle. Windows uses a signed NSIS installer. Linux uses an AppImage. Linux package-manager installs report `disabled`. Current prebuilt packages cover macOS; other targets need a native build on that host.

## Publishing

Increase `version` in `quickgui.config.ts`. Load the private key into the environment:

```sh
export QUICKGUI_UPDATER_PRIVATE_KEY="$(cat "$HOME/.config/my-app/update-keys/quickgui-update.key")"
```

```sh
bunx @quickgui/cli build --target darwin-arm64 --update-manifest \
  --sign "Developer ID Application: Example (TEAMID)" \
  --notarize my-app-notary
```

Upload the versioned archive first, then the appcast. Each architecture has its own feed. `updates.manifest: true` generates a feed on every production build.

## Native artifacts

From this repository, build the updater once with `bun packages/native/build.ts --extension updater`. Packaged apps include it when the extension is listed in config.
