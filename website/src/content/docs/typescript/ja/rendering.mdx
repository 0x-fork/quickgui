## レンダリングモデル

The Solid universal compiler creates native nodes and retained bindings. It selects the reactive client build even though Bun normally resolves server conditions. Native layout, painting, focus, input, accessibility, and component state remain in Rust.

## 条件付きコンテンツ

```tsx
<Show when={expanded()} fallback={<Text>Collapsed</Text>}>
  <Text>Expanded content</Text>
</Show>
```

A conditional region owns its effects and nodes. Removing the region disposes those resources; unrelated sibling nodes keep their identities.

## リストとノードの同一性

```tsx
<For each={items()}>{item => <Text>{item.name}</Text>}</For>
```

Use stable item identities for stateful rows. `For` moves existing nodes when order changes. Use `Table` or `Tree` for large native virtual collections and feed only requested visible data.

## ウィンドウのライフサイクル

Each `Window` owns an independent Solid root. Closing a child window must not dispose its siblings. Handle macOS Dock reopening by constructing a fresh window when `hasVisibleWindows` is false.

## 現在のウィンドウ

```tsx
function Content() {
  const window = Window.getCurrentWindow();
  return <Button onClick={() => window.close()}>Close</Button>;
}
```

The current window exists during renderer construction and native event dispatch. Capture it in setup or pass it explicitly to asynchronous work.
