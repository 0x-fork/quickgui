## 拡張の種類を選ぶ

Use an ordinary TypeScript package for reusable Solid components. Use a native extension when a feature needs a Rust, Go, Zig, or MoonBit service or an optional native renderer backend. All native providers load into the same process.

## 拡張プロジェクトを作成する

```sh
quickgui init-extension my-provider --type rust
```

Provider scaffolds use the shared extension ABI. A TypeScript consumer can use the same provider package as Go or MoonBit.

## コンポーネントの共有

```tsx
import { Button, type NativeProps } from "@quickgui/solid";
export function PrimaryButton(props: NativeProps) {
  return <Button backgroundColor="#2563eb" color="#ffffff" borderRadius={8} padding={12} {...props} />;
}
```

## ネイティブ拡張の構成

A native provider ships `quickgui.extension.json`, a versioned shared library, and any declared resources. Its manifest identifies the service name, ABI, npm package, release version, library, and per-platform resources.

## 依存関係の宣言

```tsx
export default defineConfig({
  frontend: "typescript", name: "Terminal App", identifier: "com.example.terminal",
  native: { extensions: ["terminal"] },
});
```

Add `@quickgui/native-terminal` to application dependencies. Custom providers may be selected by scoped npm package or a directory containing their manifest.

## ネイティブインターフェースを実装する

Implement the bounded `ServiceApi` or renderer extension contract in the native provider. Copy borrowed input before returning, keep event streams scoped to their sessions, and release worker resources when the session stops.

## 自動登録

The CLI resolves and bundles declared providers. The worker registers their descriptors and exact versions through FFI before creating the application, so components use the same core renderer and native resource registry.

## 成果物のビルドとパッケージ化

App edits reuse prebuilt provider artifacts. Rebuild a provider when its native implementation changes, then rebuild the application to stage those bytes. Provider resources are copied before signing.

## テストと配布

```tsx
import { ExtensionSession, invokeExtension } from "@quickgui/native";
const result = await invokeExtension("acme-service", "lookup", { key: "example" });
const session = new ExtensionSession("acme-service", {}, event => console.log(event));
await session.ready;
await session.request("refresh", null);
await session.close();
```

Test against a packed provider and CLI in a fresh project. Extension commands are asynchronous and share the bounded native event transport.
