## 動作要件

- macOS 14 以降
- Bun 1.4 以降
- TypeScript 7
- Xcode Command Line Tools（`xcode-select --install`）

現在サポートしている対象は macOS です。

## プロジェクトを作成

いちばん早い試し方は、このリポジトリのカウンターです。

```sh
git clone https://github.com/egoist/quickgui.git
cd quickgui
bun install
bun run build:native
cd examples/counter-typescript
bun run dev
```

パッケージ公開後は：

```sh
bunx @quickgui/cli init my-app --language typescript
cd my-app
bun run dev
```

チェックアウトからは `bun packages/cli/src/cli.ts init ../my-app --language typescript` で同じプロジェクトを作れます。

## 最初のウィンドウ

```tsx
import { app, Window } from "@quickgui/native";
import { Button, Text, View, createRenderer } from "@quickgui/solid";
import { createSignal } from "solid-js";

function Counter() {
  const [count, setCount] = createSignal(0);
  return (
    <View style={{ padding: 24, display: "flex", flexDirection: "column", gap: 12 }}>
      <Text>Count: {count()}</Text>
      <Button onClick={() => setCount(count() + 1)}>Increment</Button>
    </View>
  );
}

function openWindow() {
  new Window({ title: "Counter", width: 720, height: 480, renderer: createRenderer(Counter) });
}

app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openWindow();
});
await app.whenReady();
openWindow();
```

表示中のウィンドウがないときに Dock アイコンをクリックすると、`reopen` がウィンドウを開き直します。

## 実行とビルド

```sh
bun run check
bun run test
bun run dev
bun run build
```

`dev` は編集に合わせて再ビルドします。`build` はパッケージ済みアプリを `dist/` に書き出します。
