## Host

Import native SwiftUI components from `@quickgui/solid/swift-ui` and wrap them in `Host`. These controls are AppKit/SwiftUI views composed with QuickGUI’s retained scene, not replicas drawn by JavaScript.

## ネイティブコントロール

The adapter includes buttons, labels, toggles, sliders, steppers, progress views, gauges, text and secure fields, pickers, segmented controls, date/color pickers, and popovers. Each component’s reference lists its exact prop and event types.

## 制御値

```tsx
import { Host, Toggle } from "@quickgui/solid/swift-ui";
<Host matchContents><Toggle label="Notifications" isOn={enabled()} onIsOnChange={setEnabled} /></Host>
```

## サイズ

Use `matchContents` for intrinsic native sizing, including per-axis options where supported. Keep the parent’s dimensions constrained so native measurement and GPU layout agree.

## 対応プラットフォーム

SwiftUI hosting is macOS-specific. System availability determines optional appearances and controls, including Liquid Glass. Go and MoonBit expose the same core capability through their own adapters.
