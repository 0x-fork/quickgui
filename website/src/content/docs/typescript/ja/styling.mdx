## スタイルメソッド

Use kebab-case native style attributes or a `style` object with camelCase fields. Numeric lengths are logical pixels; supported percentages and keywords are parsed by Rust. `color` and `textColor` declare inherited text color.

```tsx
<View padding={16} gap={12} background-color="#18181b" color="#fafafa" />
```

Rust's 272 fixed layout and style presets are available as boolean attributes and style fields:

```tsx
<View flex-col p-3 gap-2 rounded-lg>
  <Text text-lg font-semibold>Panel title</Text>
</View>
```

Preset helpers are boolean attributes: `rounded-lg`, `flex-col`, `items-center`, `p-3`, `text-lg`, and `font-bold`. `rounded-lg` uses Rust's 8-pixel radius; `p-3` uses 12 pixels from Rust's four-pixel spacing scale. Helpers take no size or string value. For custom values, use native style attributes such as `border-radius={10}`, `padding={14}`, `grid-template-columns={3}`, and `width="50%"`. Corner radii use attributes such as `border-top-left-radius={8}`. `position-sticky` is the boolean sticky-layout helper.

Helpers expand before style arrays merge. Direct helper props override the corresponding style fields; `false`, `null`, or `undefined` withdraws a helper and reveals the underlying style. The helper types and values are generated from Rust by `scripts/generate-style-helpers.ts`.

## スタイルのマージ

Nested style arrays merge left to right; later fields override earlier ones. Falsy entries are ignored. Removing a style field withdraws that declaration.

```tsx
<View style={[base, selected() && selectedStyle, { padding: 20 }]} />
```

## スタイルの再利用

Use `JSX.Style` for reusable styles. Keep getters in JSX when their values should update reactively.

```tsx
import type { JSX } from "@quickgui/solid";

const panel = { "p-3": true, "rounded-xl": true, backgroundColor: "#20242c" } satisfies JSX.Style;
<View style={panel}><Text>Reusable panel</Text></View>
```

## Flexbox

Use `display`, `flexDirection`, `flexGrow`, `flexShrink`, `flexBasis`, alignment, and gap. Set `minWidth: 0` or `minHeight: 0` on flexible scroll containers so content can shrink into the available viewport.

## グリッド

Use `display: "grid"`, track declarations, placement, and spans for two-dimensional layouts. Grid sizing and intrinsic measurements are native; children keep their identities when positions change.

## テキストと色

Font family, weight, size, line height, wrapping, ellipsis, decoration, and selection use retained native text. Colors accept hex, supported CSS color strings, or packed RGBA values. Images and SVGs share the core’s bounded caches.

## インタラクション状態

```tsx
<Button style={{
  backgroundColor: "#2563eb",
  hover: { backgroundColor: "#1d4ed8" },
  active: { opacity: 0.8 },
  focusVisible: { outlineColor: "#93c5fd", outlineWidth: 2 },
}}>Save</Button>
```

## グループと名前付きグループのホバー

Use a named `group` on an ancestor and `groupHover` or `groupActive` on descendants to style coordinated states. The core resolves group membership and invalidates the affected retained subtree.
