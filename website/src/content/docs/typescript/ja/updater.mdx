## 設定

Install `@quickgui/native-updater`, declare `native.extensions: ["updater"]`, and configure `updates.baseUrl` and `updates.publicKey`. Release builds require the signing key metadata; development updates remain disabled unless explicitly allowed.

## アプリでの使用

```tsx
import { app, Updater } from "@quickgui/native";
await app.whenReady();
const updater = new Updater({}, event => console.log(event.status));
await updater.ready;
// Invoke these from user actions:
await updater.check();
// await updater.install();
```

## ライフサイクル

An updater is application-owned. `state` is the last native event, so reading it does not poll. `check()`, `install()`, and `setAutomaticChecks()` return promises. Close the session when it is no longer needed.

## 対応プラットフォーム

The optional Rust provider uses Sparkle on macOS and the native verified handoff implementation on Windows/Linux. The TypeScript layer declares options and observes native events; it does not implement an updater or installer.

## 更新の公開

Use the normal CLI update-manifest and signing workflow. Build, sign, and publish complete native artifacts with their versioned metadata. Never treat a downloaded artifact as trusted before native verification.

## ネイティブ成果物

```sh
bun packages/native/build.ts --extension updater
```

In a source checkout, build the provider once. Packaged applications include its shared library, Sparkle resources or portable handoff helper, and the update metadata selected by the CLI.
