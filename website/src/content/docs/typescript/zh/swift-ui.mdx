从 `@quickgui/solid/swift-ui` 导入 SwiftUI 控件，并用 `Host` 包裹它们。普通 QuickGUI 组件不需要这样做。

## Host

```tsx
import { Host, Button } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Button label="Continue" />
</Host>
```

Host 是原生视图边界，可以根据内容调整自身尺寸。

## 原生控件

按钮、标签、开关、滑块、步进器、进度视图、仪表、文本字段和安全字段、选择器、分段控件、日期选择器和颜色选择器，以及弹出框。外观和行为与系统控件一致。

## 受控值

```tsx
import { Host, Toggle } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Toggle label="Notifications" isOn={enabled()} onIsOnChange={setEnabled} />
</Host>
```

## 尺寸

`matchContents` 根据控件决定 Host 的尺寸。需要固定宽度和固有高度时，可以使用按轴的选项。

## 平台支持

SwiftUI 托管需要 macOS。Liquid Glass 等可选外观取决于操作系统版本。
