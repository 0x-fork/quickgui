修饰器用于设置原生 SwiftUI 控件的样式。反向托管把 QuickGUI 内容放进 SwiftUI。

## 修饰器

从 `@quickgui/solid/swift-ui/modifiers` 导入工厂，并按顺序传入。

```tsx
<Button
  label="Create project"
  modifiers={[buttonStyle("borderedProminent"), controlSize("large"), tint("#f97316")]}
/>
```

它们包括控件尺寸、着色、禁用状态、标签样式、按钮边框形状和按钮样式。

## Liquid Glass

```tsx
<Button label="Continue" modifiers={[buttonStyle("glass"), controlSize("large")]} />
```

macOS 在可用的地方绘制玻璃效果。

## 反向托管

```tsx
<Host matchContents>
  <QuickGUIHostView width={320} height={180}>
    <View style={{ padding: 16 }}><Text>QuickGUI inside SwiftUI</Text></View>
  </QuickGUIHostView>
</Host>
```

## SwiftUI Popover

使用 `Popover.Trigger` 配合 SwiftUI 控件，并用 `Popover.Content` 呈现界面。该内容中的 `QuickGUIHostView` 托管普通 QuickGUI 子节点。

## 生命周期

嵌入的 Host 随所属窗口关闭。卸载会移除原生视图；不要通过全局订阅保留已分离的 Host。
