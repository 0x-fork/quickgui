在原生浮窗中渲染的紧凑型模型驱动菜单。

## 导入

从 `@quickgui/solid` 导入 `PopoverMenu`。

```tsx
import { PopoverMenu } from "@quickgui/solid";
```

## 用法

```tsx
<PopoverMenu.Root
  items={menuItems}
  appearance={menuAppearance}
  onSelect={({ value }) => runCommand(value)}
>
  <PopoverMenu.Trigger><Text>Actions</Text></PopoverMenu.Trigger>
  <PopoverMenu.Popup />
</PopoverMenu.Root>
```

## 结构

- `PopoverMenu.Root`
- `PopoverMenu.Trigger`
- `PopoverMenu.Popup`

```tsx
<PopoverMenu.Root>
  <PopoverMenu.Trigger />
  <PopoverMenu.Popup />
</PopoverMenu.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `items` | 用于选项或键盘导航的有限声明模型。 |
| `appearance` | 核心绘制的原生菜单或选择器所用的结构颜色和几何属性。 |
| `open` | 受控的打开状态。 |
| `onOpenChange` | 报告核心做出的打开或关闭决定。 |
| `onSelect` | 报告核心选中的菜单项。 |
