虚拟化层级集合，支持展开、选择和键盘导航。

## 导入

从 `@quickgui/solid` 导入 `Tree`。

```tsx
import { Tree } from "@quickgui/solid";
```

## 用法

```tsx
<Tree.Root
  nodes={nodes}
  expanded={expanded()}
  value={selected()}
  onExpandedChange={setExpanded}
  onValueChange={setSelected}
>
  <For each={visibleNodes()}>{(node) =>
    <Tree.Row nodeId={node.id}><Text>{node.label}</Text></Tree.Row>
  }</For>
</Tree.Root>
```

## 结构

- `Tree.Root`
- `Tree.Row`

```tsx
<Tree.Root>
  <Tree.Row />
</Tree.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `nodes` | 树使用的有限层级节点声明。 |
| `expanded` | 受控的已展开树节点标识符。 |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `onExpandedChange` | 报告核心展开的有序节点标识符。 |
| `onValueChange` | 报告核心接受的值。 |
