多行文本编辑基础组件，受控值约定与 Input 相同。

## 导入

从 `@quickgui/solid` 导入 `TextArea`。

```tsx
import { TextArea } from "@quickgui/solid";
```

## 用法

```tsx
<TextArea
  value={notes()}
  placeholder="Release notes"
  onInput={(event) => setNotes(event.value ?? "")}
  style={{ width: 360, height: 140 }}
/>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `placeholder` | 可编辑值为空时显示的文本。 |
| `onInput` | 报告原生编辑输入。 |
| `onChange` | 报告已提交的原生值变化。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
