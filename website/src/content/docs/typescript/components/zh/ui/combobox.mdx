将可编辑文本、筛选、可选标签项和原生建议界面结合在一起。

## 导入

从 `@quickgui/solid` 导入 `Combobox`。

```tsx
import { Combobox } from "@quickgui/solid";
```

## 用法

```tsx
<Combobox.Root
  ariaLabel="Framework"
  items={frameworks}
  value={framework()}
  inputValue={query()}
  filterMode="fuzzy"
  onValueChange={setFramework}
  onInputValueChange={setQuery}
/>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `items` | 用于选项或键盘导航的有限声明模型。 |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `inputValue` | Combobox 或 Autocomplete 使用的可编辑查询文本。 |
| `multiple` | 允许选择或打开多个值。 |
| `filterMode` | 由核心管理的包含、前缀、模糊或禁用筛选模式。 |
| `onValueChange` | 报告核心接受的值。 |
