单选或多选选择器，选项界面显示在原生浮窗中。

## 导入

从 `@quickgui/solid` 导入 `Select`。

```tsx
import { Select } from "@quickgui/solid";
```

## 用法

```tsx
<Select.Root
  ariaLabel="Theme"
  items={[
    { value: "system", label: "System" },
    { value: "light", label: "Light" },
    { value: "dark", label: "Dark" },
  ]}
  value={theme()}
  onValueChange={setTheme}
/>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `items` | 用于选项或键盘导航的有限声明模型。 |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `multiple` | 允许选择或打开多个值。 |
| `onValueChange` | 报告核心接受的值。 |
