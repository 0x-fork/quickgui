使用保留式图像资源显示文件系统路径、文件 URL 或 base64 数据 URL。

## 导入

从 `@quickgui/solid` 导入 `Image`。

```tsx
import { Image } from "@quickgui/solid";
```

## 用法

```tsx
<Image
  source="assets/hero.png"
  fit="cover"
  style={{ width: 240, height: 160, borderRadius: 12 }}
/>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `source` | 组件所需的文件系统路径、数据 URL、SVG 文档或着色器源码。 |
| `fit` | 图像内容在声明区域中的适配方式。 |
| `objectFit` | 图像适配策略的别名。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
