支持键盘导航的月历网格，用于选择单个日期。

## 导入

从 `@quickgui/solid` 导入 `Calendar`。

```tsx
import { Calendar } from "@quickgui/solid";
```

## 用法

```tsx
<Calendar.Root value={date()} onValueChange={setDate} onMonthChange={setMonth}>
  <For each={weeks()}>{(week, weekIndex) =>
    <Calendar.Week itemIndex={weekIndex()}>
      <For each={week}>{(day) => <Calendar.Day day={day} />}</For>
    </Calendar.Week>
  }</For>
</Calendar.Root>
```

## 结构

- `Calendar.Root`
- `Calendar.Week`
- `Calendar.Day`

```tsx
<Calendar.Root>
  <Calendar.Week />
  <Calendar.Day />
</Calendar.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `firstWeekday` | 第一列对应的星期；周一为 0，周日为 6。 |
| `onValueChange` | 报告核心接受的值。 |
