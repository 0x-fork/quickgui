窗口内模态框，支持焦点约束、关闭操作和精确的过渡结束时机。

## 导入

从 `@quickgui/solid` 导入 `Dialog`。

```tsx
import { Dialog } from "@quickgui/solid";
```

## 用法

```tsx
<Dialog.Root open={open()} onOpenChange={setOpen}>
  <Dialog.Trigger><Text>Edit profile</Text></Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Viewport>
      <Dialog.Popup>
        <Dialog.Title><Text>Edit profile</Text></Dialog.Title>
        <Dialog.Description><Text>Changes are saved immediately.</Text></Dialog.Description>
        <Dialog.Close><Text>Done</Text></Dialog.Close>
      </Dialog.Popup>
    </Dialog.Viewport>
  </Dialog.Portal>
</Dialog.Root>
```

## 结构

- `Dialog.Root`
- `Dialog.Trigger`
- `Dialog.Portal`
- `Dialog.Backdrop`
- `Dialog.Viewport`
- `Dialog.Popup`
- `Dialog.Title`
- `Dialog.Description`
- `Dialog.Close`

```tsx
<Dialog.Root>
  <Dialog.Trigger />
  <Dialog.Portal />
  <Dialog.Backdrop />
  <Dialog.Viewport />
  <Dialog.Popup />
  <Dialog.Title />
  <Dialog.Description />
  <Dialog.Close />
</Dialog.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `open` | 受控的打开状态。 |
| `defaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `onOpenChange` | 报告核心做出的打开或关闭决定。 |
| `dismissOnEscape` | 允许按 Escape 键关闭界面。 |
| `exitDuration` | 在精确的退出过渡时长内保持关闭中的内容已挂载。 |
