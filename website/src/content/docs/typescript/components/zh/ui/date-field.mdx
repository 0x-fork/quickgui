可通过键盘编辑的分段日期字段，日期部分会适配区域设置。

## 导入

从 `@quickgui/solid` 导入 `DateField`。

```tsx
import { DateField } from "@quickgui/solid";
```

## 用法

```tsx
<DateField.Root value={date()} format="ymd" onValueChange={setDate}>
  <DateField.Segment segment="year" />
  <Text>–</Text>
  <DateField.Segment segment="month" />
  <Text>–</Text>
  <DateField.Segment segment="day" />
</DateField.Root>
```

## 结构

- `DateField.Root`
- `DateField.Segment`

```tsx
<DateField.Root>
  <DateField.Segment />
</DateField.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `onValueChange` | 报告核心接受的值。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
