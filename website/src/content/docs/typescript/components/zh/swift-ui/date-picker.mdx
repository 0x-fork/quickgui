受控的原生日期或日期时间选择器。

## 导入

从 `@quickgui/solid/swift-ui` 导入 `DatePicker`。

```tsx
import { Host, DatePicker } from "@quickgui/solid/swift-ui";
```

## 用法

```tsx
<Host matchContents>
  <DatePicker
    label="Schedule"
    value={scheduledAt()}
    displayedComponents="dateAndTime"
    style="field"
    onValueChange={setScheduledAt}
  />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `displayedComponents` | 选择日期、时间或日期和时间组合字段。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `onValueChange` | 报告核心接受的值。 |
