ロービングフォーカスを使い、単一または複数の押下値を管理します。

## インポート

`@quickgui/solid` から `ToggleGroup` をインポートします。

```tsx
import { ToggleGroup } from "@quickgui/solid";
```

## 使い方

```tsx
<ToggleGroup.Root
  items={[{ value: "left" }, { value: "center" }, { value: "right" }]}
  value={alignment()}
  variant="single"
  onValueChange={setAlignment}
>
  <ToggleGroup.Item partValue="left"><Text>Left</Text></ToggleGroup.Item>
  <ToggleGroup.Item partValue="center"><Text>Center</Text></ToggleGroup.Item>
  <ToggleGroup.Item partValue="right"><Text>Right</Text></ToggleGroup.Item>
</ToggleGroup.Root>
```

## 構成

- `ToggleGroup.Root`
- `ToggleGroup.Item`

```tsx
<ToggleGroup.Root>
  <ToggleGroup.Item />
</ToggleGroup.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `variant` | 単一選択または複数選択の方針を選びます。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
