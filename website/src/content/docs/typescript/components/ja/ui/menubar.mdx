ウィンドウ内の水平メニューバーとその項目を管理します。

## インポート

`@quickgui/solid` から `Menubar` をインポートします。

```tsx
import { Menubar } from "@quickgui/solid";
```

## 使い方

```tsx
<Menubar.Root count={2} open={openMenu()} onOpenChange={setOpenMenu}>
  <Menubar.Item itemIndex={0}><FileMenu /></Menubar.Item>
  <Menubar.Item itemIndex={1}><EditMenu /></Menubar.Item>
</Menubar.Root>
```

## 構成

- `Menubar.Root`
- `Menubar.Item`

```tsx
<Menubar.Root>
  <Menubar.Item />
</Menubar.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `count` | 宣言されたメニューバー項目の数です。 |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `onActiveChange` | ロービングフォーカス状態を現在持つ項目を通知します。 |
