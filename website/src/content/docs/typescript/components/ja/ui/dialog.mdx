フォーカスの閉じ込め、閉じる操作、正確なトランジション完了を備えたウィンドウ内モーダルです。

## インポート

`@quickgui/solid` から `Dialog` をインポートします。

```tsx
import { Dialog } from "@quickgui/solid";
```

## 使い方

```tsx
<Dialog.Root open={open()} onOpenChange={setOpen}>
  <Dialog.Trigger><Text>Edit profile</Text></Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Viewport>
      <Dialog.Popup>
        <Dialog.Title><Text>Edit profile</Text></Dialog.Title>
        <Dialog.Description><Text>Changes are saved immediately.</Text></Dialog.Description>
        <Dialog.Close><Text>Done</Text></Dialog.Close>
      </Dialog.Popup>
    </Dialog.Viewport>
  </Dialog.Portal>
</Dialog.Root>
```

## 構成

- `Dialog.Root`
- `Dialog.Trigger`
- `Dialog.Portal`
- `Dialog.Backdrop`
- `Dialog.Viewport`
- `Dialog.Popup`
- `Dialog.Title`
- `Dialog.Description`
- `Dialog.Close`

```tsx
<Dialog.Root>
  <Dialog.Trigger />
  <Dialog.Portal />
  <Dialog.Backdrop />
  <Dialog.Viewport />
  <Dialog.Popup />
  <Dialog.Title />
  <Dialog.Description />
  <Dialog.Close />
</Dialog.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `dismissOnEscape` | Escape キーでサーフェスを閉じられるようにします。 |
| `exitDuration` | 閉じる内容を、正確な終了トランジション時間だけマウントしたままにします。 |
