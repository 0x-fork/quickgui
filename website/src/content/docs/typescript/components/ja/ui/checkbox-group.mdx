有限個のチェックボックス値をまとめ、必要に応じて親チェックボックスの状態も導出します。

## インポート

`@quickgui/solid` から `CheckboxGroup` をインポートします。

```tsx
import { CheckboxGroup } from "@quickgui/solid";
```

## 使い方

```tsx
<CheckboxGroup.Root
  allValues={["email", "push"]}
  value={channels()}
  onValueChange={setChannels}
>
  <Checkbox.Root parent><Text>All notifications</Text></Checkbox.Root>
  <Checkbox.Root value="email"><Text>Email</Text></Checkbox.Root>
  <Checkbox.Root value="push"><Text>Push</Text></Checkbox.Root>
</CheckboxGroup.Root>
```

## 構成

- `CheckboxGroup.Root`

```tsx
<CheckboxGroup.Root>{/* content */}</CheckboxGroup.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `allValues` | 親チェックボックスの状態導出に使う、完全で順序付きの値集合です。 |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
