確認操作に特化し、背景クリックで閉じる既定動作をより厳格にしたダイアログです。

## インポート

`@quickgui/solid` から `AlertDialog` をインポートします。

```tsx
import { AlertDialog } from "@quickgui/solid";
```

## 使い方

```tsx
<AlertDialog.Root open={open()} onOpenChange={setOpen}>
  <AlertDialog.Trigger><Text>Delete project</Text></AlertDialog.Trigger>
  <AlertDialog.Portal>
    <AlertDialog.Backdrop />
    <AlertDialog.Viewport>
      <AlertDialog.Popup>
        <AlertDialog.Title><Text>Delete this project?</Text></AlertDialog.Title>
        <AlertDialog.Description><Text>This cannot be undone.</Text></AlertDialog.Description>
        <AlertDialog.Close><Text>Cancel</Text></AlertDialog.Close>
      </AlertDialog.Popup>
    </AlertDialog.Viewport>
  </AlertDialog.Portal>
</AlertDialog.Root>
```

## 構成

- `AlertDialog.Root`
- `AlertDialog.Trigger`
- `AlertDialog.Portal`
- `AlertDialog.Backdrop`
- `AlertDialog.Viewport`
- `AlertDialog.Popup`
- `AlertDialog.Title`
- `AlertDialog.Description`
- `AlertDialog.Close`

```tsx
<AlertDialog.Root>
  <AlertDialog.Trigger />
  <AlertDialog.Portal />
  <AlertDialog.Backdrop />
  <AlertDialog.Viewport />
  <AlertDialog.Popup />
  <AlertDialog.Title />
  <AlertDialog.Description />
  <AlertDialog.Close />
</AlertDialog.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `dismissOnEscape` | Escape キーでサーフェスを閉じられるようにします。 |
| `exitDuration` | 閉じる内容を、正確な終了トランジション時間だけマウントしたままにします。 |
