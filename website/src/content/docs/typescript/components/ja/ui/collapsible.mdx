アクセシブルな状態を保ちながら、トリガーで 1 つのパネルを表示／非表示にします。

## インポート

`@quickgui/solid` から `Collapsible` をインポートします。

```tsx
import { Collapsible } from "@quickgui/solid";
```

## 使い方

```tsx
<Collapsible.Root open={open()} onOpenChange={setOpen}>
  <Collapsible.Trigger><Text>Advanced settings</Text></Collapsible.Trigger>
  <Collapsible.Panel><AdvancedSettings /></Collapsible.Panel>
</Collapsible.Root>
```

## 構成

- `Collapsible.Root`
- `Collapsible.Trigger`
- `Collapsible.Panel`

```tsx
<Collapsible.Root>
  <Collapsible.Trigger />
  <Collapsible.Panel />
</Collapsible.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `keepMounted` | 非アクティブな内容をマウントしたまま、表示を無効にします。 |
