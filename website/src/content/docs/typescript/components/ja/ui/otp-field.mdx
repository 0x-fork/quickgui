個別にスタイルできる入力セルで構成された、長さ制限付きのワンタイムコードエディターです。

## インポート

`@quickgui/solid` から `OtpField` をインポートします。

```tsx
import { OtpField } from "@quickgui/solid";
```

## 使い方

```tsx
<OtpField.Root value={code()} length={6} onValueChange={setCode} onComplete={verify}>
  <For each={[0, 1, 2, 3, 4, 5]}>{(index) =>
    <OtpField.Input index={index} />
  }</For>
</OtpField.Root>
```

## 構成

- `OtpField.Root`
- `OtpField.Input`
- `OtpField.Separator`

```tsx
<OtpField.Root>
  <OtpField.Input />
  <OtpField.Separator />
</OtpField.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `length` | ワンタイムコード入力スロットの数です。上限は 12 です。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
