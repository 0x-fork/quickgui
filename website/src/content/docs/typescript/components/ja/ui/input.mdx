ネイティブのキーボードとテキストサービスに対応した、コアが管理する制御テキストエディターです。

## インポート

`@quickgui/solid` から `Input` をインポートします。

```tsx
import { Input } from "@quickgui/solid";
```

## 使い方

```tsx
<Input
  value={name()}
  placeholder="Your name"
  onInput={(event) => setName(event.value ?? "")}
/>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `placeholder` | 編集値が空のときに表示するテキストです。 |
| `multiline` | 複数行テキスト編集を有効にします。 |
| `onInput` | ネイティブ編集の入力を通知します。 |
| `onChange` | 確定したネイティブ値の変更を通知します。 |
