Coordinates a horizontal in-window menubar and its menu items.

## Import

Import `Menubar` from `@quickgui/solid`.

```tsx
import { Menubar } from "@quickgui/solid";
```

## Usage

```tsx
<Menubar.Root count={2} open={openMenu()} onOpenChange={setOpenMenu}>
  <Menubar.Item itemIndex={0}><FileMenu /></Menubar.Item>
  <Menubar.Item itemIndex={1}><EditMenu /></Menubar.Item>
</Menubar.Root>
```

## Anatomy

- `Menubar.Root`
- `Menubar.Item`

```tsx
<Menubar.Root>
  <Menubar.Item />
</Menubar.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `count` | Number of declared menubar items. |
| `open` | Controlled open state. |
| `defaultOpen` | Initial state when the component owns whether it is open. |
| `onOpenChange` | Reports an open or close decision from the core. |
| `onActiveChange` | Reports the item that now owns the roving focus state. |
