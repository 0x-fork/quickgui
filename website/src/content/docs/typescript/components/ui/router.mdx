A Solid projection of QuickGUI core routing with nested layouts and bounded memory history.

## Import

Import `Router` from `@quickgui/solid`.

```tsx
import { Router } from "@quickgui/solid";
```

## Usage

```tsx
<Router initialPath="/">
  <Route path="/" component={Shell}>
    <Route path="/" component={Home} />
    <Route path="/projects/:id" component={Project} />
  </Route>
</Router>
```

## Anatomy

- `Router`
- `Route`
- `Link`
- `Outlet`

```tsx
<Router>
  <Route path="/" component={AppShell}>
    <Route path="/projects/:id" component={Project} />
  </Route>
  <Link href="/projects/quickgui">Open project</Link>
  <Outlet />
</Router>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `initialPath` | Initial destination for the bounded in-memory history. |
| `fallback` | Content rendered when no route matches. |
| `path` | Absolute or parent-relative route pattern. |
| `component` | Component rendered when a route wins. |
| `href` | Destination resolved by the QuickGUI router. |
