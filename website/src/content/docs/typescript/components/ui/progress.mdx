Represents determinate or indeterminate task progress with composable labels and track.

## Import

Import `Progress` from `@quickgui/solid`.

```tsx
import { Progress } from "@quickgui/solid";
```

## Usage

```tsx
<Progress.Root value={completed()} max={total()} format="fraction">
  <Progress.Label><Text>Exporting</Text></Progress.Label>
  <Progress.Track><Progress.Indicator /></Progress.Track>
  <Progress.Value />
</Progress.Root>
```

## Anatomy

- `Progress.Root`
- `Progress.Track`
- `Progress.Indicator`
- `Progress.Label`
- `Progress.Value`

```tsx
<Progress.Root>
  <Progress.Track />
  <Progress.Indicator />
  <Progress.Label />
  <Progress.Value />
</Progress.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `max` | Maximum accepted value. |
| `indeterminate` | Represents progress whose completed amount is unknown. |
| `valueText` | Human-readable value preferred by assistive technology. |
| `onStatusChange` | Reports the derived status, formatted value, and completion ratio. |
