Coordinates a bounded set of checkbox values and an optional derived parent checkbox.

## Import

Import `CheckboxGroup` from `@quickgui/solid`.

```tsx
import { CheckboxGroup } from "@quickgui/solid";
```

## Usage

```tsx
<CheckboxGroup.Root
  allValues={["email", "push"]}
  value={channels()}
  onValueChange={setChannels}
>
  <Checkbox.Root parent><Text>All notifications</Text></Checkbox.Root>
  <Checkbox.Root value="email"><Text>Email</Text></Checkbox.Root>
  <Checkbox.Root value="push"><Text>Push</Text></Checkbox.Root>
</CheckboxGroup.Root>
```

## Anatomy

- `CheckboxGroup.Root`

```tsx
<CheckboxGroup.Root>{/* content */}</CheckboxGroup.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `allValues` | Complete ordered value universe used to derive a parent checkbox state. |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `defaultValue` | Initial value when the component owns its state. |
| `onValueChange` | Reports the value accepted by the core. |
| `disabled` | Prevents interaction and exposes the disabled state. |
