Presents a native SwiftUI popover from a composed SwiftUI trigger.

## Import

Import `Popover` from `@quickgui/ui/swift-ui`.

```tsx
import { Host, Popover } from "@quickgui/ui/swift-ui";
```

## Usage

```tsx
<Popover.Root
  isPresented={open()}
  onIsPresentedChange={setOpen}
  attachmentAnchor="bottom"
  arrowEdge="top"
>
  <Popover.Trigger><Button label="Open" /></Popover.Trigger>
  <Popover.Content>
    <QuickGUIHostView width={280} height={120}>
      <SettingsPanel />
    </QuickGUIHostView>
  </Popover.Content>
</Popover.Root>
```

## Anatomy

- `Popover.Trigger`
- `Popover.Content`

```tsx
<Popover.Root isPresented={open()} onIsPresentedChange={setOpen}>
  <Popover.Trigger><Button label="Open" /></Popover.Trigger>
  <Popover.Content>{/* SwiftUI-hosted content */}</Popover.Content>
</Popover.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `isPresented` | Controlled native SwiftUI popover presentation state. |
| `onIsPresentedChange` | Reports native SwiftUI popover presentation changes. |
| `attachmentAnchor` | Anchor point on the composed SwiftUI trigger. |
| `arrowEdge` | Preferred edge for the native SwiftUI popover arrow. |
