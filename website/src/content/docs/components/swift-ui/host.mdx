The NSHostingView-backed leaf that mounts one SwiftUI component tree inside QuickGUI.

## Import

Import `Host` from `@quickgui/ui/swift-ui`.

```tsx
import { Host } from "@quickgui/ui/swift-ui";
```

## Usage

```tsx
<Host matchContents>
  <Button label="Continue" />
</Host>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `matchContents` | Uses the hosted subtree’s intrinsic width, height, or both. |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
