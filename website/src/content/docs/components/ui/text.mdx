Shapes and paints Unicode text with inherited typography, selection, and accessibility.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			ui.FontSize(20),
			func() string { return fmt.Sprintf("Count: %d", count()) },
		)
		ui.Button(ui.OnClick(func() { setCount(count() + 1) }), "Increment")
	})
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `WithStyle` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
| `Ref` | Receives the retained native node. |
