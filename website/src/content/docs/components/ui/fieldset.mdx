Groups related fields under one legend and shared semantic state.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func FieldsetExample(saving func() bool) {
	ui.Fieldset.Root(
		ui.PartProps{Disabled: saving},
		func() {
			ui.Fieldset.Legend(ui.PartProps{}, "Profile")
			ui.Field.Root(
				ui.FieldRootProps{},
				func() {
					ui.Field.Label(ui.FieldLabelProps{}, "Name")
					ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Placeholder: "Ada"}})
				},
			)
		},
	)
}
```

## Anatomy

- `ui.Fieldset.Root`
- `ui.Fieldset.Legend`
- `ui.Fieldset.Description`
- `ui.Fieldset.Control`

## Key props

| Prop | Purpose |
| --- | --- |
| `Disabled` | Prevents interaction and exposes the disabled state. |
| `children` | Content mounted inside the component. |
| `Style` | QuickGUI layout, paint, typography, and interaction-state styles. |
