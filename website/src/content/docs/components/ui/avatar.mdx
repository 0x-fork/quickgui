Shows an image with a fallback that appears when the image is unavailable.

## Import

Import `Avatar` from `@quickgui/ui`.

```tsx
import { Avatar } from "@quickgui/ui/base-ui";
```

## Usage

```tsx
<Avatar.Root ariaLabel="Ada Lovelace" onLoadingStatusChange={setStatus}>
  <Avatar.Image src="assets/ada.png" fit="cover" />
  <Avatar.Fallback delay={120}><Text>AL</Text></Avatar.Fallback>
</Avatar.Root>
```

## Anatomy

- `Avatar.Root`
- `Avatar.Image`
- `Avatar.Fallback`

```tsx
<Avatar.Root>
  <Avatar.Image />
  <Avatar.Fallback />
</Avatar.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `ariaLabel` | Accessible name for a component whose visible parts may change. |
| `src` | Filesystem path, file URL, or base64 data URL for an avatar image. |
| `delay` | Core-owned delay in milliseconds before opening. |
| `onLoadingStatusChange` | Reports every avatar image load-state transition. |
