Composes a scrollable viewport with caller-styled scrollbars, thumbs, and corner.

## Import

Import `ScrollArea` from `@quickgui/ui`.

```tsx
import { ScrollArea } from "@quickgui/ui/base-ui";
```

## Usage

```tsx
<ScrollArea.Root
  viewportSize={{ width: 320, height: 240 }}
  contentSize={{ width: 320, height: 1200 }}
  onScrollStateChange={setScrollState}
>
  <ScrollArea.Viewport><ScrollArea.Content><LongList /></ScrollArea.Content></ScrollArea.Viewport>
  <ScrollArea.Scrollbar orientation="vertical"><ScrollArea.Thumb /></ScrollArea.Scrollbar>
</ScrollArea.Root>
```

## Anatomy

- `ScrollArea.Root`
- `ScrollArea.Viewport`
- `ScrollArea.Content`
- `ScrollArea.Scrollbar`
- `ScrollArea.Thumb`
- `ScrollArea.Corner`

```tsx
<ScrollArea.Root>
  <ScrollArea.Viewport />
  <ScrollArea.Content />
  <ScrollArea.Scrollbar />
  <ScrollArea.Thumb />
  <ScrollArea.Corner />
</ScrollArea.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `viewportSize` | Declared scroll viewport extent. |
| `contentSize` | Declared scroll content extent. |
| `overflowEdgeThreshold` | Distance from an edge that still counts as being at that edge. |
| `onScrollStateChange` | Reports clamped offset and derived overflow state. |
