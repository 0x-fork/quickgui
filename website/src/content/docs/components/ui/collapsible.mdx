Shows and hides one panel from a trigger while preserving accessible state.

## Import

Import `Collapsible` from `@quickgui/ui`.

```tsx
import { Collapsible } from "@quickgui/ui/disclosure";
```

## Usage

```tsx
<Collapsible.Root open={open()} onOpenChange={setOpen}>
  <Collapsible.Trigger><Text>Advanced settings</Text></Collapsible.Trigger>
  <Collapsible.Panel><AdvancedSettings /></Collapsible.Panel>
</Collapsible.Root>
```

## Anatomy

- `Collapsible.Root`
- `Collapsible.Trigger`
- `Collapsible.Panel`

```tsx
<Collapsible.Root>
  <Collapsible.Trigger />
  <Collapsible.Panel />
</Collapsible.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `open` | Controlled open state. |
| `defaultOpen` | Initial state when the component owns whether it is open. |
| `onOpenChange` | Reports an open or close decision from the core. |
| `keepMounted` | Keeps inactive content mounted with display disabled. |
