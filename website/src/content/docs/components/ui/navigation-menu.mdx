A disclosure-style navigation surface with animated direction, viewport, and popup parts.

## Import

Import `NavigationMenu` from `@quickgui/ui`.

```tsx
import { NavigationMenu } from "@quickgui/ui/base-ui";
```

## Usage

```tsx
<NavigationMenu.Root value={section()} onValueChange={setSection}>
  <NavigationMenu.List>
    <NavigationMenu.Item value="products">
      <NavigationMenu.Trigger><Text>Products</Text></NavigationMenu.Trigger>
      <NavigationMenu.Content><ProductLinks /></NavigationMenu.Content>
    </NavigationMenu.Item>
  </NavigationMenu.List>
  <NavigationMenu.Portal>
    <NavigationMenu.Positioner><NavigationMenu.Popup><NavigationMenu.Viewport /></NavigationMenu.Popup></NavigationMenu.Positioner>
  </NavigationMenu.Portal>
</NavigationMenu.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `defaultValue` | Initial value when the component owns its state. |
| `onValueChange` | Reports the value accepted by the core. |
| `orientation` | Horizontal or vertical layout and keyboard direction. |
| `delay` | Core-owned delay in milliseconds before opening. |
