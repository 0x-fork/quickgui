A general-purpose retained container for layout, paint, pointer input, and accessibility.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ViewExample() {
	ui.View(
		ui.Padding(20),
		ui.Gap(12),
		func() {
			ui.Text("Hello from Go")
			ui.Button(ui.OnClick(func() {}), "Continue")
		},
	)
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `WithStyle` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
| `OnClick` | Runs after the core resolves an activation. |
| `Ref` | Receives the retained native node. |
