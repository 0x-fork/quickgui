A compact model-driven menu rendered in a native popover window.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func PopoverMenuExample() {
	ui.PopoverMenu.Root(
		ui.PopoverMenuRootProps{
			Items: func() []ui.MenuItemDeclaration {
				return []ui.MenuItemDeclaration{{ID: "copy", Label: "Copy"}, {ID: "paste", Label: "Paste"}}
			},
			OnSelect: func(item ui.MenuSelectDetails, _ *native.Event) { fmt.Println(item.ID) },
		},
		func() {
			ui.PopoverMenu.Trigger(ui.PartProps{}, "Edit")
			ui.PopoverMenu.Popup(ui.PopoverMenuPopupProps{})
		},
	)
}
```

## Anatomy

- `ui.PopoverMenu.Root`
- `ui.PopoverMenu.Trigger`
- `ui.PopoverMenu.Popup`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Appearance` | Structural colors and geometry for a core-painted native menu or picker. |
| `Open` | Controlled open state. |
| `OnOpenChange` | Reports an open or close decision from the core. |
| `OnSelect` | Reports the menu entry selected by the core. |
