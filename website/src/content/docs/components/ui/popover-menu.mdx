A compact model-driven menu rendered in a native popover window.

## Import

Import `PopoverMenu` from `@quickgui/ui`.

```tsx
import { PopoverMenu } from "@quickgui/ui/menu";
```

## Usage

```tsx
<PopoverMenu.Root
  items={menuItems}
  appearance={menuAppearance}
  onSelect={({ value }) => runCommand(value)}
>
  <PopoverMenu.Trigger><Text>Actions</Text></PopoverMenu.Trigger>
  <PopoverMenu.Popup />
</PopoverMenu.Root>
```

## Anatomy

- `PopoverMenu.Root`
- `PopoverMenu.Trigger`
- `PopoverMenu.Popup`

```tsx
<PopoverMenu.Root>
  <PopoverMenu.Trigger />
  <PopoverMenu.Popup />
</PopoverMenu.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `items` | Bounded declaration model used for options or keyboard navigation. |
| `appearance` | Structural colors and geometry for a core-painted native menu or picker. |
| `open` | Controlled open state. |
| `onOpenChange` | Reports an open or close decision from the core. |
| `onSelect` | Reports the menu entry selected by the core. |
