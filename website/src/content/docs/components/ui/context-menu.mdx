Opens a model-driven native menu from a secondary-button press on its trigger.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ContextMenuExample() {
	ui.ContextMenu.Root(
		ui.ContextMenuRootProps{
			Items:    func() []ui.MenuItemDeclaration { return []ui.MenuItemDeclaration{{ID: "copy", Label: "Copy"}} },
			OnSelect: func(item ui.MenuSelectDetails, _ *native.Event) { fmt.Println(item.ID) },
		},
		func() { ui.ContextMenu.Trigger(ui.ContextMenuTriggerProps{}, "Right-click here") },
	)
}
```

## Anatomy

- `ui.ContextMenu.Root`
- `ui.ContextMenu.Trigger`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Appearance` | Structural colors and geometry for a core-painted native menu or picker. |
| `OnSelect` | Reports the menu entry selected by the core. |
| `Loop` | Wraps highlight navigation at the ends of a menu level. |
