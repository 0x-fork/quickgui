Groups actions and inputs under one roving-focus keyboard model.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToolbarExample() {
	ui.Toolbar.Root(
		ui.ToolbarRootProps{
			Items:         []ui.ComponentItem{{Value: "select"}, {Value: "draw"}},
			DefaultActive: "select",
		},
		func() {
			ui.Toolbar.Item(ui.ToolbarItemProps{Value: "select"}, "Select")
			ui.Toolbar.Item(ui.ToolbarItemProps{Value: "draw"}, "Draw")
		},
	)
}
```

## Anatomy

- `ui.Toolbar.Root`
- `ui.Toolbar.Item`
- `ui.Toolbar.Button`
- `ui.Toolbar.Link`
- `ui.Toolbar.Input`
- `ui.Toolbar.Group`
- `ui.Toolbar.Separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Active` | Controlled item holding the active or roving focus state. |
| `DefaultActive` | Initial active item for an uncontrolled component. |
| `Orientation` | Horizontal or vertical layout and keyboard direction. |
| `OnActiveChange` | Reports the item that now owns the roving focus state. |
