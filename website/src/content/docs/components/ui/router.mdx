A QuickGUI UI projection of QuickGUI core routing with nested layouts and bounded memory history.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func RouterExample() {
	ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route(
				"/",
				func() {
					ui.Link(
						ui.LinkProps{Href: "/settings"},
						"Settings",
					)
				},
			),
			ui.Route(
				"/settings",
				func() { ui.Text("Settings") },
			),
		},
		Fallback: func() { ui.Text("Page not found") },
	})
}
```

## Anatomy

- `ui.Router`
- `ui.Route`
- `ui.Layout`
- `ui.Link`
- `ui.Outlet`

## Key props

| Prop | Purpose |
| --- | --- |
| `InitialPath` | Initial destination for the bounded in-memory history. |
| `Fallback` | Content rendered when no route matches. |
| `Routes` | Static route declarations built with `ui.Route` and `ui.Layout`. |
| `Path` | Absolute or parent-relative route pattern. |
| `Component` | Component rendered when a route wins. |
| `Href` | Destination resolved by the QuickGUI router. |
