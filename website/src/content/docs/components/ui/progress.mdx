Represents determinate or indeterminate task progress with composable labels and track.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ProgressExample(progress func() *float64) {
	ui.Progress.Root(
		ui.ProgressProps{Value: progress, Max: 100},
		func() {
			ui.Progress.Label(ui.PartProps{}, "Uploading")
			ui.Progress.Track(
				ui.PartProps{},
				func() { ui.Progress.Indicator(ui.PartProps{}) },
			)
			ui.Progress.Value(ui.PartProps{})
		},
	)
}
```

## Anatomy

- `ui.Progress.Root`
- `ui.Progress.Track`
- `ui.Progress.Indicator`
- `ui.Progress.Label`
- `ui.Progress.Value`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Max` | Maximum accepted value. |
| `Indeterminate` | Represents progress whose completed amount is unknown. |
| `ValueText` | Human-readable value preferred by assistive technology. |
| `OnStatusChange` | Reports the derived status, formatted value, and completion ratio. |
