A bounded one-time-code editor made from individually styled input cells.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func OtpFieldExample() {
	code, setCode := ui.CreateSignal("")
	ui.OtpField.Root(
		ui.OtpFieldRootProps{
			Value:          code,
			Length:         6,
			ValidationType: "numeric",
			OnValueChange:  func(next string, _ *native.Event) { setCode(next) },
			OnComplete:     func(value string, _ *native.Event) { fmt.Println("Complete:", value) },
		},
		func() {
			for index := range 6 {
				ui.OtpField.Input(ui.OtpFieldInputProps{Index: index})
			}
		},
	)
}
```

## Anatomy

- `ui.OtpField.Root`
- `ui.OtpField.Input`
- `ui.OtpField.Separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `Length` | Number of one-time-code input slots, bounded to twelve. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
