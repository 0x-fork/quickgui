The multiline text-editing primitive, with the same controlled value contract as Input.

## Import

Import `TextArea` from `@quickgui/ui`.

```tsx
import { TextArea } from "@quickgui/ui";
```

## Usage

```tsx
<TextArea
  value={notes()}
  placeholder="Release notes"
  onInput={(event) => setNotes(event.value ?? "")}
  style={{ width: 360, height: 140 }}
/>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `placeholder` | Text shown while the editable value is empty. |
| `onInput` | Reports native editing input. |
| `onChange` | Reports a committed native value change. |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
