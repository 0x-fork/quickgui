A segmented, keyboard-editable time field with hour, minute, second, and period parts.

## Import

Import `TimeField` from `@quickgui/ui`.

```tsx
import { TimeField } from "@quickgui/ui/date-time";
```

## Usage

```tsx
<TimeField.Root value={time()} showSeconds onValueChange={setTime}>
  <TimeField.Segment segment="hour" />
  <Text>:</Text>
  <TimeField.Segment segment="minute" />
  <Text>:</Text>
  <TimeField.Segment segment="second" />
</TimeField.Root>
```

## Anatomy

- `TimeField.Root`
- `TimeField.Segment`

```tsx
<TimeField.Root>
  <TimeField.Segment />
</TimeField.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `defaultValue` | Initial value when the component owns its state. |
| `hour12` | Adds an AM/PM segment and uses a twelve-hour clock. |
| `showSeconds` | Mounts a seconds segment. |
| `onValueChange` | Reports the value accepted by the core. |
