Paints validated WGSL with a bounded set of numeric shader parameters.

## Import

Import `Shader` from `@quickgui/ui`.

```tsx
import { Shader } from "@quickgui/ui";
```

## Usage

```tsx
<Shader
  source={gradientShader}
  shaderParameters={[time(), intensity()]}
  style={{ width: 320, height: 180 }}
/>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `source` | Filesystem path, data URL, SVG document, or shader source expected by the component. |
| `shaderParameters` | Up to sixteen numeric values packed into fixed shader parameter vectors. |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
