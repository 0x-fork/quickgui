Filters suggestions for free-form text without requiring a selected value.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func AutocompleteExample() {
	ui.Autocomplete.Root(ui.AutocompleteRootProps{
		PickerInputProps: ui.PickerInputProps{
			PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
				return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
			}},
			Placeholder:        "Find a language",
			OnInputValueChange: func(query string, _ *native.Event) { fmt.Println(query) },
		},
	})
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `InputValue` | Editable query text used by a combobox or autocomplete. |
| `FilterMode` | Core-owned contains, prefix, fuzzy, or disabled filtering. |
| `OnInputValueChange` | Reports the editable query text retained by the core. |
| `OnCommit` | Reports one explicit commit boundary and its final value details. |
