Coordinates a bounded set of checkbox values and an optional derived parent checkbox.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func CheckboxGroupExample() {
	values, setValues := ui.CreateSignal([]string{"email"})
	ui.CheckboxGroup.Root(
		ui.CheckboxGroupProps{
			AllValues:     []string{"email", "push"},
			Value:         values,
			OnValueChange: func(next []string, _ *native.Event) { setValues(next) },
		},
		func() {
			ui.Checkbox.Root(ui.CheckboxProps{Parent: true}, "All notifications")
			ui.Checkbox.Root(ui.CheckboxProps{Value: "email"}, "Email")
			ui.Checkbox.Root(ui.CheckboxProps{Value: "push"}, "Push")
		},
	)
}
```

## Anatomy

- `ui.CheckboxGroup.Root`

## Key props

| Prop | Purpose |
| --- | --- |
| `AllValues` | Complete ordered value universe used to derive a parent checkbox state. |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `OnValueChange` | Reports the value accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
