An on/off control with a root track and independently styled thumb.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func SwitchExample() {
	on, setOn := ui.CreateSignal(false)
	ui.Switch.Root(
		ui.SwitchProps{
			Checked:         on,
			OnCheckedChange: func(next bool, _ *native.Event) { setOn(next) },
		},
		func() { ui.Switch.Thumb(ui.PartProps{}); ui.Text("Notifications") },
	)
}
```

## Anatomy

- `ui.Switch.Root`
- `ui.Switch.Thumb`

## Key props

| Prop | Purpose |
| --- | --- |
| `Checked` | Controlled checked state. |
| `DefaultChecked` | Initial checked state when the component owns it. |
| `OnCheckedChange` | Reports the checked state accepted by the core. |
| `Disabled` | Prevents interaction and exposes the disabled state. |
