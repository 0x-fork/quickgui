Coordinates single or multiple pressed values with roving keyboard focus.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func ToggleGroupExample() {
	values, setValues := ui.CreateSignal([]string{"bold"})
	ui.ToggleGroup.Root(
		ui.ToggleGroupProps{
			Multiple:      true,
			Value:         values,
			Items:         []ui.ComponentItem{{Value: "bold"}, {Value: "italic"}},
			OnValueChange: func(next []string, _ *native.Event) { setValues(next) },
		},
		func() {
			ui.ToggleGroup.Item(ui.ToggleGroupItemProps{Value: "bold"}, "Bold")
			ui.ToggleGroup.Item(ui.ToggleGroupItemProps{Value: "italic"}, "Italic")
		},
	)
}
```

## Anatomy

- `ui.ToggleGroup.Root`
- `ui.ToggleGroup.Item`

## Key props

| Prop | Purpose |
| --- | --- |
| `Items` | Bounded declaration model used for options or keyboard navigation. |
| `Value` | Controlled value. The precise value type follows this component’s contract. |
| `DefaultValue` | Initial value when the component owns its state. |
| `Multiple` | Chooses the single- or multiple-selection policy. |
| `OnValueChange` | Reports the value accepted by the core. |
