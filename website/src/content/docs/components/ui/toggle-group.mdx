Coordinates single or multiple pressed values with roving keyboard focus.

## Import

Import `ToggleGroup` from `@quickgui/ui`.

```tsx
import { ToggleGroup } from "@quickgui/ui/controls";
```

## Usage

```tsx
<ToggleGroup.Root
  items={[{ value: "left" }, { value: "center" }, { value: "right" }]}
  value={alignment()}
  variant="single"
  onValueChange={setAlignment}
>
  <ToggleGroup.Item partValue="left"><Text>Left</Text></ToggleGroup.Item>
  <ToggleGroup.Item partValue="center"><Text>Center</Text></ToggleGroup.Item>
  <ToggleGroup.Item partValue="right"><Text>Right</Text></ToggleGroup.Item>
</ToggleGroup.Root>
```

## Anatomy

- `ToggleGroup.Root`
- `ToggleGroup.Item`

```tsx
<ToggleGroup.Root>
  <ToggleGroup.Item />
</ToggleGroup.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `items` | Bounded declaration model used for options or keyboard navigation. |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `defaultValue` | Initial value when the component owns its state. |
| `variant` | Chooses the single- or multiple-selection policy. |
| `onValueChange` | Reports the value accepted by the core. |
