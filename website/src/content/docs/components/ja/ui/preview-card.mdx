現在の画面を変えず、トリガーの横により詳しいホバー／フォーカスプレビューを表示します。

## インポート

`@quickgui/ui` から `PreviewCard` をインポートします。

```tsx
import { PreviewCard } from "@quickgui/ui/tooltip";
```

## 使い方

```tsx
<PreviewCard.Root open={open()} onOpenChange={setOpen} placement="bottom">
  <PreviewCard.Trigger delay={300}><Text>@quickgui</Text></PreviewCard.Trigger>
  <PreviewCard.Portal>
    <PreviewCard.Positioner><PreviewCard.Popup><ProfilePreview /></PreviewCard.Popup></PreviewCard.Positioner>
  </PreviewCard.Portal>
</PreviewCard.Root>
```

## 構成

- `PreviewCard.Root`
- `PreviewCard.Trigger`
- `PreviewCard.Portal`
- `PreviewCard.Backdrop`
- `PreviewCard.Positioner`
- `PreviewCard.Popup`
- `PreviewCard.Arrow`

```tsx
<PreviewCard.Root>
  <PreviewCard.Trigger />
  <PreviewCard.Portal />
  <PreviewCard.Backdrop />
  <PreviewCard.Positioner />
  <PreviewCard.Popup />
  <PreviewCard.Arrow />
</PreviewCard.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `closeDelay` | 閉じるまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `side` | 衝突処理前に優先する配置方向です。 |
