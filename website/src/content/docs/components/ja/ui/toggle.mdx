オン／オフの押下状態を保持する、押下可能なコントロールです。

## インポート

`@quickgui/ui` から `Toggle` をインポートします。

```tsx
import { Toggle } from "@quickgui/ui/controls";
```

## 使い方

```tsx
<Toggle.Root pressed={bold()} onPressedChange={setBold}>
  <Text>B</Text>
  <Toggle.Indicator />
</Toggle.Root>
```

## 構成

- `Toggle.Root`
- `Toggle.Indicator`

```tsx
<Toggle.Root>
  <Toggle.Indicator />
</Toggle.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `pressed` | 制御された押下状態です。 |
| `defaultPressed` | コンポーネント自身が状態を管理するときの初期押下状態です。 |
| `onPressedChange` | コアが受け入れた押下状態を通知します。 |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
