1 つの日付を選ぶための、キーボードで操作できる月間カレンダーグリッドです。

## インポート

`@quickgui/ui` から `Calendar` をインポートします。

```tsx
import { Calendar } from "@quickgui/ui/date-time";
```

## 使い方

```tsx
<Calendar.Root value={date()} onValueChange={setDate} onMonthChange={setMonth}>
  <For each={weeks()}>{(week, weekIndex) =>
    <Calendar.Week itemIndex={weekIndex()}>
      <For each={week}>{(day) => <Calendar.Day day={day} />}</For>
    </Calendar.Week>
  }</For>
</Calendar.Root>
```

## 構成

- `Calendar.Root`
- `Calendar.Week`
- `Calendar.Day`

```tsx
<Calendar.Root>
  <Calendar.Week />
  <Calendar.Day />
</Calendar.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `min` | 受け入れる最小値です。 |
| `max` | 受け入れる最大値です。 |
| `firstWeekday` | 最初の曜日列です。月曜日が 0、日曜日が 6 です。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
