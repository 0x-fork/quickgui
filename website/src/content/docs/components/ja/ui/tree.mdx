展開、選択、キーボードナビゲーションに対応した仮想化階層コレクションです。

## インポート

`@quickgui/ui` から `Tree` をインポートします。

```tsx
import { Tree } from "@quickgui/ui/collections";
```

## 使い方

```tsx
<Tree.Root
  nodes={nodes}
  expanded={expanded()}
  value={selected()}
  onExpandedChange={setExpanded}
  onValueChange={setSelected}
>
  <For each={visibleNodes()}>{(node) =>
    <Tree.Row nodeId={node.id}><Text>{node.label}</Text></Tree.Row>
  }</For>
</Tree.Root>
```

## 構成

- `Tree.Root`
- `Tree.Row`

```tsx
<Tree.Root>
  <Tree.Row />
</Tree.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `nodes` | Tree の上限付き階層ノード宣言です。 |
| `expanded` | 制御された展開済み Tree ノード ID です。 |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `onExpandedChange` | コアが展開した順序付きノード ID を通知します。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
