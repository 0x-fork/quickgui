1 つのコントロールをラベル、説明、検証状態、エラーメッセージに関連付けます。

## インポート

`@quickgui/ui` から `Field` をインポートします。

```tsx
import { Field } from "@quickgui/ui/field";
```

## 使い方

```tsx
<Field.Root required invalid={name().length === 0} validationMessage="Enter a name">
  <Field.Label><Text>Name</Text></Field.Label>
  <Field.Control value={name()} onInput={(event) => setName(event.value ?? "")} />
  <Field.Description><Text>Shown on your profile.</Text></Field.Description>
  <Field.Error><Text>Enter a name.</Text></Field.Error>
</Field.Root>
```

## 構成

- `Field.Root`
- `Field.Item`
- `Field.Label`
- `Field.Control`
- `Field.Validity`
- `Field.Description`
- `Field.Error`

```tsx
<Field.Root>
  <Field.Item />
  <Field.Label />
  <Field.Control />
  <Field.Validity />
  <Field.Description />
  <Field.Error />
</Field.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `invalid` | Field とそのパーツへ検証エラー状態を反映します。 |
| `required` | 検証とフォーム送信で必須の値としてマークします。 |
| `validationMessage` | エラー内容とアクセシビリティに公開する、長さ制限付きメッセージです。 |
| `validationMode` | 検証を開始するインタラクション境界を選びます。 |
| `onValidationChange` | コアが選んだ検証のトリガーとタイミングを通知します。 |
