レイアウト、描画、ポインター入力、アクセシビリティに使える汎用の保持型コンテナです。

## インポート

`@quickgui/ui` から `View` をインポートします。

```tsx
import { View } from "@quickgui/ui";
```

## 使い方

```tsx
<View
  style={{
    display: "flex",
    flexDirection: "column",
    gap: 12,
    padding: 16,
  }}
>
  <Text>Content</Text>
</View>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `onClick` | コアがアクティブ化を解決した後に実行します。 |
| `ref` | 保持されたネイティブノードを受け取ります。 |
