Radio 項目間の単一選択とキーボード移動を管理します。

## インポート

`@quickgui/ui` から `RadioGroup` をインポートします。

```tsx
import { RadioGroup } from "@quickgui/ui/controls";
```

## 使い方

```tsx
<RadioGroup.Root value={theme()} onValueChange={setTheme}>
  <Radio.Root value="light"><Radio.Indicator /><Text>Light</Text></Radio.Root>
  <Radio.Root value="dark"><Radio.Indicator /><Text>Dark</Text></Radio.Root>
</RadioGroup.Root>
```

## 構成

- `RadioGroup.Root`

```tsx
<RadioGroup.Root>{/* content */}</RadioGroup.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
| `readOnly` | 値の変更を防ぎつつ、コントロールはフォーカス可能なままにします。 |
| `required` | 検証とフォーム送信で必須の値としてマークします。 |
