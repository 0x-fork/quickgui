ウィンドウ内の水平メニューバーとその項目を管理します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func MenubarExample() {
	ui.Menubar.Root(
		ui.MenubarRootProps{Count: 2},
		func() {
			for index, label := range []string{"File", "Edit"} {
				ui.Menubar.Item(ui.MenubarItemProps{Index: &index}, label)
			}
		},
	)
}
```

## 構成

- `ui.Menubar.Root`
- `ui.Menubar.Item`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Count` | 宣言されたメニューバー項目の数です。 |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `OnActiveChange` | ロービングフォーカス状態を現在持つ項目を通知します。 |
