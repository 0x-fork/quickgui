関連するフィールドを 1 つの凡例と共有セマンティック状態の下にまとめます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func FieldsetExample(saving func() bool) {
	ui.Fieldset.Root(
		ui.PartProps{Disabled: saving},
		func() {
			ui.Fieldset.Legend(ui.PartProps{}, "Profile")
			ui.Field.Root(
				ui.FieldRootProps{},
				func() {
					ui.Field.Label(ui.FieldLabelProps{}, "Name")
					ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{Placeholder: "Ada"}})
				},
			)
		},
	)
}
```

## 構成

- `ui.Fieldset.Root`
- `ui.Fieldset.Legend`
- `ui.Fieldset.Description`
- `ui.Fieldset.Control`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `Style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
