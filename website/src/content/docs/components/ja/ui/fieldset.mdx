関連するフィールドを 1 つの凡例と共有セマンティック状態の下にまとめます。

## インポート

`@quickgui/ui` から `Fieldset` をインポートします。

```tsx
import { Fieldset } from "@quickgui/ui/field";
```

## 使い方

```tsx
<Fieldset.Root disabled={saving()}>
  <Fieldset.Legend><Text>Billing address</Text></Fieldset.Legend>
  <Fieldset.Description><Text>Used for receipts.</Text></Fieldset.Description>
  <Fieldset.Control element="input" value={address()} />
</Fieldset.Root>
```

## 構成

- `Fieldset.Root`
- `Fieldset.Legend`
- `Fieldset.Description`
- `Fieldset.Control`

```tsx
<Fieldset.Root>
  <Fieldset.Legend />
  <Fieldset.Description />
  <Fieldset.Control />
</Fieldset.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
| `children` | コンポーネント内にマウントする内容です。 |
| `style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
