既知の範囲内のスカラー測定値を、低・高・最適のセマンティックな帯域とともに表示します。

## インポート

`@quickgui/ui` から `Meter` をインポートします。

```tsx
import { Meter } from "@quickgui/ui/gauges";
```

## 使い方

```tsx
<Meter.Root value={storage()} min={0} max={100} high={80} optimum={40} format="percent">
  <Meter.Label><Text>Storage</Text></Meter.Label>
  <Meter.Track><Meter.Indicator /></Meter.Track>
  <Meter.Value />
</Meter.Root>
```

## 構成

- `Meter.Root`
- `Meter.Track`
- `Meter.Indicator`
- `Meter.Label`
- `Meter.Value`

```tsx
<Meter.Root>
  <Meter.Track />
  <Meter.Indicator />
  <Meter.Label />
  <Meter.Value />
</Meter.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `min` | 受け入れる最小値です。 |
| `max` | 受け入れる最大値です。 |
| `low` | Meter の低い範囲の上限です。 |
| `high` | Meter の高い範囲の下限です。 |
| `optimum` | Meter 値の望ましい点または範囲です。 |
