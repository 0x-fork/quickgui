時、分、秒、午前／午後の各パーツを持つ、キーボード編集可能な分割時刻フィールドです。

## インポート

`@quickgui/ui` から `TimeField` をインポートします。

```tsx
import { TimeField } from "@quickgui/ui/date-time";
```

## 使い方

```tsx
<TimeField.Root value={time()} showSeconds onValueChange={setTime}>
  <TimeField.Segment segment="hour" />
  <Text>:</Text>
  <TimeField.Segment segment="minute" />
  <Text>:</Text>
  <TimeField.Segment segment="second" />
</TimeField.Root>
```

## 構成

- `TimeField.Root`
- `TimeField.Segment`

```tsx
<TimeField.Root>
  <TimeField.Segment />
</TimeField.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `hour12` | 午前／午後セグメントを追加し、12 時間表記を使います。 |
| `showSeconds` | 秒セグメントをマウントします。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
