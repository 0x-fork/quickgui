QuickGUI コアのルーティングを QuickGUI UI に投影し、ネストされたレイアウトと上限付きメモリ履歴を提供します。

## インポート

`@quickgui/ui` から `Router` をインポートします。

```tsx
import { Router } from "@quickgui/ui/router";
```

## 使い方

```tsx
import { Router, route } from "@quickgui/ui/router";

<Router initialPath="/" routes={[
  route("/", Shell, [route("", Home), route("projects/:id", Project)]),
]} />;
```

## 構成

- `Router`
- `route` / `layout`
- `Link`
- `Outlet`

```tsx
import { Router, route } from "@quickgui/ui/router";

<Router initialPath="/" routes={[
  route("/", Shell, [route("", Home), route("projects/:id", Project)]),
]} />;
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `initialPath` | 上限付きメモリ履歴の初期移動先です。 |
| `fallback` | どのルートにも一致しないときに描画する内容です。 |
| `routes` | Static route declarations built with `route` and `layout`. |
| `path` | 絶対または親からの相対ルートパターンです。 |
| `component` | ルートが一致したときに描画するコンポーネントです。 |
| `href` | QuickGUI Router が解決する移動先です。 |
