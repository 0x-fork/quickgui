ネイティブのポップオーバー内に描画される、コンパクトなモデル駆動メニューです。

## インポート

`@quickgui/ui` から `PopoverMenu` をインポートします。

```tsx
import { PopoverMenu } from "@quickgui/ui/menu";
```

## 使い方

```tsx
<PopoverMenu.Root
  items={menuItems}
  appearance={menuAppearance}
  onSelect={({ value }) => runCommand(value)}
>
  <PopoverMenu.Trigger><Text>Actions</Text></PopoverMenu.Trigger>
  <PopoverMenu.Popup />
</PopoverMenu.Root>
```

## 構成

- `PopoverMenu.Root`
- `PopoverMenu.Trigger`
- `PopoverMenu.Popup`

```tsx
<PopoverMenu.Root>
  <PopoverMenu.Trigger />
  <PopoverMenu.Popup />
</PopoverMenu.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `appearance` | コア描画のネイティブメニューまたはピッカーに使う構造色とジオメトリです。 |
| `open` | 制御された開閉状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `onSelect` | コアが選択したメニュー項目を通知します。 |
