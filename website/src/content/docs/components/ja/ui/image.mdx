ファイルパス、ファイル URL、base64 データ URL を保持型の画像リソースとして表示します。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func ImageExample(path string) {
	ui.Image(ui.Value(path), ui.ObjectFit("cover"), ui.Width(160), ui.Height(120))
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | コンポーネントが受け取るファイルパス、データ URL、SVG ドキュメント、またはシェーダーソースです。 |
| `ObjectFit` | 宣言したボックスに画像内容を収める方法です。 |
| `WithStyle` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
