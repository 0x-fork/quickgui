選択値を必須にせず、自由入力テキストの候補を絞り込みます。

## インポート

`@quickgui/ui` から `Autocomplete` をインポートします。

```tsx
import { Autocomplete } from "@quickgui/ui/select";
```

## 使い方

```tsx
<Autocomplete.Root
  ariaLabel="Search commands"
  items={commands}
  inputValue={query()}
  filterMode="fuzzy"
  onInputValueChange={setQuery}
  onCommit={(details) => run(details.inputValue ?? "")}
/>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `inputValue` | Combobox または Autocomplete が使う、編集可能な検索テキストです。 |
| `filterMode` | コアが管理する、部分一致、前方一致、あいまい一致、または無効の絞り込みです。 |
| `onInputValueChange` | コアが保持した編集可能な検索テキストを通知します。 |
| `onCommit` | 明示的なコミット境界と最終値の詳細を通知します。 |
