選択値を必須にせず、自由入力テキストの候補を絞り込みます。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"fmt"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func AutocompleteExample() {
	ui.Autocomplete.Root(ui.AutocompleteRootProps{
		PickerInputProps: ui.PickerInputProps{
			PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
				return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
			}},
			Placeholder:        "Find a language",
			OnInputValueChange: func(query string, _ *native.Event) { fmt.Println(query) },
		},
	})
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `InputValue` | Combobox または Autocomplete が使う、編集可能な検索テキストです。 |
| `FilterMode` | コアが管理する、部分一致、前方一致、あいまい一致、または無効の絞り込みです。 |
| `OnInputValueChange` | コアが保持した編集可能な検索テキストを通知します。 |
| `OnCommit` | 明示的なコミット境界と最終値の詳細を通知します。 |
