フォーカスの閉じ込め、閉じる操作、正確なトランジション完了を備えたウィンドウ内モーダルです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func DialogExample() {
	ui.Dialog.Root(
		ui.DialogRootProps{},
		func() {
			ui.Dialog.Trigger(ui.PartProps{}, "Open dialog")
			ui.Dialog.Portal(
				ui.PartProps{},
				func() {
					ui.Dialog.Backdrop(ui.PartProps{})
					ui.Dialog.Viewport(
						ui.PartProps{},
						func() {
							ui.Dialog.Popup(
								ui.DialogPopupProps{},
								func() {
									ui.Dialog.Title(ui.PartProps{}, "Confirm action")
									ui.Dialog.Description(
										ui.PartProps{},
										"Review the details before continuing.",
									)
									ui.Dialog.Close(ui.PartProps{}, "Cancel")
								},
							)
						},
					)
				},
			)
		},
	)
}
```

## 構成

- `ui.Dialog.Root`
- `ui.Dialog.Trigger`
- `ui.Dialog.Portal`
- `ui.Dialog.Backdrop`
- `ui.Dialog.Viewport`
- `ui.Dialog.Popup`
- `ui.Dialog.Title`
- `ui.Dialog.Description`
- `ui.Dialog.Close`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Open` | 制御された開閉状態です。 |
| `DefaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `OnOpenChange` | コアが決定した開閉を通知します。 |
| `DismissOnEscape` | Escape キーでサーフェスを閉じられるようにします。 |
| `ExitDuration` | 閉じる内容を、正確な終了トランジション時間だけマウントしたままにします。 |
