ルートのトラックと個別にスタイルできるつまみを持つ、オン／オフコントロールです。

## インポート

`@quickgui/ui` から `Switch` をインポートします。

```tsx
import { Switch } from "@quickgui/ui/controls";
```

## 使い方

```tsx
<Switch.Root checked={enabled()} onCheckedChange={setEnabled}>
  <Switch.Thumb />
</Switch.Root>
```

## 構成

- `Switch.Root`
- `Switch.Thumb`

```tsx
<Switch.Root>
  <Switch.Thumb />
</Switch.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `checked` | 制御されたチェック状態です。 |
| `defaultChecked` | コンポーネント自身が状態を管理するときの初期チェック状態です。 |
| `onCheckedChange` | コアが受け入れたチェック状態を通知します。 |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
