ロケールに応じた日付パーツを持つ、キーボード編集可能な分割日付フィールドです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func DateFieldExample() {
	value, setValue := ui.CreateSignal[*string](nil)
	ui.DateField.Root(
		ui.DateFieldRootProps{
			Value:         value,
			Format:        "ymd",
			Min:           "2026-01-01",
			Max:           "2026-12-31",
			OnValueChange: func(next *string, _ *native.Event) { setValue(next) },
		},
		func() {
			for _, segment := range []string{"year", "month", "day"} {
				ui.DateField.Segment(ui.DateFieldSegmentProps{Segment: segment})
			}
		},
	)
}
```

## 構成

- `ui.DateField.Root`
- `ui.DateField.Segment`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `Disabled` | 操作を無効にし、無効状態を公開します。 |
