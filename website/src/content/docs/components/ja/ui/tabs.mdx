ラベル付きパネルを切り替え、キーボードによる自動または手動のアクティブ化に対応します。

## インポート

`@quickgui/ui` から `Tabs` をインポートします。

```tsx
import { Tabs } from "@quickgui/ui/tabs";
```

## 使い方

```tsx
<Tabs.Root value={tab()} onValueChange={setTab}>
  <Tabs.List>
    <Tabs.Tab value="general" index={0}>General</Tabs.Tab>
    <Tabs.Tab value="advanced" index={1}>Advanced</Tabs.Tab>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel value="general"><General /></Tabs.Panel>
  <Tabs.Panel value="advanced"><Advanced /></Tabs.Panel>
</Tabs.Root>
```

## 構成

- `Tabs.Root`
- `Tabs.List`
- `Tabs.Tab`
- `Tabs.Indicator`
- `Tabs.Panel`

```tsx
<Tabs.Root>
  <Tabs.List />
  <Tabs.Tab />
  <Tabs.Indicator />
  <Tabs.Panel />
</Tabs.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
| `orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `activation` | フォーカスまたは明示的な押下で Tab をアクティブにするかどうかです。 |
