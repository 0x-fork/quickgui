線形と円形のアクセサリースタイルに対応した、ネイティブ SwiftUI Gauge です。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiGaugeExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Gauge(ui.SwiftUIGaugeProps{
				Value: 60,
				Min:   0,
				Max:   100,
				Label: "Capacity",
				Style: "accessoryLinearCapacity",
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Min` | 受け入れる最小値です。 |
| `Max` | 受け入れる最大値です。 |
| `Label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `CurrentValueLabel` | 現在のネイティブ進捗または Gauge 値を表す読みやすいラベルです。 |
| `Style` | このコントロールのネイティブ SwiftUI 表示スタイルです。 |
