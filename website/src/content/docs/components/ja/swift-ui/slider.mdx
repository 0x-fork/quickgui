連続値または段階値に対応した、制御されたネイティブ Slider です。

## インポート

`@quickgui/ui/swift-ui` から `Slider` をインポートします。

```tsx
import { Host, Slider } from "@quickgui/ui/swift-ui";
```

## 使い方

```tsx
<Host matchContents={{ vertical: true }} style={{ width: 360 }}>
  <Slider
    value={volume()}
    min={0}
    max={1}
    step={0.05}
    label="Volume"
    onValueChange={setVolume}
  />
</Host>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `min` | 受け入れる最小値です。 |
| `max` | 受け入れる最大値です。 |
| `step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
