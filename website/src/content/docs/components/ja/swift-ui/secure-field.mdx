TextField と同じ制御規約を持つ、入力内容を隠すネイティブエディターです。

## インポート

`github.com/egoist/quickgui/go/ui` から `ui` をインポートします。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func SwiftUiSecureFieldExample() {
	text, setText := ui.CreateSignal("")
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.SecureField(ui.SwiftUITextFieldProps{
				Value:         text,
				Placeholder:   "Enter text",
				OnValueChange: func(next string, _ *native.Event) { setText(next) },
			})
		},
	)
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `Placeholder` | 編集値が空のときに表示するテキストです。 |
| `OnValueChange` | コアが受け入れた値を通知します。 |
| `OnSubmit` | ネイティブフィールドが現在値を送信したときに実行します。 |
