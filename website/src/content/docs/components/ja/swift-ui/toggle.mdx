制御されたネイティブ SwiftUI オン／オフスイッチです。

## インポート

`@quickgui/ui/swift-ui` から `Toggle` をインポートします。

```tsx
import { Host, Toggle } from "@quickgui/ui/swift-ui";
```

## 使い方

```tsx
<Host matchContents>
  <Toggle
    label="Notifications"
    isOn={notifications()}
    onIsOnChange={setNotifications}
  />
</Host>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `isOn` | 制御された SwiftUI Toggle の値です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `onIsOnChange` | ネイティブ SwiftUI Toggle が受け入れた値を通知します。 |
| `modifiers` | ホストしたコントロールへ順番に適用する SwiftUI View モディファイアです。 |
