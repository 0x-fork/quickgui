値選択とニュートラルな Xcode 風タブロールを持つ、ネイティブのセグメントピッカーです。

## インポート

`@quickgui/ui/swift-ui` から `SegmentedControl` をインポートします。

```tsx
import { Host, SegmentedControl } from "@quickgui/ui/swift-ui";
```

## 使い方

```tsx
<Host matchContents>
  <SegmentedControl
    role="tabs"
    selection={layout()}
    options={[
      { value: "list", label: "List" },
      { value: "grid", label: "Grid" },
    ]}
    onSelectionChange={setLayout}
  />
</Host>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `selection` | テーブル、ネイティブピッカー、カラーコントロールの制御選択値です。 |
| `options` | 順序付きのネイティブピッカー選択肢です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `role` | 保持ノードが公開するアクセシビリティロールです。 |
| `onSelectionChange` | 選択したネイティブピッカー項目または色を通知します。 |
