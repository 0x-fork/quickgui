SwiftUI 階層の中へ通常の QuickGUI サブツリーをリバースホストします。

## インポート

`@quickgui/ui/swift-ui` から `QuickGUIHostView` をインポートします。

```tsx
import { Host, QuickGUIHostView } from "@quickgui/ui/swift-ui";
```

## 使い方

```tsx
<Host matchContents>
  <QuickGUIHostView width={280} height={120}>
    <View style={{ width: 280, height: 120, padding: 16 }}>
      <Text>Ordinary QuickGUI content</Text>
    </View>
  </QuickGUIHostView>
</Host>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `width` | 宣言された論理幅です。 |
| `height` | 宣言された論理高さです。 |
| `matchContents` | ホストしたサブツリー固有の幅、高さ、またはその両方を使います。 |
| `background` | リバースホストした QuickGUI WGPU サーフェスのクリアカラーです。 |
| `children` | コンポーネント内にマウントする内容です。 |
