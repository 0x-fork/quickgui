確定または不確定のネイティブ SwiftUI 進捗インジケーターです。

## インポート

`@quickgui/ui/swift-ui` から `ProgressView` をインポートします。

```tsx
import { Host, ProgressView } from "@quickgui/ui/swift-ui";
```

## 使い方

```tsx
<Host matchContents={{ vertical: true }} style={{ width: 320 }}>
  <ProgressView
    value={completed()}
    total={100}
    label="Exporting"
    currentValueLabel={String(completed()) + "%"}
  />
</Host>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `total` | 確定型の SwiftUI 進捗で使う分母です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `currentValueLabel` | 現在のネイティブ進捗または Gauge 値を表す読みやすいラベルです。 |
