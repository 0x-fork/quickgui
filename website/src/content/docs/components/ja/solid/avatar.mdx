画像を表示し、読み込めない場合はフォールバックを表示します。

## インポート

`@quickgui/solid` から `Avatar` をインポートします。

```tsx
import { Avatar } from "@quickgui/solid";
```

## 使い方

```tsx
<Avatar.Root ariaLabel="Ada Lovelace" onLoadingStatusChange={setStatus}>
  <Avatar.Image src="assets/ada.png" fit="cover" />
  <Avatar.Fallback delay={120}><Text>AL</Text></Avatar.Fallback>
</Avatar.Root>
```

## 構成

- `Avatar.Root`
- `Avatar.Image`
- `Avatar.Fallback`

```tsx
<Avatar.Root>
  <Avatar.Image />
  <Avatar.Fallback />
</Avatar.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `ariaLabel` | 表示パーツが変化するコンポーネントに付けるアクセシブル名です。 |
| `src` | アバター画像のファイルパス、ファイル URL、または base64 データ URL です。 |
| `delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `onLoadingStatusChange` | アバター画像の読み込み状態が変わるたびに通知します。 |
