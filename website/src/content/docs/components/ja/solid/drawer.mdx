スナップポイントを備え、スワイプによる閉じる操作をコアが管理するモーダルまたはフォーカストラップ型シートです。

## インポート

`@quickgui/solid` から `Drawer` をインポートします。

```tsx
import { Drawer } from "@quickgui/solid";
```

## 使い方

```tsx
<Drawer.Root open={open()} snapPoints={[0.4, 0.9]} onOpenChange={setOpen}>
  <Drawer.Trigger><Text>Open drawer</Text></Drawer.Trigger>
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Viewport>
      <Drawer.Popup><Drawer.SwipeArea /><Drawer.Content><Settings /></Drawer.Content></Drawer.Popup>
    </Drawer.Viewport>
  </Drawer.Portal>
</Drawer.Root>
```

## 構成

- `Drawer.Root`
- `Drawer.Trigger`
- `Drawer.Portal`
- `Drawer.Backdrop`
- `Drawer.Viewport`
- `Drawer.Popup`
- `Drawer.Content`
- `Drawer.Title`
- `Drawer.Description`
- `Drawer.Close`
- `Drawer.SwipeArea`

```tsx
<Drawer.Root>
  <Drawer.Trigger />
  <Drawer.Portal />
  <Drawer.Backdrop />
  <Drawer.Viewport />
  <Drawer.Popup />
  <Drawer.Content />
  <Drawer.Title />
  <Drawer.Description />
  <Drawer.Close />
  <Drawer.SwipeArea />
</Drawer.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `snapPoints` | ドロワーで許可する展開量を、ビューポート比率またはピクセルで指定します。 |
| `swipeDirection` | スワイプでサーフェスを閉じる、または移動する方向の端です。 |
