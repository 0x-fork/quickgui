ネイティブのポップオーバーに選択肢を表示する、単一または複数選択のピッカーです。

## インポート

`@quickgui/solid` から `Select` をインポートします。

```tsx
import { Select } from "@quickgui/solid";
```

## 使い方

```tsx
<Select.Root
  ariaLabel="Theme"
  items={[
    { value: "system", label: "System" },
    { value: "light", label: "Light" },
    { value: "dark", label: "Dark" },
  ]}
  value={theme()}
  onValueChange={setTheme}
/>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `defaultValue` | コンポーネント自身が状態を管理するときの初期値です。 |
| `multiple` | 複数の値を選択または開けるようにします。 |
| `onValueChange` | コアが受け入れた値を通知します。 |
