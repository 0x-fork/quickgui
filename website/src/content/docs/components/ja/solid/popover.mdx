呼び出し側がスタイルした内容を、現在のウィンドウ内でアンカーの横に配置します。

## インポート

`@quickgui/solid` から `Popover` をインポートします。

```tsx
import { Popover } from "@quickgui/solid";
```

## 使い方

```tsx
<Popover.Root open={open()} onOpenChange={setOpen}>
  <Popover.Trigger><Text>Open</Text></Popover.Trigger>
  <Popover.Portal>
    <Popover.Positioner side="bottom" sideOffset={8}>
      <Popover.Popup><Popover.Arrow /><Text>Popover content</Text></Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>
```

## 構成

- `Popover.Root`
- `Popover.Trigger`
- `Popover.Content`
- `Popover.Portal`
- `Popover.Backdrop`
- `Popover.Positioner`
- `Popover.Popup`
- `Popover.Arrow`
- `Popover.Viewport`
- `Popover.Title`
- `Popover.Description`
- `Popover.Close`

```tsx
<Popover.Root>
  <Popover.Trigger />
  <Popover.Content />
  <Popover.Portal />
  <Popover.Backdrop />
  <Popover.Positioner />
  <Popover.Popup />
  <Popover.Arrow />
  <Popover.Viewport />
  <Popover.Title />
  <Popover.Description />
  <Popover.Close />
</Popover.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `side` | 衝突処理前に優先する配置方向です。 |
| `align` | 配置の交差軸上で優先する揃え方です。 |
| `modal` | フォーカスを内部に閉じ込め、背後のサーフェスへの操作を防ぎます。 |
