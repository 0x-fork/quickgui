サブメニュー、グループ、リンク、チェック項目、ラジオ項目を組み合わせられるメニューです。

## インポート

`@quickgui/solid` から `Menu` をインポートします。

```tsx
import { Menu } from "@quickgui/solid";
```

## 使い方

```tsx
<Menu.Root open={open()} onOpenChange={setOpen}>
  <Menu.Trigger><Text>File</Text></Menu.Trigger>
  <Menu.Portal>
    <Menu.Positioner side="bottom">
      <Menu.Popup>
        <Menu.Item value="new"><Text>New</Text></Menu.Item>
        <Menu.Separator />
        <Menu.CheckboxItem value="sidebar" checked={sidebar()}><Text>Sidebar</Text></Menu.CheckboxItem>
      </Menu.Popup>
    </Menu.Positioner>
  </Menu.Portal>
</Menu.Root>
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `defaultOpen` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `onOpenChange` | コアが決定した開閉を通知します。 |
| `orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `loopFocus` | 現在のメニューレベルの端でキーボードハイライトを循環させます。 |
