外部リソースを読み込まずに、完全なインライン SVG ドキュメントを描画します。

## インポート

`@quickgui/solid` から `Svg` をインポートします。

```tsx
import { Svg } from "@quickgui/solid";
```

## 使い方

```tsx
<Svg source={iconSvg} style={{ width: 20, height: 20 }} />
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `source` | コンポーネントが受け取るファイルパス、データ URL、SVG ドキュメント、またはシェーダーソースです。 |
| `style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
