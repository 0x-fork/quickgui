A segmented, keyboard-editable date field with locale-aware date parts.

## Import

Import `DateField` from `@quickgui/solid`.

```tsx
import { DateField } from "@quickgui/solid";
```

## Usage

```tsx
<DateField.Root value={date()} format="ymd" onValueChange={setDate}>
  <DateField.Segment segment="year" />
  <Text>–</Text>
  <DateField.Segment segment="month" />
  <Text>–</Text>
  <DateField.Segment segment="day" />
</DateField.Root>
```

## Anatomy

- `DateField.Root`
- `DateField.Segment`

```tsx
<DateField.Root>
  <DateField.Segment />
</DateField.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `min` | Minimum accepted value. |
| `max` | Maximum accepted value. |
| `onValueChange` | Reports the value accepted by the core. |
| `disabled` | Prevents interaction and exposes the disabled state. |
