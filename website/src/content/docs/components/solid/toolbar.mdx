Groups actions and inputs under one roving-focus keyboard model.

## Import

Import `Toolbar` from `@quickgui/solid`.

```tsx
import { Toolbar } from "@quickgui/solid";
```

## Usage

```tsx
<Toolbar.Root
  items={[{ value: "back" }, { value: "forward" }, { value: "search" }]}
  active={active()}
  onActiveChange={setActive}
>
  <Toolbar.Button partValue="back"><Text>Back</Text></Toolbar.Button>
  <Toolbar.Button partValue="forward"><Text>Forward</Text></Toolbar.Button>
  <Toolbar.Input partValue="search" placeholder="Search" />
</Toolbar.Root>
```

## Anatomy

- `Toolbar.Root`
- `Toolbar.Item`
- `Toolbar.Button`
- `Toolbar.Link`
- `Toolbar.Input`
- `Toolbar.Group`
- `Toolbar.Separator`

```tsx
<Toolbar.Root>
  <Toolbar.Item />
  <Toolbar.Button />
  <Toolbar.Link />
  <Toolbar.Input />
  <Toolbar.Group />
  <Toolbar.Separator />
</Toolbar.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `items` | Bounded declaration model used for options or keyboard navigation. |
| `active` | Controlled item holding the active or roving focus state. |
| `defaultActive` | Initial active item for an uncontrolled component. |
| `orientation` | Horizontal or vertical layout and keyboard direction. |
| `onActiveChange` | Reports the item that now owns the roving focus state. |
