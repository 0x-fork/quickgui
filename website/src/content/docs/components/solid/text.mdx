Shapes and paints Unicode text with inherited typography, selection, and accessibility.

## Import

Import `Text` from `@quickgui/solid`.

```tsx
import { Text } from "@quickgui/solid";
```

## Usage

```tsx
<Text style={{ fontSize: 18, fontWeight: 600 }}>
  Native, retained text
</Text>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
| `children` | Content mounted inside the component. |
| `role` | Accessibility role exposed by the retained node. |
| `ref` | Receives the retained native node. |
