Renders a complete inline SVG document without loading external SVG resources.

## Import

Import `Svg` from `@quickgui/solid`.

```tsx
import { Svg } from "@quickgui/solid";
```

## Usage

```tsx
<Svg source={iconSvg} style={{ width: 20, height: 20 }} />
```

## Key props

| Prop | Purpose |
| --- | --- |
| `source` | Filesystem path, data URL, SVG document, or shader source expected by the component. |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
