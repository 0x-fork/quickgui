Opens a model-driven native menu from a secondary-button press on its trigger.

## Import

Import `ContextMenu` from `@quickgui/solid`.

```tsx
import { ContextMenu } from "@quickgui/solid";
```

## Usage

```tsx
<ContextMenu.Root items={menuItems} onSelect={({ value }) => runCommand(value)}>
  <ContextMenu.Trigger><ProjectRow /></ContextMenu.Trigger>
</ContextMenu.Root>
```

## Anatomy

- `ContextMenu.Root`
- `ContextMenu.Trigger`

```tsx
<ContextMenu.Root>
  <ContextMenu.Trigger />
</ContextMenu.Root>
```

## Key props

| Prop | Purpose |
| --- | --- |
| `items` | Bounded declaration model used for options or keyboard navigation. |
| `appearance` | Structural colors and geometry for a core-painted native menu or picker. |
| `onSelect` | Reports the menu entry selected by the core. |
| `loop` | Wraps highlight navigation at the ends of a menu level. |
