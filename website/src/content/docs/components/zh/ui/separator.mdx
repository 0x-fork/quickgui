具备语义的水平或垂直分隔线，不附带视觉样式。

## 导入

从 `@quickgui/ui` 导入 `Separator`。

```tsx
import { Separator } from "@quickgui/ui/toolbar";
```

## 用法

```tsx
<Separator.Root
  orientation="horizontal"
  style={{ height: 1, backgroundColor: "#e4e4e7" }}
/>
```

## 结构

- `Separator.Root`

```tsx
<Separator.Root>{/* content */}</Separator.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
