由可分别设置样式的输入格组成、长度受限的一次性验证码编辑器。

## 导入

从 `@quickgui/ui` 导入 `OtpField`。

```tsx
import { OtpField } from "@quickgui/ui/base-ui";
```

## 用法

```tsx
<OtpField.Root value={code()} length={6} onValueChange={setCode} onComplete={verify}>
  <For each={[0, 1, 2, 3, 4, 5]}>{(index) =>
    <OtpField.Input index={index} />
  }</For>
</OtpField.Root>
```

## 结构

- `OtpField.Root`
- `OtpField.Input`
- `OtpField.Separator`

```tsx
<OtpField.Root>
  <OtpField.Input />
  <OtpField.Separator />
</OtpField.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `length` | 一次性验证码输入格数量，上限为 12。 |
| `onValueChange` | 报告核心接受的值。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
