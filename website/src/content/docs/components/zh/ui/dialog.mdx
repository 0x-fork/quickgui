窗口内模态框，支持焦点约束、关闭操作和精确的过渡结束时机。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func DialogExample() {
	ui.Dialog.Root(
		ui.DialogRootProps{},
		func() {
			ui.Dialog.Trigger(ui.PartProps{}, "Open dialog")
			ui.Dialog.Portal(
				ui.PartProps{},
				func() {
					ui.Dialog.Backdrop(ui.PartProps{})
					ui.Dialog.Viewport(
						ui.PartProps{},
						func() {
							ui.Dialog.Popup(
								ui.DialogPopupProps{},
								func() {
									ui.Dialog.Title(ui.PartProps{}, "Confirm action")
									ui.Dialog.Description(
										ui.PartProps{},
										"Review the details before continuing.",
									)
									ui.Dialog.Close(ui.PartProps{}, "Cancel")
								},
							)
						},
					)
				},
			)
		},
	)
}
```

## 结构

- `ui.Dialog.Root`
- `ui.Dialog.Trigger`
- `ui.Dialog.Portal`
- `ui.Dialog.Backdrop`
- `ui.Dialog.Viewport`
- `ui.Dialog.Popup`
- `ui.Dialog.Title`
- `ui.Dialog.Description`
- `ui.Dialog.Close`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Open` | 受控的打开状态。 |
| `DefaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `OnOpenChange` | 报告核心做出的打开或关闭决定。 |
| `DismissOnEscape` | 允许按 Escape 键关闭界面。 |
| `ExitDuration` | 在精确的退出过渡时长内保持关闭中的内容已挂载。 |
