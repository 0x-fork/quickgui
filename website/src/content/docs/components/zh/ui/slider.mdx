单滑块或多滑块范围输入，指针与键盘交互由核心管理。

## 导入

从 `@quickgui/ui` 导入 `Slider`。

```tsx
import { Slider } from "@quickgui/ui/range";
```

## 用法

```tsx
<Slider.Root
  value={[volume()]}
  min={0}
  max={100}
  step={1}
  onValueChange={(values) => setVolume(values[0] ?? 0)}
>
  <Slider.Label><Text>Volume</Text></Slider.Label>
  <Slider.Control>
    <Slider.Track><Slider.Indicator /></Slider.Track>
    <Slider.Thumb index={0} />
  </Slider.Control>
  <Slider.Value />
</Slider.Root>
```

## 结构

- `Slider.Root`
- `Slider.Label`
- `Slider.Value`
- `Slider.Control`
- `Slider.Track`
- `Slider.Range`
- `Slider.Indicator`
- `Slider.Thumb`

```tsx
<Slider.Root>
  <Slider.Label />
  <Slider.Value />
  <Slider.Control />
  <Slider.Track />
  <Slider.Range />
  <Slider.Indicator />
  <Slider.Thumb />
</Slider.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `step` | 键盘、指针或原生控件输入使用的步长。 |
| `onValueChange` | 报告核心接受的值。 |
