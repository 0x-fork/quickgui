使用保留式图像资源显示文件系统路径、文件 URL 或 base64 数据 URL。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ImageExample(path string) {
	ui.Image(ui.Value(path), ui.ObjectFit("cover"), ui.Width(160), ui.Height(120))
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 组件所需的文件系统路径、数据 URL、SVG 文档或着色器源码。 |
| `ObjectFit` | 图像内容在声明区域中的适配方式。 |
| `WithStyle` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
