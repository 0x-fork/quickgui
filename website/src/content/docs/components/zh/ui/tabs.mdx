在带标签的面板之间切换，支持自动或手动键盘激活。

## 导入

从 `@quickgui/ui` 导入 `Tabs`。

```tsx
import { Tabs } from "@quickgui/ui/tabs";
```

## 用法

```tsx
<Tabs.Root value={tab()} onValueChange={setTab}>
  <Tabs.List>
    <Tabs.Tab value="general" index={0}>General</Tabs.Tab>
    <Tabs.Tab value="advanced" index={1}>Advanced</Tabs.Tab>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel value="general"><General /></Tabs.Panel>
  <Tabs.Panel value="advanced"><Advanced /></Tabs.Panel>
</Tabs.Root>
```

## 结构

- `Tabs.Root`
- `Tabs.List`
- `Tabs.Tab`
- `Tabs.Indicator`
- `Tabs.Panel`

```tsx
<Tabs.Root>
  <Tabs.List />
  <Tabs.Tab />
  <Tabs.Indicator />
  <Tabs.Panel />
</Tabs.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `onValueChange` | 报告核心接受的值。 |
| `orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `activation` | 焦点或明确按下操作是否会激活标签页。 |
