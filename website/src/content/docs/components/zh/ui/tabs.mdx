在带标签的面板之间切换，支持自动或手动键盘激活。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TabsExample() {
	ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() {
			ui.Tabs.List(
				ui.PartProps{},
				func() {
					ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview")
					ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings")
				},
			)
			ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content")
			ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content")
		},
	)
}
```

## 结构

- `ui.Tabs.Root`
- `ui.Tabs.List`
- `ui.Tabs.Tab`
- `ui.Tabs.Indicator`
- `ui.Tabs.Panel`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `Orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `Activation` | 焦点或明确按下操作是否会激活标签页。 |
