管理一个或多个可展开区域及其键盘焦点。

## 导入

从 `@quickgui/ui` 导入 `Accordion`。

```tsx
import { Accordion } from "@quickgui/ui/disclosure";
```

## 用法

```tsx
<Accordion.Root value={open()} onValueChange={setOpen}>
  <Accordion.Item value="shipping">
    <Accordion.Header>
      <Accordion.Trigger><Text>Shipping</Text></Accordion.Trigger>
    </Accordion.Header>
    <Accordion.Panel><Text>Ships in 2–3 days.</Text></Accordion.Panel>
  </Accordion.Item>
</Accordion.Root>
```

## 结构

- `Accordion.Root`
- `Accordion.Item`
- `Accordion.Header`
- `Accordion.Trigger`
- `Accordion.Panel`

```tsx
<Accordion.Root>
  <Accordion.Item />
  <Accordion.Header />
  <Accordion.Trigger />
  <Accordion.Panel />
</Accordion.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `onValueChange` | 报告核心接受的值。 |
| `multiple` | 允许选择或打开多个值。 |
| `keepMounted` | 保持非活动内容已挂载，但禁用其显示。 |
