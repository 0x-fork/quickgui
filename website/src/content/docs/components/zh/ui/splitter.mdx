创建可调整大小的面板，分隔手柄支持指针和键盘操作。

## 导入

从 `@quickgui/ui` 导入 `Splitter`。

```tsx
import { Splitter } from "@quickgui/ui/range";
```

## 用法

```tsx
<Splitter.Root value={sizes()} panes={[{ min: 180 }, { min: 280 }]} onSizesChange={setSizes}>
  <Splitter.Pane itemIndex={0}><Sidebar /></Splitter.Pane>
  <Splitter.Handle itemIndex={0} />
  <Splitter.Pane itemIndex={1}><Editor /></Splitter.Pane>
</Splitter.Root>
```

## 结构

- `Splitter.Root`
- `Splitter.Pane`
- `Splitter.Handle`

```tsx
<Splitter.Root>
  <Splitter.Pane />
  <Splitter.Handle />
</Splitter.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `panes` | 每个面板的最小尺寸和折叠声明。 |
| `orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `onSizesChange` | 在核心调整大小后报告完整的面板尺寸集合。 |
