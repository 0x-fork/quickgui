以保留模式渲染 Markdown，并支持用于流式内容的增量模式。

## 导入

从 `@quickgui/ui` 导入 `Markdown`。

```tsx
import { Markdown } from "@quickgui/ui";
```

## 用法

```tsx
<Markdown content={message()} streaming={isStreaming()} />
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `content` | 用于排版和绘制的 Markdown 源文本。 |
| `source` | 组件所需的文件系统路径、数据 URL、SVG 文档或着色器源码。 |
| `streaming` | 对追加内容使用增量 Markdown 协调。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
