以保留模式渲染 Markdown，并支持用于流式内容的增量模式。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func MarkdownExample(source func() string, streaming func() bool) {
	ui.Markdown(ui.Value(source), ui.Streaming(streaming), ui.Style{Width: "100%"})
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 用于排版和绘制的 Markdown 源文本。 |
| `Streaming` | 对追加内容使用增量 Markdown 协调。 |
| `ui.Style{}` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
