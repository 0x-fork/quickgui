单选或多选选择器，选项界面显示在原生浮窗中。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SelectExample() {
	value, setValue := ui.CreateSignal[*string](nil)
	ui.Select.Root(
		ui.SelectRootProps{
			PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
				return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
			}},
			Value:         value,
			OnValueChange: func(next *string, _ *native.Event) { setValue(next) },
		},
		func() { ui.Select.Value(ui.PartProps{}); ui.Select.Icon(ui.PartProps{}, "▾") },
	)
}
```

- `ui.Select.Trigger`

- `ui.Select.Group`

- `ui.Select.Separator`
- `ui.Select.ScrollUpArrow`
- `ui.Select.ScrollDownArrow`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Items` | 用于选项或键盘导航的有限声明模型。 |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `DefaultValue` | 组件自行管理状态时的初始值。 |
| `Multiple` | 允许选择或打开多个值。 |
| `OnValueChange` | 报告核心接受的值。 |
