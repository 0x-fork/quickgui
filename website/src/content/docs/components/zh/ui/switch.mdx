开关控件，根节点作为轨道，滑块可独立设置样式。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwitchExample() {
	on, setOn := ui.CreateSignal(false)
	ui.Switch.Root(
		ui.SwitchProps{
			Checked:         on,
			OnCheckedChange: func(next bool, _ *native.Event) { setOn(next) },
		},
		func() { ui.Switch.Thumb(ui.PartProps{}); ui.Text("Notifications") },
	)
}
```

## 结构

- `ui.Switch.Root`
- `ui.Switch.Thumb`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Checked` | 受控的选中状态。 |
| `DefaultChecked` | 组件自行管理状态时的初始选中状态。 |
| `OnCheckedChange` | 报告核心接受的选中状态。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
