显示定时堆叠通知，支持操作、关闭和滑动手势。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ToastExample() {
	ui.Toast.Provider(
		ui.ToastProviderProps{Timeout: 5000, Limit: 3},
		func() {
			manager := ui.UseToastManager()
			ui.Button(
				ui.OnClick(func() { manager.Add(ui.ToastRequest{Title: "Saved", Type: "success"}) }),
				"Save",
			)
			ui.Toast.Viewport(
				ui.ToastViewportProps{},
				func() {
					ui.For(
						manager.Toasts,
						func(toast ui.ToastDeclaration, _ func() int) {
							ui.Toast.Root(
								ui.ToastPartProps{ToastID: toast.ID},
								func() {
									ui.Toast.Title(
										ui.ToastPartProps{ToastID: toast.ID},
										toast.Title,
									)
									ui.Toast.Close(ui.ToastPartProps{ToastID: toast.ID}, "Dismiss")
								},
							)
						},
						func(toast ui.ToastDeclaration) any { return toast.ID },
						nil,
					)
				},
			)
		},
	)
}
```

## 结构

- `ui.Toast.Provider`
- `ui.Toast.Portal`
- `ui.Toast.Viewport`
- `ui.Toast.Positioner`
- `ui.Toast.Root`
- `ui.Toast.Content`
- `ui.Toast.Title`
- `ui.Toast.Description`
- `ui.Toast.Action`
- `ui.Toast.Close`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Toasts` | 视口渲染的完整 Toast 队列声明。 |
| `ToastID` | 与一个已渲染 Toast 关联的稳定队列标识符。 |
| `Timeout` | 继承的自动关闭时长或预热 Provider 的超时时间。 |
| `SwipeDirection` | 滑动关闭或移动界面时朝向的边缘。 |
| `OnDismiss` | 报告核心关闭的 Toast 标识符。 |
