显示定时堆叠通知，支持操作、关闭和滑动手势。

## 导入

从 `@quickgui/ui` 导入 `Toast`。

```tsx
import { Toast } from "@quickgui/ui/toast";
```

## 用法

```tsx
const toast = useToastManager();

toast.add({ id: "saved", title: "Saved", description: "Your changes are live." });

<Toast.Provider timeout={5000} limit={3}>
  <Toast.Portal>
    <Toast.Viewport toasts={toast.toasts()} onDismiss={toast.dismiss}>
      <For each={toast.toasts()}>{(item) =>
        <Toast.Root toastId={item.id}>
          <Toast.Content><Toast.Title /><Toast.Description /></Toast.Content>
          <Toast.Close><Text>Close</Text></Toast.Close>
        </Toast.Root>
      }</For>
    </Toast.Viewport>
  </Toast.Portal>
</Toast.Provider>
```

## 结构

- `Toast.Provider`
- `Toast.Portal`
- `Toast.Viewport`
- `Toast.Positioner`
- `Toast.Root`
- `Toast.Content`
- `Toast.Title`
- `Toast.Description`
- `Toast.Action`
- `Toast.Close`

```tsx
<Toast.Root>
  <Toast.Provider />
  <Toast.Portal />
  <Toast.Viewport />
  <Toast.Positioner />
  <Toast.Content />
  <Toast.Title />
  <Toast.Description />
  <Toast.Action />
  <Toast.Close />
</Toast.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `toasts` | 视口渲染的完整 Toast 队列声明。 |
| `toastId` | 与一个已渲染 Toast 关联的稳定队列标识符。 |
| `timeout` | 继承的自动关闭时长或预热 Provider 的超时时间。 |
| `swipeDirection` | 滑动关闭或移动界面时朝向的边缘。 |
| `onDismiss` | 报告核心关闭的 Toast 标识符。 |
