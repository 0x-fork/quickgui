管理单选状态以及 Radio 项之间的键盘移动。

## 导入

从 `@quickgui/ui` 导入 `RadioGroup`。

```tsx
import { RadioGroup } from "@quickgui/ui/controls";
```

## 用法

```tsx
<RadioGroup.Root value={theme()} onValueChange={setTheme}>
  <Radio.Root value="light"><Radio.Indicator /><Text>Light</Text></Radio.Root>
  <Radio.Root value="dark"><Radio.Indicator /><Text>Dark</Text></Radio.Root>
</RadioGroup.Root>
```

## 结构

- `RadioGroup.Root`

```tsx
<RadioGroup.Root>{/* content */}</RadioGroup.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `onValueChange` | 报告核心接受的值。 |
| `readOnly` | 阻止值变化，但仍允许控件获得焦点。 |
| `required` | 将值标记为验证和表单提交所必需。 |
