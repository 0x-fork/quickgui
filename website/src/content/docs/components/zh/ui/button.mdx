可访问的按压目标，可自行设置样式并组合文本或其他内容。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ButtonExample(save func()) {
	ui.Button(
		ui.Height(40),
		ui.PaddingLeft(16),
		ui.PaddingRight(16),
		ui.BackgroundColor("#2563eb"),
		ui.Color("white"),
		ui.BorderRadius(8),
		ui.Hover(ui.BackgroundColor("#3b82f6")),
		ui.OnClick(save),
		"Save changes",
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `WithStyle` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
| `OnClick` | 在核心完成激活判定后运行。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
