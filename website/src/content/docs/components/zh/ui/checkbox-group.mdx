管理一组有限的复选框值，并可派生出可选的父复选框状态。

## 导入

从 `@quickgui/ui` 导入 `CheckboxGroup`。

```tsx
import { CheckboxGroup } from "@quickgui/ui/controls";
```

## 用法

```tsx
<CheckboxGroup.Root
  allValues={["email", "push"]}
  value={channels()}
  onValueChange={setChannels}
>
  <Checkbox.Root parent><Text>All notifications</Text></Checkbox.Root>
  <Checkbox.Root value="email"><Text>Email</Text></Checkbox.Root>
  <Checkbox.Root value="push"><Text>Push</Text></Checkbox.Root>
</CheckboxGroup.Root>
```

## 结构

- `CheckboxGroup.Root`

```tsx
<CheckboxGroup.Root>{/* content */}</CheckboxGroup.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `allValues` | 用于派生父复选框状态的完整有序值集合。 |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `onValueChange` | 报告核心接受的值。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
