可通过键盘编辑的分段日期字段，日期部分会适配区域设置。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func DateFieldExample() {
	value, setValue := ui.CreateSignal[*string](nil)
	ui.DateField.Root(
		ui.DateFieldRootProps{
			Value:         value,
			Format:        "ymd",
			Min:           "2026-01-01",
			Max:           "2026-12-31",
			OnValueChange: func(next *string, _ *native.Event) { setValue(next) },
		},
		func() {
			for _, segment := range []string{"year", "month", "day"} {
				ui.DateField.Segment(ui.DateFieldSegmentProps{Segment: segment})
			}
		},
	)
}
```

## 结构

- `ui.DateField.Root`
- `ui.DateField.Segment`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `OnValueChange` | 报告核心接受的值。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
