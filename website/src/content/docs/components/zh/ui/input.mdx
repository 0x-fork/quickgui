由核心管理的受控文本编辑器，支持原生键盘和文本服务。

## 导入

从 `@quickgui/ui` 导入 `Input`。

```tsx
import { Input } from "@quickgui/ui";
```

## 用法

```tsx
<Input
  value={name()}
  placeholder="Your name"
  onInput={(event) => setName(event.value ?? "")}
/>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `placeholder` | 可编辑值为空时显示的文本。 |
| `multiline` | 启用多行文本编辑。 |
| `onInput` | 报告原生编辑输入。 |
| `onChange` | 报告已提交的原生值变化。 |
