可按压的控件，会保留开启或关闭的按下状态。

## 导入

从 `@quickgui/ui` 导入 `Toggle`。

```tsx
import { Toggle } from "@quickgui/ui/controls";
```

## 用法

```tsx
<Toggle.Root pressed={bold()} onPressedChange={setBold}>
  <Text>B</Text>
  <Toggle.Indicator />
</Toggle.Root>
```

## 结构

- `Toggle.Root`
- `Toggle.Indicator`

```tsx
<Toggle.Root>
  <Toggle.Indicator />
</Toggle.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `pressed` | 受控的按下状态。 |
| `defaultPressed` | 组件自行管理状态时的初始按下状态。 |
| `onPressedChange` | 报告核心接受的按下状态。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
