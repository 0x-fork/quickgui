可按压的控件，会保留开启或关闭的按下状态。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func ToggleExample() {
	on, setOn := ui.CreateSignal(false)
	ui.Toggle.Root(
		ui.ToggleProps{
			Pressed:         on,
			OnPressedChange: func(next bool, _ *native.Event) { setOn(next) },
		},
		func() { ui.Toggle.Indicator(ui.PartProps{}); ui.Text("Notifications") },
	)
}
```

## 结构

- `ui.Toggle.Root`
- `ui.Toggle.Indicator`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Pressed` | 受控的按下状态。 |
| `DefaultPressed` | 组件自行管理状态时的初始按下状态。 |
| `OnPressedChange` | 报告核心接受的按下状态。 |
| `Disabled` | 禁止交互，并暴露禁用状态。 |
