可通过键盘编辑的分段时间字段，包含时、分、秒和上下午部分。

## 导入

从 `@quickgui/ui` 导入 `TimeField`。

```tsx
import { TimeField } from "@quickgui/ui/date-time";
```

## 用法

```tsx
<TimeField.Root value={time()} showSeconds onValueChange={setTime}>
  <TimeField.Segment segment="hour" />
  <Text>:</Text>
  <TimeField.Segment segment="minute" />
  <Text>:</Text>
  <TimeField.Segment segment="second" />
</TimeField.Root>
```

## 结构

- `TimeField.Root`
- `TimeField.Segment`

```tsx
<TimeField.Root>
  <TimeField.Segment />
</TimeField.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `hour12` | 添加上午/下午分段，并使用 12 小时制。 |
| `showSeconds` | 挂载秒数分段。 |
| `onValueChange` | 报告核心接受的值。 |
