确定或不确定的原生 SwiftUI 进度指示器。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `ProgressView`。

```tsx
import { Host, ProgressView } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents={{ vertical: true }} style={{ width: 320 }}>
  <ProgressView
    value={completed()}
    total={100}
    label="Exporting"
    currentValueLabel={String(completed()) + "%"}
  />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `total` | SwiftUI 确定进度的分母。 |
| `label` | 原生 SwiftUI 控件的可见标签。 |
| `currentValueLabel` | 当前原生进度或仪表值的易读标签。 |
