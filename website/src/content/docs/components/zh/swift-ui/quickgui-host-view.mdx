在 SwiftUI 层级中反向托管一棵普通的 QuickGUI 子树。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `QuickGUIHostView`。

```tsx
import { Host, QuickGUIHostView } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents>
  <QuickGUIHostView width={280} height={120}>
    <View style={{ width: 280, height: 120, padding: 16 }}>
      <Text>Ordinary QuickGUI content</Text>
    </View>
  </QuickGUIHostView>
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `width` | 声明的逻辑宽度。 |
| `height` | 声明的逻辑高度。 |
| `matchContents` | 使用托管子树的固有宽度、高度或两者。 |
| `background` | 反向托管 QuickGUI WGPU 表面的清除颜色。 |
| `children` | 挂载在组件内部的内容。 |
