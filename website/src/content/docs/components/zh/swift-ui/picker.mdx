受控的 SwiftUI 选择器，支持菜单、分段、单选组和内联样式。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `Picker`。

```tsx
import { Host, Picker } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents>
  <Picker
    label="Theme"
    selection={theme()}
    options={[
      { value: "system", label: "System" },
      { value: "light", label: "Light" },
      { value: "dark", label: "Dark" },
    ]}
    style="menu"
    onSelectionChange={setTheme}
  />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `selection` | 表格、原生选择器或颜色控件的受控选中值。 |
| `options` | 有序的原生选择器选项。 |
| `label` | 原生 SwiftUI 控件的可见标签。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `onSelectionChange` | 报告选中的原生选择器选项或颜色。 |
