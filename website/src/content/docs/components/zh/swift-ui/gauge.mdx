原生 SwiftUI 仪表，支持线性和圆形附属样式。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `Gauge`。

```tsx
import { Host, Gauge } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents>
  <Gauge
    value={storageUsed()}
    min={0}
    max={100}
    label="Storage"
    currentValueLabel={String(storageUsed()) + "%"}
    style="accessoryCircularCapacity"
  />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `label` | 原生 SwiftUI 控件的可见标签。 |
| `currentValueLabel` | 当前原生进度或仪表值的易读标签。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
