受控的原生 SwiftUI 文本字段，提供编辑和提交回调。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `TextField`。

```tsx
import { Host, TextField } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents={{ vertical: true }} style={{ width: 280 }}>
  <TextField
    value={name()}
    placeholder="Name"
    onValueChange={setName}
    onSubmit={save}
  />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `placeholder` | 可编辑值为空时显示的文本。 |
| `onValueChange` | 报告核心接受的值。 |
| `onSubmit` | 原生字段提交当前值时运行。 |
