基于 NSHostingView 的叶节点，用于在 QuickGUI 中挂载一棵 SwiftUI 组件树。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `Host`。

```tsx
import { Host } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents>
  <Button label="Continue" />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `matchContents` | 使用托管子树的固有宽度、高度或两者。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
