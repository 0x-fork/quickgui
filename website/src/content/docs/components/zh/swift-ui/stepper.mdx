受控的原生数字步进器，数值范围可限制。

## 导入

从 `@quickgui/ui/swift-ui` 导入 `Stepper`。

```tsx
import { Host, Stepper } from "@quickgui/ui/swift-ui";
```

## 用法

```tsx
<Host matchContents>
  <Stepper
    value={copies()}
    min={1}
    max={20}
    label={"Copies: " + copies()}
    onValueChange={setCopies}
  />
</Host>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `step` | 键盘、指针或原生控件输入使用的步长。 |
| `label` | 原生 SwiftUI 控件的可见标签。 |
| `onValueChange` | 报告核心接受的值。 |
