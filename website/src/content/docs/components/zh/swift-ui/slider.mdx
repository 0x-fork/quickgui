受控的原生滑块，支持连续值或步进值。

## 导入

从 `github.com/egoist/quickgui/go/ui` 导入 `ui`。

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func SwiftUiSliderExample() {
	value, setValue := ui.CreateSignal(40.0)
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Slider(ui.SwiftUISliderProps{
				Value:         value,
				Min:           0,
				Max:           100,
				Step:          1,
				Label:         "Value",
				OnValueChange: func(next float64, _ *native.Event) { setValue(next) },
			})
		},
	)
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Value` | 受控值，具体类型取决于该组件的约定。 |
| `Min` | 可接受的最小值。 |
| `Max` | 可接受的最大值。 |
| `Step` | 键盘、指针或原生控件输入使用的步长。 |
| `Label` | 原生 SwiftUI 控件的可见标签。 |
| `OnValueChange` | 报告核心接受的值。 |
