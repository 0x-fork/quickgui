表示确定或不确定的任务进度，可组合标签和轨道。

## 导入

从 `@quickgui/solid` 导入 `Progress`。

```tsx
import { Progress } from "@quickgui/solid";
```

## 用法

```tsx
<Progress.Root value={completed()} max={total()} format="fraction">
  <Progress.Label><Text>Exporting</Text></Progress.Label>
  <Progress.Track><Progress.Indicator /></Progress.Track>
  <Progress.Value />
</Progress.Root>
```

## 结构

- `Progress.Root`
- `Progress.Track`
- `Progress.Indicator`
- `Progress.Label`
- `Progress.Value`

```tsx
<Progress.Root>
  <Progress.Track />
  <Progress.Indicator />
  <Progress.Label />
  <Progress.Value />
</Progress.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `max` | 可接受的最大值。 |
| `indeterminate` | 表示完成量未知的进度。 |
| `valueText` | 辅助技术优先使用的易读值。 |
| `onStatusChange` | 报告派生状态、格式化值和完成比例。 |
