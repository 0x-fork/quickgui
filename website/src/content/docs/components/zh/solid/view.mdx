用于布局、绘制、指针输入和无障碍支持的通用保留式容器。

## 导入

从 `@quickgui/solid` 导入 `View`。

```tsx
import { View } from "@quickgui/solid";
```

## 用法

```tsx
<View
  style={{
    display: "flex",
    flexDirection: "column",
    gap: 12,
    padding: 16,
  }}
>
  <Text>Content</Text>
</View>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
| `children` | 挂载在组件内部的内容。 |
| `onClick` | 在核心完成激活判定后运行。 |
| `ref` | 接收保留式原生节点。 |
