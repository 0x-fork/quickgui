开关控件，根节点作为轨道，滑块可独立设置样式。

## 导入

从 `@quickgui/solid` 导入 `Switch`。

```tsx
import { Switch } from "@quickgui/solid";
```

## 用法

```tsx
<Switch.Root checked={enabled()} onCheckedChange={setEnabled}>
  <Switch.Thumb />
</Switch.Root>
```

## 结构

- `Switch.Root`
- `Switch.Thumb`

```tsx
<Switch.Root>
  <Switch.Thumb />
</Switch.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `checked` | 受控的选中状态。 |
| `defaultChecked` | 组件自行管理状态时的初始选中状态。 |
| `onCheckedChange` | 报告核心接受的选中状态。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
