配合移动式键盘焦点管理单选或多选的按下值。

## 导入

从 `@quickgui/solid` 导入 `ToggleGroup`。

```tsx
import { ToggleGroup } from "@quickgui/solid";
```

## 用法

```tsx
<ToggleGroup.Root
  items={[{ value: "left" }, { value: "center" }, { value: "right" }]}
  value={alignment()}
  variant="single"
  onValueChange={setAlignment}
>
  <ToggleGroup.Item partValue="left"><Text>Left</Text></ToggleGroup.Item>
  <ToggleGroup.Item partValue="center"><Text>Center</Text></ToggleGroup.Item>
  <ToggleGroup.Item partValue="right"><Text>Right</Text></ToggleGroup.Item>
</ToggleGroup.Root>
```

## 结构

- `ToggleGroup.Root`
- `ToggleGroup.Item`

```tsx
<ToggleGroup.Root>
  <ToggleGroup.Item />
</ToggleGroup.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `items` | 用于选项或键盘导航的有限声明模型。 |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `defaultValue` | 组件自行管理状态时的初始值。 |
| `variant` | 选择单选或多选策略。 |
| `onValueChange` | 报告核心接受的值。 |
