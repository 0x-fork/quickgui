将 QuickGUI 核心路由投影到 Solid，支持嵌套布局和容量受限的内存历史。

## 导入

从 `@quickgui/solid` 导入 `Router`。

```tsx
import { Router } from "@quickgui/solid";
```

## 用法

```tsx
<Router initialPath="/">
  <Route path="/" component={Shell}>
    <Route path="/" component={Home} />
    <Route path="/projects/:id" component={Project} />
  </Route>
</Router>
```

## 结构

- `Router`
- `Route`
- `Link`
- `Outlet`

```tsx
<Router>
  <Route path="/" component={AppShell}>
    <Route path="/projects/:id" component={Project} />
  </Route>
  <Link href="/projects/quickgui">Open project</Link>
  <Outlet />
</Router>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `initialPath` | 有界内存历史的初始目标地址。 |
| `fallback` | 没有路由匹配时渲染的内容。 |
| `path` | 绝对路由模式或相对于父路由的模式。 |
| `component` | 路由匹配时渲染的组件。 |
| `href` | QuickGUI 路由器解析的目标地址。 |
