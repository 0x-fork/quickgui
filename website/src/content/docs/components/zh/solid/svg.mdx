无需加载外部 SVG 资源即可渲染完整的内联 SVG 文档。

## 导入

从 `@quickgui/solid` 导入 `Svg`。

```tsx
import { Svg } from "@quickgui/solid";
```

## 用法

```tsx
<Svg source={iconSvg} style={{ width: 20, height: 20 }} />
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `source` | 组件所需的文件系统路径、数据 URL、SVG 文档或着色器源码。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
