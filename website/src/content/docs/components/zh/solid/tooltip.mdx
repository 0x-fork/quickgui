在核心精确控制的延迟后显示辅助信息，并支持 Provider 级预热。

## 导入

从 `@quickgui/solid` 导入 `Tooltip`。

```tsx
import { Tooltip } from "@quickgui/solid";
```

## 用法

```tsx
<Tooltip.Provider delay={600} closeDelay={100}>
  <Tooltip.Root>
    <Tooltip.Trigger><Text>?</Text></Tooltip.Trigger>
    <Tooltip.Portal>
      <Tooltip.Positioner side="top"><Tooltip.Popup><Text>Keyboard shortcuts</Text></Tooltip.Popup></Tooltip.Positioner>
    </Tooltip.Portal>
  </Tooltip.Root>
</Tooltip.Provider>
```

## 结构

- `Tooltip.Provider`
- `Tooltip.Root`
- `Tooltip.Trigger`
- `Tooltip.Portal`
- `Tooltip.Positioner`
- `Tooltip.Popup`
- `Tooltip.Arrow`

```tsx
<Tooltip.Root>
  <Tooltip.Provider />
  <Tooltip.Trigger />
  <Tooltip.Portal />
  <Tooltip.Positioner />
  <Tooltip.Popup />
  <Tooltip.Arrow />
</Tooltip.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `open` | 受控的打开状态。 |
| `defaultOpen` | 组件自行管理打开状态时的初始状态。 |
| `delay` | 打开前由核心管理的延迟（毫秒）。 |
| `closeDelay` | 关闭前由核心管理的延迟（毫秒）。 |
| `side` | 碰撞处理前的首选放置方向。 |
| `hoverable` | 允许指针移入 Tooltip 而不会将其关闭。 |
