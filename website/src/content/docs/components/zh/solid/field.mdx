将控件与标签、说明、验证状态和错误信息关联起来。

## 导入

从 `@quickgui/solid` 导入 `Field`。

```tsx
import { Field } from "@quickgui/solid";
```

## 用法

```tsx
<Field.Root required invalid={name().length === 0} validationMessage="Enter a name">
  <Field.Label><Text>Name</Text></Field.Label>
  <Field.Control value={name()} onInput={(event) => setName(event.value ?? "")} />
  <Field.Description><Text>Shown on your profile.</Text></Field.Description>
  <Field.Error><Text>Enter a name.</Text></Field.Error>
</Field.Root>
```

## 结构

- `Field.Root`
- `Field.Item`
- `Field.Label`
- `Field.Control`
- `Field.Validity`
- `Field.Description`
- `Field.Error`

```tsx
<Field.Root>
  <Field.Item />
  <Field.Label />
  <Field.Control />
  <Field.Validity />
  <Field.Description />
  <Field.Error />
</Field.Root>
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `invalid` | 将无效状态传递给字段及其各部件。 |
| `required` | 将值标记为验证和表单提交所必需。 |
| `validationMessage` | 向错误内容和无障碍 API 暴露的有限长度消息。 |
| `validationMode` | 选择触发验证的交互边界。 |
| `onValidationChange` | 报告核心选择的验证触发条件和时机。 |
