在明确的宿主边界内组合 SwiftUI 和 QuickGUI 子树。

## 修饰器

QuickGUI 样式作用于宿主。原生控件通过 `.swift_ui_modifiers(...)` 传入核心的修饰符 JSON，通过 `.label(...)` 添加标签。

## Liquid Glass

在支持的 macOS 版本上，通过 `.swift_ui_modifiers(...)` 传入 `style: "glass"` 的 `buttonStyle` 修饰符。最终外观由系统负责；这是 SwiftUI 修饰符，而非 QuickGUI 背景样式。

## 反向托管

将原生控件放在 `swift_ui_host([])` 中。普通 QuickGUI 布局应位于宿主外，或通过明确的反向托管接口添加。

```moonbit
fn embedded_content() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_quickgui_host_view(() => {
      @ui.view([@ui.text("QuickGUI content")]).padding(16)
    })
    .width(320)
    .height(120),
  ])
}
```

通过 `swift_ui_quickgui_host_view(render, width=..., height=...)` 在 SwiftUI 内创建 QuickGUI 子树。回调在嵌入视图自己的窗口中创建节点。

## SwiftUI Popover

`swift_ui_popover([])` 在 SwiftUI 宿主内组合原生触发器和内容。使用 `swift_ui_popover_trigger([...])` 和 `swift_ui_popover_content([...])`，需要时反向托管 QuickGUI 内容。完整示例见 [SwiftUI Popover](/docs/moonbit/swift-ui/popover)。

## 生命周期

宿主在所属窗口挂载后创建嵌入视图，并在宿主移除时关闭。不要跨窗口移动已有节点。
