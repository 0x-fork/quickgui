为 MoonBit 应用打包可选更新服务。

## 配置

在 `quickgui.toml` 的 `[updates]` 中配置公钥和下载地址。TypeScript CLI 为两个前端生成 appcast 元数据和签名包。

## 应用用法

MoonBit 尚未提供专用的 updater 会话辅助接口。应用包装器需要管理服务 ABI、会话标识、`check` / `install` / `automatic` 命令和持续的 `extension-event` 订阅。普通 `@native.invoke` 不返回请求或会话 ID，因此仅调用 `start` 不构成完整集成。服务契约详见[编写扩展](/docs/moonbit/extensions)。

## 生命周期

将 updater 会话保留在应用作用域，避免关闭单个窗口时停止更新。在 UI 线程处理完成错误和状态事件。清理时发送会话的 `stop` 请求；剩余资源由提供程序关闭时释放。已接受的安装交接可以继续运行。

## 平台支持

macOS 使用 Sparkle 和签名应用归档。可移植后端支持 Windows 安装程序及 Linux AppImage。应在每个目标宿主上构建和验证；提供后端并不等于所有平台都已完成运行验收。

## 发布更新

使用 `quickgui keygen --sparkle` 创建签名密钥，将私钥保存在仓库之外。运行 `quickgui build`，然后将生成的 appcast 和签名归档发布到配置的下载地址。

## 原生产物

在 `[native].extensions` 中选择 updater 扩展的目录。CLI 读取其中的 `quickgui.extension.json` 并打包后端；MoonBit 不分析 Go 导入。macOS 使用 Sparkle，其他平台使用兼容的原生更新服务。封装通过[编写扩展](/docs/moonbit/extensions)文档中的同一 ABI 调用。
