MoonBit 应用包含模块、可执行包和 QuickGUI 配置。Bun 运行开发工具，打包后的应用是原生可执行文件。

## 生成的文件

```text
my-app/
  main/
    main.mbt
    moon.pkg
  moon.mod
  quickgui.toml
  package.json
```

`moon.mod` 声明应用模块与 SDK 依赖。`main/moon.pkg` 导入可执行程序使用的包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/native",
  "egoist/quickgui/reactive",
}

pkgtype(kind: "executable")
```

## 本地开发

SDK 发布前，在应用与 QuickGUI 源码仓库的共同父目录创建 `moon.work`。路径相对于工作区：

```toml
members = ["quickgui/moonbit", "my-app"]
```

`quickgui` 目录中运行 `bun packages/cli/src/cli.ts dev --project ../my-app`，无需安装已发布的 CLI 包。

## 配置

```toml
name = "My App"
identifier = "com.example.myapp"
frontend = "moonbit"
entry = "main"

[native]
extensions = []
```

`frontend` 选择 MoonBit，省略时默认 Go。`entry` 指定可执行包目录。将包含 `quickgui.extension.json` 的扩展目录放入 `native.extensions`。`quickgui build` 打包可执行文件、选中的原生库、字体和配置的资源。`.quickgui` 保存开发产物和缓存，不应提交。

## 包

| 包 | 用途 |
| --- | --- |
| `egoist/quickgui/ui` | 链式元素、样式、绑定、列表、表格与分隔条。 |
| `egoist/quickgui/reactive` | 信号、派生值、副作用、批处理和清理。 |
| `egoist/quickgui/native` | 窗口、事件、对话框、菜单、服务与扩展。 |
| `egoist/quickgui/protocol` | 核心属性常量和变更值类型。 |
