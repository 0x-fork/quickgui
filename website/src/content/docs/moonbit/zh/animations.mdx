过渡为已有元素的原生样式变化插值。声明目标与时间后，由核心推进帧，并在完成后停止请求帧。

## 悬停过渡

```moonbit
fn animated_button() -> @ui.Element {
  @ui.button("Hover me")
  .padding(12)
  .bg(@ui.rgb8(51, 65, 85))
  .text_color(@ui.rgb8(255, 255, 255))
  .opacity(0.8)
  .transition_duration(160)
  .transition_property("background-color,opacity")
  .transition_easing("ease-out")
  .hover(s => s.bg(@ui.rgb8(37, 99, 235)).opacity(1))
}
```

将时间配置放在基础元素上，使进入和离开状态都产生过渡。信号驱动的 `bind_style` 目标也使用同一过渡。中途改变目标时，从当前可见值继续。

## 状态驱动的动画

在链式目标样式中读取信号。视图编译器将目标值绑定到保留的元素，原生核心负责插值。值变化时保持同一个节点挂载。

```moonbit
fn animated_state() -> @ui.Element {
  let (dimmed, set_dimmed) = @ui.create_signal(false)
  @ui.button("Toggle opacity")
  .on_click(() => set_dimmed(!dimmed()))
  .opacity(if dimmed() { 0.4 } else { 1.0 })
  .transition_property("opacity")
  .transition_duration(160)
}
```

## 时长与帧率

时长以毫秒为单位，限制在 0–10 秒。`.transition_easing(...)` 支持 `linear`、`ease`、`ease-in`、`ease-out` 和 `ease-in-out`。可用 `.transition_max_fps(30)` 限制帧率，省略则跟随显示节奏。每个元素的选定属性共用一个时长、缓动和帧率上限。不支持延迟和自定义三次贝塞尔曲线。

## 支持的属性

支持 `background-color`、`border-color`、`border-width`、`border-radius`、`color`、`opacity`、`box-shadow` 和 `transform`。`all` 选择这些绘制属性。宽、高、内边距、渐变和其他布局变化不进行插值。滑动滑块时使用变换，而不是动画修改布局位置。

## 挂载与减少动态效果

初始样式直接应用。目标变化要产生动画，元素必须保持挂载；`child_if` 会立即移除分支，不会等待退出淡出。零透明度仍占据布局并接收输入。过渡遵循系统“减少动态效果”设置，隐藏或被遮挡的窗口会暂停局部过渡。

## 动态图像

动画图片可使用 `@ui.image(path)` 加载 GIF 或 WebP。原生解码器保留帧和重复策略，无需信号定时器。
