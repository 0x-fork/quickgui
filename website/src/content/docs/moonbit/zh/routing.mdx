路由根据应用当前路径选择组件并维护导航历史。路由内容在当前窗口中以原生 QuickGUI 节点渲染。

## 嵌套布局

用 `@ui.route` 声明路由，以 `@ui.layout` 共享外围内容，并在匹配子路由的位置调用它的 `outlet()` 回调。通过 `router.outlet()` 挂载路由。

```moonbit
fn routing_example() -> @ui.Element {
  let router = @ui.router([
    @ui.layout(
      (router, outlet) => {
        @ui.div([
          router.link("/", "Home"),
          router.link("/settings", "Settings"),
          outlet(),
        ]).flex_col()
      },
      [
        @ui.route("/", _ => @ui.text("Home")),
        @ui.route("/settings", _ => @ui.text("Settings")),
      ],
    ),
  ])
  router.outlet()
}
```

## 导航

使用 `router.link(path, label)` 声明导航链接。`router.navigate(path)` 添加历史记录，传入 `replace=true` 则替换当前记录。`router.go(-1)` 后退，`router.go(1)` 前进。

## 保留的路由出口

路由出口按匹配的路由身份保留节点。在同级路由之间导航时，公共布局及其状态保持挂载。在绑定中读取 `router.state()` 获取当前位置和匹配参数；用 `router.is_active(path)` 检查导航目标。
