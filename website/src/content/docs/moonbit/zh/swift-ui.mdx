从 MoonBit 托管原生 macOS 控件。

## 托管控件

在 `@ui.swift_ui_host([])` 下创建 SwiftUI 控件，仅支持 macOS。侧栏列出了全部受支持的 SwiftUI 控件。

```moonbit
fn native_toggle() -> @ui.Element {
  let (enabled, set_enabled) = @reactive.create_signal(false)
  @ui.swift_ui_host([
    @ui.swift_ui_toggle()
    .checked(enabled())
    .on_bool_input(value => set_enabled(value))
    .label("Notifications"),
  ])
}
```

## 受控值

通过 `.bind_value(...)`、`.bind_checked(...)` 或 `.bind_number(...)` 绑定信号，使用 `.on_input(...)`、`.on_bool_input(...)` 或 `.on_number_input(...)` 更新值。

## 原生修饰符

QuickGUI 样式作用于宿主。原生控件通过 `.swift_ui_modifiers(...)` 传入核心的修饰符 JSON，通过 `.label(...)` 添加标签。
