从 MoonBit 托管原生 macOS 控件。

## Host

在 `@ui.swift_ui_host([])` 下创建 SwiftUI 控件，仅支持 macOS。侧栏列出了全部受支持的 SwiftUI 控件。

```moonbit
fn native_toggle() -> @ui.Element {
  let (enabled, set_enabled) = @ui.create_signal(false)
  @ui.swift_ui_host([
    @ui.swift_ui_toggle()
    .checked(enabled())
    .on_bool_input(value => set_enabled(value))
    .label("Notifications"),
  ])
}
```

## 原生控件

SwiftUI 系列包括按钮、滑块、开关、进度视图、步进器、普通和安全输入、选择器、日期和颜色选择器以及仪表。各控件的属性和事件见侧栏参考。

## 受控值

通过 `.bind_value(...)`、`.bind_checked(...)` 或 `.bind_number(...)` 绑定信号，使用 `.on_input(...)`、`.on_bool_input(...)` 或 `.on_number_input(...)` 更新值。

## 尺寸

在宿主上设置 `.swift_ui_match_contents_horizontal(true)` 和 `.swift_ui_match_contents_vertical(true)` 可按内容确定尺寸。通过 `.width(...)` 和 `.height(...)` 限制宿主大小。QuickGUI 样式作用于宿主边界，原生修饰符作用于内部 SwiftUI 控件。

## 平台支持

SwiftUI 托管需要 macOS 和宿主库中的原生桥接。外观由系统版本决定。原生样式和反向托管详见[修饰符与托管](/docs/moonbit/swift-ui-hosting)。
