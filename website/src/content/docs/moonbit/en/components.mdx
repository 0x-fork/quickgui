MoonBit provides the same native component families as Go, using child lists and fluent styles, properties, and event handlers. The sidebar includes the full component reference and macOS SwiftUI hosts.

## Defining components

A MoonBit component is a function returning `@ui.Element`. Compose it in a child list. Use plain typed parameters and pass signal reads directly. The QuickGUI compiler preserves live expressions through component calls, including imported workspace components. Components construct once and their native bindings track the props they read; no annotation or special prop type is needed.

```moonbit
fn counter_label(count : Int) -> @ui.Element {
  @ui.text("Count: \{count}").font_size(20)
}

fn component_composition() -> @ui.Element {
  let (count, set_count) = @ui.create_signal(0)
  @ui.div([
    counter_label(count()),
    @ui.button("Increment").on_click(() => set_count(count() + 1)),
  ]).flex_col()
}
```

Reusable containers can accept an array of children and spread them after their own heading. The nested native expressions still create independent bindings. The title parameter accepts either a static string or a live expression such as `title()`. Creating a local copy inside the component intentionally captures a setup snapshot.

```moonbit
fn card_section(title : String, children : Array[@ui.Element]) -> @ui.Element {
  @ui.div([@ui.text(title).font_weight(600), ..children])
  .flex_col()
  .gap(12)
  .padding(20)
}

fn card_composition() -> @ui.Element {
  let (count, set_count) = @ui.create_signal(0)
  card_section("Counter", [
    @ui.text("Count: \{count()}"),
    @ui.button("Increment").on_click(() => set_count(count() + 1)),
  ])
}
```

## Primitives

| Constructor | Content |
| --- | --- |
| `div([...])` | Container accepting only a child list. Apply styles and handlers with fluent methods. |
| `text(value)` | Static or reactive text. |
| `button(content)` | A button with native input behavior. |
| `input()` | Text input with value and event bindings. |
| `image(source)` / `svg(source)` | Images or tinted SVG masks. |
| `markdown(source)` | Native Markdown content. |

## Compound components

Create a root such as `checkbox([])`, `tabs([])` or `dialog([])`, then create related parts with `root.slot(@ui.Indicator)` or `root.slot(@ui.Panel, value="settings")`. Parts share the root scope automatically. Descendants of an accordion item also inherit its value and index. Set initial state with `.checked(false)` or `.active_value("overview")`; use `.bind_checked(...)` or `.bind_active_value(...)` and a change callback for controlled state. Every builder returns an `Element`. The raw `.part(...)` API remains available for extensions.

## Controlled state

Read signal getters in `.checked(checked())` or `.active_value(value())`, and write changes through the corresponding callbacks. Literals initialize component-owned state. Explicit `bind_*` methods remain available when composing bindings manually.

```moonbit
fn notifications() -> @ui.Element {
  let (checked, set_checked) = @ui.create_signal(false)
  let box = @ui.checkbox([])
    .checked(checked())
    .on_checked_change(value => set_checked(value))
  box.children([box.slot(@ui.Indicator)]).width(20).height(20)
}
```

Every native control has a dedicated page in the Components sidebar. For complete workflows, see [Forms & Input](/docs/moonbit/forms-and-input) and [Overlays & Dialogs](/docs/moonbit/overlays-and-dialogs).

### Tables and visible rows

`table([]).columns(columns).row_count(rows).row_height(height)` binds column definitions and the full row count. Add `table_row([]).row_index(index)` and `table_cell([]).column(column_id)` parts. The core handles layout, scrolling, keyboard selection, and accessibility. This small table mounts all three rows:

```moonbit
fn small_table() -> @ui.Element {
  let names = ["Ada", "Grace", "Linus"]
  @ui.table([])
  .columns([{ "id": "name", "track": "1fr" }])
  .row_count(names.length())
  .row_height(32)
  .height(160)
  .children(
    names.mapi((index, name) => {
      @ui.table_row([])
      .row_index(index)
      .children([@ui.table_cell([]).column("name").children([@ui.text(name)])])
    }),
  )
}
```

For large data, listen to `.on_change(...)` and retain its `visibleRange` field when present. Pass that field to `@ui.visible_range(range, count)` and mount only `[start, end)` with `children_keyed`. The end is exclusive; the initial range is bounded to 40 rows. Selection events may omit `visibleRange`, so do not reset the range on every event.

`selectedRanges` reports selection with inclusive range ends. Bind controlled selection through `@protocol.SELECTION`. See [Quick Git’s table usage](https://github.com/egoist/quickgui/tree/main/examples/quick-git-moonbit) for virtualized history and diff rows.

### Resizable panels

```moonbit
fn split_view() -> @ui.Element {
  let (width, set_width) = @ui.create_signal(260.0)
  @ui.div([
    @ui.text("Sidebar").resizable_panel(
      () => width(),
      value => set_width(value),
      minimum=180,
      maximum=500,
    ),
    @ui.div([@ui.text("Content")]).flex_1().min_width(0),
  ])
  .size_full()
  .flex_row()
}
```

The core tracks the drag and updates pane geometry. The callback reports the width for application state or persistence; it is not part of pointer tracking.

## Styling parts

Every compound part is an `Element`, so it accepts the same `.style(shared)`, layout, typography, and interaction modifiers as a primitive. Create parts with `.slot(...)` to retain their root scope and item identity. Reuse builders as described in [Styling & Layout](/docs/moonbit/styling#reusable-styles).
