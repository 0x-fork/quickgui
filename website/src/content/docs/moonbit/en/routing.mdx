The router selects components from the current application path and keeps a navigation history. Routes render native QuickGUI content in the current window.

## Routes

Build a route tree with `@ui.router([...])` and `@ui.route(path, render)`. Each render callback receives the router and returns an element. Mount `router.outlet()` where the active route belongs; `initial="/settings"` selects a starting destination.

## Nested layouts

Declare routes with `@ui.route`. Use `@ui.layout` to share surrounding content, and call its `outlet()` callback where the matched child belongs. Mount the router with `router.outlet()`.

```moonbit
fn routing_example() -> @ui.Element {
  let router = @ui.router([
    @ui.layout(
      (router, outlet) => {
        @ui.div([
          router.link("/", "Home"),
          router.link("/settings", "Settings"),
          outlet(),
        ]).flex_col()
      },
      [
        @ui.route("/", _ => @ui.text("Home")),
        @ui.route("/settings", _ => @ui.text("Settings")),
      ],
    ),
  ])
  router.outlet()
}
```

Outlets retain nodes by matched route identity. Navigating between sibling routes keeps their common layout and its state. Read `router.state()` in a binding for the current location and matched parameters; `router.is_active(path)` tests a navigation destination.

## Navigation

Use `router.link(path, label)` for a navigation link. `router.navigate(path)` pushes history; pass `replace=true` to replace the current entry. `router.go(-1)` goes back and `router.go(1)` goes forward.

A shared navigation component can receive the router from its layout callback. The active-link weight below tracks route changes, while Back and Forward move through this router’s in-memory history. These controls navigate within the current window.

```moonbit
fn navigation_controls(router : @ui.Router) -> @ui.Element {
  @ui.div([
    @ui.button("Back").on_click(() => router.go(-1)),
    @ui.button("Forward").on_click(() => router.go(1)),
    router
    .link("/settings", "Settings")
    .font_weight(if router.is_active("/settings") { 600 } else { 400 }),
  ])
  .flex_row()
  .gap(8)
}
```

## Route parameters

Dynamic route patterns such as `/projects/:id` share the native router’s matching rules. Read `router.state()` in a binding to inspect the current location and `matched.params` JSON. `router.is_active(path)` tests a navigation destination. Keep the router in the component that owns its history.
