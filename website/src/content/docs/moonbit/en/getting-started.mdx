QuickGUI for MoonBit uses child lists, fluent properties, and fine-grained signals. Components create retained native nodes; changes update only their bindings. Go is also available in the sidebar picker.

## Requirements

- [MoonBit toolchain](https://www.moonbitlang.com/download/) (tested with `moon 0.1.20260827` / `moonc v0.10.11`)
- Bun 1.3 or newer
- A C compiler; on macOS, install Xcode Command Line Tools

Build on the OS and architecture you are targeting. macOS has native runtime validation; Linux and Windows still need runtime and visual acceptance.

## Run the counter

The CLI and MoonBit SDK are not published yet. Start from the [QuickGUI checkout](https://github.com/egoist/quickgui); its `moon.work` resolves the SDK locally:

```sh
bun install
bun packages/cli/src/cli.ts dev --project examples/moonbit-counter
```

To scaffold a project, run `bun packages/cli/src/cli.ts init ../my-app --frontend moonbit --no-install`. Follow [Project Structure](/docs/moonbit/project-structure) to connect the generated module to this checkout.

## Your first window

Put this in `main/main.mbt`. Import `egoist/quickgui/ui` and `egoist/quickgui/native` in `main/moon.pkg`. Every component returns `@ui.Element`.

```moonbit
fn counter() -> @ui.Element {
  let (count, set_count) = @ui.create_signal(0)
  @ui.div([
    @ui.text("Count: \{count()}").font_size(24),
    @ui.button("Increment")
    .on_click(() => set_count(count() + 1))
    .px(16)
    .py(8)
    .border_radius(8)
    .bg(@ui.rgb8(45, 105, 180))
    .text_color(@ui.rgb8(255, 255, 255)),
  ])
  .size_full()
  .flex_col()
  .items_center()
  .justify_center()
  .gap(12)
}

fn main {
  match
    @native.run(() => {
      ignore(
        @ui.window(counter, options={
          "title": "Counter",
          "width": 620,
          "height": 480,
        }),
      )
    }) {
    Ok(_) => ()
    Err(error) => abort(error)
  }
}
```

## Build and examples

From the checkout, format and package the example:

```sh
bun packages/cli/src/cli.ts fmt --project examples/moonbit-counter
bun packages/cli/src/cli.ts build --project examples/moonbit-counter
```

Development uses the fast native backend on Apple Silicon macOS and x64 Linux/Windows, reusing bridge and runtime objects in `.quickgui/moonbit`. Release builds and other hosts use the optimizing C backend. Set `MOONBIT_NEW_NATIVE=0` to try the C backend during development.

For a larger application, run `bun --cwd examples/quick-git-moonbit dev`. [Quick Git](https://github.com/egoist/quickgui/tree/main/examples/quick-git-moonbit) demonstrates multiple windows, menus, virtualized diffs, a history graph, and an independent I/O extension.
