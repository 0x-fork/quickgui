Shapes and paints Unicode text with inherited typography, selection, and accessibility.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  let (count, _) = @ui.create_signal(0)
  @ui.text("Count: \{count()}")
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Key props

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

| Method | Purpose |
| --- | --- |
| `signal(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Signal) |
| `text(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Text) |
| `get(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Get) |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
