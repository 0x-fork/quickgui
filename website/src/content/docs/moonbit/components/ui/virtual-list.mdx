Lays out and paints the visible part of a long or variable-height collection.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.virtual_list([@ui.text("One"), @ui.text("Two"), @ui.text("Three")])
  .height(320)
  .estimated_item_height(32)
  .overscan(4)
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Key props

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

| Method | Purpose |
| --- | --- |
| `virtual_list(...)` | Native component configuration; `bind_` accepts a reactive accessor. (VirtualList) |
| `text(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Text) |
| `height(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Height) |
| `estimated_item_height(...)` | Initial logical row-height estimate used by virtualization. |
| `overscan(...)` | Extra rows mounted before and after the visible range. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
