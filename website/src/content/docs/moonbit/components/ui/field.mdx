Connects one control to its label, description, validation state, and error message.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  let field = @ui.field([]).required(true)
  field
  .flex_col()
  .gap(6)
  .children([
    field.slot(@ui.Label).label("Email"),
    field.slot(@ui.Control).placeholder("you@example.com"),
    field.slot(@ui.Description).label("Used for notifications"),
    field.slot(@ui.Error),
  ])
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Anatomy

Create parts from the root or an item with `.slot(...)`. They inherit the component scope and item identity. Each call returns an `Element`, so the same fluent styling and child methods work throughout.

- `root.slot(@ui.Item)`
- `root.slot(@ui.Label)`
- `root.slot(@ui.Control)`
- `root.slot(@ui.Validity)`
- `root.slot(@ui.Description)`
- `root.slot(@ui.Error)`

## Key props

Read signal getters directly in fluent property setters. The QuickGUI CLI creates controlled bindings for those expressions. Use change callbacks to write state; literal properties initialize component-owned state. Explicit `bind_` methods remain available for lower-level composition.

| Method | Purpose |
| --- | --- |
| `disabled(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Disabled) |
| `read_only(...)` | Native component configuration; `bind_` accepts a reactive accessor. (ReadOnly) |
| `required(...)` | Marks the value as required for validation and form submission. |
| `invalid(...)` | Projects invalid state to the field and its parts. |
| `touched(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Touched) |
| `dirty(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Dirty) |
| `filled(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Filled) |
| `validation_message(...)` | Bounded message exposed to error content and accessibility. |
| `validation_mode(...)` | Selects which interaction boundary triggers validation. |
| `validation_debounce_time(...)` | Native component configuration; `bind_` accepts a reactive accessor. (ValidationDebounceTime) |
| `on_change(handler)` | Receives semantic component state reported by the native core. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
