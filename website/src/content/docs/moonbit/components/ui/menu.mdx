A fully composable menu with submenus, groups, links, checkbox items, and radio items.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  let menu = @ui.menu([])
  menu.children([
    menu.slot(@ui.Trigger).label("Actions"),
    menu
    .slot(@ui.Positioner)
    .children([
      menu
      .slot(@ui.Popup)
      .children([
        menu
        .slot(@ui.Item, value="copy")
        .label("Copy")
        .on_click(() => println("Copy")),
      ])
      .padding(6),
    ]),
  ])
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Anatomy

Create parts from the root or an item with `.slot(...)`. They inherit the component scope and item identity. Each call returns an `Element`, so the same fluent styling and child methods work throughout.

- `root.slot(@ui.Trigger)`
- `root.slot(@ui.Portal)`
- `root.slot(@ui.Backdrop)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Popup)`
- `root.slot(@ui.Arrow)`
- `root.slot(@ui.Item)`
- `root.slot(@ui.LinkItem)`
- `root.slot(@ui.SubmenuRoot)`
- `root.slot(@ui.SubmenuTrigger)`
- `root.slot(@ui.Group)`
- `root.slot(@ui.GroupLabel)`
- `root.slot(@ui.RadioGroup)`
- `root.slot(@ui.RadioItem)`
- `root.slot(@ui.RadioItemIndicator)`
- `root.slot(@ui.CheckboxItem)`
- `root.slot(@ui.CheckboxItemIndicator)`
- `root.slot(@ui.Separator)`

## Key props

Read signal getters directly in fluent property setters. The QuickGUI CLI creates controlled bindings for those expressions. Use change callbacks to write state; literal properties initialize component-owned state. Explicit `bind_` methods remain available for lower-level composition.

| Method | Purpose |
| --- | --- |
| `open(...)` | Controlled open state. |
| `disabled(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Disabled) |
| `side(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Side) |
| `align(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Align) |
| `side_offset(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SideOffset) |
| `align_offset(...)` | Native component configuration; `bind_` accepts a reactive accessor. (AlignOffset) |
| `collision_padding(...)` | Native component configuration; `bind_` accepts a reactive accessor. (CollisionPadding) |
| `sticky(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Sticky) |
| `anchor_target(...)` | Native component configuration; `bind_` accepts a reactive accessor. (AnchorTarget) |
| `anchor_point(...)` | Native component configuration; `bind_` accepts a reactive accessor. (AnchorPoint) |
| `modal(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Modal) |
| `open_on_hover(...)` | Native component configuration; `bind_` accepts a reactive accessor. (OpenOnHover) |
| `delay(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Delay) |

| `orientation(...)` | Horizontal or vertical layout and keyboard direction. |

| `close_parent_on_esc(...)` | Native component configuration; `bind_` accepts a reactive accessor. (CloseParentOnEsc) |
| `menu(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Items) |
| `on_change(handler)` | Receives semantic component state reported by the native core. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
