An accessible press target that you style and compose with text or other content.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.button("Save").on_click(() => println("Saved")).px(16).py(8)
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Key props

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

| Method | Purpose |
| --- | --- |
| `button(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Button) |
| `on_click(...)` | Runs after the core resolves an activation. |
| `px(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Px) |
| `py(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Py) |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
