Renders a complete inline SVG document without loading external SVG resources.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.svg(
    "<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"0 0 24 24\"><path d=\"M4 12h16M12 4v16\" stroke=\"black\" stroke-width=\"2\"/></svg>",
  )
  .width(20)
  .height(20)
  .text_color(@ui.rgb8(48, 120, 220))
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Key props

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

| Method | Purpose |
| --- | --- |
| `svg(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Svg) |
| `width(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Width) |
| `height(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Height) |
| `text_color(...)` | Native component configuration; `bind_` accepts a reactive accessor. (TextColor) |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
