A single- or multiple-choice picker whose option surface is rendered in a native popover window.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.select([])
  .items([
    { "value": "go", "label": "Go" },
    { "value": "moonbit", "label": "MoonBit" },
  ])
  .active_value("moonbit")
  .width(180)
  .height(32)
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Anatomy

Create parts from the root or an item with `.slot(...)`. They inherit the component scope and item identity. Each call returns an `Element`, so the same fluent styling and child methods work throughout.

- `root.slot(@ui.Label)`
- `root.slot(@ui.Value)`
- `root.slot(@ui.Icon)`
- `root.slot(@ui.Backdrop)`
- `root.slot(@ui.Portal)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Popup)`
- `root.slot(@ui.Arrow)`
- `root.slot(@ui.List)`
- `root.slot(@ui.Item)`
- `root.slot(@ui.ItemText)`
- `root.slot(@ui.ItemIndicator)`
- `root.slot(@ui.Group)`
- `root.slot(@ui.GroupLabel)`
- `root.slot(@ui.Separator)`
- `root.slot(@ui.ScrollUpArrow)`
- `root.slot(@ui.ScrollDownArrow)`

## Key props

Read signal getters directly in fluent property setters. The QuickGUI CLI creates controlled bindings for those expressions. Use change callbacks to write state; literal properties initialize component-owned state. Explicit `bind_` methods remain available for lower-level composition.

| Method | Purpose |
| --- | --- |
| `disabled(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Disabled) |
| `read_only(...)` | Native component configuration; `bind_` accepts a reactive accessor. (ReadOnly) |
| `required(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Required) |
| `active_value(...)` | Controlled value. The precise value type follows this component’s contract. |
| `values(...)` | Controlled value. The precise value type follows this component’s contract. |
| `items(...)` | Bounded declaration model used for options or keyboard navigation. |
| `multiple(...)` | Allows more than one value to be selected or opened. |
| `orientation(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Orientation) |
| `loop_focus(...)` | Native component configuration; `bind_` accepts a reactive accessor. (LoopFocus) |
| `input_value(...)` | Native component configuration; `bind_` accepts a reactive accessor. (InputValue) |
| `filter_mode(...)` | Native component configuration; `bind_` accepts a reactive accessor. (FilterMode) |
| `options(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Options) |
| `appearance(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Appearance) |
| `auto_highlight(...)` | Native component configuration; `bind_` accepts a reactive accessor. (AutoHighlight) |
| `open_on_input_click(...)` | Native component configuration; `bind_` accepts a reactive accessor. (OpenOnInputClick) |
| `highlight_item_on_hover(...)` | Native component configuration; `bind_` accepts a reactive accessor. (HighlightItemOnHover) |
| `align_item_with_trigger(...)` | Native component configuration; `bind_` accepts a reactive accessor. (AlignItemWithTrigger) |
| `modal(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Modal) |
| `on_change(handler)` | Receives semantic component state reported by the native core. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
