Renders retained Markdown, including an incremental mode for streaming content.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.markdown("# Hello\n\nThis is **native** Markdown.").streaming(false)
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Key props

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

| Method | Purpose |
| --- | --- |
| `markdown(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Markdown) |
| `streaming(...)` | Uses incremental Markdown reconciliation for appended content. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
