A segmented, keyboard-editable time field with hour, minute, second, and period parts.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  let field = @ui.time_field([]).civil_value("09:30")
  field
  .flex_row()
  .gap(4)
  .children([
    field.slot(@ui.Segment, value="hour"),
    @ui.text(":"),
    field.slot(@ui.Segment, value="minute"),
  ])
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Anatomy

Create parts from the root or an item with `.slot(...)`. They inherit the component scope and item identity. Each call returns an `Element`, so the same fluent styling and child methods work throughout.

- `root.slot(@ui.Segment)`

## Key props

Read signal getters directly in fluent property setters. The QuickGUI CLI creates controlled bindings for those expressions. Use change callbacks to write state; literal properties initialize component-owned state. Explicit `bind_` methods remain available for lower-level composition.

| Method | Purpose |
| --- | --- |
| `disabled(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Disabled) |
| `read_only(...)` | Native component configuration; `bind_` accepts a reactive accessor. (ReadOnly) |
| `required(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Required) |
| `civil_value(...)` | Controlled value. The precise value type follows this component’s contract. |
| `civil_minimum(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Min) |
| `civil_maximum(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Max) |
| `segment_order(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SegmentOrder) |
| `variant(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Variant) |
| `format(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Format) |
| `on_change(handler)` | Receives semantic component state reported by the native core. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
