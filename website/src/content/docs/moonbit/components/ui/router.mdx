A QuickGUI UI projection of QuickGUI core routing with nested layouts and bounded memory history.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  let router = @ui.router([
    @ui.layout(
      (router, outlet) => {
        @ui.div([
          router.link("/", "Home"),
          router.link("/settings", "Settings"),
          outlet(),
        ]).flex_col()
      },
      [
        @ui.route("/", _ => @ui.text("Home")),
        @ui.route("/settings", _ => @ui.text("Settings")),
      ],
    ),
  ])
  router.outlet()
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Key props

| Method | Purpose |
| --- | --- |
| `router(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Router) |
| `layout(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Layout) |
| `div(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Div) |
| `link(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Link) |
| `flex_col(...)` | Native component configuration; `bind_` accepts a reactive accessor. (FlexCol) |
| `route(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Route) |
| `text(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Text) |
| `outlet(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Outlet) |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
