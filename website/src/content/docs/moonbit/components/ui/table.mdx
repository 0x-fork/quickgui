A virtualized tabular collection with header, row, and cell parts.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  let table = @ui.data_table([])
    .columns([{ "id": "name", "track": "1fr" }])
    .row_count(1)
    .row_height(32)
    .header_height(0)
    .selection_mode("single")
  table
  .children([
    table
    .slot(@ui.Row, index=0)
    .children([table.slot(@ui.Cell, value="name").children([@ui.text("Ada")])]),
  ])
  .height(160)
  .overflow_y("scroll")
}
```

The native core owns interaction, layout, accessibility and animation. These parts are unstyled: set sizes, colors and spacing for your application.

## Anatomy

Create parts from the root or an item with `.slot(...)`. They inherit the component scope and item identity. Each call returns an `Element`, so the same fluent styling and child methods work throughout.

- `root.slot(@ui.Header)`
- `root.slot(@ui.Row)`
- `root.slot(@ui.Cell)`

## Key props

Read signal getters directly in fluent property setters. The QuickGUI CLI creates controlled bindings for those expressions. Use change callbacks to write state; literal properties initialize component-owned state. Explicit `bind_` methods remain available for lower-level composition.

| Method | Purpose |
| --- | --- |
| `columns(...)` | Column declarations for the virtual table. |
| `row_count(...)` | Total logical row count. |
| `row_height(...)` | Logical height of each virtualized row. |
| `header_height(...)` | Native component configuration; `bind_` accepts a reactive accessor. (HeaderHeight) |
| `selection_mode(...)` | Allows single or multiple table selection. |
| `selection(...)` | Controlled selection for a table, native picker, or color control. |
| `sort_column(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SortColumn) |
| `sort_direction(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SortDirection) |
| `on_change(handler)` | Receives semantic component state reported by the native core. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
