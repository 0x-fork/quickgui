Reverse-hosts one ordinary QuickGUI subtree inside a SwiftUI hierarchy.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_quickgui_host_view(() => {
      @ui.view([@ui.text("QuickGUI inside SwiftUI")]).padding(12)
    })
    .width(320)
    .height(120),
  ])
}
```

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

## Key props

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

| Method | Purpose |
| --- | --- |
| `swift_ui_host(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiHost) |
| `swift_ui_quickgui_host_view(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiQuickguiHostView) |
| `view(...)` | Native component configuration; `bind_` accepts a reactive accessor. (View) |
| `text(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Text) |
| `padding(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Padding) |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
