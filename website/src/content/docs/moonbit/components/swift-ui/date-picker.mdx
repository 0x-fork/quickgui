A controlled native date or date-and-time picker.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_date_picker()
    .civil_value("2026-09-08")
    .swift_ui_date_picker_components("date")
    .label("Date"),
  ])
}
```

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

## Key props

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

| Method | Purpose |
| --- | --- |
| `swift_ui_host(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiHost) |
| `swift_ui_date_picker(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiDatePicker) |
| `civil_value(...)` | Unix timestamp in milliseconds; `Min` and `Max` use the same unit. |
| `swift_ui_date_picker_components(...)` | Chooses date, time, or combined date-and-time fields. |
| `label(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Label) |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
