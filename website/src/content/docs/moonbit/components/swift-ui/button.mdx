A native SwiftUI button with text, SF Symbol, semantic role, and press handling.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_button()
    .value("Save")
    .swift_ui_system_image("square.and.arrow.down")
    .on_click(() => println("Saved")),
  ])
}
```

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

## Key props

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

| Method | Purpose |
| --- | --- |
| `swift_ui_host(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiHost) |
| `swift_ui_button(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiButton) |
| `value(...)` | Native component configuration; `bind_` accepts a reactive accessor. (Value) |
| `swift_ui_system_image(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiSystemImage) |
| `on_click(...)` | Runs when the native SwiftUI button is activated. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
