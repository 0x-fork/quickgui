A native SwiftUI gauge with linear and circular accessory styles.

## Import

Add these package imports to `moon.pkg`:

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## Usage

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_gauge()
    .value(65)
    .minimum(0)
    .maximum(100)
    .swift_ui_gauge_style("accessoryLinear")
    .label("Storage"),
  ])
}
```

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

## Key props

SwiftUI controls require macOS and a `swift_ui_host([])` ancestor. Use `label(...)` for a native control label, `value(...)` for its value, and `swift_ui_modifiers(...)` for native SwiftUI modifiers.

| Method | Purpose |
| --- | --- |
| `swift_ui_host(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiHost) |
| `swift_ui_gauge(...)` | Native component configuration; `bind_` accepts a reactive accessor. (SwiftUiGauge) |
| `value(...)` | Controlled value. The precise value type follows this component’s contract. |
| `minimum(...)` | Minimum accepted value. |
| `maximum(...)` | Maximum accepted value. |
| `swift_ui_gauge_style(...)` | Native SwiftUI presentation style for this control. |
| `label(...)` | Visible native SwiftUI control label. |
| `style(...), [children]` | Layout, typography, colors, interaction states and child composition. |
