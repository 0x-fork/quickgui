長いリストや高さが可変のコレクションの表示範囲をレイアウトして描画します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  @ui.virtual_list([@ui.text("One"), @ui.text("Two"), @ui.text("Three")])
  .height(320)
  .estimated_item_height(32)
  .overscan(4)
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 主なプロパティ

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

| メソッド | 用途 |
| --- | --- |
| `virtual_list(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (VirtualList) |
| `text(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Text) |
| `height(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Height) |
| `estimated_item_height(...)` | 仮想化で使う初期論理行高の推定値です。 |
| `overscan(...)` | 表示範囲の前後に追加でマウントする行数です。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
