呼び出し側がスタイルした内容を、現在のウィンドウ内でアンカーの横に配置します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let popover = @ui.popover([]).side("bottom").side_offset(6)
  popover.children([
    popover.slot(@ui.Trigger).label("Details"),
    popover
    .slot(@ui.Positioner)
    .children([
      popover
      .slot(@ui.Popup)
      .children([@ui.text("Popover content")])
      .padding(16),
    ]),
  ])
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 構成

ルートまたは項目の `.slot(...)` からパーツを作成します。パーツはコンポーネントのスコープと項目の識別子を継承します。すべて `Element` を返すため、共通の fluent API でスタイルと子要素を設定できます。

- `root.slot(@ui.Trigger)`
- `root.slot(@ui.Portal)`
- `root.slot(@ui.Backdrop)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Popup)`
- `root.slot(@ui.Arrow)`
- `root.slot(@ui.Viewport)`
- `root.slot(@ui.Title)`
- `root.slot(@ui.Description)`
- `root.slot(@ui.Close)`

## 主なプロパティ

fluent プロパティメソッドでシグナルの getter を直接読みます。QuickGUI CLI が式を制御用バインディングに変換します。変更コールバックで状態を書き込み、リテラルは内部状態の初期値に使います。低レベルの組み立てには明示的な `bind_` メソッドも使えます。

| メソッド | 用途 |
| --- | --- |
| `open(...)` | 制御された開閉状態です。 |
| `disabled(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Disabled) |
| `side(...)` | 衝突処理前に優先する配置方向です。 |
| `align(...)` | 配置の交差軸上で優先する揃え方です。 |
| `side_offset(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SideOffset) |
| `align_offset(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (AlignOffset) |
| `collision_padding(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (CollisionPadding) |
| `sticky(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Sticky) |
| `anchor_target(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (AnchorTarget) |
| `anchor_point(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (AnchorPoint) |
| `modal(...)` | フォーカスを内部に閉じ込め、背後のサーフェスへの操作を防ぎます。 |
| `open_on_hover(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (OpenOnHover) |
| `delay(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Delay) |
| `close_delay(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (CloseDelay) |
| `enter_duration(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (EnterDuration) |
| `exit_duration(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (ExitDuration) |
| `dismiss_on_escape(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (DismissOnEscape) |
| `dismiss_on_pointer_outside(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (DismissOnPointerOutside) |
| `keep_mounted(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (KeepMounted) |
| `on_change(handler)` | ネイティブコアが通知するコンポーネントの状態を受け取ります。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
