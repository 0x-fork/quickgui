有限個のチェックボックス値をまとめ、必要に応じて親チェックボックスの状態も導出します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let group = @ui.checkbox_group([]).items(["email", "push"]).values(["email"])
  group
  .flex_col()
  .gap(8)
  .children([
    group.slot(@ui.Item, value="email").label("Email"),
    group.slot(@ui.Item, value="push").label("Push"),
    group.slot(@ui.Parent).label("All notifications"),
  ])
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 構成

ルートまたは項目の `.slot(...)` からパーツを作成します。パーツはコンポーネントのスコープと項目の識別子を継承します。すべて `Element` を返すため、共通の fluent API でスタイルと子要素を設定できます。

- `root.slot(@ui.Item)`
- `root.slot(@ui.Indicator)`
- `root.slot(@ui.Parent)`

## 主なプロパティ

fluent プロパティメソッドでシグナルの getter を直接読みます。QuickGUI CLI が式を制御用バインディングに変換します。変更コールバックで状態を書き込み、リテラルは内部状態の初期値に使います。低レベルの組み立てには明示的な `bind_` メソッドも使えます。

| メソッド | 用途 |
| --- | --- |
| `disabled(...)` | 操作を無効にし、無効状態を公開します。 |
| `read_only(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (ReadOnly) |
| `required(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Required) |
| `active_value(...)` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `values(...)` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `items(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Items) |
| `multiple(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Multiple) |
| `orientation(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Orientation) |
| `loop_focus(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (LoopFocus) |
| `on_change(handler)` | ネイティブコアが通知するコンポーネントの状態を受け取ります。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
