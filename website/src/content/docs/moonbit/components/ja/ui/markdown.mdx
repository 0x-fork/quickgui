保持型の Markdown を描画し、ストリーミング内容向けの差分更新にも対応します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  @ui.markdown("# Hello\n\nThis is **native** Markdown.").streaming(false)
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 主なプロパティ

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

| メソッド | 用途 |
| --- | --- |
| `markdown(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Markdown) |
| `streaming(...)` | 追記された内容に Markdown の差分更新を使います。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
