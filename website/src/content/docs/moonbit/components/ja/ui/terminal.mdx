保持型の Ghostty ターミナルサーフェスを埋め込み、プロセスのライフサイクルイベントを通知します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/terminal",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  @terminal.view("/bin/zsh", args=["-l"]).size_full()
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

`@native.run` の前に `@terminal.register()` を呼び、`quickgui.toml` の `[native].extensions` に terminal 拡張を追加します。[拡張の作成](/docs/moonbit/extensions)を参照してください。

## 主なプロパティ

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

| メソッド | 用途 |
| --- | --- |
| `view(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (View) |
| `size_full(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SizeFull) |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
