展開、選択、キーボードナビゲーションに対応した仮想化階層コレクションです。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let tree = @ui.tree([])
    .nodes([
      {
        "id": "src",
        "label": "src",
        "children": [{ "id": "main", "label": "main.mbt" }],
      },
    ])
    .expanded(["src"])
    .row_height(28)
  tree
  .height(160)
  .children([
    tree.slot(@ui.Row, value="src").label("src"),
    tree.slot(@ui.Row, value="main").label("main.mbt"),
  ])
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 構成

ルートまたは項目の `.slot(...)` からパーツを作成します。パーツはコンポーネントのスコープと項目の識別子を継承します。すべて `Element` を返すため、共通の fluent API でスタイルと子要素を設定できます。

- `root.slot(@ui.Row)`

## 主なプロパティ

fluent プロパティメソッドでシグナルの getter を直接読みます。QuickGUI CLI が式を制御用バインディングに変換します。変更コールバックで状態を書き込み、リテラルは内部状態の初期値に使います。低レベルの組み立てには明示的な `bind_` メソッドも使えます。

| メソッド | 用途 |
| --- | --- |
| `nodes(...)` | Tree の上限付き階層ノード宣言です。 |
| `expanded(...)` | 制御された展開済み Tree ノード ID です。 |
| `selected_value(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SelectedValue) |
| `row_height(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (RowHeight) |
| `header_height(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (HeaderHeight) |
| `selection_mode(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SelectionMode) |
| `selection(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Selection) |
| `on_change(handler)` | ネイティブコアが通知するコンポーネントの状態を受け取ります。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
