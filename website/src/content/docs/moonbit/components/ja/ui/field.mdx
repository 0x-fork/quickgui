1 つのコントロールをラベル、説明、検証状態、エラーメッセージに関連付けます。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let field = @ui.field([]).required(true)
  field
  .flex_col()
  .gap(6)
  .children([
    field.slot(@ui.Label).label("Email"),
    field.slot(@ui.Control).placeholder("you@example.com"),
    field.slot(@ui.Description).label("Used for notifications"),
    field.slot(@ui.Error),
  ])
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 構成

ルートまたは項目の `.slot(...)` からパーツを作成します。パーツはコンポーネントのスコープと項目の識別子を継承します。すべて `Element` を返すため、共通の fluent API でスタイルと子要素を設定できます。

- `root.slot(@ui.Item)`
- `root.slot(@ui.Label)`
- `root.slot(@ui.Control)`
- `root.slot(@ui.Validity)`
- `root.slot(@ui.Description)`
- `root.slot(@ui.Error)`

## 主なプロパティ

fluent プロパティメソッドでシグナルの getter を直接読みます。QuickGUI CLI が式を制御用バインディングに変換します。変更コールバックで状態を書き込み、リテラルは内部状態の初期値に使います。低レベルの組み立てには明示的な `bind_` メソッドも使えます。

| メソッド | 用途 |
| --- | --- |
| `disabled(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Disabled) |
| `read_only(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (ReadOnly) |
| `required(...)` | 検証とフォーム送信で必須の値としてマークします。 |
| `invalid(...)` | Field とそのパーツへ検証エラー状態を反映します。 |
| `touched(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Touched) |
| `dirty(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Dirty) |
| `filled(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Filled) |
| `validation_message(...)` | エラー内容とアクセシビリティに公開する、長さ制限付きメッセージです。 |
| `validation_mode(...)` | 検証を開始するインタラクション境界を選びます。 |
| `validation_debounce_time(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (ValidationDebounceTime) |
| `on_change(handler)` | ネイティブコアが通知するコンポーネントの状態を受け取ります。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
