継承されたタイポグラフィ、選択、アクセシビリティを使って Unicode テキストを組版・描画します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let (count, _) = @reactive.create_signal(0)
  @ui.text("Count: \{count()}")
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 主なプロパティ

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

| メソッド | 用途 |
| --- | --- |
| `signal(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Signal) |
| `text(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Text) |
| `get(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Get) |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
