ポインターとキーボード操作をコアが管理する、単一または複数つまみの範囲入力です。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let slider = @ui.slider([]).values([40]).minimum(0).maximum(100).step(1)
  slider
  .children([
    slider
    .slot(@ui.Control)
    .children([
      slider.slot(@ui.Track).children([slider.slot(@ui.Indicator)]).height(4),
      slider.slot(@ui.Thumb, index=0).width(16).height(16).border_radius(8),
    ])
    .height(24),
  ])
  .width(260)
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 構成

ルートまたは項目の `.slot(...)` からパーツを作成します。パーツはコンポーネントのスコープと項目の識別子を継承します。すべて `Element` を返すため、共通の fluent API でスタイルと子要素を設定できます。

- `root.slot(@ui.Label)`
- `root.slot(@ui.Value)`
- `root.slot(@ui.Control)`
- `root.slot(@ui.Track)`
- `root.slot(@ui.Range)`
- `root.slot(@ui.Indicator)`
- `root.slot(@ui.Thumb)`

## 主なプロパティ

fluent プロパティメソッドでシグナルの getter を直接読みます。QuickGUI CLI が式を制御用バインディングに変換します。変更コールバックで状態を書き込み、リテラルは内部状態の初期値に使います。低レベルの組み立てには明示的な `bind_` メソッドも使えます。

| メソッド | 用途 |
| --- | --- |
| `disabled(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Disabled) |
| `read_only(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (ReadOnly) |
| `required(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Required) |
| `values(...)` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `minimum(...)` | 受け入れる最小値です。 |
| `maximum(...)` | 受け入れる最大値です。 |
| `step(...)` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `large_step(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (LargeStep) |
| `min_steps_between_values(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (MinStepsBetweenValues) |
| `thumb_alignment(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (ThumbAlignment) |
| `format(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Format) |
| `orientation(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Orientation) |
| `on_change(handler)` | ネイティブコアが通知するコンポーネントの状態を受け取ります。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
