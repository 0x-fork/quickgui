Input と同じ制御値の規約を持つ、複数行テキスト編集プリミティブです。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let (value, set_value) = @ui.create_signal("")
  @ui.text_area().on_input(next => set_value(next)).value(value()).height(120)
}
```

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

## 主なプロパティ

ネイティブコアが操作、レイアウト、アクセシビリティ、アニメーションを管理します。パーツに既定の見た目はないため、サイズ、色、間隔を設定してください。

| メソッド | 用途 |
| --- | --- |
| `signal(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Signal) |
| `text_area(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (TextArea) |
| `on_input(...)` | ネイティブ編集の入力を通知します。 |
| `set(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Set) |
| `bind_value(...)` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `get(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Get) |
| `height(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Height) |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
