値の範囲を制限できる、制御されたネイティブ数値 Stepper です。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let (value, set_value) = @ui.create_signal(5.0)
  @ui.swift_ui_host([
    @ui.swift_ui_stepper()
    .value(Float::from_double(value()))
    .minimum(0)
    .maximum(10)
    .step(1)
    .on_number_input(next => set_value(next))
    .label("Copies"),
  ])
}
```

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

## 主なプロパティ

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

| メソッド | 用途 |
| --- | --- |
| `signal(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Signal) |
| `swift_ui_host(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiHost) |
| `swift_ui_stepper(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiStepper) |
| `bind_number(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Number) |
| `get(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Get) |
| `minimum(...)` | 受け入れる最小値です。 |
| `maximum(...)` | 受け入れる最大値です。 |
| `step(...)` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `on_number_input(...)` | コアが受け入れた値を通知します。 |
| `set(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Set) |
| `label(...)` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
