CSS 形式の RGBA 文字列を返す、ネイティブ SwiftUI カラーピッカーです。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let (value, set_value) = @ui.create_signal("#2563eb")
  @ui.swift_ui_host([
    @ui.swift_ui_color_picker()
    .value(value())
    .on_input(next => set_value(next))
    .swift_ui_color_supports_opacity(true)
    .label("Color"),
  ])
}
```

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

## 主なプロパティ

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

| メソッド | 用途 |
| --- | --- |
| `signal(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Signal) |
| `swift_ui_host(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiHost) |
| `swift_ui_color_picker(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiColorPicker) |
| `bind_value(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Value) |
| `get(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Get) |
| `on_input(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (OnInput) |
| `set(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Set) |
| `swift_ui_color_supports_opacity(...)` | ネイティブのカラーパネルでアルファ値を選択できるようにします。 |
| `label(...)` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
