組み合わせた SwiftUI トリガーから、ネイティブ SwiftUI Popover を表示します。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  let (opened, set_opened) = @ui.create_signal(false)
  @ui.swift_ui_host([
    @ui.swift_ui_popover([
      @ui.swift_ui_popover_trigger([
        @ui.swift_ui_button()
        .value("Details")
        .on_click(() => set_opened(!opened())),
      ]),
      @ui.swift_ui_popover_content([
        @ui.swift_ui_button().value("Close").on_click(() => set_opened(false)),
      ]),
    ])
    .swift_ui_is_presented(opened())
    .on("presentation", 0, event => set_opened(event.value == Some("true"))),
  ])
}
```

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

## 主なプロパティ

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

| メソッド | 用途 |
| --- | --- |
| `signal(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Signal) |
| `swift_ui_host(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiHost) |
| `swift_ui_popover(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiPopover) |
| `swift_ui_popover_trigger(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiPopoverTrigger) |
| `swift_ui_button(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiButton) |
| `value(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Value) |
| `on_click(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (OnPress) |
| `update(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Update) |
| `swift_ui_popover_content(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiPopoverContent) |
| `set(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Set) |
| `bind_swift_ui_is_presented(...)` | 制御されたネイティブ SwiftUI Popover の表示状態です。 |
| `get(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Get) |
| `on(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (On) |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
