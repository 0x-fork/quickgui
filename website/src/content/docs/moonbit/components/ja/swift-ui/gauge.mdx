線形と円形のアクセサリースタイルに対応した、ネイティブ SwiftUI Gauge です。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_gauge()
    .value(65)
    .minimum(0)
    .maximum(100)
    .swift_ui_gauge_style("accessoryLinear")
    .label("Storage"),
  ])
}
```

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

## 主なプロパティ

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

| メソッド | 用途 |
| --- | --- |
| `swift_ui_host(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiHost) |
| `swift_ui_gauge(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiGauge) |
| `value(...)` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `minimum(...)` | 受け入れる最小値です。 |
| `maximum(...)` | 受け入れる最大値です。 |
| `swift_ui_gauge_style(...)` | このコントロールのネイティブ SwiftUI 表示スタイルです。 |
| `label(...)` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
