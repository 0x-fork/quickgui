制御されたネイティブの日付または日時ピッカーです。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_date_picker()
    .civil_value("2026-09-08")
    .swift_ui_date_picker_components("date")
    .label("Date"),
  ])
}
```

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

## 主なプロパティ

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

| メソッド | 用途 |
| --- | --- |
| `swift_ui_host(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiHost) |
| `swift_ui_date_picker(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiDatePicker) |
| `civil_value(...)` | ミリ秒単位の Unix タイムスタンプです。`Min` と `Max` も同じ単位です。 |
| `swift_ui_date_picker_components(...)` | 日付、時刻、または日付と時刻の両方のフィールドを選びます。 |
| `label(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Label) |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
