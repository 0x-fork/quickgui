SwiftUI 階層の中へ通常の QuickGUI サブツリーをリバースホストします。

## インポート

`moon.pkg` に次のパッケージを追加します。

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 使い方

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_quickgui_host_view(() => {
      @ui.view([@ui.text("QuickGUI inside SwiftUI")]).padding(12)
    })
    .width(320)
    .height(120),
  ])
}
```

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

## 主なプロパティ

SwiftUI コントロールは macOS 専用で、`swift_ui_host([])` の内側に配置します。`label(...)` はラベル、`value(...)` は値、`swift_ui_modifiers(...)` は SwiftUI 修飾子を設定します。

| メソッド | 用途 |
| --- | --- |
| `swift_ui_host(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiHost) |
| `swift_ui_quickgui_host_view(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (SwiftUiQuickguiHostView) |
| `view(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (View) |
| `text(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Text) |
| `padding(...)` | ネイティブコンポーネントの設定。`bind_` はリアクティブなアクセサーを受け取ります。 (Padding) |
| `style(...), [children]` | レイアウト、文字、色、操作状態、子要素の構成。 |
