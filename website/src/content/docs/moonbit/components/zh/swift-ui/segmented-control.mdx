原生分段选择器，支持值选择和中性的 Xcode 风格标签页角色。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let (value, set_value) = @reactive.create_signal("go")
  @ui.swift_ui_host([
    @ui.swift_ui_segmented_control()
    .value(value())
    .on_input(next => set_value(next))
    .items([
      { "value": "go", "label": "Go" },
      { "value": "moonbit", "label": "MoonBit" },
    ]),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `signal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Signal) |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_segmented_control(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiSegmentedControl) |
| `bind_value(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Value) |
| `get(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Get) |
| `on_input(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (OnInput) |
| `set(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Set) |
| `items(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Items) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
