受控的原生数字步进器，数值范围可限制。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let (value, set_value) = @ui.create_signal(5.0)
  @ui.swift_ui_host([
    @ui.swift_ui_stepper()
    .value(Float::from_double(value()))
    .minimum(0)
    .maximum(10)
    .step(1)
    .on_number_input(next => set_value(next))
    .label("Copies"),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `signal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Signal) |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_stepper(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiStepper) |
| `bind_number(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Number) |
| `get(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Get) |
| `minimum(...)` | 可接受的最小值。 |
| `maximum(...)` | 可接受的最大值。 |
| `step(...)` | 键盘、指针或原生控件输入使用的步长。 |
| `on_number_input(...)` | 报告核心接受的值。 |
| `set(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Set) |
| `label(...)` | 原生 SwiftUI 控件的可见标签。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
