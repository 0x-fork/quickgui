在 SwiftUI 层级中反向托管一棵普通的 QuickGUI 子树。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_quickgui_host_view(() => {
      @ui.div([@ui.text("QuickGUI inside SwiftUI")]).padding(12)
    })
    .width(320)
    .height(120),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_quickgui_host_view(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiQuickguiHostView) |
| `div(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Div) |
| `text(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Text) |
| `padding(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Padding) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
