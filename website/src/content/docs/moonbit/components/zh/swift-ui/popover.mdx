从组合式 SwiftUI 触发器显示原生 SwiftUI 浮窗。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let (opened, set_opened) = @ui.create_signal(false)
  @ui.swift_ui_host([
    @ui.swift_ui_popover([
      @ui.swift_ui_popover_trigger([
        @ui.swift_ui_button()
        .value("Details")
        .on_click(() => set_opened(!opened())),
      ]),
      @ui.swift_ui_popover_content([
        @ui.swift_ui_button().value("Close").on_click(() => set_opened(false)),
      ]),
    ])
    .swift_ui_is_presented(opened())
    .on("presentation", 0, event => set_opened(event.value == Some("true"))),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `signal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Signal) |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_popover(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiPopover) |
| `swift_ui_popover_trigger(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiPopoverTrigger) |
| `swift_ui_button(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiButton) |
| `value(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Value) |
| `on_click(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (OnPress) |
| `update(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Update) |
| `swift_ui_popover_content(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiPopoverContent) |
| `set(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Set) |
| `bind_swift_ui_is_presented(...)` | 受控的原生 SwiftUI Popover 显示状态。 |
| `get(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Get) |
| `on(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (On) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
