受控的原生 SwiftUI 开关。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let (checked, set_checked) = @ui.create_signal(false)
  @ui.swift_ui_host([
    @ui.swift_ui_toggle()
    .checked(checked())
    .on_bool_input(next => set_checked(next))
    .label("Notifications"),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `signal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Signal) |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_toggle(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiToggle) |
| `bind_checked(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Checked) |
| `get(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Get) |
| `on_bool_input(...)` | 报告原生 SwiftUI 开关接受的值。 |
| `set(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Set) |
| `label(...)` | 原生 SwiftUI 控件的可见标签。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
