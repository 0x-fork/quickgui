原生 SwiftUI 仪表，支持线性和圆形附属样式。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_gauge()
    .value(65)
    .minimum(0)
    .maximum(100)
    .swift_ui_gauge_style("accessoryLinear")
    .label("Storage"),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_gauge(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiGauge) |
| `value(...)` | 受控值，具体类型取决于该组件的约定。 |
| `minimum(...)` | 可接受的最小值。 |
| `maximum(...)` | 可接受的最大值。 |
| `swift_ui_gauge_style(...)` | 此控件的原生 SwiftUI 展示样式。 |
| `label(...)` | 原生 SwiftUI 控件的可见标签。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
