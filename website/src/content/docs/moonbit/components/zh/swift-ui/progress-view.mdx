确定或不确定的原生 SwiftUI 进度指示器。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_progress_view().value(0.65).maximum(1).label("Uploading"),
  ])
}
```

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

## 主要属性

SwiftUI 控件仅支持 macOS，并且必须位于 `swift_ui_host([])` 中。使用 `label(...)` 设置原生标签，`value(...)` 设置值，`swift_ui_modifiers(...)` 设置 SwiftUI 修饰符。

| 方法 | 用途 |
| --- | --- |
| `swift_ui_host(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiHost) |
| `swift_ui_progress_view(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SwiftUiProgressView) |
| `value(...)` | 受控值，具体类型取决于该组件的约定。 |
| `maximum(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Max) |
| `label(...)` | 原生 SwiftUI 控件的可见标签。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
