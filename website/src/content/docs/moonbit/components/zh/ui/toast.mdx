显示定时堆叠通知，支持操作、关闭和滑动手势。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let viewport = @ui.toast_viewport([])
    .toasts([{ "id": "saved", "title": "Saved", "timeout": 5000 }])
    .timeout(5000)
  let toast = viewport.slot(@ui.Item, value="saved")
  viewport.children([
    toast
    .padding(16)
    .children([
      toast.slot(@ui.Title).label("Saved"),
      toast.slot(@ui.Close).label("Dismiss"),
    ]),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Portal)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Content)`
- `root.slot(@ui.Title)`
- `root.slot(@ui.Description)`
- `root.slot(@ui.Action)`
- `root.slot(@ui.Close)`
- `root.slot(@ui.Item)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `toasts(...)` | 视口渲染的完整 Toast 队列声明。 |
| `timeout(...)` | 继承的自动关闭时长或预热 Provider 的超时时间。 |
| `limit(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Limit) |
| `swipe_direction(...)` | 滑动关闭或移动界面时朝向的边缘。 |
| `stack_expanded(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (StackExpanded) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
