虚拟化表格集合，包含表头、行和单元格部件。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let table = @ui.data_table([])
    .columns([{ "id": "name", "track": "1fr" }])
    .row_count(1)
    .row_height(32)
    .header_height(0)
    .selection_mode("single")
  table
  .children([
    table
    .slot(@ui.Row, index=0)
    .children([table.slot(@ui.Cell, value="name").children([@ui.text("Ada")])]),
  ])
  .height(160)
  .overflow_y("scroll")
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Header)`
- `root.slot(@ui.Row)`
- `root.slot(@ui.Cell)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `columns(...)` | 虚拟表格的列声明。 |
| `row_count(...)` | 逻辑总行数。 |
| `row_height(...)` | 每个虚拟化行的逻辑高度。 |
| `header_height(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (HeaderHeight) |
| `selection_mode(...)` | 允许表格单选或多选。 |
| `selection(...)` | 表格、原生选择器或颜色控件的受控选中值。 |
| `sort_column(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SortColumn) |
| `sort_direction(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SortDirection) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
