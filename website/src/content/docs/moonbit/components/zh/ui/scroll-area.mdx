组合可滚动视口，以及可由调用方设置样式的滚动条、滑块和角落。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let scroll = @ui.scroll_area([])
  scroll
  .children([
    scroll
    .slot(@ui.Viewport)
    .children([
      scroll
      .slot(@ui.Content)
      .children([@ui.text("Scrollable content")])
      .height(600),
    ])
    .size_full()
    .overflow_y("scroll"),
  ])
  .width(280)
  .height(160)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Viewport)`
- `root.slot(@ui.Content)`
- `root.slot(@ui.Scrollbar)`
- `root.slot(@ui.Thumb)`
- `root.slot(@ui.Corner)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `values(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Value) |
| `viewport_size(...)` | 声明的滚动视口范围。 |
| `content_size(...)` | 声明的滚动内容范围。 |
| `overflow_edge_threshold(...)` | 仍视为位于边缘的最大距离。 |
| `orientation(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Orientation) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
