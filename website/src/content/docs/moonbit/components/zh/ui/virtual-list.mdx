为长列表或不等高集合布局并绘制可见部分。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.virtual_list([@ui.text("One"), @ui.text("Two"), @ui.text("Three")])
  .height(320)
  .estimated_item_height(32)
  .overscan(4)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `virtual_list(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (VirtualList) |
| `text(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Text) |
| `height(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Height) |
| `estimated_item_height(...)` | 虚拟化使用的初始逻辑行高估计值。 |
| `overscan(...)` | 在可见范围前后额外挂载的行数。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
