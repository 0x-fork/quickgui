以保留模式渲染 Markdown，并支持用于流式内容的增量模式。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.markdown("# Hello\n\nThis is **native** Markdown.").streaming(false)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `markdown(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Markdown) |
| `streaming(...)` | 对追加内容使用增量 Markdown 协调。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
