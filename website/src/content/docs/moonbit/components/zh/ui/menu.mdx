可完全组合的菜单，支持子菜单、分组、链接、复选项和单选项。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let menu = @ui.menu([])
  menu.children([
    menu.slot(@ui.Trigger).label("Actions"),
    menu
    .slot(@ui.Positioner)
    .children([
      menu
      .slot(@ui.Popup)
      .children([
        menu
        .slot(@ui.Item, value="copy")
        .label("Copy")
        .on_click(() => println("Copy")),
      ])
      .padding(6),
    ]),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Trigger)`
- `root.slot(@ui.Portal)`
- `root.slot(@ui.Backdrop)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Popup)`
- `root.slot(@ui.Arrow)`
- `root.slot(@ui.Item)`
- `root.slot(@ui.LinkItem)`
- `root.slot(@ui.SubmenuRoot)`
- `root.slot(@ui.SubmenuTrigger)`
- `root.slot(@ui.Group)`
- `root.slot(@ui.GroupLabel)`
- `root.slot(@ui.RadioGroup)`
- `root.slot(@ui.RadioItem)`
- `root.slot(@ui.RadioItemIndicator)`
- `root.slot(@ui.CheckboxItem)`
- `root.slot(@ui.CheckboxItemIndicator)`
- `root.slot(@ui.Separator)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。
