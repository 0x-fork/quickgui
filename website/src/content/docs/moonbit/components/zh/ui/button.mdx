可访问的按压目标，可自行设置样式并组合文本或其他内容。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.button("Save").on_click(() => println("Saved")).px(16).py(8)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `button(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Button) |
| `on_click(...)` | 在核心完成激活判定后运行。 |
| `px(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Px) |
| `py(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Py) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
