管理一个或多个可展开区域及其键盘焦点。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let accordion = @ui.accordion([]).multiple(true)
  let item = accordion.slot(@ui.Item, value="details", index=0)
  accordion.children([
    item
    .flex_col()
    .children([
      item.slot(@ui.Header).children([item.slot(@ui.Trigger).label("Details")]),
      item.slot(@ui.Panel).children([@ui.text("Expanded content")]),
    ]),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Item)`
- `root.slot(@ui.Header)`
- `root.slot(@ui.Trigger)`
- `root.slot(@ui.Panel)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `values(...)` | 受控值，具体类型取决于该组件的约定。 |
| `multiple(...)` | 允许选择或打开多个值。 |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `keep_mounted(...)` | 保持非活动内容已挂载，但禁用其显示。 |
| `heading_level(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (HeadingLevel) |
| `open(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Open) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
