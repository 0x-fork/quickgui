在核心精确控制的延迟后显示辅助信息，并支持 Provider 级预热。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let tip = @ui.tooltip([]).delay(500).side("top")
  tip.children([
    tip.slot(@ui.Trigger).label("Hover for help"),
    tip
    .slot(@ui.Positioner)
    .children([
      tip.slot(@ui.Popup).children([@ui.text("Helpful information")]).padding(8),
    ]),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Trigger)`
- `root.slot(@ui.Portal)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Popup)`
- `root.slot(@ui.Arrow)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `open(...)` | 受控的打开状态。 |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `side(...)` | 碰撞处理前的首选放置方向。 |
| `align(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Align) |
| `side_offset(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SideOffset) |
| `align_offset(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (AlignOffset) |
| `collision_padding(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (CollisionPadding) |
| `sticky(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Sticky) |
| `anchor_target(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (AnchorTarget) |
| `anchor_point(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (AnchorPoint) |
| `modal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Modal) |
| `open_on_hover(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (OpenOnHover) |
| `delay(...)` | 打开前由核心管理的延迟（毫秒）。 |
| `close_delay(...)` | 关闭前由核心管理的延迟（毫秒）。 |
| `enter_duration(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (EnterDuration) |
| `exit_duration(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ExitDuration) |
| `dismiss_on_escape(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (DismissOnEscape) |
| `dismiss_on_pointer_outside(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (DismissOnPointerOutside) |
| `keep_mounted(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (KeepMounted) |
| `provider(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Provider) |
| `hoverable(...)` | 允许指针移入 Tooltip 而不会将其关闭。 |
| `track_cursor_axis(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (TrackCursorAxis) |
| `close_on_click(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (CloseOnClick) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
