嵌入保留式 Ghostty 终端表面，并报告进程生命周期事件。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/terminal",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @terminal.view("/bin/zsh", args=["-l"]).size_full()
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

在 `@native.run` 前调用 `@terminal.register()`，并在 `quickgui.toml` 的 `[native].extensions` 中添加独立的 terminal 扩展。参见[编写扩展](/docs/moonbit/extensions)。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `view(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (View) |
| `size_full(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SizeFull) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
