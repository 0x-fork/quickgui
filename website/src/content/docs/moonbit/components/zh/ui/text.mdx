使用继承的排版、文本选择和无障碍属性来排版并绘制 Unicode 文本。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let (count, _) = @ui.create_signal(0)
  @ui.text("Count: \{count()}")
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `signal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Signal) |
| `text(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Text) |
| `get(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Get) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
