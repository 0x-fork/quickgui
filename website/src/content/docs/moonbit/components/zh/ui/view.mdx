用于布局、绘制、指针输入和无障碍支持的通用保留式容器。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.div([@ui.text("Hello")]).size_full().flex_col().gap(12).padding(24)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `div(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Div) |
| `text(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Text) |
| `size_full(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (SizeFull) |
| `flex_col(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (FlexCol) |
| `gap(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Gap) |
| `padding(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Padding) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
