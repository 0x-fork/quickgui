筛选自由输入文本的建议项，无需选中某个值。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.autocomplete([])
  .items([
    { "value": "Paris", "label": "Paris" },
    { "value": "Prague", "label": "Prague" },
  ])
  .filter_mode("startsWith")
  .placeholder("City")
  .width(220)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Label)`
- `root.slot(@ui.Value)`
- `root.slot(@ui.Icon)`
- `root.slot(@ui.InputGroup)`
- `root.slot(@ui.Clear)`
- `root.slot(@ui.Portal)`
- `root.slot(@ui.Positioner)`
- `root.slot(@ui.Popup)`
- `root.slot(@ui.Arrow)`
- `root.slot(@ui.Status)`
- `root.slot(@ui.Empty)`
- `root.slot(@ui.List)`
- `root.slot(@ui.Item)`
- `root.slot(@ui.ItemIndicator)`
- `root.slot(@ui.Group)`
- `root.slot(@ui.GroupLabel)`
- `root.slot(@ui.Collection)`
- `root.slot(@ui.Separator)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `read_only(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ReadOnly) |
| `required(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Required) |
| `active_value(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Value) |
| `values(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Value) |
| `items(...)` | 用于选项或键盘导航的有限声明模型。 |
| `multiple(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Multiple) |
| `orientation(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Orientation) |
| `loop_focus(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (LoopFocus) |
| `input_value(...)` | Combobox 或 Autocomplete 使用的可编辑查询文本。 |
| `filter_mode(...)` | 由核心管理的包含、前缀、模糊或禁用筛选模式。 |
| `options(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Options) |
| `appearance(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Appearance) |
| `auto_highlight(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (AutoHighlight) |
| `open_on_input_click(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (OpenOnInputClick) |
| `highlight_item_on_hover(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (HighlightItemOnHover) |
| `align_item_with_trigger(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (AlignItemWithTrigger) |
| `modal(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Modal) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
