支持键盘导航的月历网格，用于选择单个日期。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let calendar = @ui.calendar([]).civil_value("2026-09-08").first_weekday(1)
  calendar.children([
    calendar
    .slot(@ui.Week, index=0)
    .flex_row()
    .children([
      calendar.slot(@ui.Day, value="2026-09-07").label("7"),
      calendar.slot(@ui.Day, value="2026-09-08").label("8"),
    ]),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Week)`
- `root.slot(@ui.Day)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `read_only(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ReadOnly) |
| `required(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Required) |
| `civil_value(...)` | 受控值，具体类型取决于该组件的约定。 |
| `civil_minimum(...)` | 可接受的最小值。 |
| `civil_maximum(...)` | 可接受的最大值。 |
| `first_weekday(...)` | 第一列对应的星期；周一为 0，周日为 6。 |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
