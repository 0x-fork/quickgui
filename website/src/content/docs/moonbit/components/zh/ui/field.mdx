将控件与标签、说明、验证状态和错误信息关联起来。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let field = @ui.field([]).required(true)
  field
  .flex_col()
  .gap(6)
  .children([
    field.slot(@ui.Label).label("Email"),
    field.slot(@ui.Control).placeholder("you@example.com"),
    field.slot(@ui.Description).label("Used for notifications"),
    field.slot(@ui.Error),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Item)`
- `root.slot(@ui.Label)`
- `root.slot(@ui.Control)`
- `root.slot(@ui.Validity)`
- `root.slot(@ui.Description)`
- `root.slot(@ui.Error)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `read_only(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ReadOnly) |
| `required(...)` | 将值标记为验证和表单提交所必需。 |
| `invalid(...)` | 将无效状态传递给字段及其各部件。 |
| `touched(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Touched) |
| `dirty(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Dirty) |
| `filled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Filled) |
| `validation_message(...)` | 向错误内容和无障碍 API 暴露的有限长度消息。 |
| `validation_mode(...)` | 选择触发验证的交互边界。 |
| `validation_debounce_time(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ValidationDebounceTime) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
