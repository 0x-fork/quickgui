单滑块或多滑块范围输入，指针与键盘交互由核心管理。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let slider = @ui.slider([]).values([40]).minimum(0).maximum(100).step(1)
  slider
  .children([
    slider
    .slot(@ui.Control)
    .children([
      slider.slot(@ui.Track).children([slider.slot(@ui.Indicator)]).height(4),
      slider.slot(@ui.Thumb, index=0).width(16).height(16).border_radius(8),
    ])
    .height(24),
  ])
  .width(260)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Label)`
- `root.slot(@ui.Value)`
- `root.slot(@ui.Control)`
- `root.slot(@ui.Track)`
- `root.slot(@ui.Range)`
- `root.slot(@ui.Indicator)`
- `root.slot(@ui.Thumb)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `read_only(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ReadOnly) |
| `required(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Required) |
| `values(...)` | 受控值，具体类型取决于该组件的约定。 |
| `minimum(...)` | 可接受的最小值。 |
| `maximum(...)` | 可接受的最大值。 |
| `step(...)` | 键盘、指针或原生控件输入使用的步长。 |
| `large_step(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (LargeStep) |
| `min_steps_between_values(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (MinStepsBetweenValues) |
| `thumb_alignment(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (ThumbAlignment) |
| `format(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Format) |
| `orientation(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Orientation) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
