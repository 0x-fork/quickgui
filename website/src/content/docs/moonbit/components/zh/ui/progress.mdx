表示确定或不确定的任务进度，可组合标签和轨道。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  let progress = @ui.progress([]).values([0.65]).maximum(1)
  progress
  .width(240)
  .flex_col()
  .gap(6)
  .children([
    progress.slot(@ui.Label).label("Upload"),
    progress
    .slot(@ui.Track)
    .children([progress.slot(@ui.Indicator).bg(@ui.rgb8(40, 120, 230))])
    .height(6),
    progress.slot(@ui.Value),
  ])
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

通过根元素或条目的 `.slot(...)` 创建部件。部件继承组件作用域和条目标识。每次调用都返回 `Element`，可继续使用相同的链式样式和子元素方法。

- `root.slot(@ui.Track)`
- `root.slot(@ui.Indicator)`
- `root.slot(@ui.Label)`
- `root.slot(@ui.Value)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `values(...)` | 受控值，具体类型取决于该组件的约定。 |
| `maximum(...)` | 可接受的最大值。 |
| `indeterminate(...)` | 表示完成量未知的进度。 |
| `value_text(...)` | 辅助技术优先使用的易读值。 |
| `format(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Format) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
