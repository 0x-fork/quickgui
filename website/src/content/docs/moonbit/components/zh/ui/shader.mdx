使用有限数量的数值着色器参数绘制经过验证的 WGSL。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/reactive",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.shader(
    "fn quickgui_fragment(input: QuickGuiShaderInput) -> vec4<f32> { return vec4<f32>(input.uv, 0.5, 1.0); }",
  )
  .width(240)
  .height(160)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `shader(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Shader) |
| `width(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Width) |
| `height(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Height) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
