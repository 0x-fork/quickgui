使用保留式图像资源显示文件系统路径、文件 URL 或 base64 数据 URL。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.image("assets/avatar.png").width(64).height(64)
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 主要属性

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

| 方法 | 用途 |
| --- | --- |
| `image(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Image) |
| `width(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Width) |
| `height(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Height) |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
