在独立的原生子窗口中显示 QuickGUI 内容，可超出所属窗口边界。

## 导入

在 `moon.pkg` 中添加以下包：

```moonbit
import {
  "egoist/quickgui/ui",
}
```

## 用法

```moonbit
fn component_example() -> @ui.Element {
  @ui.system_popover([])
  .label("Open details")
  .system_content(
    () => @ui.view([@ui.text("Native child window")]).padding(16),
    options={
      "width": 260,
      "height": 120,
      "popoverPlacement": "bottom-start",
      "popoverDismissOnEscape": true,
      "popoverDismissOnPointerOutside": true,
    },
  )
}
```

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。

## 结构

原生核心负责交互、布局、无障碍和动画。这些部件不预设视觉样式，请按应用需要设置尺寸、颜色和间距。



`system_popover([]).system_content(...)`

## 主要属性

在链式属性方法中直接读取信号访问器，QuickGUI CLI 会为表达式创建受控绑定。通过变更回调写入状态；字面量属性初始化组件内部状态。底层组合仍可使用显式 `bind_` 方法。

| 方法 | 用途 |
| --- | --- |
| `open(...)` | 受控的打开状态。 |
| `disabled(...)` | 原生组件配置；`bind_` 接收响应式访问器。 (Disabled) |
| `on_change(handler)` | 接收原生核心报告的组件语义状态。 |
| `style(...), [children]` | 布局、字体、颜色、交互状态和子元素组合。 |
