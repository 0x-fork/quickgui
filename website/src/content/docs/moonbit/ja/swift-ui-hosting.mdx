ホスト境界を明確にして SwiftUI と QuickGUI を組み合わせます。

## ホスト境界

ネイティブコントロールを `swift_ui_host([])` に配置します。通常の QuickGUI レイアウトはホストの外側に置くか、逆方向ホストを使います。

```moonbit
///|
fn embedded_content() -> @ui.Element {
  @ui.swift_ui_host([
    @ui.swift_ui_quickgui_host_view(() => {
      @ui.div([@ui.text("QuickGUI content")]).padding(16)
    })
    .width(320)
    .height(120),
  ])
}
```

## 逆方向のホスティング

`swift_ui_quickgui_host_view(render, width=..., height=...)` で SwiftUI 内に QuickGUI サブツリーを作ります。コールバックは埋め込みビュー自身のウィンドウでノードを構築します。

## ライフサイクル

所有ウィンドウのマウント後に埋め込みビューを作成し、ホストの削除時に閉じます。既存のノードをウィンドウ間で移動しないでください。
