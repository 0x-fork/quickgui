MoonBit アプリ向けに任意の更新サービスをパッケージ化します。

## 設定

`quickgui.toml` の `[updates]` に公開鍵とダウンロード先を設定します。TypeScript CLI が両フロントエンド向けの appcast メタデータと署名済みパッケージを生成します。

## アプリでの使用

MoonBit には updater セッション専用のヘルパーがまだありません。アプリ側のラッパーでサービス ABI、セッション識別子、`check` / `install` / `automatic` コマンド、継続する `extension-event` 購読を管理する必要があります。通常の `@native.invoke` は要求・セッション ID を返さないため、`start` を呼ぶだけでは連携は完成しません。サービス仕様は[拡張の作成](/docs/moonbit/extensions)を参照してください。

## ライフサイクル

ウィンドウを一つ閉じても更新が止まらないよう、updater セッションはアプリのスコープで保持します。完了エラーと状態イベントは UI スレッドで処理します。クリーンアップ時に `stop` を送り、残りのリソースはプロバイダーの終了時に解放します。受理済みのインストーラーへの引き継ぎはセッション終了後も継続できます。

## 対応プラットフォーム

macOS は署名済みアプリアーカイブと Sparkle を使います。移植可能なバックエンドは Windows インストーラーと Linux AppImage に対応します。各対象ホストでビルドと検証を行ってください。バックエンドの存在だけでは全プラットフォームでの動作確認にはなりません。

## 更新の公開

`quickgui keygen --sparkle` で署名鍵を作成し、秘密鍵をリポジトリの外に保管します。`quickgui build` の生成物である appcast と署名済みアーカイブを、設定したダウンロード先に公開します。

## ネイティブ成果物

`[native].extensions` で updater 拡張のディレクトリを選択します。CLI はその中の `quickgui.extension.json` を読み取り、プロバイダーをパッケージ化します。MoonBit は Go の import を解析しません。macOS は Sparkle、他のプラットフォームは互換のネイティブ更新サービスを使います。[拡張の作成](/docs/moonbit/extensions)と同じ ABI から呼び出します。
