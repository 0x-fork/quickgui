MoonBit アプリにはモジュール、実行可能パッケージ、QuickGUI 設定があります。Bun は開発ツールを実行し、完成したアプリはネイティブ実行ファイルになります。

## 生成されるファイル

```text
my-app/
  main/
    main.mbt
    moon.pkg
  moon.mod
  quickgui.toml
  package.json
```

`moon.mod` はアプリのモジュールと SDK 依存を宣言します。`main/moon.pkg` は実行ファイルで使うパッケージをインポートします。

```moonbit
import {
  "egoist/quickgui/ui",
  "egoist/quickgui/native",
}

pkgtype(kind: "executable")
```

## アプリケーションのエントリ

`main/main.mbt` に `main` とコンポーネントを定義します。`@native.run` を一度呼び、`@ui.window(component)` でウィンドウを作成します。各コンポーネントは `@ui.Element` を返します。大きなアプリは通常の MoonBit パッケージに分割します。

## 設定

```toml
name = "My App"
identifier = "com.example.myapp"
frontend = "moonbit"
entry = "main"

[native]
extensions = []
```

`frontend` は MoonBit を選び、省略すると Go になります。`entry` は実行可能パッケージのディレクトリです。`quickgui.extension.json` を含む拡張ディレクトリを `native.extensions` に追加します。`quickgui build` は実行ファイル、選択したネイティブライブラリ、フォント、設定したリソースをパッケージ化します。`.quickgui` は開発出力とキャッシュ用なのでコミットしないでください。

## パッケージ

| パッケージ | 用途 |
| --- | --- |
| `egoist/quickgui/ui` | コンポーネント、スタイル、シグナル、メモ、副作用、クリーンアップ、ルーティング。 |
| `egoist/quickgui/native` | ウィンドウ、イベント、ダイアログ、メニュー、サービス、拡張。 |
| `egoist/quickgui/protocol` | コアのプロパティ定数と変更値の型。 |

## ローカル開発

SDK が公開されるまでは、アプリと QuickGUI チェックアウトの共通の親ディレクトリに `moon.work` を作ります。パスはワークスペースからの相対パスです。

```toml
members = ["quickgui/moonbit", "my-app"]
```

`quickgui` から `bun packages/cli/src/cli.ts dev --project ../my-app` を実行すると、公開パッケージを使わずローカル CLI を利用できます。
