MoonBit から macOS のネイティブコントロールをホストします。

## Host

`@ui.swift_ui_host([])` の内側で SwiftUI コントロールを作ります。macOS 専用です。対応する全コントロールをサイドバーに掲載しています。

```moonbit
fn native_toggle() -> @ui.Element {
  let (enabled, set_enabled) = @ui.create_signal(false)
  @ui.swift_ui_host([
    @ui.swift_ui_toggle()
    .checked(enabled())
    .on_bool_input(value => set_enabled(value))
    .label("Notifications"),
  ])
}
```

## ネイティブコントロール

SwiftUI ではボタン、スライダー、トグル、進行状況、ステッパー、通常・セキュア入力、ピッカー、日付・色ピッカー、ゲージを使えます。プロパティとイベントはサイドバーの各コントロールを参照してください。

## 制御値

`.bind_value(...)`、`.bind_checked(...)`、`.bind_number(...)` でシグナルを接続し、対応する入力コールバックで更新します。

## サイズ

ホストに `.swift_ui_match_contents_horizontal(true)` と `.swift_ui_match_contents_vertical(true)` を指定すると内容に合わせてサイズを決めます。`.width(...)` と `.height(...)` でホストを制限できます。QuickGUI スタイルはホスト境界に、ネイティブ修飾子は内部の SwiftUI コントロールに適用します。

## 対応プラットフォーム

SwiftUI ホスティングには macOS とホストライブラリーのネイティブブリッジが必要です。外観は OS のバージョンに従います。スタイルと逆方向ホストは[修飾子とホスティング](/docs/moonbit/swift-ui-hosting)を参照してください。
