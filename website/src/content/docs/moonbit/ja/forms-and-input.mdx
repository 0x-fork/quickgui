編集可能な値はシグナルに保存し、イベントハンドラーで変更を書き戻します。選択、フォーカス、テキスト編集の動作はネイティブ入力が保持します。

## テキスト入力

```moonbit
fn name_form() -> @ui.Element {
  let (name, set_name) = @ui.create_signal("")
  let (saved, set_saved) = @ui.create_signal("")
  let submit = () => set_saved(name())
  @ui.div([
    @ui.text("Name"),
    @ui.input()
    .on_input(value => set_name(value))
    .on_submit(_ => submit())
    .value(name()),
    @ui.button("Save").on_click(submit).disabled(name() == ""),
    @ui.text("Saved: \{saved()}"),
  ])
  .flex_col()
  .gap(12)
}
```

`on_input` は更新後の文字列、`on_submit` は送信された文字列を受け取ります。プログラムからフォーカスを移すには保持した入力ハンドルで `.focus()` を呼びます。

### 無効と読み取り専用

`.bind_disabled(() => disabled.get())` は実際のネイティブ操作状態を変えます。薄く表示するだけでは無効になりません。読み取り専用には `.property(@protocol.READ_ONLY, @protocol.Boolean(true))`、プレースホルダーには `.property(@protocol.PLACEHOLDER, @protocol.Text("Name"))` を使います。定数を使うには `egoist/quickgui/protocol` をインポートします。

外観は `bind_style` またはネイティブの状態スタイルで、動作は対応するプロパティで設定します。

## フィールド

`@ui.field([])` の Label、Control、Description、Error スロットでラベルと検証内容を関連付けます。意味上の関連はネイティブコアが管理します。検証とフォーム連携は [Field](/docs/moonbit/components/field) を参照してください。

## 選択コントロール

[Checkbox](/docs/moonbit/components/checkbox)、[Switch](/docs/moonbit/components/switch)、[Select](/docs/moonbit/components/select)など、サイドバーの各コントロールを使用してください。ヘルパーがネイティブの役割、値、スコープを接続します。読み取り専用または無効なコントロールでは既定の変更を抑止します。`Event.prevent_default()` でイベントの既定動作をキャンセルできます。

## Select

`@ui.select([]).items(items).active_value(value())` はネイティブ項目モデルからピッカーを作成します。変更コールバックで選択シグナルを書き戻します。単一・複数選択とポップアップのパーツは [Select](/docs/moonbit/components/select) を参照してください。

## イベント

`.on_input(handler)` と `.on_submit(handler)` は文字列を受け取ります。意味を持つコントロールは専用コールバックで変更を通知します。伝播や `Event.prevent_default()` が必要ならイベントを受け取るハンドラーを使います。動作には `.disabled(...)` と `.read_only(...)` を指定し、見た目だけで編集を無効にしないでください。
