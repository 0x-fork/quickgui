Enable the `updater` feature on the `quickgui` crate. Rust apps call `UpdateClient` directly.

## Configuration

Generate a signing key pair and copy the public key into the project:

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

Keep the private `quickgui-update.key` out of version control.

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: ".",
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

Enable the crate feature. Keep the crate version already in your project:

```toml
[dependencies]
quickgui = { version = "...", features = ["updater"] }
```

The CLI embeds the public key, version, identifier, and feed URL. A `darwin-arm64` build checks `https://downloads.example.com/my-app/appcast-darwin-arm64.xml` unless you set `updates.feedUrl`.

## Application usage

Construct one `UpdateClient` after the application starts, outside `View::render`:

```rust
use quickgui::{UpdateClient, default_update_target};

let client = UpdateClient::new("1.0.0", public_key)?
    .target(default_update_target())?;
if let Some(update) = client.check("https://downloads.example.com/my-app/{{target}}/latest.json")? {
    let staged = client.download_and_stage(&update)?;
    client.install_staged(&staged)?;
}
```

A Check for Updates action can call `check` from a listener and `cx.invalidate()` when UI should show progress.

## Lifecycle

Keep the client for the process lifetime. Closing a window must not drop it if other windows still need update status.

## Platforms

macOS can emit Sparkle appcasts when `updates.publicKey` is set. Windows and Linux use signed JSON manifests. Point development builds at a disposable feed.

## Publishing

```sh
bun run build --update-manifest
```

Signing needs the private key in `updates.minisignSecretKey` or `QUICKGUI_MINISIGN_SECRET_KEY`. The private key is never embedded in the application.

## Native artifacts

Packaged Rust apps include the executable and `quickgui.json`. The updater reads the embedded public key and current version from that metadata.
