フォーカスの閉じ込め、閉じる操作、正確なトランジション完了を備えたウィンドウ内モーダルです。

## インポート

`quickgui` から `Dialog` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let dialog = Dialog::new("save", open);
dialog.root().child(dialog.title_with(text("Save changes")))
```

## 構成

- `Dialog::root`
- `Dialog::trigger`
- `Dialog::portal`
- `Dialog::backdrop`
- `Dialog::viewport`
- `Dialog::popup`
- `Dialog::title`
- `Dialog::description`
- `Dialog::close`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `default_open` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `on_open_change` | コアが決定した開閉を通知します。 |
| `dismiss_on_escape` | Escape キーでサーフェスを閉じられるようにします。 |
| `exit_duration` | 閉じる内容を、正確な終了トランジション時間だけマウントしたままにします。 |
