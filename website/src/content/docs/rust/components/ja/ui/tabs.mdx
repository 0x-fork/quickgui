ラベル付きパネルを切り替え、キーボードによる自動または手動のアクティブ化に対応します。

## インポート

`quickgui` から `Tabs` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let tabs = Tabs::new("settings", "general");
tabs.root().flex_col().child(tabs.list().flex_row())
```

## 構成

- `Tabs::root`
- `Tabs::list`
- `Tabs::tab`
- `Tabs::indicator`
- `Tabs::panel`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `default_value` | コンポーネント自身が状態を管理するときの初期値です。 |
| `on_value_change` | コアが受け入れた値を通知します。 |
| `orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `activation` | フォーカスまたは明示的な押下で Tab をアクティブにするかどうかです。 |
