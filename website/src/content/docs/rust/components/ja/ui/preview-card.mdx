現在の画面を変えず、トリガーの横により詳しいホバー／フォーカスプレビューを表示します。

## インポート

`quickgui` から `PreviewCard` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let card = PreviewCard::new("file", &state);
card.trigger_with(text("README.md"))
```

## 構成

- `PreviewCard::root`
- `PreviewCard::trigger`
- `PreviewCard::portal`
- `PreviewCard::backdrop`
- `PreviewCard::positioner`
- `PreviewCard::popup`
- `PreviewCard::arrow`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `default_open` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `delay` | 開くまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `close_delay` | 閉じるまでの、コアが管理する遅延時間（ミリ秒）です。 |
| `placement` | 衝突処理前に優先する配置方向です。 |
