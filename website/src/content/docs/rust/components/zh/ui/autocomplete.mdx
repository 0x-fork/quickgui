筛选自由输入文本的建议项，无需选中某个值。

## 导入

从 `quickgui` 导入 `Autocomplete`。

```rust
use quickgui::*;
```

## 用法

```rust
let mut state = AutocompleteState::new(items);
state.set_query("qui");
div().child(text(state.query()))
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `items` | 用于选项或键盘导航的有限声明模型。 |
| `input_value` | Combobox 或 Autocomplete 使用的可编辑查询文本。 |
| `filter_mode` | 由核心管理的包含、前缀、模糊或禁用筛选模式。 |
| `on_input_value_change` | 报告核心保留的可编辑查询文本。 |
| `on_commit` | 报告一次明确的提交边界及最终值详情。 |
