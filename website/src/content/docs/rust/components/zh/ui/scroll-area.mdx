组合可滚动视口，以及可由调用方设置样式的滚动条、滑块和角落。

## 导入

从 `quickgui` 导入 `ScrollArea`。

```rust
use quickgui::*;
```

## 用法

```rust
let area = ScrollArea::new("log");
area.viewport().h(160.0).overflow_hidden()
```

## 结构

- `ScrollArea::root`
- `ScrollArea::viewport`
- `ScrollArea::content`
- `ScrollArea::scrollbar`
- `ScrollArea::thumb`
- `ScrollArea::corner`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `viewport_size` | 声明的滚动视口范围。 |
| `content_size` | 声明的滚动内容范围。 |
| `overflow_edge_threshold` | 仍视为位于边缘的最大距离。 |
| `on_scroll_state_change` | 报告限制后的偏移量和派生的溢出状态。 |
