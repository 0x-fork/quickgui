在当前窗口中，将调用方设置样式的内容放在锚点旁。

## 导入

从 `quickgui` 导入 `Popover`。

```rust
use quickgui::*;
```

## 用法

```rust
let popover = Popover::new("help-trigger", "help-popup", open)
    .side(AnchorSide::Bottom)
    .side_offset(8.0);
let mut root = popover.root().child(
    popover.trigger().on_click(toggle).child("Account"),
);
if popover.is_open() {
    root = root.child(popover.positioner().child(
        popover.popup().w(240.0).p(16.0).on_dismiss(dismiss).children([
            popover.title().child("Account"),
            popover.description().child("Manage your account settings."),
            popover.close("Close").on_click(dismiss).child("Done"),
        ]),
    ));
}
root
```

## 结构

- `Popover::root`
- `Popover::trigger`
- `Popover::surface`
- `Popover::portal`
- `Popover::backdrop`
- `Popover::positioner`
- `Popover::popup`
- `Popover::arrow`
- `Popover::viewport`
- `Popover::title`
- `Popover::description`
- `Popover::close`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `open` | 受控的打开状态。 |
| `default_open` | 组件自行管理打开状态时的初始状态。 |
| `on_open_change` | 报告核心做出的打开或关闭决定。 |
| `side` | 碰撞处理前的首选放置方向。 |
| `align` | 在放置交叉轴上的首选对齐方式。 |
| `modal` | 将焦点限制在界面内，并阻止与后方内容交互。 |
