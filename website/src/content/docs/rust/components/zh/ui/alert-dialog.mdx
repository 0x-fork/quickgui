专注确认操作的对话框变体，默认采用更严格的背景点击关闭策略。

## 导入

从 `quickgui` 导入 `Dialog`。

```rust
use quickgui::*;
```

## 用法

```rust
let dialog = Dialog::alert("quit", open);
dialog.root().child(dialog.title_with(text("Quit without saving?")))
```

## 结构

- `Dialog::root`
- `Dialog::trigger`
- `Dialog::portal`
- `Dialog::backdrop`
- `Dialog::viewport`
- `Dialog::popup`
- `Dialog::title`
- `Dialog::description`
- `Dialog::close`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `open` | 受控的打开状态。 |
| `default_open` | 组件自行管理打开状态时的初始状态。 |
| `on_open_change` | 报告核心做出的打开或关闭决定。 |
| `dismiss_on_escape` | 允许按 Escape 键关闭界面。 |
| `exit_duration` | 在精确的退出过渡时长内保持关闭中的内容已挂载。 |
