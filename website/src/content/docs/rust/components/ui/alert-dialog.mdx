The confirmation-focused dialog variant with stricter backdrop-dismissal defaults.

## Import

Import `Dialog` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let dialog = Dialog::alert("quit", open);
dialog.root().child(dialog.title_with(text("Quit without saving?")))
```

## Anatomy

- `Dialog::root`
- `Dialog::trigger`
- `Dialog::portal`
- `Dialog::backdrop`
- `Dialog::viewport`
- `Dialog::popup`
- `Dialog::title`
- `Dialog::description`
- `Dialog::close`

## Key props

| Prop | Purpose |
| --- | --- |
| `open` | Controlled open state. |
| `default_open` | Initial state when the component owns whether it is open. |
| `on_open_change` | Reports an open or close decision from the core. |
| `dismiss_on_escape` | Allows Escape to dismiss the surface. |
| `exit_duration` | Keeps closing content mounted for the exact exit transition duration. |
