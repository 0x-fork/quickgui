A bounded one-time-code editor made from individually styled input cells.

## Import

Import `OtpField` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let field = OtpField::new("code");
field.root().flex_row().gap(8.0)
```

## Anatomy

- `OtpField::root`
- `OtpField::input`
- `OtpField::separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `length` | Number of one-time-code input slots, bounded to twelve. |
| `on_value_change` | Reports the value accepted by the core. |
| `disabled` | Prevents interaction and exposes the disabled state. |
