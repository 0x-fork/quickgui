A disclosure-style navigation surface with animated direction, viewport, and popup parts.

## Import

Import `NavigationMenu` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let menu = NavigationMenu::new("docs", &state, &items);
menu.root().flex_row()
```

## Anatomy

- `NavigationMenu::root`
- `NavigationMenu::list`
- `NavigationMenu::item`
- `NavigationMenu::trigger`
- `NavigationMenu::icon`
- `NavigationMenu::content`
- `NavigationMenu::link`
- `NavigationMenu::portal`
- `NavigationMenu::positioner`
- `NavigationMenu::popup`
- `NavigationMenu::viewport`
- `NavigationMenu::arrow`
- `NavigationMenu::backdrop`

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `default_value` | Initial value when the component owns its state. |
| `on_value_change` | Reports the value accepted by the core. |
| `orientation` | Horizontal or vertical layout and keyboard direction. |
| `delay` | Core-owned delay in milliseconds before opening. |
