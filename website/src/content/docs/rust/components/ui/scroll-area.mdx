Composes a scrollable viewport with caller-styled scrollbars, thumbs, and corner.

## Import

Import `ScrollArea` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let area = ScrollArea::new("log");
area.viewport().h(160.0).overflow_hidden()
```

## Anatomy

- `ScrollArea::root`
- `ScrollArea::viewport`
- `ScrollArea::content`
- `ScrollArea::scrollbar`
- `ScrollArea::thumb`
- `ScrollArea::corner`

## Key props

| Prop | Purpose |
| --- | --- |
| `viewport_size` | Declared scroll viewport extent. |
| `content_size` | Declared scroll content extent. |
| `overflow_edge_threshold` | Distance from an edge that still counts as being at that edge. |
| `on_scroll_state_change` | Reports clamped offset and derived overflow state. |
