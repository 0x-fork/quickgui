A numeric editor with increment, decrement, and drag-to-scrub parts.

## Import

Import `NumberField` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let field = NumberField::new("amount", &state);
field.root().child(field.input_with(text_input(state.text())))
```

## Anatomy

- `NumberField::root`
- `NumberField::group`
- `NumberField::input`
- `NumberField::increment`
- `NumberField::decrement`
- `NumberField::scrub_area`
- `NumberField::scrub_area_cursor`

## Key props

| Prop | Purpose |
| --- | --- |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `default_value` | Initial value when the component owns its state. |
| `min` | Minimum accepted value. |
| `max` | Maximum accepted value. |
| `step` | Increment used by keyboard, pointer, or native control input. |
| `on_value_change` | Reports the value accepted by the core. |
