Combines editable text, filtering, optional chips, and a native suggestion surface.

## Import

Import `Combobox` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let mut state = ComboboxState::new(items);
state.set_query("pro");
div().child(text_input(state.query()))
```

## Key props

| Prop | Purpose |
| --- | --- |
| `items` | Bounded declaration model used for options or keyboard navigation. |
| `value` | Controlled value. The precise value type follows this component’s contract. |
| `input_value` | Editable query text used by a combobox or autocomplete. |
| `multiple` | Allows more than one value to be selected or opened. |
| `filter_mode` | Core-owned contains, prefix, fuzzy, or disabled filtering. |
| `on_value_change` | Reports the value accepted by the core. |
