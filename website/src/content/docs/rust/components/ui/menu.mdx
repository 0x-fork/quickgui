A fully composable menu with submenus, groups, links, checkbox items, and radio items.

## Import

Import `PopoverMenu` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let menu = PopoverMenu::new("actions", &state);
menu.root().child(menu.trigger().child("Actions"))
```

## Anatomy

- `PopoverMenu::root`
- `PopoverMenu::trigger`
- `PopoverMenu::portal`
- `PopoverMenu::backdrop`
- `PopoverMenu::positioner`
- `PopoverMenu::popup`
- `PopoverMenu::arrow`
- `PopoverMenu::item`
- `PopoverMenu::link_item`
- `PopoverMenu::submenu_root`
- `PopoverMenu::submenu_trigger`
- `PopoverMenu::group`
- `PopoverMenu::group_label`
- `PopoverMenu::radio_group`
- `PopoverMenu::radio_item`
- `PopoverMenu::radio_item_indicator`
- `PopoverMenu::checkbox_item`
- `PopoverMenu::checkbox_item_indicator`
- `PopoverMenu::separator`

## Key props

| Prop | Purpose |
| --- | --- |
| `open` | Controlled open state. |
| `default_open` | Initial state when the component owns whether it is open. |
| `on_open_change` | Reports an open or close decision from the core. |
| `orientation` | Horizontal or vertical layout and keyboard direction. |
| `loop_focus` | Wraps keyboard highlight at the ends of the current menu level. |
