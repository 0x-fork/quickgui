QuickGUI has in-window overlays, native child-window popovers, and operating-system dialogs. Choose the surface based on what may escape the current window and who owns its behavior.

## Popover

`Popover` stays in the current retained window. Compose its trigger, portal, positioner, popup, and optional arrow or backdrop.

```tsx
<Popover.Root open={open()} onOpenChange={setOpen}>
  <Popover.Trigger><Text>Open</Text></Popover.Trigger>
  <Popover.Portal>
    <Popover.Positioner side="bottom" sideOffset={8}>
      <Popover.Popup><Popover.Arrow /><Settings /></Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>
```

The core flips and re-aligns a preferred placement when it would collide with the viewport.

## Dialog

`Dialog` contains focus, restores previous focus on dismissal, and holds closing content mounted for an exact `exitDuration`.

```tsx
<Dialog.Root open={open()} onOpenChange={setOpen} exitDuration={160}>
  <Dialog.Trigger><Text>Edit profile</Text></Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Viewport>
      <Dialog.Popup>
        <Dialog.Title><Text>Edit profile</Text></Dialog.Title>
        <Dialog.Close><Text>Done</Text></Dialog.Close>
      </Dialog.Popup>
    </Dialog.Viewport>
  </Dialog.Portal>
</Dialog.Root>
```

Use `AlertDialog` for consequential confirmation. It refuses backdrop dismissal by default.

## System popover

`SystemPopover` creates a native child window, so its content can extend beyond the owner window.

```tsx
<SystemPopover.Root>
  <SystemPopover.Trigger><Text>Show details</Text></SystemPopover.Trigger>
  <SystemPopover.Content width={320} height={180} placement="bottom">
    <Details />
  </SystemPopover.Content>
</SystemPopover.Root>
```

## Native dialogs

File pickers, message boxes, and similar operating-system dialogs come from `@quickgui/native`. Their results are Promise-based.

```tsx
const result = await dialog.open({
  title: "Choose a project",
  properties: ["openDirectory"],
});
```
