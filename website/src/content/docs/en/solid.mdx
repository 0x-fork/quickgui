QuickGUI uses Solid for composition and reactivity while the Rust core owns retained native state, layout, rendering, input, and accessibility.

## Rendering model

`createRenderer` mounts one Solid root into a `Window`. JSX creates retained QuickGUI nodes rather than DOM elements.

```tsx
new Window({
  title: "Tasks",
  renderer: createRenderer(() => <Tasks />),
});
```

Signals update only the affected retained properties. QuickGUI redraws damaged regions and stays idle when nothing changes.

## Reactive state

Use ordinary Solid signals, memos, resources, and control flow.

```tsx
function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ gap: 8 }}>
      <Text>{count()}</Text>
      <Button onClick={() => setCount((value) => value + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}
```

Native callbacks enter Solid asynchronously. A callback receives the result already decided by the core; JavaScript never synchronously asks the native main thread for a value.

## Window lifecycle

Create windows after `app.whenReady()`. Re-create the main window from the `reopen` event when macOS activates an app with no visible windows.

```tsx
app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});
```

## Current window

Use `useWindow()` from a component mounted by a QuickGUI window renderer when an action belongs to that window.

```tsx
function CloseButton() {
  const window = useWindow();
  return <Button onClick={() => window.close()}><Text>Close</Text></Button>;
}
```

## Routing

The Solid router projects QuickGUI's core-owned route table and bounded memory history.

```tsx
<Router initialPath="/">
  <Route path="/" component={Shell}>
    <Route path="/" component={Home} />
    <Route path="/projects/:id" component={Project} />
  </Route>
</Router>
```

Use `Link`, `Outlet`, `useLocation`, `useParams`, `useSearchParams`, `useNavigate`, and `useRouter` below `Router`.
