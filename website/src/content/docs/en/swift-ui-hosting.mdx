SwiftUI modifiers style native controls. Reverse hosting puts an ordinary QuickGUI subtree inside SwiftUI.

## Modifiers

Apply modifier factories from `ui.SwiftUI` in order through `Modifiers`. Available factories include ButtonStyle, ButtonBorderShape, ControlSize, LabelStyle, Tint, and Disabled.

```go
ui.SwiftUI.Button(ui.SwiftUIButtonProps{
	Label: "Create project",
	Modifiers: []ui.SwiftUIModifier{
		ui.SwiftUI.ButtonStyle("borderedProminent"),
		ui.SwiftUI.ControlSize("large"),
		ui.SwiftUI.Tint("#f97316"),
	},
})
```

## Liquid Glass

On supported systems, request the native glass button style with `ui.SwiftUI.ButtonStyle("glass")`. macOS owns the final appearance.

## Reverse hosting

`ui.SwiftUI.QuickGUIHostView` owns a QuickGUI subtree inside the native hierarchy. Provide its size and declare children in a callback so they mount under the embedded window’s lifecycle.

```go
func SwiftUiQuickguiHostViewExample() {
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.QuickGUIHostView(
				ui.SwiftUIQuickGUIHostViewProps{Width: 320, Height: 180},
				func() {
					ui.View(
						ui.Width("100%"),
						ui.Height("100%"),
						ui.Padding(16),
						"QuickGUI inside SwiftUI",
					)
				},
			)
		},
	)
}
```

## SwiftUI popover

The SwiftUI popover composes a native trigger through `Render`. Its content can reverse-host interactive QuickGUI components.

```go
func SwiftUiPopoverExample() {
	open, setOpen := ui.CreateSignal(false)
	ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() {
			ui.SwiftUI.Popover.Root(
				ui.SwiftUIPopoverProps{
					IsPresented:         open,
					OnIsPresentedChange: setOpen,
				},
				func() {
					ui.SwiftUI.Popover.Trigger(ui.SwiftUIPopoverTriggerProps{Render: func() { ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Account"}) }})
					ui.SwiftUI.Popover.Content(
						ui.SwiftUIPopoverContentProps{},
						func() {
							ui.SwiftUI.QuickGUIHostView(
								ui.SwiftUIQuickGUIHostViewProps{Width: 240, Height: 120},
								"Account settings",
							)
						},
					)
				},
			)
		},
	)
}
```
