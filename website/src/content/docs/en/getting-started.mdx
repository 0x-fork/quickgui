QuickGUI lets you build native desktop applications with Solid. There is no DOM or webview: Solid updates a retained tree that QuickGUI lays out and renders on the GPU.

## Requirements

- macOS 13 or newer
- [Bun](https://bun.sh/) 1.3 or newer
- Xcode Command Line Tools

<Note>
  The Solid host currently targets macOS. The Rust framework also compiles for Windows and Linux, but those platforms are not yet the supported path for Solid applications.
</Note>

## Create a project

Scaffold a project and start its native development app:

```bash
bunx @quickgui/cli init my-app
cd my-app
bun run dev
```

The development command watches your source and replaces the running app only after the next build opens its first native window.

## Your first window

Application and window APIs come from `@quickgui/native`. Solid components and the renderer come from `@quickgui/solid`.

```tsx
import { app, Window } from "@quickgui/native";
import { Button, Text, View, createRenderer } from "@quickgui/solid";
import { createSignal } from "solid-js";

function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ flex: 1, alignItems: "center", justifyContent: "center", gap: 12 }}>
      <Text>Count: {count()}</Text>
      <Button onClick={() => setCount((value) => value + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}

function openMainWindow() {
  new Window({
    title: "My App",
    width: 720,
    height: 480,
    renderer: createRenderer(() => <Counter />),
  });
}

app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});

await app.whenReady();
openMainWindow();
```

Always await `app.whenReady()` before creating the first window. Each `Window` owns its renderer root and disposes it when the window closes.

## Run and build

```bash
bun run dev
bun run build
```

On macOS, a production build is written under `dist/darwin-*`. Signing and notarization can be configured when you are ready to distribute.
