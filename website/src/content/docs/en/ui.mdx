Go components create retained native nodes. Signals subscribe individual bindings to the state they read.

## Rendering model

Every component uses `func()`, including window roots, routes, conditional branches, and children blocks. It declares zero or more children without returning a node. Components run once when mounted. UI calls inside a children block attach to that block’s parent. Use normal Go `if` and `for` for static construction; use `ui.Show` or `ui.For` when a signal must change the child structure.

```go
func ViewExample() {
	ui.View(
		ui.Padding(20),
		ui.Gap(12),
		func() {
			ui.Text("Hello from Go")
			ui.Button(ui.OnClick(func() {}), "Continue")
		},
	)
}
```

## Reactive state

Pass an accessor for changing text or properties. Calling `count()` while constructing a string captures its current value; placing the call in `func() string` keeps it reactive. Event handlers batch writes automatically. Use `ui.Batch` for a group of writes elsewhere, and `ui.CreateMemo` for derived values.

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			ui.FontSize(20),
			func() string { return fmt.Sprintf("Count: %d", count()) },
		)
		ui.Button(ui.OnClick(func() { setCount(count() + 1) }), "Increment")
	})
}
```

## Window lifecycle

`WindowOptions.Component` creates one reactive root per window. Closing the window disposes its nodes and effects. Register resource cleanup with `ui.OnCleanup`. For background work, `ui.Async` delivers its result back to the UI goroutine and cancels when its component is disposed.

## Current window

Capture `native.CurrentWindow()` while the component is mounting, then use the captured window in callbacks. Do not look it up from an unrelated goroutine. Window events and native requests expose asynchronous callbacks.

```go
func CloseButton() {
	window := native.CurrentWindow()
	ui.Button(ui.OnClick(func() { window.Close() }), "Close window")
}
```

## Routing

Declare routes with `ui.Route` and `ui.Layout`. A layout mounts its matched child with `ui.Outlet`. Read parameters with `ui.UseParams`, or navigate with `ui.UseRouter`.

```go
func RouterExample() {
	ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route(
				"/",
				func() {
					ui.Link(
						ui.LinkProps{Href: "/settings"},
						"Settings",
					)
				},
			),
			ui.Route(
				"/settings",
				func() { ui.Text("Settings") },
			),
		},
		Fallback: func() { ui.Text("Page not found") },
	})
}
```
