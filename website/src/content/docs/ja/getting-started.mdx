QuickGUI では Solid を使ってネイティブのデスクトップアプリを構築できます。DOM も WebView も使いません。Solid が保持型ツリーを更新し、QuickGUI がレイアウトと GPU 描画を担います。

## 動作要件

- macOS 13 以降
- [Bun](https://bun.sh/) 1.3 以降
- Xcode Command Line Tools

<Note>
  現在、Solid ホストの対象は macOS です。Rust フレームワーク自体は Windows と Linux でもコンパイルできますが、Solid アプリで正式に対応している経路ではありません。
</Note>

## プロジェクトを作成

プロジェクトを生成し、ネイティブの開発アプリを起動します。

```bash
bunx @quickgui/cli init my-app
cd my-app
bun run dev
```

開発コマンドはソースを監視します。次のビルドが最初のネイティブウィンドウを開いてから、実行中のアプリを置き換えます。

## 最初のウィンドウ

アプリケーションとウィンドウの API は `@quickgui/native`、Solid コンポーネントとレンダラーは `@quickgui/solid` から読み込みます。

```tsx
import { app, Window } from "@quickgui/native";
import { Button, Text, View, createRenderer } from "@quickgui/solid";
import { createSignal } from "solid-js";

function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ flex: 1, alignItems: "center", justifyContent: "center", gap: 12 }}>
      <Text>Count: {count()}</Text>
      <Button onClick={() => setCount((value) => value + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}

function openMainWindow() {
  new Window({
    title: "My App",
    width: 720,
    height: 480,
    renderer: createRenderer(() => <Counter />),
  });
}

app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});

await app.whenReady();
openMainWindow();
```

最初のウィンドウを作る前に、必ず `app.whenReady()` を待ってください。各 `Window` はそれぞれのレンダラールートを所有し、ウィンドウを閉じると破棄します。

## 実行とビルド

```bash
bun run dev
bun run build
```

macOS では、本番ビルドが `dist/darwin-*` の下に出力されます。配布するときに署名と公証を設定できます。
