QuickGUI は Solid をコンポーネント構成とリアクティビティに使い、保持型のネイティブ状態、レイアウト、描画、入力、アクセシビリティは Rust コアが管理します。

## レンダリングモデル

`createRenderer` は 1 つの Solid ルートを `Window` にマウントします。JSX が作るのは DOM 要素ではなく、保持型の QuickGUI ノードです。

```tsx
new Window({
  title: "Tasks",
  renderer: createRenderer(() => <Tasks />),
});
```

Signal は影響を受ける保持プロパティだけを更新します。QuickGUI は変更された領域を再描画し、何も変わらなければ待機します。

## リアクティブな状態

通常どおり Solid の Signal、Memo、Resource、制御フローを使えます。

```tsx
function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ gap: 8 }}>
      <Text>{count()}</Text>
      <Button onClick={() => setCount((value) => value + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}
```

ネイティブのコールバックは非同期で Solid に入ります。コールバックが受け取るのはコアがすでに決定した結果です。JavaScript がネイティブのメインスレッドへ同期的に値を問い合わせることはありません。

## ウィンドウのライフサイクル

ウィンドウは `app.whenReady()` の完了後に作成します。表示中のウィンドウがないアプリを macOS がアクティブにしたときは、`reopen` イベントからメインウィンドウを作り直します。

```tsx
app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});
```

## 現在のウィンドウ

操作が特定のウィンドウに属する場合は、QuickGUI のウィンドウレンダラーがマウントしたコンポーネント内で `useWindow()` を使います。

```tsx
function CloseButton() {
  const window = useWindow();
  return <Button onClick={() => window.close()}><Text>Close</Text></Button>;
}
```

## ルーティング

Solid Router は、QuickGUI のコアが管理するルートテーブルと上限付きメモリ履歴を投影します。

```tsx
<Router initialPath="/">
  <Route path="/" component={Shell}>
    <Route path="/" component={Home} />
    <Route path="/projects/:id" component={Project} />
  </Route>
</Router>
```

`Router` の下では、`Link`、`Outlet`、`useLocation`、`useParams`、`useSearchParams`、`useNavigate`、`useRouter` を使えます。
