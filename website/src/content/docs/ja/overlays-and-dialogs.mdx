アプリ独自のスタイルには QuickGUI オーバーレイ、ファイル選択やアラートにはネイティブダイアログを使います。

## Popover

Popover はトリガー、Positioner、Popup を組み合わせます。指定した方向は優先設定で、コアが衝突を解決します。ルート内の `ui.UsePopoverPlacement` で確定位置を取得できます。

```go
func PopoverExample() {
	ui.Popover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.Popover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.Popover.Positioner(
				ui.PopoverPositionerProps{},
				func() {
					ui.Popover.Popup(
						ui.PopoverPopupProps{PartProps: ui.PartProps{Style: ui.Style{
							Width:   240,
							Padding: 16,
						}}},
						func() {
							ui.Popover.Title(ui.PartProps{}, "Account")
							ui.Popover.Close(ui.PartProps{}, "Done")
						},
					)
				},
			)
		},
	)
}
```

## Dialog

モーダル内容は `Dialog.Portal` の下で作成します。`Dialog.Title` と `Dialog.Description` がアクセシブルな名前と説明を提供します。`AlertDialog` は確認の意味を加えます。制御されたルートは次の開閉状態とその理由を受け取ります。

```go
func DialogExample() {
	ui.Dialog.Root(
		ui.DialogRootProps{},
		func() {
			ui.Dialog.Trigger(ui.PartProps{}, "Open dialog")
			ui.Dialog.Portal(
				ui.PartProps{},
				func() {
					ui.Dialog.Backdrop(ui.PartProps{})
					ui.Dialog.Viewport(
						ui.PartProps{},
						func() {
							ui.Dialog.Popup(
								ui.DialogPopupProps{},
								func() {
									ui.Dialog.Title(ui.PartProps{}, "Confirm action")
									ui.Dialog.Description(
										ui.PartProps{},
										"Review the details before continuing.",
									)
									ui.Dialog.Close(ui.PartProps{}, "Cancel")
								},
							)
						},
					)
				},
			)
		},
	)
}
```

## システムポップオーバー

`ui.SystemPopover` は OS のポップオーバー内に内容をホストします。論理幅と高さを指定し、通常の QuickGUI の子を宣言します。

```go
func SystemPopoverExample() {
	ui.SystemPopover.Root(
		ui.PopoverRootProps{},
		func() {
			ui.SystemPopover.Trigger(ui.PopoverTriggerProps{}, "Account")
			ui.SystemPopover.Content(
				ui.PopoverContentProps{
					Width:     240,
					Height:    120,
					Placement: "bottom-start",
				},
				"Account settings",
			)
		},
	)
}
```

## ネイティブダイアログ

ネイティブダイアログは非同期コールバックを使います。レンダリング時に親ウィンドウを取得してリクエストへ明示的に渡します。キャンセルされた場合は `Canceled: true` が返ります。

```go
func OpenFolderButton() {
	window := native.CurrentWindow()
	ui.Button(
		ui.OnClick(func() {
			native.ShowOpenDialog(
				native.OpenDialogOptions{
					Window:     window,
					Title:      "Open folder",
					Properties: []string{"openDirectory"},
				},
				func(result native.OpenDialogResult, err error) {
					if err == nil && !result.Canceled {
						fmt.Println(result.FilePaths)
					}
				},
			)
		}),
		"Open folder",
	)
}
```
