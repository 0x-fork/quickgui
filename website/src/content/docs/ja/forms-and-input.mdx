QuickGUI のフォームコントロールは、テキストサービスと操作をネイティブコア内に保ちながら、QuickGUI UI には使い慣れた制御値を公開します。

## テキスト入力

`Input` は既定で 1 行です。複数行には、便利な `TextArea` コンポーネントを使います。

```tsx
<Input
  value={name()}
  placeholder="Project name"
  onInput={(event) => setName(event.value ?? "")}
/>

<TextArea
  value={notes()}
  placeholder="Notes"
  onInput={(event) => setNotes(event.value ?? "")}
/>
```

## フィールド

`Field` は、1 つのコントロールをラベル、説明、有効性、エラー内容に関連付けます。

```tsx
<Field.Root required invalid={!email()} validationMessage="Enter an email address">
  <Field.Label><Text>Email</Text></Field.Label>
  <Field.Control value={email()} onInput={(event) => setEmail(event.value ?? "")} />
  <Field.Description><Text>Used for account recovery.</Text></Field.Description>
  <Field.Error><Text>Enter an email address.</Text></Field.Error>
</Field.Root>
```

## 選択コントロール

独立した真偽状態には `Checkbox` または `Switch`、1 つの値には `RadioGroup`、ツールバー形式の押下状態には `ToggleGroup` を使います。

```tsx
<RadioGroup.Root value={theme()} onValueChange={setTheme}>
  <Radio.Root value="light"><Radio.Indicator /><Text>Light</Text></Radio.Root>
  <Radio.Root value="dark"><Radio.Indicator /><Text>Dark</Text></Radio.Root>
</RadioGroup.Root>
```

## Select

`Select`、`Combobox`、`Autocomplete` は、上限のある項目モデルを宣言します。QuickGUI が絞り込みとネイティブ選択肢サーフェスの描画を担います。

```tsx
<Select.Root
  ariaLabel="Theme"
  items={[
    { value: "system", label: "System" },
    { value: "dark", label: "Dark" },
  ]}
  value={theme()}
  onValueChange={setTheme}
/>
```

## イベント

低レベル入力は `QuickGuiEvent` を通知します。複合コンポーネントの値コールバックは、正規化済みの値を第 1 引数、イベントを第 2 引数として受け取ります。ネイティブ側の決定は、コアが操作を処理した後に非同期で届きます。
