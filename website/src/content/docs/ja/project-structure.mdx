QuickGUI は scriptc で TypeScript と TSX をネイティブコードにコンパイルします。TypeScript 7 が JSX を変換し、Rust コアがレイアウト、描画、入力、プラットフォームのメインスレッドを管理します。Bun は開発ツールにのみ使用します。

## 生成されるファイル

```text
my-app/
├── src/
│   └── app.tsx
├── package.json
├── quickgui.config.ts
└── tsconfig.json
```

アプリの UI は `src/` に置きます。ほかのファイルやディレクトリを本番バンドルへ含めるには、`resources` オプションを使います。

## アプリケーションのエントリ

エントリモジュールはネイティブアプリの準備を待ち、ウィンドウを作成して、QuickGUI UI ルートを `createRenderer` に渡します。

```tsx
await app.whenReady();

new Window({
  title: "Notes",
  renderer: createRenderer(() => <NotesApp />),
});
```

アプリでは scriptc が対応する TypeScript と Node 互換 API のサブセットを使います。Bun のアプリ API や JavaScript エンジンを必要とするパッケージには対応しません。ネイティブウィンドウの操作と結果は非同期です。

## 設定

`quickgui.config.ts` は、コンパイルとパッケージ化の対象を CLI に伝えます。

```tsx
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  entry: "src/app.tsx",
  name: "Notes",
  identifier: "dev.example.notes",
  resources: ["assets"],
});
```

リリース専用のオプションには、アイコン、署名、公証、Mac App Store、アップデーターマニフェストがあります。

## パッケージ

| パッケージ | 用途 |
| --- | --- |
| `@quickgui/native` | アプリケーション、ウィンドウ、メニュー、ダイアログ、通知、ネイティブサービス |
| `@quickgui/ui` | QuickGUI UI レンダラー、プリミティブ、コンポーネント、ルーティング |
| `@quickgui/ui/swift-ui` | macOS 上で QuickGUI UI からホストするネイティブ SwiftUI コントロール |
| `@quickgui/cli` | プロジェクト作成、開発、本番パッケージ化 |
