QuickGUI は scriptc で TypeScript と TSX をネイティブコードにコンパイルします。TypeScript 7 が JSX を変換し、Rust コアがレイアウト、描画、入力、プラットフォームのメインスレッドを管理します。Bun は開発ツールにのみ使用します。

シグナルは `@quickgui/ui` から読み込みます。Setter は `setCount(count() + 1)` のように値を受け取ります。独自コンポーネントの動的なプロパティは `Accessor<T>` として宣言し、`props.value()` で読みます。`KeyedFor` は不変データの更新でも行を保持し、項目のアクセサーを子に渡します。非同期データは関数、シグナル、クリーンアップで管理します。

## レンダリングモデル

`createRenderer` は 1 つの QuickGUI UI ルートを `Window` にマウントします。JSX が作るのは DOM 要素ではなく、保持型の QuickGUI ノードです。

```tsx
new Window({
  title: "Tasks",
  renderer: createRenderer(() => <Tasks />),
});
```

Signal は影響を受ける保持プロパティだけを更新します。QuickGUI は変更された領域を再描画し、何も変わらなければ待機します。

## リアクティブな状態

通常どおり QuickGUI UI の Signal、Memo、Resource、制御フローを使えます。

```tsx
function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ gap: 8 }}>
      <Text>{count()}</Text>
      <Button onClick={() => setCount(count() + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}
```

ネイティブのコールバックは非同期で QuickGUI UI に入ります。コールバックが受け取るのはコアがすでに決定した結果です。JavaScript がネイティブのメインスレッドへ同期的に値を問い合わせることはありません。

## ウィンドウのライフサイクル

ウィンドウは `app.whenReady()` の完了後に作成します。表示中のウィンドウがないアプリを macOS がアクティブにしたときは、`reopen` イベントからメインウィンドウを作り直します。

```tsx
app.onReopen( ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});
```

## 現在のウィンドウ

操作が特定のウィンドウに属する場合は、QuickGUI のウィンドウレンダラーがマウントしたコンポーネント内で `Window.getCurrentWindow()` を使います。

```tsx
function CloseButton() {
  const window = Window.getCurrentWindow();
  return <Button onClick={() => window.close()}><Text>Close</Text></Button>;
}
```

## ルーティング

QuickGUI UI Router は、QuickGUI のコアが管理するルートテーブルと上限付きメモリ履歴を投影します。

```tsx
import { Router, route } from "@quickgui/ui/router";

<Router initialPath="/" routes={[
  route("/", Shell, [route("", Home), route("projects/:id", Project)]),
]} />;
```

`Router` の下では、`Link`、`Outlet`、`useLocation`、`useParams`、`useSearchParams`、`useNavigate`、`useRouter` を使えます。


ルートとクエリのパラメーターは `Map<string, string>` のアクセサーです。`params().get("id")` で読みます。ルート宣言は静的で、レイアウトは `Outlet` で一致した子ルートを描画します。
