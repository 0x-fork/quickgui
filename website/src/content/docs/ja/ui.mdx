Go コンポーネントは保持型のネイティブノードを作成します。各バインディングは読み取ったシグナルを購読します。

## レンダリングモデル

ウィンドウのルート、ルート画面、条件分岐、子要素ブロックはすべて `func()` を使います。コンポーネントはノードを返さず、0 個以上の子要素を宣言し、マウント時に一度実行されます。ブロック内の UI 呼び出しはその親に追加されます。静的な構築には通常の Go の `if` や `for` を使い、シグナルで子構造を変える場合は `ui.Show` や `ui.For` を使います。

```go
func ViewExample() {
	ui.View(
		ui.Padding(20),
		ui.Gap(12),
		func() {
			ui.Text("Hello from Go")
			ui.Button(ui.OnClick(func() {}), "Continue")
		},
	)
}
```

## リアクティブな状態

変化するテキストやプロパティにはアクセサーを渡します。文字列の構築時に `count()` を呼ぶと現在値だけを取得しますが、`func() string` 内ならリアクティブになります。イベント内の更新は自動的にバッチ処理されます。それ以外では `ui.Batch`、派生値には `ui.CreateMemo` を使います。

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			ui.FontSize(20),
			func() string { return fmt.Sprintf("Count: %d", count()) },
		)
		ui.Button(ui.OnClick(func() { setCount(count() + 1) }), "Increment")
	})
}
```

## ウィンドウのライフサイクル

`WindowOptions.Component` はウィンドウごとにリアクティブルートを作成します。閉じるとノードとエフェクトが破棄されます。リソースの後始末は `ui.OnCleanup` に登録します。バックグラウンド処理には `ui.Async` を使うと、結果が UI goroutine に返され、コンポーネント破棄時にキャンセルされます。

## 現在のウィンドウ

コンポーネントのマウント時に `native.CurrentWindow()` を取得し、コールバックではそのウィンドウを使います。無関係な goroutine から取得しないでください。ウィンドウイベントやネイティブリクエストは非同期コールバックで結果を返します。

```go
func CloseButton() {
	window := native.CurrentWindow()
	ui.Button(ui.OnClick(func() { window.Close() }), "Close window")
}
```

## ルーティング

`ui.Route` と `ui.Layout` でルートを宣言します。レイアウトは `ui.Outlet` で一致した子を表示します。パラメーターには `ui.UseParams`、ナビゲーションには `ui.UseRouter` を使います。

```go
func RouterExample() {
	ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route(
				"/",
				func() {
					ui.Link(
						ui.LinkProps{Href: "/settings"},
						"Settings",
					)
				},
			),
			ui.Route(
				"/settings",
				func() { ui.Text("Settings") },
			),
		},
		Fallback: func() { ui.Text("Page not found") },
	})
}
```
