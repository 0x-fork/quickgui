QuickGUI 使用 Solid 进行组合和响应式更新；保留式原生状态、布局、渲染、输入与无障碍则由 Rust 核心管理。

## 渲染模型

`createRenderer` 会把一个 Solid 根节点挂载到 `Window` 中。JSX 创建的是保留式 QuickGUI 节点，而不是 DOM 元素。

```tsx
new Window({
  title: "Tasks",
  renderer: createRenderer(() => <Tasks />),
});
```

Signal 只更新受影响的保留属性。QuickGUI 会重绘发生变化的区域；没有变化时则保持空闲。

## 响应式状态

照常使用 Solid 的 Signal、Memo、Resource 和控制流。

```tsx
function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ gap: 8 }}>
      <Text>{count()}</Text>
      <Button onClick={() => setCount((value) => value + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}
```

原生回调会异步进入 Solid。回调收到的是核心已经确定的结果；JavaScript 绝不会同步向原生主线程索取值。

## 窗口生命周期

请在 `app.whenReady()` 完成后创建窗口。当 macOS 激活一个没有可见窗口的应用时，通过 `reopen` 事件重新创建主窗口。

```tsx
app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});
```

## 当前窗口

如果某项操作属于特定窗口，请在由 QuickGUI 窗口渲染器挂载的组件中使用 `useWindow()`。

```tsx
function CloseButton() {
  const window = useWindow();
  return <Button onClick={() => window.close()}><Text>Close</Text></Button>;
}
```

## 路由

Solid 路由器会投影 QuickGUI 由核心管理的路由表和容量受限的内存历史。

```tsx
<Router initialPath="/">
  <Route path="/" component={Shell}>
    <Route path="/" component={Home} />
    <Route path="/projects/:id" component={Project} />
  </Route>
</Router>
```

在 `Router` 下使用 `Link`、`Outlet`、`useLocation`、`useParams`、`useSearchParams`、`useNavigate` 和 `useRouter`。
