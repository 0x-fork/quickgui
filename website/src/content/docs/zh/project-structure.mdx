生成的项目刻意保持精简。你的 TSX 在 Bun Worker 中运行，QuickGUI 则让平台事件循环留在原生主线程上。

## 生成的文件

```text
my-app/
├── src/
│   └── app.tsx
├── package.json
├── quickgui.config.ts
└── tsconfig.json
```

将应用界面放在 `src/` 中。通过 `resources` 选项，把其他文件和目录加入生产构建包。

## 应用入口

入口模块先等待原生应用就绪，然后创建窗口，并将 Solid 根节点传给 `createRenderer`。

```tsx
await app.whenReady();

new Window({
  title: "Notes",
  renderer: createRenderer(() => <NotesApp />),
});
```

源代码模块可以使用常规 Bun API。在托管边界上，原生应用与窗口操作应始终保持异步。

## 配置

`quickgui.config.ts` 告诉 CLI 要编译和打包哪些内容。

```tsx
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  entry: "src/app.tsx",
  productName: "Notes",
  identifier: "dev.example.notes",
  resources: ["assets"],
});
```

仅发布时使用的选项包括图标、签名、公证、Mac App Store 和更新清单。

## 软件包

| 软件包 | 用途 |
| --- | --- |
| `@quickgui/native` | 应用、窗口、菜单、对话框、通知和原生服务 |
| `@quickgui/solid` | Solid 渲染器、基础组件、复合组件和路由 |
| `@quickgui/solid/swift-ui` | 在 macOS 上从 Solid 托管原生 SwiftUI 控件 |
| `@quickgui/cli` | 创建项目、开发和生产打包 |
