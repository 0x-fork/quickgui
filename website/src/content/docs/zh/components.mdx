QuickGUI 同时提供底层基础组件和具备无障碍行为的复合组件。它们没有预设样式：核心负责行为与语义，所有可见界面由你的应用定义。

## 基础组件

将 [View](/docs/components/view)、[Text](/docs/components/text)、[Button](/docs/components/button)、[Input](/docs/components/input)、[TextArea](/docs/components/text-area)、[Markdown](/docs/components/markdown)、[Image](/docs/components/image)、[Svg](/docs/components/svg)、[Shader](/docs/components/shader)、[VirtualList](/docs/components/virtual-list) 和 [Terminal](/docs/components/terminal) 作为保留式界面的构建单元。

## 复合组件

复合组件会暴露具名部件。根节点协调状态；Rust 核心管理键盘行为、焦点、无障碍关系、挂载策略和精确的交互时限。

```tsx
<Tabs.Root value={tab()} onValueChange={setTab}>
  <Tabs.List>
    <Tabs.Tab value="general"><Text>General</Text></Tabs.Tab>
    <Tabs.Tab value="advanced"><Text>Advanced</Text></Tabs.Tab>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel value="general"><GeneralSettings /></Tabs.Panel>
  <Tabs.Panel value="advanced"><AdvancedSettings /></Tabs.Panel>
</Tabs.Root>
```

## 受控状态

大多数根组件都接受受控值和对应的回调，同时也提供 `default*` 值用于非受控模式。

```tsx
const [open, setOpen] = createSignal(false);

<Dialog.Root open={open()} onOpenChange={setOpen}>
  {/* parts */}
</Dialog.Root>
```

回调报告核心接受的结果。更新 Signal，让受控声明保持同步。

## 设置各部件的样式

通过 `style` 设置每个可见部件的样式。组件状态会投影到保留式节点上，因此悬停、聚焦、选择和无障碍行为都不依赖 Web 运行时。

```tsx
<Switch.Root
  checked={enabled()}
  onCheckedChange={setEnabled}
  style={{ width: 38, height: 22, borderRadius: 11 }}
>
  <Switch.Thumb style={{ width: 18, height: 18, borderRadius: 9 }} />
</Switch.Root>
```
