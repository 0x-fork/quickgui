QuickGUI 将无样式基础组件与具备无障碍行为的复合控件组合在一起。两者都可以通过普通 Go 函数进行组合。

## 基础组件

从 `ui.View`、`ui.Text`、`ui.Button` 和 `ui.Input` 开始。可以直接传入选项与文本。`func() { ... }` 参数将多个子节点分组到当前父节点下。

```go
func ButtonExample(save func()) {
	ui.Button(
		ui.Height(40),
		ui.PaddingLeft(16),
		ui.PaddingRight(16),
		ui.BackgroundColor("#2563eb"),
		ui.Color("white"),
		ui.BorderRadius(8),
		ui.Hover(ui.BackgroundColor("#3b82f6")),
		ui.OnClick(save),
		"Save changes",
	)
}
```

## 复合组件

复合组件族暴露 `ui.Tabs.Root`、`ui.Tabs.List`、`ui.Tabs.Panel` 等部件。核心负责角色、键盘导航、焦点与控件状态。请在根节点的子节点回调中创建部件，以确保上下文已经存在。

```go
func TabsExample() {
	ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() {
			ui.Tabs.List(
				ui.PartProps{},
				func() {
					ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview")
					ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings")
				},
			)
			ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content")
			ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content")
		},
	)
}
```

## 受控状态

受控值使用访问器，其回调保存控件接受的新值。使用默认值可让组件自己管理状态。可选标量使用指针，多选值使用切片。

```go
func CheckboxExample() {
	checked, setChecked := ui.CreateSignal(false)
	ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() { ui.Checkbox.Indicator(ui.PartProps{}, "✓"); ui.Text("Remember me") },
	)
}
```

## 设置各部件的样式

每个部件都可通过 `PartProps.Style` 设置样式。它接受样式记录、记录切片，或返回这些值的访问器。选中状态和主题信号可以更新已有部件，而不必重新创建子节点。

```go
ui.PartProps{
	Style: ui.Style{
		Display:         "flex",
		Height:          32,
		PaddingLeft:     12,
		PaddingRight:    12,
		BackgroundColor: "#2563eb",
		Color:           "white",
		BorderRadius:    8,
	},
}
```
