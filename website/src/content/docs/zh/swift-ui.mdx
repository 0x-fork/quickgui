SwiftUI 桥接层会在 macOS 上由 Solid 渲染的 QuickGUI 窗口中挂载真正的原生 SwiftUI 控件。

## Host

`Host` 是由 `NSHostingView` 支持的单个保留式 QuickGUI 布局叶节点。请把 SwiftUI 桥接组件放在它下面。

```tsx
import { Host, Button, Toggle } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Button label="Continue" onPress={continueFlow} />
</Host>
```

## 原生控件

桥接层导出 `Button`、`Slider`、`Toggle`、`ProgressView`、`Stepper`、`TextField`、`SecureField`、`Picker`、`SegmentedControl`、`DatePicker`、`ColorPicker` 和 `Gauge`。侧边栏中每个控件都有独立的参考页面。

## 受控值

值仍由 Solid 控制。原生更改通过对应的回调传入。

```tsx
<Host matchContents={{ vertical: true }} style={{ width: 340 }}>
  <Slider
    value={volume()}
    min={0}
    max={1}
    step={0.05}
    label="Volume"
    onValueChange={setVolume}
  />
</Host>
```

## 尺寸

默认情况下，QuickGUI 会像其他保留式节点一样布局 `Host`。设置 `matchContents` 可以在两个轴上使用 SwiftUI 的固有尺寸，也可以只选择 `{ horizontal: true }` 或 `{ vertical: true }`。

```tsx
<Host matchContents={{ vertical: true }} style={{ width: 360 }}>
  <Picker selection={theme()} options={themes} onSelectionChange={setTheme} />
</Host>
```

## 平台支持

<Note title="仅限 macOS">
  SwiftUI 托管是 macOS 桥接能力。跨平台界面请使用常规的 `@quickgui/solid` 组件。
</Note>
