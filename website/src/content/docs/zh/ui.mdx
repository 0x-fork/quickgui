Go 组件创建保留式原生节点。信号让每个绑定订阅它所读取的状态。

## 渲染模型

窗口根组件、路由、条件分支和子节点块统一使用 `func()`。组件直接声明零个或多个子节点，无需返回节点，并在挂载时执行一次。块内的 UI 调用会添加到该块的父节点。静态结构使用普通 Go `if` 和 `for`；需要信号改变子节点结构时使用 `ui.Show` 或 `ui.For`。

```go
func ViewExample() {
	ui.View(
		ui.Padding(20),
		ui.Gap(12),
		func() {
			ui.Text("Hello from Go")
			ui.Button(ui.OnClick(func() {}), "Continue")
		},
	)
}
```

## 响应式状态

动态文本或属性应传入访问器。在构造字符串时调用 `count()` 只会捕获当前值；放入 `func() string` 才会保持响应式。事件处理器会自动批处理写入；其他位置可用 `ui.Batch` 合并写入，用 `ui.CreateMemo` 创建派生值。

```go
func TextExample() {
	count, setCount := ui.CreateSignal(0)
	ui.View(func() {
		ui.Text(
			ui.FontSize(20),
			func() string { return fmt.Sprintf("Count: %d", count()) },
		)
		ui.Button(ui.OnClick(func() { setCount(count() + 1) }), "Increment")
	})
}
```

## 窗口生命周期

`WindowOptions.Component` 为每个窗口创建一个响应式根。关闭窗口会释放节点和副作用。使用 `ui.OnCleanup` 注册资源清理；后台任务可使用 `ui.Async`，它会将结果送回 UI goroutine，并在组件释放时取消。

## 当前窗口

在组件挂载时捕获 `native.CurrentWindow()`，之后在回调中使用该窗口。不要从无关的 goroutine 中查询当前窗口。窗口事件与原生请求通过异步回调返回。

```go
func CloseButton() {
	window := native.CurrentWindow()
	ui.Button(ui.OnClick(func() { window.Close() }), "Close window")
}
```

## 路由

使用 `ui.Route` 和 `ui.Layout` 声明路由。布局通过 `ui.Outlet` 挂载匹配的子路由。用 `ui.UseParams` 读取参数，或用 `ui.UseRouter` 导航。

```go
func RouterExample() {
	ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route(
				"/",
				func() {
					ui.Link(
						ui.LinkProps{Href: "/settings"},
						"Settings",
					)
				},
			),
			ui.Route(
				"/settings",
				func() { ui.Text("Settings") },
			),
		},
		Fallback: func() { ui.Text("Page not found") },
	})
}
```
