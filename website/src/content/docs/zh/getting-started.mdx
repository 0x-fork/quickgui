QuickGUI 应用是普通的 Go 程序。用 Go 编写组件和细粒度响应式状态，并以 `CGO_ENABLED=0` 构建。purego 在同一进程中加载预编译原生库；Bun 仅运行开发与打包 CLI。

## 系统要求

- macOS 14 或更新版本
- Go 1.23 或更新版本
- Bun 1.3 或更新版本
- Xcode Command Line Tools（`xcode-select --install`）

当前打包的 UI 应用面向 macOS。普通应用构建直接使用预编译原生宿主。

## 创建项目

创建项目并启动原生开发应用。

```bash
bunx @quickgui/cli init my-app
cd my-app
bun run dev
```

## 第一个窗口

生成的 `main.go` 从 `native` 导入窗口 API，从 `ui` 导入组件。将组件函数直接传给 `WindowOptions.Component`。调用一次 `native.Run` 启动应用事件循环。

```go
package main

import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"log"
)

func Counter() {
	count, setCount := ui.CreateSignal(0)
	ui.View(
		func() {
			ui.Text("Count: ", count)
			ui.Button(
				"Increment",
				ui.Style{Padding: 12, BorderRadius: 8, BackgroundColor: "#2563eb", Color: "white"},
				ui.OnClick(func() { setCount(count() + 1) }),
			)
		},
		ui.Style{
			Display:        "flex",
			FlexDirection:  "column",
			Width:          "100%",
			Height:         "100%",
			AlignItems:     "center",
			JustifyContent: "center",
			Gap:            12,
		},
	)
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

## 运行与构建

监视器会重新构建 Go 源码并重启开发应用。格式化命令为较长的组件调用添加一致的换行，输出仍是标准 Go 语法。生产构建输出到 `dist/darwin-*`。

```bash
bun run dev
bun run fmt
bun run build
```
