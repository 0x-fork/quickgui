QuickGUI 使用 scriptc 将 TypeScript 和 TSX 编译为原生代码。TypeScript 7 负责转换 JSX，Rust 核心负责布局、渲染、输入和平台主线程。Bun 仅用于开发工具。

## 系统要求

- macOS 14 或更高版本
- [Bun](https://bun.sh/) 1.3 或更高版本
- Node.js 24+ (scriptc compiler)
- Xcode Command Line Tools

<Note>
  QuickGUI UI 托管层目前面向 macOS。Rust 框架也能在 Windows 和 Linux 上编译，但这两个平台尚不是 QuickGUI UI 应用的受支持路径。
</Note>

## 创建项目

创建一个项目并启动原生开发应用：

```bash
bunx @quickgui/cli init my-app
cd my-app
bun run dev
```

开发命令会监听源代码。下一次构建打开首个原生窗口后，它才会替换当前运行的应用。

## 第一个窗口

应用和窗口 API 来自 `@quickgui/native`，QuickGUI UI 组件与渲染器来自 `@quickgui/ui`。

```tsx
import { app, Window } from "@quickgui/native";
import { Button } from "@quickgui/ui";
import { Text, View, createRenderer } from "@quickgui/ui";
import { createSignal } from "@quickgui/ui";

function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <View style={{ flex: 1, alignItems: "center", justifyContent: "center", gap: 12 }}>
      <Text>Count: {count()}</Text>
      <Button onClick={() => setCount(count() + 1)}>
        <Text>Increment</Text>
      </Button>
    </View>
  );
}

function openMainWindow() {
  new Window({
    title: "My App",
    width: 720,
    height: 480,
    renderer: createRenderer(() => <Counter />),
  });
}

app.onReopen( ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openMainWindow();
});

await app.whenReady();
openMainWindow();
```

创建第一个窗口前，务必等待 `app.whenReady()` 完成。每个 `Window` 都拥有自己的渲染器根节点，并在窗口关闭时将其释放。

## 运行与构建

```bash
bun run dev
bun run build
```

在 macOS 上，生产构建会写入 `dist/darwin-*`。准备发布时，你可以再配置签名和公证。
