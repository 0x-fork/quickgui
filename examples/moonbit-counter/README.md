# MoonBit counter

The native MoonBit frontend, with child lists, fluent properties and handlers, reactive text, conditional children, hover styling, and multiple windows.

Install MoonBit, a native C compiler, and Bun. From the repository root:

```sh
bun install
bun packages/cli/src/cli.ts dev --project examples/moonbit-counter
```

The root `moon.work` resolves the SDK locally. See the [MoonBit guide](../../moonbit/README.md) for application setup, reactivity, extension loading, and validation.
