# {{README_TITLE}}

A native QuickGUI application written in Rust.

```console
bun install
bun run dev
```

`bun run dev` compiles the crate, launches the app, and rebuilds on source changes. `bun run build` produces a distributable application.

Use Rust 1.90 or later, Bun 1.4 or later, and Xcode Command Line Tools on macOS.

Configuration can use `quickgui.toml` or `quickgui.config.ts`. Set `language = "rust"`.
